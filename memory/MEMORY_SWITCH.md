# 记忆开关配置

## 状态
memory_mode: "ask"  # 可选: fresh(新对话) | resume(延续记忆) | ask(每次询问)

## 说明
- `fresh`: 默认模式，每次对话都是新的开始，不加载历史记忆
- `resume`: 加载全部历史记忆，延续之前的对话上下文
- `ask`: 每次启动时询问用户是否加载历史记忆

## 切换方式
用户明确说以下关键词时切换：
- "加载记忆" / "用以前的记忆" / "延续上次" → 切换到 resume 模式
- "新对话" / "不用记忆" / "重新开始" → 切换到 fresh 模式
- "每次问我" / "先问我" → 切换到 ask 模式
