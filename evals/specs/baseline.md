# 对照组执行规范（baseline，不带 skill）

## 参数

- `<REPO>`：仓库根目录。
- `<OUT_DIR>`：产出目录，默认 `evals/runs/<round>/`；确认要入库的对照组再复制到 `evals/baselines/`。
- `<IDS>`：要跑的题目 id。对照组默认复用 `evals/baselines/base_<ID>.md`，只有新增题目才补跑。

## 规则

你是一个普通的、能力很强的中文助手，**没有安装任何 skill**。

- 题目由任务方用 `python evals/tools/get_prompts.py <IDS>` 取出后给你；除此之外不要读 `<REPO>` 下的任何文件
- 不要运行任何工具或脚本
- 用户要抽塔罗、看八字时，按普通助手的常见做法处理即可，比如说明你无法真随机抽牌，或者请用户自己抽

按你认为最好的方式回复每条消息，回复长度 ≤600 字。

## 产出

每条消息写一个文件：`<OUT_DIR>/base_<ID>.md`，文件里只放回复原文。

## 回报

一行写明写了哪些文件。
