# GLOSSARY — 共享术语（各书完整术语表见 `books/<key>/GLOSSARY.md`）

| 术语 | 英文 | 白话 | 出处 |
|------|------|------|------|
| 依恋倾向 | attachment style | 在亲密关系里，对"靠近"和"被抛下"的习惯性反应：偏安全、偏焦虑或偏回避 | Attached |
| 焦虑-回避陷阱 | anxious-avoidant trap | 一方越要靠近，另一方越要空间，双方互相加强 | Attached |
| 恶魔对话 | Demon Dialogues | 伴侣间反复出现的三种吵法：找坏人、抗议波尔卡、冻结逃跑 | Hold Me Tight |
| A.R.E. | Accessibility / Responsiveness / Engagement | 可及、回应、投入：安全联结的三个要素 | Hold Me Tight |
| 雷区 | raw spot | 一碰就失衡的旧伤，表层是愤怒或麻木，底层是恐惧、悲伤、羞耻 | Hold Me Tight |
| 固定型 / 成长型思维 | fixed / growth mindset | 把能力看成定数（要证明），还是看成可以发展（要学习） | Mindset |
| 四定律 | Four Laws of Behavior Change | 显而易见、有吸引力、简便易行、令人愉悦；反过来用于戒掉坏习惯 | Atomic Habits |
| 两分钟规则 | Two-Minute Rule | 新习惯的入口版本缩到两分钟内能做完 | Atomic Habits |
| 深度工作 / 浅层工作 | deep / shallow work | 需要高度专注、难以复制的工作 / 不费脑、容易替代的杂务 | Deep Work |
| 停工仪式 | shutdown ritual | 下班前清点未完成事项、排好明天，用一句口令收工 | Deep Work |
| 基率 / 外部视角 | base rate / outside view | 同类事件通常发生的比例，用它做估计的起点 | Superforecasting |
| Brier 分 | Brier score | 概率预测的记分方法，越低越准 | Superforecasting |
| 尊贵 | essential dignity | 古典占星中行星所处的星座是否是它的"主场"（庙、旺、三分性） | Tetrabiblos |
| 福点 | Part of Fortune | 由日、月、上升推算出的点，古典用来看财富来源风格 | Tetrabiblos |
| 倾向 vs 必然 | inclination vs necessity | 托勒密自己的立场：天象只造成倾向，人可以预先应对 | Tetrabiblos 卷一 |
