# GLOSSARY — 《深度工作》术语中英对照

| 中文 | English | 位置 | 白话解释 |
|---|---|---|---|
| 深度工作 | Deep Work | 引言 PAGE 5 | 在不受打扰的专注状态下做、把脑力推到极限、能产生新价值且别人难以复制的工作。 |
| 浅层工作 | Shallow Work | 引言 PAGE 7；规则4 PAGE 134 | 不太费脑、偏事务性、常在分心状态下做、谁都能接手的工作，比如回邮件、排会议。 |
| 深度工作假说 | The Deep Work Hypothesis | 引言 PAGE 11 | 深度工作能力越来越少见又越来越值钱，所以练成它的人会占优势。 |
| 大重构 | Great Restructuring | 第1章 PAGE 16 | 两位 MIT 经济学家的说法：数字技术正在把劳动力市场切成赢家和输家两头。 |
| 超级明星效应 | Superstar effect / winner-take-all | 第1章 PAGE 17–18 | 市场能接触到所有人时，最好的那一个会拿走大部分份额。 |
| 刻意练习 | Deliberate Practice | 第1章 PAGE 22–23 | 专注于一项具体技能并根据反馈不断修正的练习方式，不能边分心边做。 |
| 注意力残留 | Attention Residue | 第1章 PAGE 26–27 | 从任务 A 切到任务 B 时，脑子还有一部分卡在 A 上，拖累 B 的表现。 |
| 高质量产出公式 | High-Quality Work Produced = Time Spent × Intensity of Focus | 第1章 PAGE 26 | 产出取决于花的时间乘以专注强度，强度高可以少花时间。 |
| 特异性规则 | rule of specificity（作者对 Dorsey 反例的处理） | 第1章 PAGE 29 | 高管、部分销售等角色靠随时在线创造价值，他们的做法不能外推到别的岗位。 |
| 度量黑洞 | Metric Black Hole | 第2章 PAGE 34 | 分心的成本和深度的收益都很难算清，于是没人去管。 |
| 最小阻力原则 | Principle of Least Resistance | 第2章 PAGE 36 | 看不清哪种做法对结果更好时，人们会选当下最省事的做法。 |
| 忙碌即生产力代理 | Busyness as Proxy for Productivity | 第2章 PAGE 39 | 不知道怎样证明自己有价值时，就靠"显得很忙"来证明。 |
| 深度哲学 | Depth Philosophy | 规则1 PAGE 60 | 你把深度工作放进日程的总体方式，选错了习惯就立不住。 |
| 禁欲式 | Monastic Philosophy | 规则1 PAGE 62 | 几乎砍掉所有浅层义务，只做一件核心的事；适合产出清晰、个人化的人。 |
| 双峰式 | Bimodal Philosophy | 规则1 PAGE 64 | 把时间切成两块：一段时间（至少一整天）完全闭关，其余时间照常开放。 |
| 节奏式 | Rhythmic Philosophy | 规则1 PAGE 66 | 每天固定时段做深度工作，让它变成不需要再做决定的惯例。 |
| 新闻记者式 | Journalistic Philosophy | 规则1 PAGE 69 | 哪里有空当就随时切进深度模式；需要熟练和自信，新手不适用。 |
| 链条法 | chain method / Don't break the chain | 规则1 PAGE 66 | Seinfeld 的办法：每天做完就在日历上打个红叉，别让红叉链断掉。 |
| 仪式化 | Ritualize | 规则1 PAGE 70–72 | 给深度工作定好在哪、多久、怎么做、靠什么支撑，减少每次开工时的内耗。 |
| 宏大姿态 | Grand Gesture | 规则1 PAGE 73 | 花钱或大幅换环境来专门做一件事，借此抬高它在心里的分量。 |
| 中心-辐条 | Hub-and-Spoke | 规则1 PAGE 78 | 在公共区域碰撞想法，回到独立空间深入加工，两件事分开做。 |
| 白板效应 | Whiteboard Effect | 规则1 PAGE 79 | 和搭档在同一块白板前轮流深挖，有时比一个人想得更深。 |
| 执行的4个原则 | 4 Disciplines of Execution (4DX) | 规则1 PAGE 80–84 | 聚焦极其重要的目标、盯领先指标、做醒目的记分板、定期问责。 |
| 领先指标 / 滞后指标 | Lead Measures / Lag Measures | 规则1 PAGE 81 | 滞后指标是最终结果（论文数），领先指标是你今天就能推动的行为（深度小时数）。 |
| 停工仪式 | Shutdown Ritual | 规则1 PAGE 89–90 | 每天收工前按固定步骤把所有未完成事项过一遍、定好明天计划，然后说一句"停工完成"。 |
| 蔡格尼克效应 | Zeigarnik Effect | 规则1 PAGE 90 | 没做完的事会一直占着注意力（该效应的稳健性近年存疑）。 |
| 注意力恢复理论 | Attention Restoration Theory (ART) | 规则1 PAGE 87 | 让"刻意集中注意力"的能力休息（比如在自然中散步），它能恢复。 |
| 互联网安息日 / 数字排毒 | Internet Sabbath / Digital Detox | 规则2 PAGE 95 | 每周拿出一天断网；作者认为光这样治不好分心的脑子。 |
| 预约上网时段 | scheduling Internet blocks（"Take breaks from focus"） | 规则2 PAGE 95–96 | 事先定好什么时候可以上网，其余时间一律离线，把抵抗分心当作训练。 |
| 罗斯福冲刺 | Roosevelt Dash | 规则2 PAGE 99–100 | 给一项深度任务定一个远短于平时的截止时间，逼自己全力专注。 |
| 生产性冥想 | Productive Meditation | 规则2 PAGE 101 | 走路、跑步、洗澡这类身体忙但脑子闲的时候，把注意力锁定在一个工作难题上。 |
| 循环 | Looping | 规则2 PAGE 102 | 思考时反复嚼已知内容、不往下一步推进的偷懒方式。 |
| 任何好处思维 | Any-Benefit Approach | 规则3 PAGE 110 | 只要能想到一点好处就使用某个工具，完全不算它的代价。 |
| 手艺人工具选择法 | Craftsman Approach to Tool Selection | 规则3 PAGE 112 | 先找出决定成功和幸福的核心因素，只有当工具对这些因素的好处明显大于坏处时才用。 |
| 关键少数法则 | Law of the Vital Few（80/20 / Pareto） | 规则3 PAGE 118 | 大部分结果来自少数原因，所以只看最重要的两三项活动。 |
| 日中之日 | "day within a day"（Arnold Bennett） | 规则3 PAGE 123 | 下班后的十几个小时也是完整的一天，值得事先规划怎么过。 |
| 溢出条件块 | Overflow Conditional Block | 规则4 PAGE 132 | 不确定一件事要多久时，在后面加一个备用块：没做完就继续做，做完了就做预先指定的杂事。 |
| 应届生培训月数 | "How long would it take to train a smart recent college graduate…" | 规则4 PAGE 135 | 用"培训一个聪明应届生接手要几个月"来给任务的深浅打分。 |
| 浅层工作预算 | Shallow Work Budget | 规则4 PAGE 136 | 和老板（或自己）定下浅层工作最多占多少比例，多数岗位约 30%–50%。 |
| 固定日程生产力 | Fixed-Schedule Productivity | 规则4 PAGE 139 | 先定死不工作的时间点，再倒推需要哪些规则和取舍来做到。 |
| 发件人过滤 | Sender Filter | 规则4 PAGE 143 | 公开说明什么样的来信才会回复，让对方先自己筛一遍。 |
| 流程式回复 | Process-Centric Approach to E-mail | 规则4 PAGE 146 | 回邮件时一次把整个流程、当前步骤和下一步写清楚，减少来回。 |
