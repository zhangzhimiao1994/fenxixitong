# GLOSSARY — Hold Me Tight 术语中英对照

| 中文 | English | 位置 | 白话解释 |
|------|---------|------|---------|
| 情绪取向治疗 | Emotionally Focused Therapy (EFT) | PAGE 9、36 | 以依恋为底层逻辑、通过改变关键情绪时刻来修复关系的伴侣疗法。 |
| 依恋纽带 | attachment bond | PAGE 10、37 | 成年人对伴侣的情感依赖，和孩子依赖父母是同一种需要。 |
| 原始恐慌 | primal panic | PAGE 27、197 | 感到和最重要的人断了联系时，身体里自动拉响的那种慌。 |
| 恶魔对话 | Demon Dialogues | PAGE 27、51、195 | 三种会自我强化、越吵越远的互动循环。 |
| 找坏人 | Find the Bad Guy | PAGE 52–55 | 双方互相指责，都想证明对方才是问题。 |
| 抗议波尔卡 | Protest Polka (Demand-Withdraw) | PAGE 56–67 | 一方追着要回应、批评；另一方防守、退开；越追越退，越退越追。 |
| 冻结逃跑 | Freeze and Flee (Withdraw-Withdraw) | PAGE 67–71 | 追的一方也放弃了，两人都把需要冻起来，表面客气，实际最危险。 |
| 内容管道 | Content Tube | PAGE 54 | 吵架时逐条翻旧账、争“到底谁先”的细节漩涡。 |
| 依恋抗议 | attachment protest | PAGE 194–195 | 感到被疏远时的第一反应，常以愤怒和焦虑的形式出现，目的是让对方回应。 |
| 雷区 | raw spot | PAGE 73 | 因为依恋需要曾被反复忽视而形成的过敏点，一碰就失衡。 |
| 两个 D | 2 Ds: deprived / deserted | PAGE 73、198 | 两种最普遍的雷区：感到被剥夺（得不到关心）和被抛弃（被拒绝、不被看重）。 |
| 依恋线索 | attachment cue | PAGE 78、194 | 一个眼神、一种语气、一个转身——任何让依恋系统开机的信号。 |
| 把手 | handles | PAGE 108、196 | 能打开内心感受的词或画面，比如“碎掉”“被丢下”。 |
| 下行电梯 | the down elevator | PAGE 85、97 | 从表层情绪一层层往下问到底层情绪的过程。 |
| 重温低谷 | Revisiting a Rocky Moment | PAGE 90–103 | 事后一起回放一次不愉快的互动，看清步子与感受，补上当时没说的话。 |
| 降级 | de-escalation | PAGE 92、95 | 让冲突降温、先恢复基本安全感的一组步骤。 |
| 抱紧我对话 | Hold Me Tight conversation | PAGE 104–120 | 说出“我最怕什么”和“我最需要你什么”的关键对话。 |
| 可怕的如果 | Terrible Ifs | PAGE 109、112 | 把最怕发生的后果一条条说出来，用来找到核心恐惧。 |
| 可及 / 回应 / 投入 | A.R.E.: Accessibility / Responsiveness / Engagement | PAGE 40、194 | 我能找到你吗；你会在情绪上回应我吗；你会看重我、留在我身边吗。 |
| 安全对话 | secure talk | PAGE 115 | 不翻脸、不讲道理躲开，直接、连贯地说出需要和恐惧。 |
| 依恋伤害 | attachment injury | PAGE 122、194 | 在最需要对方的时刻被抛下或被背叛，不处理就会长期侵蚀信任。 |
| 再也不了时刻 | Never Again moment | PAGE 122 | 受伤方暗下决心“再也不向你求助”的那一刻。 |
| 获得性安全 | earned security | PAGE 77、195–196 | 即使早年依恋不好，有回应的伴侣也能让人后来变得安全。 |
| 有效依赖 | effective dependency | PAGE 196 | 能察觉自己需要别人、并成功开口求助的健康状态。 |
| 接触安慰 | contact comfort | PAGE 84、195 | 身体接触带来的安抚，Harlow 认为是灵长类的基本需要。 |
| 同步 | synchrony | PAGE 140、198 | 彼此情绪和身体节奏对上的状态。 |
