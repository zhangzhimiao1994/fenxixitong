# GLOSSARY —《关系依恋》(Attached)

| 中文 | English | 白话解释 | 位置 |
|---|---|---|---|
| 依恋风格 | attachment style | 一个人在亲密关系里怎么看待和回应"靠近"的习惯倾向 | PAGE 15 |
| 依恋系统 | attachment system | 大脑里负责盯着"重要的人还在不在、靠不靠得住"的警报机制 | PAGE 18、79 |
| 安全型 | secure | 对亲密自在，也不太担心被抛弃 | PAGE 15、45 |
| 焦虑型 | anxious | 很想亲近，但常担心对方不够爱自己 | PAGE 15、45 |
| 回避型 | avoidant | 把亲密当成失去独立，总想保持距离 | PAGE 15、45 |
| 焦虑-回避混合（恐惧型） | anxious and avoidant combination / disorganized | 既怕太近又怕被抛弃，书里说占少数，基本没展开 | PAGE 15、47–48 |
| 关系焦虑维度 | anxiety (dimension) | 对"对方爱不爱我、会不会走"有多操心 | PAGE 46 |
| 亲密回避维度 | avoidance (dimension) | 对靠近有多不自在 | PAGE 46 |
| 稳定但可塑 | stable but plastic | 大多数人长期不变，但能变，也会变 | PAGE 39、148 |
| 抗议行为 | protest behavior | 为了让对方注意到自己而做的举动：狂打电话、冷战、记分、威胁分手、让对方吃醋 | PAGE 18、86–87 |
| 激活策略 | activating strategies | 让自己满脑子都是对方、非要重新联系上的念头 | PAGE 80–81 |
| 去激活策略 | deactivating strategies | 压下亲近需要的做法：挑小毛病、不说爱、亲近后就消失 | PAGE 112–113 |
| 危险区 / 舒适区 | danger zone / comfort zone | 依恋系统长期被拉警报 vs 被安抚后能平静 | PAGE 84 |
| 安全基地 | secure base | 让人敢出去闯的那个"后方" | PAGE 32–33 |
| 避风港 | safe haven | 遇事能回去找安慰的人 | PAGE 34 |
| 依赖悖论 | dependency paradox | 越能放心依靠一个人，越敢独立做事 | PAGE 25、31 |
| 共依存 | codependency | 原本用于成瘾者家属的概念，作者批评它被滥用到所有关系 | PAGE 28–29 |
| 陌生情境测验 | strange situation test | 观察婴儿与母亲分离、重聚反应的经典实验 | PAGE 32、48 |
| 亲密关系经历量表 | ECR / ECR-R (Experiences in Close Relationships) | 研究里测焦虑、回避两个维度的问卷；书中用的是改编版 | PAGE 39、79 |
| 工作模型 | working model | 你对恋爱"会怎样、该怎样"的一整套默认信念 | PAGE 150 |
| 关系清单 | relationship inventory | 按七栏回顾历任关系、找出触发点和替代反应的练习 | PAGE 150–152 |
| 依恋指定人 | attachment-designated person (ADP) | 懂你模式、能在你上头时提醒你的朋友/家人/咨询师 | PAGE 158 |
| 安全启动 | security priming | 回想安全的人和经历，让自己暂时更安全 | PAGE 148 |
| 整合安全榜样 | integrated secure role model | 把身边几位安全型的做法拼成一个可以模仿的样子 | PAGE 149–150 |
| 冒烟的枪 | smoking gun | 强烈提示对方回避的信号，核心是"你的感受对他不重要" | PAGE 97–98 |
| 丰富心态 | abundance philosophy | 相信合适的人很多，同时多认识几个人，别过早押注一个 | PAGE 100–101 |
| 焦虑-回避陷阱 | anxious-avoidant trap | 一方越追、另一方越躲，互相加剧 | PAGE 142 |
| 过山车效应 | roller-coaster effect | 偶尔的亲近带来"上头"，紧接着又被推开 | PAGE 144 |
| 情绪跷跷板 | emotional counterbalancing | 回避者的"强大"建立在对方显得"需要"之上 | PAGE 144 |
| 稳定的不稳定 | stable instability | 能处很久，但一直不踏实 | PAGE 144 |
| 内圈 | inner circle | 最亲近的那一圈人：配偶、孩子、父母 | PAGE 183 |
| 被当敌人 | becoming "the enemy" | 越亲近反而被对待得越差 | PAGE 183–184 |
| 被当王室 | treated like royalty | 亲近后被优先、被保护、被信任 | PAGE 184 |
| 反弹效应 | rebound effect | 分开后被好回忆淹没，忍不住回去 | PAGE 186 |
| 幻影前任 | phantom ex | 回避者在分开后才美化的前任，用来和现任比较 | PAGE 118 |
| "真命天子"幻想 | "the one" | 总觉得完美的人在后面，从而不投入眼前的人 | PAGE 118–119 |
| 缓冲效应 | buffering effect | 一方安全，就能把整对伴侣的功能拉上来 | PAGE 124 |
| 共情准确性 | empathic accuracy | 猜中伴侣真实想法和感受的能力 | PAGE 116 |
| 有效沟通 | effective communication | 直接、具体、不指责、不道歉地说出自己的需要 | PAGE 195、206 |
| "米兰达式"声明 | Mirandizing | 提前声明"我没准备好承诺"，好像就不用为对方负责了 | PAGE 207–208 |
| 面包黄油型冲突 | bread-and-butter conflict | 吃什么、看哪个台这类日常分歧，不涉及要多亲近 | PAGE 213–214 |
| 亲密中心型冲突 | intimacy-centered conflict | 表面吵小事，实际在争要多近 | PAGE 213 |
| 催产素 | oxytocin | 与亲密、信任有关的激素；书中关于它的建议已拒用 | PAGE 220 |
| 后天获得的安全感 | earned security | 原本不安全、后来通过关系或治疗变安全（研究术语，书中以"可塑"表述） | PAGE 130（概念对应） |
