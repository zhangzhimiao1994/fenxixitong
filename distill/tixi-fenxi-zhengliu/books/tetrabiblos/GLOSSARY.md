# GLOSSARY —《四书》Tetrabiblos 术语中英对照

"白话"一列是给用户看的说法；输出时古典术语全文最多 2 个，首次出现括注白话（遵守 `fortune` 第四节）。

| 英文（Ashmand 译名） | 中文 | 位置（PAGE） | 白话解释 |
|---|---|---|---|
| Ambient | 周遭环境 / 天地之气 | I.2, 30 | 托勒密设想的、天体通过空气与以太传给地上万物的"影响场" |
| Prognostication / prescience | 预知 | I.1-3, 29-41 | 依据天象推测倾向；作者自己说只能"在一定程度上"做到 |
| Concurrent causes | 同时原因 | I.2, 34-35 | 天象之外同样起作用的因素：物种、出生地、养育、习俗 |
| Opposing influence / antidote | 对冲 / 解药 | I.3, 38-40 | 能削弱或阻止某一倾向的其他因素，包括人为的准备 |
| Heat / Cold / Moisture / Dryness | 热 / 冷 / 湿 / 干 | I.4-5, 41-42 | 古希腊"四性"；热湿算滋养，冷干算消耗 |
| Benefic | 吉星（木、金、月） | I.5, 42 | 输出改称"滋养型行星" |
| Malefic | 凶星（土、火） | I.5, 42 | 输出改称"张力型行星"：土星偏收缩、迟滞；火星偏冲动、切割 |
| Common | 中性（日、水） | I.5, 42 | 随与之联结的行星而变 |
| Diurnal / Nocturnal (sect) | 昼 / 夜（派别） | I.7, 43 | 白天出生与夜里出生；土星在昼盘、火星在夜盘被认为"被调和" |
| Matutine / Vespertine | 晨出 / 昏入 | I.6, 43；I.8, 44 | 行星在太阳之前升起 / 之后落下；前者通常更"有力"、更"早" |
| Oriental / Occidental | 东方 / 西方 | I.6, 43；I.27, 67 | 相对太阳或地平线偏东 / 偏西；东方 = 发力早而强 |
| Station / Retrograde | 停滞 / 逆行 | I.8, 44；I.27, 67 | 视运动停下或倒退；托勒密认为逆行、迟缓 = 力量减弱 |
| Angles (ascendant, mid-heaven, west, lower heaven) | 四角（上升、中天、下降、天底） | I.13, 49-50 | 盘中最"显眼"的四个点，落在附近的行星最强 |
| Succedent / Cadent | 续宫 / 果宫 | III.4, 105 | 角宫之后的宫 / 再之后的宫；续宫次强，果宫弱 |
| Tropical / Equinoctial / Fixed / Bicorporeal signs | 回归（至点）/ 二分 / 固定 / 双体星座 | I.14, 51 | 约等于现代"启动 / 固定 / 变动"：开局、巩固、过渡 |
| Configuration / aspect | 相位 | I.16, 52-54 | 两点相隔 60°/90°/120°/180° 的特定关系 |
| Trine / Sextile | 三分 / 六分 | I.16, 53-54 | 和谐相位（同性别星座之间） |
| Quartile / Opposition | 四分 / 对冲 | I.16, 54 | 不和谐相位（异性别星座之间）；输出改称"张力相位" |
| Inconjunct | 不合 | I.19, 55 | 相隔 30° 或 150°、彼此"背过身"的星座，没有亲和关系 |
| Houses (of the planets) | 庙（入庙） | I.20, 56-57 | 行星"自己家"的星座，如太阳-狮子、月亮-巨蟹 |
| Triplicity | 三分性 | I.21, 57-58 | 同元素三个星座组成的三角，各有昼主、夜主 |
| Exaltation / Fall | 旺 / 落 | I.22, 59 | 行星特别得力 / 特别失力的星座 |
| Terms | 界 | I.23-24, 60-64 | 每个星座再分 5 段，分给五颗行星；书中给了埃及、迦勒底、托勒密三套 |
| Face | 面（托勒密义） | I.26, 65 | 行星与日月的角距等于其庙与日月庙的角距时；与后世"十度面"不同 |
| Chariot / throne | 战车 / 宝座 | I.26, 65 | 一颗行星在所处星座同时拥有两种以上尊贵 = 特别得力 |
| Rejoice | 喜乐 | I.26, 65-66 | 与同类条件的星有联系时 |
| Application / Separation | 入相 / 离相 | I.27, 66 | 两星正在靠近 / 正在离开某个相位 |
| Prerogatives (five) | 五种权利 | III.3, 102；III.4, 104 | 庙、三分性、旺、界、相位（phase/configuration）——用来"投票"选主宰星 |
| Ruler / lord (of a place) | 主宰星 | III.4, 104-105 | 对某一主题位置拥有最多权利的行星 |
| Doryphory | 护卫星 | III.5, 106；IV.3, 146 | 紧跟日月、像卫队一样的行星 |
| Part of Fortune | 福点 | III.13, 117；IV.2, 145 | 上升 + 月亮 − 太阳（托勒密昼夜同一公式）；被称为"月亮的上升点"，用于看财富风格 |
| In glory / inglorious | 得位 / 失位 | III.18, 137-141 | 主宰星宇宙状态与盘中位置都好 / 都差；同一特质的"高版本 / 低版本" |
| Elevation (in elevation above) | 压制（居上） | III.5, 107 注；III.18, 137 | 一颗行星位置更高（更近天顶）而压过另一颗 |
| Prorogator (hyleg) / Anaretic | 生命主 / 杀星 | III.12-13, 116-119 | 寿命推算术语——**本包拒绝使用** |
| Profection | 年推 | IV.10, 168-169 | 每年推进一个星座看"年主"——**本包拒绝使用** |
| Genethlialogy | 本命学 | III.1, 99 | 关于个人出生盘的学问（对比卷二的世运学） |
| Animodar | 出生度数校准法 | III.3, 102-103 注 | 用前一次新/满月校正上升度数——**本包拒绝使用** |
