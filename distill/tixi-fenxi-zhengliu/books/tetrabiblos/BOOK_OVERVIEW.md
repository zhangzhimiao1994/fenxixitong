# BOOK_OVERVIEW —《四书》(Tetrabiblos) Claudius Ptolemy

- 版本：J. M. Ashmand 英译本（1822 初版，Foulsham 新版重印；archive.org `ptolemystetrabib00ptol`），据 **Proclus 希腊文意译本**（Elzevir 1635 版）译出，参校 Camerarius 1535、Melanchthon 1553、Junctinus 1581 及两种拉丁译本（译者序，PAGE 21-22）。
- 页码约定：本蒸馏包所有 `PAGE n` 均为 PDF 页（= 印刷页 + 28）。正文 PAGE 29 起，卷四止于约 PAGE 170，其后为附录（《至大论》摘录、《百言集》Centiloquy、星盘说明）。
- 维度：象征维度（fortune），作为**古典本命结构解读框架**，与现代行运的 `astrology-transit` 区分。

## 二、核心论点（作者主张，firsthand）

1. **占星预测"有限可能"**：天体通过"周遭环境"(the Ambient)影响地上万物，季节、潮汐即可观察的例子；推到个人"倾向与体质"也说得通（I.2, PAGE 30-33）。
2. **误差是结构性的**：(a) 物质的性质只能靠推论而非证明；(b) 天象组合永不精确重复，历史经验不能原样套用；(c) 种子（物种）、出生地、养育、习俗是"不容忽视的同时原因"（I.2, PAGE 33-35）。
3. **不是宿命**：并非一切都出自"不可解的上天谕令"；强因而无对冲 → 发生；弱因遇到对冲 → 被阻止或削弱。占星师的断言应与医生说"伤口会恶化"同一级别——是"若不处理"的条件句（I.3, PAGE 37-39）。
4. **预知的用处是准备**：事前知道，心能保持平稳；像夏天预备凉物；埃及人把占星与医术结合，正说明他们不认为一切不可改变（I.3, PAGE 37-41）。
5. **行星按"冷热干湿"四性构成吉凶**：热、湿 = 滋养；冷、干 = 消耗。木、金、月为吉，土、火为凶，日、水随所联结者（I.4-5, PAGE 41-42）。
6. **尊贵体系是"亲和关系"的多种方式**：庙、三分性、旺、界、相位（"五种权利"，III.3/III.4 反复使用）；同时拥有两种以上 = "战车/宝座"（I.20-26）。
7. **强弱 = 宇宙状态 + 盘中位置**：东方、快速、顺行、在自己的位置 = 宇宙意义上强；在角宫/续宫（尤其上升、中天）= 盘中强；西方、迟缓、逆行、落陷/果宫 = 弱（I.27, PAGE 67；III.4, PAGE 105）。
8. **本命判断通用五步**：找主题对应的位置 → 按五种权利选主宰星 → 由主宰星与星座的性质定"性质" → 由其强弱定"程度" → 由东出/西入、角宫/续宫定"早晚"（III.4, PAGE 104-105）。
9. **心性由水星（理性）与月亮（感性）及其主宰星决定**，每颗行星的特质都有"得位"与"失位"两个版本（III.18, PAGE 135-141）。
10. **时间上的混合**：同一时期可同时有失有得，"人性一般不处于极好或极坏的极端，而是适度的交替"（IV.10, PAGE 167-168）。

## 三、写作背景

- 托勒密（约 100-170 CE），亚历山大里亚；先写《至大论》(Syntaxis/Almagest，天体运动的数学天文学），本书是"第二种"——天象对地上事物的影响（I.1, PAGE 29）。致 Syrus。
- 本书立场是**亚里士多德式自然哲学**：把占星说成物理因果（四性、以太），刻意排斥"签与数"之类的占卜（III.4, PAGE 104）和"无自然依据"的细分（I.25, PAGE 64-65）。这是它与后世占星最大的风格差异：作者自认为在做"自然科学"。
- 译本层：Ashmand 用的是 5 世纪 Proclus 的**意译本**，非托勒密原文；Robbins（Loeb, 1940）据原文校订本另译（reliable-secondary）。因此本包所有"托勒密说"实为"Ashmand 所译 Proclus 意译的托勒密"，细节措辞不应当作原文定论。
- 注释层：大量脚注来自 Whalley（1701 英译）、Placidus、Cardan 等后世占星家，**不是托勒密本人**；本包引用时已区分（例：Hemmings "时间孪生"轶事是 Ashmand 的脚注，PAGE 34-35）。

## 四、外部批评与证据强度

| 主张 | 证据强度 | 标注 |
|---|---|---|
| 太阳主季节、月亮影响潮汐 | 有天文/物理支持 | reliable-secondary |
| 行星"冷热干湿"、吉凶性 | 源自古希腊四性说，无现代物理基础 | firsthand（作者主张）/ inference |
| 本命盘能预示性格、职业、婚姻 | **不被现代科学支持**：Carlson (1985, *Nature*) 双盲实验，占星师无法把星盘与人格测验结果匹配到高于随机；Dean & Kelly (2003, *J. Consciousness Studies*) 对两千余名出生时间相近者（"时间孪生"）的追踪未见相似性 | reliable-secondary |
| 读盘"很准"的主观体验 | 巴纳姆/福勒效应 (Forer, 1949)、确认偏误可解释 | reliable-secondary |
| 星座随岁差"错位" | 托勒密把星座定义为从春分点起算的 30° 段（回归黄道，I.25, PAGE 65；Ashmand 注 PAGE 49），故对回归黄道这一批评不成立；但"星座 = 星群"的通俗理解确已错位 | firsthand + reliable-secondary |
| 托勒密承认误差、反宿命 | 文本内证明确（I.2-3） | firsthand |
| 《百言集》为托勒密所作 | 存疑，Ashmand 自己也说部分条目与本书学说不合（PAGE 181） | reliable-secondary |
| 卷二地域-民族性格论 | 属古代气候决定论与民族刻板印象，不可用于对人的判断 | firsthand（内容）/ inference（评价） |

**一句话结论**：托勒密体系可以作为一套**有内部规则的古典象征语言**，用于自我反思与叙事整理；它不具备经验验证的预测效力。输出中必须写明这一点（与 `fortune` 第五节第 1 条一致）。

## 五、适用性

- **适合**：已有本命盘数据（工具或用户粘贴）的人，想用"古典规则"而非现代心理占星理解自己的结构：哪颗行星"在主场"、性格的高低两面、职业倾向的象征类别、对"命定"说法的冷静校准。
- **不适合**：寿命、死亡、疾病、生育、父母安危、意外事故、具体事件日期、择日、投资择时、外貌评判、性取向/性行为判断、民族性格判断——一律拒绝落地（见 `REJECTED.md`）。
- **与现有 skill 的分工**：`astrology-transit` = 现代三要素 + 行运周期；本包 = 古典尊贵与主题主宰星的**本命结构**解读。两者可组合：先用本包读结构，再交给 transit 看当前周期。
- **语言**：一律经 `fortune` 第三节转换表；托勒密原书大量使用"凶星""邪恶""短命""通奸"等字眼，本包全部改写为倾向语言或直接不输出。
