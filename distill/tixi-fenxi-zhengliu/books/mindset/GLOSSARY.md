# GLOSSARY · mindset

| 中文 | English | 一句白话 | 位置 |
|---|---|---|---|
| 思维模式 | mindset | 你对"能力和品质能不能改变"的底层看法，它决定你怎么解读成败 | Ch1 PAGE 7 |
| 固定型思维 | fixed mindset | 认为能力天生定好了，所以每件事都在检验"我到底行不行" | Ch1 PAGE 7 |
| 成长型思维 | growth mindset | 认为能力可以靠投入、方法和帮助长出来，所以事情是用来学的 | Ch1 PAGE 8 |
| 证明 vs 发展 | validating vs developing yourself | 一个想向别人和自己证明"我本来就行"，一个想让自己变得更行 | Ch2 PAGE 12 |
| 非学习者 | nonlearner | 为了不暴露短处而放弃学习机会的人 | Ch2 PAGE 12–13 |
| "还没有" | yet | 把"我不会"改成"我还不会"，提醒能力在路上 | Ch2 PAGE 17 |
| 失败从行为变成身份 | failure as identity | 从"我失败了一次"滑到"我就是个失败者" | Ch2 PAGE 21 |
| 低努力综合征 | low-effort syndrome | 故意不努力，这样失败了还能说"我只是没用心" | Ch3 PAGE 35 |
| 能力表扬 / 过程表扬 | ability praise / process praise | 夸"你真聪明"是给特质打分；夸"你换了三种方法"是在讲做法 | Ch3 PAGE 42；Ch7 PAGE 98 |
| 正面标签 / 负面标签 | positive / negative labels | 好标签让人怕失去它，坏标签让人怕坐实它 | Ch3 PAGE 44–45 |
| 刻板印象威胁 | stereotype threat | 担心坐实群体偏见而分心、发挥变差（证据有争议） | Ch3 PAGE 44 |
| 某人–无名之辈综合征 | somebody–nobody syndrome | "赢了我就是人物，输了我就什么都不是" | Ch4 PAGE 61 |
| 天才加一千个助手 | genius with a thousand helpers | 领导者只要听话的帮手、不要强团队（引自 Collins） | Ch5 PAGE 65 |
| CEO 病 | CEO disease | 身居高位后只听吹捧、赶走批评者 | Ch2 PAGE 14–15 |
| 建设性批评 | constructive criticism | 帮对方修好一件事的反馈，而不是给人下定论 | Ch7 PAGE 100 |
| 高标准加关怀 | high standards and a nurturing atmosphere | 要求很高，同时让人感到被接住、被教会 | Ch7 PAGE 108 |
| 被成功感染 | infected with success | 赢了之后觉得"我天生就会赢"，于是松懈 | Ch7 PAGE 115–116 |
| 内心独白 | internal monologue | 事情发生时脑子里那句自动解说，如"这说明我不行" | Ch8 PAGE 118 |
| 评判框架 / 学习框架 | judge-and-be-judged / learn-and-help-learn | 一个把每件事当打分，一个把每件事当学和帮别人学 | Ch8 PAGE 134 |
| 实施意图（具体计划） | implementation intention (when, where, how) | 把"我要做"写成"明天几点在哪儿怎么做"，执行率更高（Gollwitzer） | Ch8 PAGE 125 |
| 假成长型思维 | false growth mindset | 嘴上说成长型，实际只夸努力、只喊乐观、行为没变（Dweck 2015/2016 提出，初版无） | 初版无；相关 PAGE 28, 133 |
| 固定型触发点 | fixed-mindset triggers | 让你瞬间切回评判模式的情境，如被比较、出错、看到别人更强 | 术语来自 2016 修订版；相关 PAGE 29, 118 |
