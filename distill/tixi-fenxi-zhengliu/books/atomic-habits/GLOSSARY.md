# GLOSSARY —《掌控习惯》术语中英对照

| # | 英文 | 中文 | 一句白话解释 | 位置 |
|---|---|---|---|---|
| 1 | Atomic habit | 原子习惯 | 很小、很容易做，但属于一个更大系统、能累积出大效果的习惯。 | PAGE 29 |
| 2 | Plateau of Latent Potential | 潜力平台期 | 努力了却看不到结果的那段时间——效果在积累，只是还没越过临界点。 | PAGE 24 |
| 3 | Valley of Disappointment | 失望之谷 | 预期线性进步、实际进步滞后，两者之间的落差让人想放弃。 | PAGE 23–25 |
| 4 | Systems vs. goals | 系统 vs 目标 | 目标是想要的结果，系统是每天产出结果的做法；改系统才能长久。 | PAGE 26–29 |
| 5 | Identity-based habits | 身份导向习惯 | 先想"我要成为什么样的人"，再让习惯去证明它，而不是只盯结果。 | PAGE 33 |
| 6 | Outcome-based habits | 结果导向习惯 | 从"我想得到什么"出发设计习惯，容易达成后反弹或中途泄气。 | PAGE 33 |
| 7 | Vote (for an identity) | 为身份投票 | 每做一次，就是给"我是这种人"多投一票；不用全票，过半就行。 | PAGE 38–39 |
| 8 | Habit loop: cue, craving, response, reward | 习惯回路：提示、渴望、反应、奖励 | 看到信号 → 想改变状态 → 做出行为 → 得到满足并记住。 | PAGE 46–49 |
| 9 | Four Laws of Behavior Change | 行为改变四定律 | 让它显而易见、有吸引力、简便易行、令人愉悦。 | PAGE 52 |
| 10 | Inversion (of the laws) | 定律反向 | 戒坏习惯就反着来：隐形、没吸引力、困难、不愉悦。 | PAGE 52–53 |
| 11 | Habits Scorecard | 习惯记分卡 | 把一天的习惯列出来，标 + / − / =，先看见再改变。 | PAGE 60–61 |
| 12 | Pointing-and-Calling | 指认呼唤 | 把要做的动作和后果大声说出来，把自动行为拉回意识层。 | PAGE 59、62 |
| 13 | Implementation intention | 执行意图 | 事先写好"我会在[时间][地点]做[行为]"。 | PAGE 64–66 |
| 14 | Habit stacking | 习惯堆叠 | "在我做完[现有习惯]之后，我会做[新习惯]"，借旧习惯当提示。 | PAGE 68 |
| 15 | Diderot Effect | 狄德罗效应 | 得到一样新东西会引发一连串配套行为/购买。 | PAGE 67 |
| 16 | Environment design / choice architecture | 环境设计 / 选择架构 | 改变东西摆在哪里、看不看得见，从而改变人会选什么。 | PAGE 74–79 |
| 17 | The context is the cue | 情境即提示 | 习惯最终绑定的是整个场景，而不是单一信号。 | PAGE 79 |
| 18 | Cue-induced wanting | 提示诱发的渴望 | 一看到相关信号，就冒出重复坏习惯的冲动。 | PAGE 85 |
| 19 | Supernormal stimulus | 超常刺激 | 被放大的"加强版现实"（垃圾食品、社交点赞），比自然刺激更勾人。 | PAGE 90–91 |
| 20 | Temptation bundling | 诱惑捆绑 | 把"想做的事"和"需要做的事"绑在一起，做了后者才能享受前者。 | PAGE 95–97 |
| 21 | Motivation ritual | 动机仪式 | 在困难习惯前固定做一件你喜欢的小事，让它变成进入状态的信号。 | PAGE 115–117 |
| 22 | Motion vs. action | 忙碌 vs 行动 | 计划、研究是"在动"，真正产出结果的才是"行动"。 | PAGE 121 |
| 23 | Habit line / automaticity | 习惯线 / 自动化程度 | 重复够多次后，行为越过某条线，不用想就能做。 | PAGE 123–124 |
| 24 | Law of Least Effort | 最小努力法则 | 两个差不多的选项里，人会选更省力的那个。 | PAGE 128 |
| 25 | Friction / addition by subtraction | 摩擦 / 以减为加 | 减少好习惯路上的步骤，增加坏习惯路上的步骤。 | PAGE 130–133 |
| 26 | Decisive moment | 决定性时刻 | 一天中几个"岔路口"式的小选择，决定接下来一段时间怎么过。 | PAGE 136–137 |
| 27 | Two-Minute Rule / gateway habit | 两分钟规则 / 入口习惯 | 新习惯的起步版本要在两分钟内做完，先学会"出现"。 | PAGE 138 |
| 28 | Habit shaping | 习惯塑形 | 从两分钟版开始，一阶段一阶段往目标版本升级。 | PAGE 140–141 |
| 29 | Commitment device | 承诺装置 | 现在做一个选择，把未来的自己锁在好行为上（如提前付费）。 | PAGE 143 |
| 30 | Cardinal Rule of Behavior Change | 行为改变基本法则 | 被即时奖励的会被重复，被即时惩罚的会被避免。 | PAGE 155、158 |
| 31 | Immediate- vs. delayed-return environment | 即时回报 / 延迟回报环境 | 大脑为"马上见效"进化，现代生活却多是"很久后才见效"。 | PAGE 155 |
| 32 | Time inconsistency (hyperbolic discounting) | 时间不一致性（双曲贴现） | 人对眼前奖励的估值远高于未来奖励。 | PAGE 156、161 |
| 33 | Habit tracker / Paper Clip Strategy | 习惯追踪 / 回形针策略 | 用日历打叉、移动回形针等方式让进度看得见。 | PAGE 162–163 |
| 34 | Never miss twice | 不连续两次断 | 断一次是意外，别让它连成第二次。 | PAGE 167 |
| 35 | Goodhart's Law | 古德哈特定律 | 当一个指标变成目标，它就不再是好指标。 | PAGE 169 |
| 36 | Accountability partner / habit contract | 问责伙伴 / 习惯契约 | 请人监督，并写明做不到的代价，给坏习惯加即时成本。 | PAGE 173–175 |
| 37 | Goldilocks Rule | 金发姑娘原则 | 难度刚好在能力边缘时动机最高，不太难也不太易。 | PAGE 191 |
| 38 | Variable reward | 可变奖励 | 奖励时有时无，最能维持兴趣（老虎机原理）。 | PAGE 193–194 |
| 39 | Annual Review / Integrity Report | 年度回顾 / 诚信报告 | 作者每年两次的复盘：做得好/不好/学到什么；价值观是否一致。 | PAGE 203 |
| 40 | Keep your identity small | 让身份保持小 | 别让单一角色占满自我，把身份改写成可迁移的特质。 | PAGE 204–205 |
