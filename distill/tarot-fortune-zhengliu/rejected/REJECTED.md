# 被拒候选

| 候选 | 来源 | 拒绝理由（四检） |
|------|------|----------------|
| 神煞断事（桃花、驿马、孤辰寡宿等） | 《三命通会》等 | 区分度低、流派分歧极大、易产生恐吓式断语 → 仅允许趣味提及并标注 |
| 六亲吉凶断语（克父母、克夫妻） | 子平各家 | 边界检失败：伤害性强、不可检验 → 禁用，改为"关系张力模式" |
| 寿元推算 | 子平、紫微 | 边界检失败：高风险、无证据 → 明确拒绝 |
| 纳甲六爻（京房体系）六亲六神断法 | 京房易 | 超出本次范围，与义理路线冲突 → 未纳入，可另行蒸馏 |
| 星座配对判决（"X 座和 Y 座不合"） | 流行占星 | 生成力检失败：泛化标签，巴纳姆效应 → 改为关系模式讨论 |
| 水逆影响事件结果 | 流行占星 | 无证据 → 仅保留为"复盘沟通"的提醒 |
| 塔罗"是/否"牌阵 | 流行实践 | 与"问题改写"原则冲突、诱导确定预言 → 不纳入 |
| 卜卦占星 / 择日占星 / 医疗占星 | 传统占星 | 高风险或超出个人处境分析范围 → 不纳入 |
| "荣格证明塔罗有效" | 网络流行说法 | 无原始证据支持 → 列为反例 |
