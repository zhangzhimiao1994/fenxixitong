# GLOSSARY

| 术语 | 体系 | 含义（本体系用法） |
|------|------|-----------------|
| 观察层 | Hub | 基于用户陈述事实的维度：心理、身心 |
| 象征层 | Hub | 基于随机或出生时间的象征维度：塔罗、运势、周易 |
| 主要矛盾 | 毛选引擎 | 解决后其他问题会随之松动的那个问题；只由观察层事实决定 |
| 镜子问题 | 象征层 | 象征维度交还给用户的一个开放问题，替代"预言" |
| 大阿卡纳 / 小阿卡纳 | 塔罗 | 22 张原型牌 / 56 张花色牌（4 花色 × 14） |
| 正位 / 逆位 | 塔罗 | 牌面朝向；逆位按"受阻/内化/过度"三读法之一解释 |
| 牌阵 | 塔罗 | 牌的位置布局，每个位置有固定含义 |
| 日主 | 八字 | 日柱天干，代表"我" |
| 十神 | 八字 | 其他干支与日主的生克关系：比劫、食伤、财、官杀、印 |
| 大运 / 流年 | 八字 | 十年周期 / 一年周期 |
| 用神 / 忌神 | 八字 | 使全局趋于中和的五行 / 加剧失衡的五行 |
| 冲 | 八字 | 地支对冲，本体系只译为"变动"，不论吉凶 |
| 三要素 | 星盘 | 太阳、月亮、上升 |
| 行运 | 星盘 | 当前行星对本命盘的作用 |
| 土星回归 | 星盘 | 土星回到出生位置，约 29.5 年一次 |
| 命宫 / 十二宫 | 紫微 | 核心自我 / 人生十二领域 |
| 四化 | 紫微 | 化禄、化权、化科、化忌，能量流向 |
| 本卦 / 变爻 / 之卦 | 周易 | 当下局面 / 变动之处 / 趋势指向 |
| 再三渎 | 周易 | 《蒙》卦辞：同一事不重复占，本体系用于塔罗与起卦 |
