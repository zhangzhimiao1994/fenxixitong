# 宽恕伤害

> 伤不会消失，但可以从“你丢下了我”变成“我们一起走回来了”。

## 🧭 决策树

```
用户提到一次放不下的伤害（自己受伤，或自己伤了对方）
│
├── 暴力、恐惧对方、严重成瘾？                  → ❌ 走 B 段转介
├── 外遇仍在继续 / 长期隐瞒刚被揭穿、仍在说谎？   → ❌ 不适用，转介伴侣治疗师
├── 自伤自杀信号？                              → 🛑 psyche 第五节危机话术
├── 伤害来自伴侣以外（侵害、事故、丧亲）？        → ❌ psyche + 专业创伤治疗
├── 两人一谈就吵到失控？                        → ❌ 先降级（eft-demon-dialogues / eft-raw-spot-deescalation）
│
└── ✅ 关系中的一次关键时刻被丢下 / 否定 / 背叛，双方仍想修复
      ├── 我是受伤方 → 第 1、3、5 步为主
      └── 我是伤人方 → 第 2、4 步为主（道歉五要素）
      最后一起做第 6 步：修复的故事
```

## 📥 输入与证据假设

- 需要：一个具体的时刻（哪天、在哪里、对方说了或做了什么），而不是“这些年他一直不在乎我”。作者强调大而模糊的伤害很难处理（PAGE 132）。
- 伤痛的分量取决于它碰到了什么脆弱，不取决于事件大小；一次调情可能比一次外遇更伤（PAGE 125）。不评判“这点事值不值得”。
- 假设伤人方多半不是恶意，而是被自己的焦虑淹没或不知道怎么回应（PAGE 123）。这是作者在治疗中的观察，不是对每个案例的保证。
- 前提：两人已能停下争吵（作者说必须先做到前三个对话的安全感，PAGE 125）。

## 📖 RIA+E+B

### R（原文位置与转述）

- 有些事件不只是碰到雷区，而是“关系创伤”：在最需要的时候，最该保护自己的人没有出现（PAGE 122）。受伤方的核心感受往往不只是被背叛，而是被抛弃——“你怎么能在那个生死关头丢下我”（PAGE 123）。
- 常发生在高压力时刻：生产或流产、父母去世、失业、确诊重病（PAGE 123）。
- 受伤方会暗下决心“再也不向你求助”（Never Again 时刻），之后每次靠近都会触发警报（PAGE 122）。忽略或掩埋不会让它愈合（PAGE 124）。
- 六步：①受伤方尽量简单地说出伤痛，不立案指控；②伤人方保持情绪在场，承认对方的痛和自己的责任；③受伤方走出防护墙，说出更深的孤独与绝望；④伤人方承担责任、表达悔意，不能是冷淡的“好吧，对不起”；⑤围绕这次伤害进行抱紧我对话，受伤方直接请求现在需要的回应；⑥一起写一个新故事：伤害如何发生、如何侵蚀信任、两人如何一起修复（PAGE 126–130）。
- 有效道歉五要素：让对方看到你在乎他的痛；明说他的伤和愤怒是合理的；具体说出自己做了什么；表达对自己的失望；承诺会陪对方疗伤（PAGE 129、132）。
- 四种敷衍道歉：找出口式、淡化责任式、被迫式、工具式（PAGE 132）。
- 作者结语："Injuries may be forgiven, but they never disappear."（PAGE 131）

### I（白话解释）

“都过去三年了”对受伤的人没有意义，因为那一刻在身体里没有过去。它回答了一个最根本的问题——“我最需要你的时候，你在吗？”——而答案是“不在”。所以每次你说“来，靠近我”，对方心里都会响起“上次靠近的结果是被丢在楼梯上”。宽恕不是一个决定，而是一次重新回答：这一次，你看见了我的痛，你承认了，你留下来了。

### A1（书中案例，转述）

- **Helen 与 Conrad**（PAGE 121–125）：Helen 坐在楼梯上说医生怀疑她得了乳腺癌，Conrad 说“别慌，以后再说”，上楼关了门。三年后，正当抱紧我对话气氛很好时，Helen 突然想起这一幕，随后改口说“治疗很顺利，没什么要谈的”。转折在于 Conrad 说出那天他关上门后自己哭了一个小时，只是觉得暴露害怕会让她失望。
- **Vera 与 Ted**（PAGE 127–130）：Ted 化疗时没怎么陪她，但最伤的是：Vera 哭着说撑不下去时他一言不发，几分钟后她妹妹一哭，他立刻起身去抱妹妹。Ted 后来说出“正因为你对我太重要，看着你我只看到自己的无助”，并给出了一次包含五要素的道歉。两人约定 Vera 可以发出“现在是抱紧我时间”的信号。
- **Mary 与 Ralph**（PAGE 126）：Ralph 抽屉里的派对照片。Ralph 一直追问“时间点为什么重要”，才发现真正的伤是：她为他克服羞耻去改变，他却从未表示满意。

### A2（未来触发场景）

1. “我流产那天他在加班，回来只说了句‘还能再要’。我们现在挺好的，可我就是没法跟他亲近。”
2. “我出差时她爸住院，我没赶回去。她说原谅我了，但一年了她再也不跟我说心事。我该怎么道歉？”
3. “他多年前的一次短暂外遇早就结束了，我以为过去了，可最近一吵架我就会翻出来。”

### E（执行步骤）

1. **安全筛查**：暴力、恐惧、成瘾、外遇仍在继续或长期欺骗、自伤信号 → B 段。
2. **找到那一刻**：请受伤方从一段痛苦的时期里挑出“伤结晶”的那一个时刻（PAGE 132）。
3. **说出伤痛（第 1 步）**：用四个问题帮受伤方定位——在最需要时，我是否感到得不到安慰（被剥夺）？被丢下（被抛弃）？被贬低？对方是否突然变成了危险的来源（PAGE 127）？只描述，不立案。
4. 🔴 **CHECKPOINT 1**：受伤方能否写出“那一刻，我需要___，却得到了___，我从此决定___”？写不出“决定”那一格 → 问“那天之后，你在哪些事上不再找他了？”
5. **伤人方在场（第 2 步）**：伤人方先不解释、不辩护，复述对方的痛，再说“我那时候的反应是因为___”，帮助对方重新能预测自己（PAGE 128）。
6. **受伤方说出更深的绝望（第 3 步）**：例如“那天之后我想过放弃”。伤人方只回应感受。
7. **道歉（第 4 步）**：伤人方按五要素准备道歉，并对照四种敷衍道歉自查。
8. 🔴 **CHECKPOINT 2**：道歉里有没有“但是”“我也是因为你”“都过去了”？有 → 删掉重写。是否具体说出了自己做的那件事？没有 → 补上。
9. **当下的需要（第 5 步）**：受伤方说出“现在我需要你___”，伤人方回应可以做到的部分（可配合 eft-hold-me-tight-talk）。
10. **新故事（第 6 步）**：两人一起写几句话——发生了什么、它怎样让我们疏远、我们怎样一起回来、以后用什么信号或约定防止重演（例如外遇后，与旧人的任何联系都主动告知，PAGE 130）。
11. **重复**：伤害多、信任低时，这个对话可能要做好几次；通常一个核心伤口愈合后，其他的会随之松动（PAGE 130）。

#### 如果这一步失败

| 触发条件 | 一线修复 | 兜底 |
|---------|---------|------|
| 受伤方只能讲“他一直都这样” | 问“有没有一个画面，你一想起来就呼吸一紧？” | 先用小一点的近期伤害练习（PAGE 132） |
| 伤人方说“我都道过歉了，你还要怎样” | 指出那次道歉可能缺了“看见你的痛”这一步 | 给出五要素逐条自查 |
| 伤人方陷入羞愧、自我攻击 | 说明作者的观点：爱里犯错不可避免，没有完美伴侣（PAGE 128） | 先让伤人方只说“我让你失望了”这一句 |
| 受伤方不接受道歉 | 不催促；接受是受伤方的选择，信任需要时间 | 约定下次再谈，或寻求伴侣治疗 |
| 伤害是长期外遇或多重欺骗 | 说明这比一次性事件复杂得多（PAGE 130） | 转介受训的伴侣治疗师 |

### B（边界）

- **作者声明不适用**（PAGE 11）：有虐待或暴力的关系、严重成瘾、长期婚外情。作者在对话 5 也说，持续很久的外遇因为长期刻意欺骗，会让人无法确定什么是真的，处理起来困难得多（PAGE 130）。外遇仍在继续时，不使用本 skill，建议寻找伴侣治疗师；有人身危险拨 110。
- **害怕伴侣**：不要劝受伤方再次向对方敞开（PAGE 82）。
- **自伤自杀**：受伤方说出“那之后我想过放弃”时，要分清是指放弃关系还是放弃生命（书中 Vera 说的是放弃抗癌，PAGE 128）。只要涉及不想活、想伤害自己，或对方以自杀相威胁，立即停止，按 psyche 第五节危机话术处理。
- **伴侣以外的创伤**：侵害、战争、事故、丧子等，书中都是在治疗师陪同下处理的（第三部分 PAGE 168–180）；本 skill 不处理，转介专业创伤治疗。
- **不做诊断**：Helen 的闪回、回避、警觉被作者称为创伤应激的指标（PAGE 122），但本 skill 不判断用户是否有创伤后应激障碍；用户要诊断时用 psyche 第五节第 2 条原话。
- **宽恕不是义务**：不催促、不说“你该放下了”；受伤方可以不原谅。修复的目标是信任重建，不是装作没发生（PAGE 125）。
- **证据局限**：六步来自作者团队的录像分析和一项研究，样本小；自助效果没有研究支持。

## 💬 输出格式

按顺序，全文只问 1 个问题，不写 skill 名：

1. 一句接住：承认这件事至今仍然真实。
2. 点出这次伤害真正碰到的东西：“你最需要他的时候，他不在”，并说出“从那以后你可能决定了___”（标推测）。
3. 根据用户身份给下一步：受伤方 → 一句可以说出伤痛、不带指控的话；伤人方 → 一个包含五要素的道歉草稿。
4. 一句提醒：这类伤可能要谈不止一次，不需要一次谈完。
5. 一个问题，引用用户原话。

**示例**（“我流产那天他在加班，回来只说了句‘还能再要’。现在挺好的，可我就是没法跟他亲近。”）

```
那句话到现在还卡在你心里，这一点都不奇怪。
真正伤人的可能不只是他在加班，而是你最需要被抱住的时候，他给的是一句往前看的话。从那以后，你也许暗暗决定了“难过的时候别找他”。这是我的猜测，你最清楚。
找一个安静的时候，可以这样开头：“有件事我一直没说清楚。流产那天你说‘还能再要’，我觉得那一刻我是一个人。我不是要翻旧账，我想让你知道我为什么一直靠不近你。”
这种伤通常要谈几次才会松动，一次说不完没关系。
那天他说“还能再要”的时候，你最希望他做的是什么？
```
