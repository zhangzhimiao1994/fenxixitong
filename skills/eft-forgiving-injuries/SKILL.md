# 宽恕伤害

> 伤不会消失，但可以从“你丢下了我”变成“我们一起走回来了”。

## 🧭 决策树

```
用户提到一次放不下的伤害（自己受伤，或自己伤了对方）
│
├── 任何安全信号，或外遇仍在继续 / 长期隐瞒？    → 🛑 E1 STOP
├── 伤害来自伴侣以外（侵害、事故、丧亲）？        → ❌ psyche + 专业创伤治疗
├── 两人一谈就吵到失控？                        → ❌ 先降级（eft-demon-dialogues / eft-raw-spot-deescalation）
│
├── 同样的缺席至今还在重复？                    → ❌ 先停宽恕，转 eft-demon-dialogues
│
└── ✅ 关系中的一次关键时刻被丢下 / 否定 / 背叛，双方仍想修复
      ├── 我是受伤方 → 单轮输出 E1–E4
      └── 我是伤人方 → 单轮输出 E1、E7–E8
      E5、E6、E9–E11 两人当面做，单轮不输出
```


## 📥 输入与证据假设

- 需要：一个具体的时刻（哪天、在哪里、对方说了或做了什么），而不是“这些年他一直不在乎我”。作者强调大而模糊的伤害很难处理（PAGE 132）。
- 伤痛的分量取决于它碰到了什么脆弱，不取决于事件大小；一次调情可能比一次外遇更伤（PAGE 125）。不评判“这点事值不值得”。
- 假设伤人方多半不是恶意，而是被自己的焦虑淹没或不知道怎么回应（PAGE 123）。这是作者在治疗中的观察，不是对每个案例的保证。
- 前提：两人已能停下争吵（作者说必须先做到前三个对话的安全感，PAGE 125）。

## 📖 RIA+E+B

### R（原文位置与转述）

- 有些事件不只是碰到雷区，而是“关系创伤”：在最需要的时候，最该保护自己的人没有出现（PAGE 122）。受伤方的核心感受往往不只是被背叛，而是被抛弃——“你怎么能在那个生死关头丢下我”（PAGE 123）。
- 常发生在高压力时刻：生产或流产、父母去世、失业、确诊重病（PAGE 123）。
- 受伤方会暗下决心“再也不向你求助”（Never Again 时刻），之后每次靠近都会触发警报（PAGE 122）。忽略或掩埋不会让它愈合（PAGE 124）。
- 书中六步（执行段对应 E3、E5、E6、E7、E9、E10）：①受伤方尽量简单地说出伤痛，不立案指控；②伤人方保持情绪在场，承认对方的痛和自己的责任；③受伤方走出防护墙，说出更深的孤独与绝望；④伤人方承担责任、表达悔意，不能是冷淡的“好吧，对不起”；⑤围绕这次伤害进行抱紧我对话，受伤方直接请求现在需要的回应；⑥一起写一个新故事：伤害如何发生、如何侵蚀信任、两人如何一起修复（PAGE 126–130）。
- 有效道歉五要素：让对方看到你在乎他的痛；明说他的伤和愤怒是合理的；具体说出自己做了什么；表达对自己的失望；承诺会陪对方疗伤（PAGE 129、132）。
- 四种敷衍道歉：找出口式、淡化责任式、被迫式、工具式（PAGE 132）。
- 作者结语："Injuries may be forgiven, but they never disappear."（PAGE 131）

### I（白话解释）

“都过去三年了”对受伤的人没有意义，因为那一刻在身体里没有过去。它回答了一个最根本的问题——“我最需要你的时候，你在吗？”——而答案是“不在”。所以每次你说“来，靠近我”，对方心里都会响起“上次靠近的结果是被丢在楼梯上”。宽恕不是一个决定，而是一次重新回答：这一次，你看见了我的痛，你承认了，你留下来了。

### A1（书中案例，转述）

- **Helen 与 Conrad**（PAGE 121–125）：Helen 坐在楼梯上说医生怀疑她得了乳腺癌，Conrad 说“别慌，以后再说”，上楼关了门。三年后，正当抱紧我对话气氛很好时，Helen 突然想起这一幕，随后改口说“治疗很顺利，没什么要谈的”。转折在于 Conrad 说出那天他关上门后自己哭了一个小时，只是觉得暴露害怕会让她失望。
- **Vera 与 Ted**（PAGE 127–130）：Ted 化疗时没怎么陪她，但最伤的是：Vera 哭着说撑不下去时他一言不发，几分钟后她妹妹一哭，他立刻起身去抱妹妹。Ted 后来说出“正因为你对我太重要，看着你我只看到自己的无助”，并给出了一次包含五要素的道歉。两人约定 Vera 可以发出“现在是抱紧我时间”的信号。
- **Mary 与 Ralph**（PAGE 126）：Ralph 抽屉里的派对照片。Ralph 一直追问“时间点为什么重要”，才发现真正的伤是：她为他克服羞耻去改变，他却从未表示满意。

### E（执行步骤）

除 E1 外，任何步骤都不整轮停下：先按已知信息给出可用内容，缺的那一项用结尾唯一的问题去补。

1. 🛑 **STOP·安全筛查** — 输入：用户原话。输出：
   - 暴力、严重成瘾、长期婚外情（作者声明不适用，PAGE 11）；外遇仍在继续或长期刻意欺骗（会让人无法确定什么是真的，PAGE 130）→ 不使用本 skill，转介受训的伴侣治疗师；有人身危险拨 110，结束。
   - 害怕伴侣 → 不劝受伤方再次向对方敞开（PAGE 82），只给安全与转介信息，结束。
   - 涉及不想活、想伤害自己（含“那之后觉得活着没意思”），或对方以自杀相威胁 → 只输出 cross-system-hub C5，结束。
   - “想过放弃”分不清指关系还是生命（书中 Vera 说的是放弃抗癌，PAGE 128）→ 本轮只问“你说的放弃，是指这段关系，还是有过不想活的念头？”，等用户回答再继续。
   - 信号模糊（“他气急了会摔东西”）→ 只问安全问题；出现过推、打、摔东西威胁，一律按本步处理。
2. **找到那一刻**（受伤方）— 输入：一段痛苦时期的描述。输出：“伤结晶”的那一个时刻：哪天、在哪、对方说了或做了什么（PAGE 132）。
3. **说出伤痛**（书中①，受伤方）— 输入：那一刻。输出：用四个问题定位（PAGE 127），选用户原话最贴的 1–2 项，写进输出第 2 条：①得不到安慰（被剥夺）→ 白话“你难受的时候，没人接住”；②被丢下（被抛弃）→“最需要的时候，他不在”；③被贬低 →“他那句话像在说你的痛不算什么”；④对方变成危险来源 →“本该护着你的人，那一刻让你更怕”。只描述，不立案。
4. 🔴 **CHECKPOINT 1·下判断之前** — 核对：①是否有一个具体时刻；②能否填出“那一刻，我需要___，却得到了___，我从此决定___”。缺① → 按用户讲到的时期照常给出第 1–4 条，结尾问“有没有一个画面，你一想起来就呼吸一紧？”；“决定”一格空着 → 以推测给出，推测必须引用用户原话里的一个细节（如“还能再要”“中途走了”），可把结尾问题换成“那天之后，你在哪些事上不再找他了？”。两种情况都只占用全文唯一的那个问题，不另问。
5. **伤人方在场**（书中②）— 输入：受伤方说出的伤痛。输出：伤人方先不解释、不辩护，复述对方的痛，再说一句（只一句）“我那时候的反应是因为___”，帮助对方重新能预测自己（PAGE 128）。
6. **说出更深的绝望**（书中③，受伤方）— 输入：E5 后的对话。输出：一句更深的话，例如“那天之后我想过放弃”；伤人方只回应感受。涉及生命 → 回 E1。
7. **准备道歉**（书中④，伤人方）— 输入：事件经过 + 对方之后的变化。输出：一段覆盖五要素的道歉草稿。
8. 🔴 **CHECKPOINT 2·给出道歉之前** — 核对：①用户是否说清自己具体做了什么；②草稿里有没有“但是”“我也是因为你”“都过去了”。缺① → 按已知写草稿，具体动作处留空“那天我___”，结尾问“那天你具体做了什么？”；有② → 删掉重写。
9. **当下的需要**（书中⑤，受伤方）— 输入：E3–E6 的内容。输出：“现在我需要你___”一句；伤人方回应可以做到的部分（可配合 eft-hold-me-tight-talk）。
10. **新故事**（书中⑥，双方）— 输入：前面各步。输出：两人一起写的几句话——发生了什么、它怎样让我们疏远、我们怎样一起回来、以后用什么信号或约定防止重演（例如外遇后，与旧人的任何联系都主动告知，PAGE 130）。
11. **重复** — 输入：一次对话的结果。输出：约定下次再谈的时间。伤害多、信任低时，这个对话要做好几次；通常一个核心伤口愈合后，其他的会随之松动（PAGE 130）。

#### 如果这一步失败

| 触发条件 | 一线修复 | 仍失败兜底 |
|---------|---------|-----------|
| E2/E4 信息不足：只能讲“他一直都这样” | 问“有没有一个画面，你一想起来就呼吸一紧？” | 先用小一点的近期伤害练习（PAGE 132） |
| E5 伤人方否认事件或记忆不同（“我不记得说过”） | 不争事实，只回应“那一刻你感到被丢下” | 先只走受伤方路线，伤人方路线延后 |
| E7 伤人方说“我都道过歉了，你还要怎样” | 指出那次道歉可能缺了“看见你的痛”这一步 | 给出五要素逐条自查 |
| E7 伤人方陷入羞愧、自我攻击 | 说明作者的观点：爱里犯错不可避免，没有完美伴侣（PAGE 128） | 先让伤人方只说“我让你失望了”这一句 |
| E9 受伤方不接受道歉 | 不催促；接受是受伤方的选择，信任需要时间 | 约定下次再谈，或去伴侣治疗师那里一起谈 |
| 受伤方要求以惩罚换原谅（“你先跪下认错”） | 区分“我要你证明”与“我需要你___”，引回 E9 | 转介受训的伴侣治疗师 |
| 伤害仍在重复：对方至今在类似时刻缺席 | 先停宽恕，转 eft-demon-dialogues 处理当下的循环 | 去受训的伴侣治疗师 |
| 双方互有伤害，用户既是受伤方也是伤人方 | 本轮只走用户最先提到的那一方路线 | 两件伤分开谈，先谈对方更早的那件 |
| E1 用户否认危险：“摔东西不算什么” | 只问安全问题，不进入宽恕流程 | 按 E1 处理，不以用户自评为准 |
| 用户坚持越界要求：判定该不该离婚、诊断对方 | 说明这里不替人做去留决定、不做诊断 | 去留 → 伴侣治疗师或个体咨询师；诊断 → psyche 第五节第 2 条原话 |
| cross-system-hub C5 不可用 | 直接说：“你的安全最重要，现在有危险就拨 110 或 120。” | 给当地心理援助热线，并请用户把一句话发给信任的人 |

### B（边界）

- **伴侣以外的创伤**：侵害、战争、事故、丧子等，书中都是在治疗师陪同下处理的（第三部分 PAGE 168–180）；本 skill 不处理，转介专业创伤治疗。
- **不做诊断**：Helen 的闪回、回避、警觉被作者称为创伤应激的指标（PAGE 122），但本 skill 不判断用户是否有创伤后应激障碍；用户要诊断时用 psyche 第五节第 2 条原话。
- **宽恕不是义务**：不催促、不说“你该放下了”；受伤方可以不原谅。修复的目标是信任重建，不是装作没发生（PAGE 125）。
- **证据局限**：六步来自作者团队的录像分析和一项研究，样本小；自助效果没有研究支持。

## 💬 输出格式

E4 或 E8 缺信息时照常给出第 1–4 条，只把第 5 条换成补缺问题。严格按顺序，全文 ≤ 320 字，只在最后问 1 个问题，不写 skill 名，不说“依恋伤害/Never Again/六步/五要素”等术语：

1. 接住（≤ 30 字）：承认这件事至今仍然真实。
2. 点出真正碰到的东西（≤ 80 字）：从 E3 四项里选用户原话最贴的 1–2 项写出（例：“他不在，回来那句话又像在说你的痛不算什么”），再写“从那以后可能决定了___”（标推测）。
3. 按身份给下一步：
   - 受伤方（E3）→ 一句说出伤痛、不带指控的开场话（≤ 80 字），格式：“有件事我一直没说出口。___（那一刻的原话细节），我觉得___。我不是要翻旧账，我想让你知道___。”
   - 伤人方（E7–E8）→ 一段道歉草稿（≤ 120 字），依次覆盖：在乎对方的痛 → 承认对方的伤和气是合理的 → 具体说出自己做了什么（用户已讲 → 照原话写“那天我___”；没讲 → 留空）→ 对自己失望 → 承诺陪对方慢慢走；末尾提醒删掉“但是/都过去了”。
4. 一句收尾（≤ 50 字），按身份二选一：受伤方 →“这种伤要谈好几次，隔几天再谈；自己的难过一直很重时，去个人或伴侣咨询”；伤人方 →“这种伤要谈好几次；之后用一件日常小事持续兑现（例：主动问起她家人的身体）”。
5. 一个问题，引用用户原话。

**示例·受伤方**（“我爸葬礼那天他说公司有急事，中途就走了。都三年了，我还是一想起来就不想跟他说话。”）

```
三年了还会一想起就不想说话，这很正常，那一天在心里没有过去。
真正伤人的可能不只是他走了，而是你最需要有人站在旁边的时候，他不在；“公司有急事”又像在说你那天的难过排在后面。从那以后，你也许暗暗决定了“难的时候别指望他”。这是我的猜测，你最清楚。
找个安静的时候可以这样开头：“有件事我一直没说出口。我爸葬礼那天你中途走了，我觉得那一刻只剩我一个人。我不是要翻旧账，我想让你知道我为什么一直离你有点远。”
这种伤要谈好几次，隔几天再谈；自己的难过一直很重时，去个人或伴侣咨询。
他中途离开的那一刻，你最希望他做的是什么？
```

**示例·伤人方**（“她做手术那天我在家打游戏，没去医院陪她。她说没事，可从那以后对我很冷淡。我想道歉。”）

```
她说“没事”却冷了下来，你看见了这一点，就有机会补上。
真正伤到她的，可能是她躺在手术台前最害怕的时候，身边没有你。从那以后，她也许决定了“难的时候自己扛”（推测）。
道歉可以这样说：“你做手术那天，我在家打游戏，没去陪你。你一个人进手术室，一定很怕。你后来对我冷淡，是应该的。我对那天的自己很失望。我不需要你马上原谅，我想陪你把那天慢慢说出来。”别加“但是我以为是小手术”，那句会把前面都抵掉。
这种伤要谈好几次；之后每次她复查，主动陪着去。
她说“没事”的时候，你觉得她最想听到你说的是什么？
```

## 反例黑名单

| # | 反模式 | 为什么 | 替代做法 |
|---|-------|-------|---------|
| 1 | 劝受伤方“都过去了，该放下了”（Nat 的错误，PAGE 25） | 掩埋不会让伤愈合（PAGE 124） | 承认伤在当下仍然真实 |
| 2 | 评判伤害大小（“这点事至于吗”） | 分量取决于碰到的脆弱，不取决于事件（PAGE 125） | 问它碰到了什么脆弱 |
| 3 | 帮伤人方写带“但是”的道歉 | “但是”属于找出口式道歉，会抵消前面的承认（PAGE 132） | 五要素，删掉辩解 |
| 4 | 外遇仍在继续时引导宽恕 | 长期欺骗让信任没有立足点（PAGE 130） | 按 E1 转介伴侣治疗师 |
| 5 | 把宽恕当成受伤方的义务 | 被迫的原谅不会重建信任 | 接受与否由受伤方决定 |
| 6 | 说“你这是创伤后应激”“他就是冷血自恋” | 单方描述撑不起诊断，标签会堵死修复 | 只描述那一刻；诊断走 B 段原话 |
