# 创伤理论与癔症模型

**基于**：Breuer & Freud, *Studies on Hysteria* (1895d)

## 触发条件
- 用户出现医学检查正常的身体症状：头痛、头晕、胃痛、麻痹、慢性疲劳
- 用户说「医生说我没事，但我真的不舒服」
- 有已知的心理创伤或长期压力源
- 用户无法或不愿用语言表达某种情绪（尤其是愤怒和悲伤）
- 用户说「我哭不出来」「这事我说不出口」
- 触发词：「查不出原因」「医生说我没事」「身体不舒服但检查正常」「说不出口」「哭不出来」「不知道哪来的痛」

## 不触发
- 有明确器质性病因的身体症状——先排除生理原因
- 单纯的疲劳（没有心理创伤背景）
- 无躯体症状的纯情绪问题
- 内心冲突为主无躯体表现 → `freud-structural-model`
- 以焦虑/恐慌为主要躯体表现（心跳加速、出汗）→ `freud-anxiety-defense`

## 核心模型

```
创伤事件（或持续压力）
  ↓
产生强烈情感（愤怒/悲伤/恐惧）
  ↓
情感无法通过正常途径释放
  （不能说、不能哭、不能报复、社会不允许）
  ↓
情感被「滞留」在记忆上 → 记忆变成创伤性异物
  ↓
情感能量转化为身体症状 ← 象征性地表达被压抑的内容
  ↓
症状成为被压抑情感的「替身」
```

### 关键命题

> 「癔症患者主要受回忆的折磨。」——症状的病因不是当前事件，而是**未处理的心理创伤记忆**。

> 创伤记忆像一个「异物」——进入心灵后持续活跃地产生作用，即使当事人已「忘记」了它。

### 象征性关系

症状与创伤之间常是象征性的联系：
- 道德厌恶 → 呕吐
- 无法言说的愤怒 → 头痛（「我快气炸了」→ 头真的痛）
- 无法承受的负担 → 肩背僵硬
- 想逃避却逃不掉 → 腿部麻痹
- 被伤害却无法回击 → 身体某部位的疼痛

### 为什么创伤记忆不消退？

正常记忆消退需要三个条件，创伤记忆三者都失败：
1. **社会抑制**：不能说、不能哭、不能复仇→情感没释放
2. **个人压抑**：「不想去想」→被主动逐出意识
3. **意识状态异常**：创伤发生时意识状态改变→记忆被隔离于正常联想链

## 执行步骤

### 第一步：排除器质性
问：做过什么检查？医生怎么说？（这不是怀疑，是排除其他原因）

### 第二步：映射症状到创伤
问：「这个（头痛/胃痛/疲劳）从什么时候开始的？那时候生活发生了什么变化？」

### 第三步：找「没被表达的情感」
问：「那段时间，有没有什么事让你想哭但没哭？想发火但没发？想跑但跑不了？」

→ 如果用户开始哭/愤怒/激动 → 这是健康的**宣泄**（abreaction），不是问题。

### 第四步：建立「词表象」连接
潜意识的物表象（身体感觉）需要连接到词表象（语言表达）才能被处理：
- 「头痛」→ 帮助用户说出：「我的头在替我说什么？谁让我头疼？」
- 「胃痛」→ 「有什么东西我消化不了？」
- 「疲劳」→ 「有什么重担我一直扛着？」

### 第五步：安全宣泄
目标：不是对导致创伤的人爆发（会制造新创伤），而是在**安全环境**中释放：
- 写下来（不给任何人看）
- 说出来（对信任的人）
- 身体动作（打枕头、跑步、大喊——在没人的地方）
- 艺术表达（画、唱、写）

### 第六步：整合
宣泄后需要认知整合——用新的理解接纳旧记忆：
- 「那个让我愤怒的事情，在当时的条件下，我确实无计可施」
- 「我已经不是那个无力的时候了」

## 危险信号——不要深入挖掘
如果自由谈论创伤时出现以下情况，**立即停止分析**，转为稳定化：
- 解离感（「我觉得我不在身体里」）
- 闪回（像重新经历创伤）
- 压倒性的恐慌
- 自伤冲动

→ 这些信号意味着保护屏障已被突破，需要专业创伤治疗师介入，不是自助层面能处理的。

## 🔴 CHECKPOINT：排除器质性 + 符号映射验证

第一步「排除器质性」后，强制确认：
```
🔴 用户是否已做过医学检查？检查结果是否正常？
- 未检查 → 「建议先做相关检查排除器质性原因，我们可以同时探索心理层面。」
- 已检查正常 → 继续第二步。
```

第五步「安全宣泄」后，确认：
```
🔴 宣泄是否在安全环境中进行？用户是否出现了危险信号（解离/闪回/恐慌/自伤冲动）？
- 安全宣泄 → 继续第六步整合。
- 出现危险信号 → 🛑 STOP：立即停止，转为稳定化。
```

## 失败模式与 fallback

| 触发条件 | 一线修复 | 仍失败兜底 |
|---------|---------|-----------|
| 用户在第二步说「症状一直都在，没有明确起点」 | 改问：「症状什么时候加重？加重时生活发生了什么？」 | 仍无法追溯 → 可能是慢性躯体化，建议长期心理咨询 |
| 用户说「我想哭但哭不出来」 | 正常化：「哭不出来不是你没感情——是它被保护屏障堵住了。」用身体动作替代（打枕头、跑步） | 如果身体动作也无法释放 → 不强迫，从写开始 |
| 宣泄后用户感觉更空/更糟 | 这不一定是坏事——可能是情感释放后的正常空荡感。但如果伴解离/恐慌 → 停 | → 如果持续恶化，转专业创伤咨询 |
| 用户说「我说出来后觉得更痛苦」 | 确认：是释放后的正常波动，还是创伤被重新激活？ | → 如果是后者，立即停止，转稳定化 |

## 边界
- 并非所有躯体症状都是「癔症」——必须先排除器质性病因
- 长期慢性创伤（如童年虐待）的躯体化更复杂，需专业介入
- 单纯宣泄不足够——需要后续认知整合
- 此模型来自1895年，后续理论有重大修正（尤其焦虑来源方面）
- 如果症状严重且持续，即使检查正常也要继续寻求医学帮助——不是所有未被诊断的症状都是心理性的

## 反例黑名单 —— 不要做的事

1. **不要在未排除器质性病因前断言「这是心理问题」** —— 先确认做过检查
2. **不要用「你这是在转化」来解释用户的痛苦** —— 用户的疼痛是真实的，躯体化的解释是框架不是否定
3. **不要强迫用户说出说不出口的事** —— 宣泄不是逼供，沉默本身就是信息
4. **不要在用户出现解离/闪回时继续深挖** —— 创伤屏障已突破，停就是最好的干预
5. **不要把宣泄当作终点** —— 哭出来不是治疗完成，认知整合才是

## 自检脚本

在完成每一步后执行以下自检（用 ✅ / ⚠️ / ❌ 标注）：

```
[ ] 第一步：排除器质性 — 用户做过检查且结果正常？（是 = ✅ / 未检查 = ⚠️先建议检查）
[ ] 第二步：症状到创伤映射 — 找到症状开始的时间关联事件？（有 = ✅ / 模糊 = ⚠️加重时关联 / 无 = ❌转慢性评估）
[ ] 第三步：未表达情感识别 — 用户是否说出了被堵住的情感？（说出 = ✅ / 哭不出来 = ⚠️用身体动作替代 / 完全空白 = ❌不强迫）
[ ] 第四步：词表象连接 — 症状的「象征意义」是否被探索？（头痛→「谁让我头疼」等映射 = ✅）
[ ] CHECKPOINT: 安全宣泄验证通过？（安全环境=✅ / 出现危险信号=❌ 🛑STOP转稳定化）
[ ] 第六步：认知整合完成？（用户是否重新理解旧记忆 = ✅ / 还在情绪中 = ⚠️暂缓）
[ ] 全局：危险信号监测通过？（无解离/闪回/恐慌/自伤 = ✅ / 出现 → ❌立即停止）
[ ] 全局：分析后用户是否更糟？（否 = ✅ / 正常波动 = ⚠️观察 / 创伤激活 = ❌转trauma-hysteria）
```

**通过标准**：至少 7 项 ✅，无 ❌。如有 ❌，立即执行对应 fallback。
