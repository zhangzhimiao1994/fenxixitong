# 结构模型与哀悼忧郁

**基于**：*Mourning and Melancholia* (1917e) + *The Ego and the Id* (1923b) + *An Outline of Psycho-Analysis* (1940a)

## 触发条件

### 结构模型触发
- 用户在纠结两个以上的冲突需求
- 用户说「我应该这么做但我不想」
- 用户说「我不知道自己想要什么」
- 用户过度自我批评、自我惩罚
- 用户在三种不同要求之间被撕扯

### 哀悼忧郁触发
- 丧失后的持续自我谴责和低价值感
- 失去人/地位/健康/理想/自我形象
- 自我谴责与实际不符——听起来像在说别人
- 用户说「我不够好」「我不配」「一切都怪我」
- 用户有自杀意念

## 不触发
- 简单的二元选择
- 纯认知问题（没有情感冲突）
- 情绪低落但自尊完好（正常哀悼）
- 有明确生理原因的抑郁

## 失败模式与 fallback

| 触发条件 | 一线修复 | 仍失败兜底 |
|---------|---------|-----------|
| 用户无法区分「这是结构冲突还是哀悼忧郁」 | 先看自尊：「你的自我价值感有没有严重受损？」受损→先走哀悼忧郁路线；完好→走结构模型路线 | 仍不确定 → 从结构模型的三向拆解开始（更安全、更通用） |
| 三向拆解时用户说「我不知道自己真的想要什么」 | 改问：「如果你完全不需要对任何人交代——你最想做什么？」不审不判 | → 跳过第一步，从追溯超我来源开始 |
| 「反转自我谴责」后不匹配任何对象 | 不是忧郁——可能是结构性冲突或焦虑 | → 转 `freud-classic-hub` 重新路由 |
| 用户说「我知道该放下但做不到」/哀悼停滞 | 正常化：「哀悼不是放下，是逐段告别。卡住不是失败。」确认是否矛盾情感太强（爱+恨并存） | → 超过2个月无改善 → 建议专业评估 |
| 分析后用户感觉更糟 | 停止分析，确认：是释放后的正常波动，还是创伤被激活？ | → 如果是后者，转 `freud-trauma-hysteria` 的危险信号处理 |

## 核心模型

### 结构模型——自我是三个暴君的奴仆

```
        本我（Id）
        「我要，现在就要」
        遵循快乐原则
            ↓ 压迫→
外部世界 ← 自我（Ego） → 超我（Super-ego）
「不行，   ↑   中介者      「你不配」
有后果」    ↕   谈判者      被内化的父母/权威
           焦虑←三方矛盾的结果
```

> 「自我的行动才是恰当的，当它同时满足本我、超我和现实的要求——即能调和它们的矛盾。」

**关键**：自我的大部分也是潜意识的——「你不是自己房子的主人。」

### 骑手与马
> 「自我与本我的关系，像一个骑手驾驭一匹比他强壮得多的马。骑手如果不想被甩下去，常常不得不把马引到它自己想去的方向。」

**健康的自我 = 有谈判能力。症状 = 谈判失败。**

### 超我的诞生

```
俄狄浦斯情结（对父母的爱与恨）
  ↓ 情结解体
放弃对父母的性欲对象投注
  ↓ 通过认同
将父母内化到自我中
  ↓
形成超我——一个特殊的、批判性的心理代理
  ↓
双重面孔：
  「你应该像父亲一样」（理想）
  「你不可以像父亲一样」（禁令）
```

### 潜意识罪疚感——最顽固的障碍
> 「这种潜意识罪疚感在很多神经症中扮演决定性角色，是康复的最大障碍。」

→ 「我不配好起来」的感觉不是意识层面的决定——它在潜意识中运作。

### 哀悼 vs 忧郁——鉴别诊断

| 特征 | 哀悼 | 忧郁 |
|------|------|------|
| 丧失 | 知道失去了什么 | 潜意识知道，但不知道失去了「哪部分」 |
| 自尊 | **完好** | **严重受损** |
| 自我谴责 | 无 | 有——且过度、与实际不符 |
| 本质 | 正常、健康 | 需要处理的病理状态 |
| 自杀风险 | 低 | **高** |

### 忧郁的核心机制——「对象的影子」

```
丧失对象 → 力比多撤回自身
  ↓ 不是投向新对象，而是通过「认同」吞下对象
「对象的影子落在自我上」
  ↓
自我被分成两半：
  批判性代理（超我雏形）vs 被对象染色的自我
  ↓
批判性代理攻击被染色的自我
  ↓
自我谴责 = 对被内化对象的谴责（被转移的指控）
```

> 一个女人哭诉「我丈夫被绑在如此无能的妻子身边」——实际是在指责丈夫无能。

### 自杀的机制
> 「人不能杀死自己，除非能把自己当作一个对象来对待。自杀是把针对对象的敌意转向自身。」

## 执行步骤

### 🔴 CHECKPOINT：入场鉴别
在执行任何步骤前，确认：
```
🔴 用户当前问题的主线是：
- 内心冲突（「应该但不想」「控制不住」）？→ 走结构模型路线
- 丧失后的自我谴责（「我不配」「都是我害的」）？→ 走哀悼忧郁路线
- 两者交织？→ 先哀悼忧郁（自杀风险更高，优先处理）
确认？
```

### 结构模型：三向拆解

**1. 分声音**
让用户对困难回答三个问题：
- 本我：「在这件事里，我**真的**想要什么？」（不自审）
- 超我：「我听到什么声音在说'应该/不配'？谁教的？」
- 现实：「我能实际做什么？选项是什么？」

### 🔴 CHECKPOINT：三向拆解后确认
```
🔴 验证：本我需求 = [用户说的真正想要的东西]，超我声音来源 = [追溯到的外部来源]，确认？如果不对，重新回答本我/超我问题。
```

**2. 追溯超我来源**
超我声音特别响时——追溯它的来源：
- 父亲/母亲的声音？学校的要求？领导的命令？
- **命名外部来源**——使它不再是内在的无名恐怖

**3. 重新分配权力**
- 本我需要被听到——给它安全出口（不是直接满足）
- 超我需要被审查——有些是过时的规则，可以降级
- 现实是客观的——不要与之战斗，要与之谈判

**4. 最小可行方案**
三方完全冲突时→回归基本：休息、吃饭、呼吸。不追求「完美解决」，追求「最小的生存方案」。

**5. 诊断症状 vs 模型**

| 症状 | 可能的模型解释 |
|------|---------------|
| 失眠 | 三方冲突在深夜持续→超我审查或本我要求浮现 |
| 疲劳但原因不明 | 自我持续消耗能量做三方谈判 |
| 头痛/身体症状 | 被堵住的本我能量→躯体化 |
| 过度自责 | 超我过度活跃，本我被审判 |
| 无法决定 | 自我被三方拉扯→失去谈判能力 |
| 食欲丧失 | 本我基本功能被超我压制 |

### 哀悼忧郁：鉴别与干预

**1. 确定丧失**
- 「你最近失去了什么？」（人/地位/理想/自我形象/健康/希望）
- 「什么时候开始感觉自己变差的？」

### 🔴 CHECKPOINT：哀悼/忧郁鉴别确认
```
🔴 丧失对象 = [用户提到的失去]，自尊受损 = [是/否]
- 否 → 正常哀悼，给空间，不分析。陪伴即可。
- 是 → 忧郁机制可能激活，继续下一步「反转自我谴责」
确认？
```

**2. 反转自我谴责（关键诊断工具）**
- 「如果你对自己说的那些坏话——反过来看，适不适合另一个人？那个你失去/对你失望的人？」
- 如果自我谴责可以「对号入座」到另一个人→忧郁机制确认

**3. 识别矛盾情感**
- 对已失去的对象有爱吗？有恨吗？
- 矛盾情感 = 忧郁的核心——恨无法直接表达→恨转向自己

**4. 完成哀悼工作**
- 哀悼是逐段记忆、逐一期待的现实检验过程
- 目标：接受丧失是永久的→释放力比多→投向新对象
- 如果矛盾情感太强→哀悼停滞→需专业帮助

## 反例黑名单 —— 不要做的事

1. **不要在没有鉴别「哀悼还是忧郁」之前就启动忧郁机制分析** —— 先看自尊是否受损。正常哀悼不需要病理化处理。
2. **不要在「反转自我谴责」时替用户下结论** —— 不要说「你其实是在骂你爸」，让用户自己发现。你的工作是问问题，不是贴标签。
3. **不要在用户说自杀意念后继续任何分析** —— 不管分析到哪一步，立即停止，给热线 400-161-9995。忧郁中的自杀是把对对象的攻击彻底转向自身。
4. **不要把结构模型的三向拆解当成永久解决方案** —— 「最小可行方案」是临时休战协议，不是永久和平。如果三向冲突持续超过数周无改善，需专业帮助。
5. **不要在用户说「我想通了」但情绪毫无变化时轻信** —— 忧郁的「想通」可能是理智化防御。观察情绪是否同步，不一致=仍在防御中。

## 自检脚本

在完成每一步后执行以下自检（用 ✅ / ⚠️ / ❌ 标注）：

```
[ ] CHECKPOINT: 入场鉴别通过？（分清结构冲突 vs 哀悼忧郁 = ✅）
[ ] 结构模型：三步拆解完成？（本我需求+超我来源+现实选项 = ✅，缺一方 = ⚠️补充）
[ ] CHECKPOINT: 三向拆解后验证通过？（用户确认 = ✅）
[ ] 结构模型：最小可行方案产出？（有方案且用户认可 = ✅，方案不可行 = ⚠️降级基础生命维持）
[ ] 哀悼忧郁：丧失对象确定？（能说出 = ✅，模糊 = ⚠️继续澄清）
[ ] CHECKPOINT: 哀悼/忧郁鉴别确认？（自尊完好=哀悼→不分析陪伴，自尊受损=忧郁→继续反转 = ✅）
[ ] 哀悼忧郁：反转自我谴责匹配完成？（反向命中对象 = ✅，不匹配 → 转 classic-hub）
[ ] CHECKPOINT: 矛盾情感识别完成？（爱+恨并存被确认 = ✅）
[ ] 全局：自杀意念监测通过？（无自杀意念 = ✅，出现 → 立即停止给热线）
[ ] 全局：用户是否变得更糟？（否 = ✅，波动 = ⚠️观察，创伤激活 = ❌转 trauma-hysteria）
```

**通过标准**：至少 8 项 ✅，无 ❌。如有 ❌，立即执行对应 fallback。

## 🚨 紧急信号——立即转介
如果用户说或暗示：
- 「死了更好」「我不应该存在」
- 「别人没有我会更好」
- 任何关于自杀的具体计划

→ **不要继续分析。立即提供：400-161-9995（心理援助热线）或当地精神卫生中心。**
→ 忧郁中的自杀 = 针对被内化对象的攻击性彻底转向自身。

## 边界
- 结构模型是心理动力的隐喻，不是脑科学事实
- 内源性抑郁（生物学基础）≠ 心因性忧郁——此模型主要适用于后者
- 正常哀悼持续时间因人而异，无固定时间表
- 自我谴责模式持续超2个月无改善→需专业评估
- 精神病性症状（现实检验失败）→不适用于自助
