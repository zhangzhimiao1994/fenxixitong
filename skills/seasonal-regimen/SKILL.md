# 四时调养法 (Seasonal Regimen)

## R — 原文 (Reading)

> 春三月,此为发陈,天地俱生,万物以荣,夜卧早起,广步于庭,被发缓形,以使志生,生而勿杀,予而勿夺,赏而勿罚,此春气之应,养生之道也;逆之则伤肝。夏三月,此为蕃秀,夜卧早起,无厌于日,使志勿怒。秋三月,此谓容平,早卧早起,与鸡俱兴,使志安宁。冬三月,此为闭藏,早卧晚起,必待日光,使志若伏若匿。逆其根则伐其本,坏其真矣。
>
> — 《素问·四气调神大论篇第二》

---

## I — 方法论骨架 (Interpretation)

人体状态随四季循环而有根本性的节律变化,每个季节对应一种核心气机:
春生、夏长、秋收、冬藏。调养不是笼统的"注意身体",而是根据当前季节的气机方向,
精确调整三个维度——起居(何时睡何时起)、运动(强度与方式)、情志(志向的收放)。
核心原则是"顺":起居运动情志都要与季节之气同频。逆季节行事不仅当下受损,
还会连累下一个季节——春逆伤肝则夏季无以奉长,夏逆伤心则秋季无以奉收,
形成跨季节的连锁亏损。这不是简单的"天冷加衣",而是一套可操作的年度健康调度系统。

## A1 — 书中的应用 (Past Application)

### 案例 1: 春季养生方案
- **问题**: 如何在春季保持健康、预防疾病
- **方法论的使用**: 春属木,气机方向为"生发"。起居:夜卧早起(随日照延长而推迟入睡、提前起床);运动:广步于庭(户外散步,舒展身体);情志:被发缓形、生而勿杀(放松约束,鼓励生发之志,不做压抑性的事)
- **结论**: 三维对齐春季生发之气,形成完整的春季调养方案
- **结果**: 顺应则肝气调和,逆之则伤肝,夏为寒变(到夏天会出现寒性病变)

### 案例 2: 冬季闭藏方案
- **问题**: 如何在冬季养护阳气以备来年
- **方法论的使用**: 冬属水,气机方向为"闭藏"。起居:早卧晚起必待日光(比其他季节睡得更多,等太阳出来再活动);运动:去寒就温无泄皮肤(保暖,避免大量出汗);情志:使志若伏若匿(收敛心志,不张扬不外露)
- **结论**: 冬季的一切调养目标是"藏"——把能量储藏好
- **结果**: 顺之则肾气充沛,逆之则伤肾,春为痿厥(来年春天会出现痿软厥冷之症)

### 案例 3: 四时逆行的连锁后果
- **问题**: 逆季节行事会怎样
- **方法论的使用**: 素问逐一列出逆四时的后果链:逆春气→少阳不生→肝气内变;逆夏气→太阳不长→心气内洞;逆秋气→太阴不收→肺气焦满;逆冬气→少阴不藏→肾气独沉
- **结论**: 每个季节的调养不仅关乎当季,更影响下一季的能量供给
- **结果**: 形成完整的"逆则成病链,从则苛疾不起"的预防逻辑

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 换季时身体出现不适(春困、秋乏、冬燥等),想了解如何调整生活节奏来适应
2. 制定年度健康计划或运动计划,需要知道不同季节应侧重什么
3. 长期生活作息固定不变,不考虑季节变化,出现慢性疲劳或反复生病
4. 想开始新的运动习惯或改变作息,需要选择合适的时机

### 语言信号 (用户的话里出现这些就应激活)

- "最近换季,身体总觉得不对劲"
- "一年四季应该怎么安排作息"
- "冬天/夏天要不要调整运动量"
- "春天老犯困怎么办"
- "我想调整生活节奏,但不知道怎么调"
- "有没有按季节来养生的方案"

### 与相邻 skill 的区分

- 与 `five-flavors-balance` 的区别: 五味调和专注于**饮食维度的调节**,四时调养是**起居+运动+情志三个维度的季节性调度**。四时调养中饮食只是其中一环,五味调和中季节只是参考因素之一。
- 与 `emotion-organ-proxy` 的区别: 情志脏腑模型是**从情绪推断脏腑健康并反向调节**,四时调养中情志调节是**顺应季节之气调心志方向**(春天生发、冬天收敛),两者的情志维度切入点完全不同。

## E — 可执行步骤 (Execution)

当 skill 被激活后, agent 应按以下步骤执行:

### 模板：季节调养诊断表

| 检查项 | 你的回答（选项） | → 自动判定 |
|--------|---------------|-----------|
| 当前是什么季节？ | 春 / 夏 / 长夏 / 秋 / 冬 | → 气机方向：春生/夏长/长夏化/秋收/冬藏 |
| 对应哪个脏腑？ | 春→肝 / 夏→心 / 长夏→脾 / 秋→肺 / 冬→肾 | → 重点养护脏腑 |
| 当前睡眠时间是？ | [__:__] 入睡 / [__:__] 起床 | vs 季节标准（春夜卧早起/夏夜卧早起/秋早卧早起/冬早卧晚起）→ 偏差告警 |
| 运动强度和方式？ | 高强度出大汗 / 中等 / 轻度舒展 / 几乎不动 | vs 季节标准（春舒展/夏适度/秋收敛/冬保暖不出大汗）→ 偏差告警 |
| 当前的心志状态？ | 积极生发 / 兴奋外向 / 安宁内敛 / 抑郁压抑 | vs 季节标准（春生发/夏外向/秋安宁/冬内敛）→ 偏差告警 |
| 饮食偏好的味型？ | 酸 / 苦 / 甘 / 辛 / 咸 | → 与季节对应（春少酸增甘/夏少苦增辛/秋少辛增酸/冬少咸增苦） |

**推导规则**：第 3-6 项与季节标准对比，任何一项偏差 → 标注「逆季风险」及可能的跨季节后果。

### 步骤

1. **填表判断季节气机**：锁定生/长/化/收/藏，标注对应脏腑。
2. **对齐三个维度**：起居（精确到钟点如"22:00 前入睡"）、运动（具体运动名称+时长）、情志（每天可执行的具体行为如"每天记录 3 件感恩的事"）。
   🔴 **CHECKPOINT**：展示分析结果，等待确认后再继续。
3. **检查逆季节行为并预警**：排查是否有与气机相逆的行为，指出跨季节后果。
   🛑 **STOP**：确认后输出完整方案。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 急性病症或外伤(这是养生框架,不是急救方案)
- 已有明确西医诊断的慢性病(四时调养是辅助,不能替代专业医疗)
- 用户处于特殊生理状态(孕期、术后恢复等),季节性调整需遵医嘱

### 作者在书中警告的失败模式

- 只调整一个维度而忽视其他维度(如只改运动不改作息),效果大打折扣
- 逆季节行事却不自知,比如"冬练三九"式的过度运动在素问看来是逆冬气、伤肾气
- 忽视地域差异: 素问的四时方案基于中原气候,极端气候地区需因地制宜
- **把四时调养当成精确食谱**: 素问给出的是方向性指导, 不是"几点几分必须睡"的精确命令。微观调参因人而异, 机械执行反而有害。

### Fallback（if-then 三段式）

| 触发条件 | 一线修复 | 仍失败 → 兜底 |
|---------|---------|-------------|
| 用户说不清当前季节的不适症状 | 不进入三维对齐，只用步骤1完成季节判断。问：「你最近一个月身体感觉和之前有什么不一样？」从症状倒推可能的失调维度 | 仍无具体症状 → 只给最基础的方向性建议（春生/夏长/秋收/冬藏的核心原则），不做深入调养方案 |
| 用户生活环境与自然季节严重脱节（空调房/夜班/极地） | 不以自然季节为准。重新分析人造环境气机方向：长期空调 = 寒+收（按冬）→ 需要温通；夜班 = 逆日周期 → 按昼伏夜出重建作息锚点 | 如果人造环境也难判定（如频繁出差、多时区切换）→ 以「你一天中感觉最好的那个时段」为锚点，围绕它建立固定作息，放弃季节调养 |
| 用户有慢性病且在服药 | 加前置声明：「此为辅助调养，不替代药物治疗。请与主治医生确认后执行。」给建议的同时标注药物-调养可能的交互风险点 | 用户不清楚药物交互 → 仅给最保守建议（如「保持规律作息、温和散步」），不推荐任何可能影响药物效果的饮食/运动变化 |
| 用户把四时调养当精确食谱来执行 | 纠正：四时调养是方向性指导，不是「几点几分必须睡」。问：「你是在用这个框架来理解身体的信号，还是把它当成了新的压力来源？」 | 如果用户说「我怕做错了会有严重后果」→ 调养焦虑比不调养更伤身。告知：「四时调养宁可不做，不可焦虑地做。身体不舒服了再调整，不勉强」 |
| 南半球/热带用户强行套用北半球四季 | 先确认地理位置和实际气候类型。热带 = 无四季 = 用旱雨季替代；南半球 = 季节反置 = 当前月份 - 6 个月 | 如果用户所处地区有独特气候体系（如季风/沙漠/高海拔）→ 不再用四季框架，改用该地区当地传统的气候-健康智慧做参考 |
| 只改一个维度（如只改作息不改饮食） | 警告：单一维度调整效果打折扣。四季调养是三维对齐（饮食+起居+情志），缺一维则整体效果下降 50%+ | 如果用户说「只能改一个维度」→ 优先级：起居 > 饮食 > 情志。先保证作息规律，其次才是吃 |

### 作者的盲点 / 时代局限

- 素问基于两千多年前中原地区的四季分明气候,对热带/亚热带/极地等非典型四季地区适用性需调整
- 现代生活方式(空调、暖气、人工照明)大幅削弱了人体对自然季节变化的感知,调养效果可能打折
- 现代人营养状况与古人差异巨大,"夜卧早起"等建议的具体执行标准需要现代化解读: "夜卧"=22:00-23:00(古人日落而息，现代人大部分城市日落在18:00-20:00之间，现代对应为22:00前), "早起"=05:00-07:00(古人日出而起，对应现代日出前后)。可同步给出黄帝内经原文和现代注解。

### 容易混淆的邻近方法论

- "四季穿衣饮食"是生活常识,四时调养提供的是**气机方向+三维对齐+跨季节连锁**的系统框架
- "生物钟调节"是现代科学概念,四时调养关注的是**年周期**而非日周期

## 相关 skills (阶段 3 填充)

- depends-on: yin-yang-balance — 四时调养的理论根基是阴阳平衡:春夏属阳(阳气生发),秋冬属阴(阴气封藏),调养的本质是在不同季节维持阴阳动态平衡。不理解阴阳盛虚就无法理解"春夏养阳、秋冬养阴"的原理。
- composes-with: five-flavors-balance — 四时调养覆盖起居/运动/情志三个维度,五味调和覆盖饮食维度。两者在饮食维度有交集——不同季节对应不同脏腑,脏腑的饮食调养需要五味归脏的精确配合(如春季养肝宜适当增酸减辛)。

## 反例黑名单（dim9）

| # | 不要做的事 | 为什么 | 正确做法 |
|---|-----------|--------|---------|
| 1 | 把四季调养当固定食谱——"春天必须吃X、冬天必须做Y" | 季节是框架，个体体质是变量。同样春天，阴虚者和阳虚者的调养方向相反 | 每个季节建议必须先判断用户体质，再在该季节框架内做个体适配 |
| 2 | 只关注当季，忽略季节间的过渡和连锁效应 | 春季调养不当 → 夏季阳气不足 → 秋季腹泻 → 冬季畏寒。四时是连锁的 | 每次调养建议必须标注：这个动作对下个季节有什么影响？ |
| 3 | 把"春夏养阳"简单粗暴理解成"夏天多出汗多运动" | 养阳是顺应阳气生发，不是耗散阳气。过度出汗 = 伤阳 | 区分"生发"和"耗散"：生发=适度活跃，耗散=过度消耗 |
| 4 | 四时调养变成教条——不是某季就不能做某事 | 四季框架是方向性指引，不是禁令。冬天也可以有适度活动 | 给出"核心方向 + 灵活边界"：某季以X为主，可以兼做Y但不能过度 |
| 5 | 不区分地理位置——把北半球的四季套到南方/热带用户 | 中原四季 ≠ 岭南四季 ≠ 热带旱雨季 | 先确认用户地理位置和实际气候，再做季节判断 |
