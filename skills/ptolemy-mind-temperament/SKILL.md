# 托勒密心性读法（Mind Temperament）

## 🧭 决策树

```
用户想用星盘理解自己的性格 / 思维 / 情绪风格
│
├── 出现自伤、绝望信号？ → 🛑 停止，`cross-system-hub` C5 危机话术
├── 要求诊断（"我是不是有病"）？ → ❌ 不诊断（psyche 第五节第 2 条），可在之后照常给象征读法
├── 没有出生日期？ → ❌ fortune 路由
├── 只要三要素速写或今年行运？ → ❌ astrology-transit
│
└── 有日期 + 想要古典心性解读 → ✅ 本 skill
    ├── 有时间 + 城市 → 全流程（含东西方、角宫）
    ├── 只有日期 → 水星星座通常可定；月亮当天可能换座 → 两个都列；不读宫位
    └── 用户描述了自己的具体困扰（如"反复后悔"）→ 第 6 步对照，以用户描述为准
```

## 📥 输入与证据假设

- 数据：`python tools/divine.py astro ...` 或用户软件粘贴；禁止心算。月亮纬度（原书用到）工具不提供 → 略过该条。
- 月相可由工具输出算：(月亮 − 太阳) 取 0-360，<180 = 渐盈，>180 = 渐亏。
- 主宰星强弱、"得位/失位"全部调用 `ptolemy-planet-condition` 第 3-5 步：**得位** ≈ 主场或有依托 + 东方或角宫；**失位** ≈ 客场/逆风 + 西方或果宫；其余 = 两面都有。
- 证据假设：古典象征语言，**不是人格测量**；现代研究未发现星盘与人格测验的稳定对应（Carlson 1985），"很准"的感受可由巴纳姆效应解释（Forer 1949）。把它当作自我观察的提示词。

## 📖 RIA+E+B

### R — 原文位置与转述

- 卷三第 18 章开篇（PAGE 135）：心灵中"理性与智识"的部分看水星；只涉及感觉、不依理性的部分看月亮，以及与月亮正在离相或入相的星。作者强调心灵的冲动方向很多，"不能草率判断"，要综合星座、相位、与太阳和四角的关系。
- 同章（PAGE 136）星座模式：回归（至点）星座使心投向公共事务、好名、善发明与思辨；双体星座使心多变、多才、难以捉摸、易后悔；固定星座使心公正、坚定、有耐性，也记仇、执拗、好争。东方及上升位置 → 坦率、自信、勇敢；在中天 → 稳定、记性好、审慎；西方 → 犹豫、易受影响；在天底等西方停滞位置 → 机敏但不够勤恳，好钻研隐秘与机械。
- 同章（PAGE 136-137）：主宰星在自己的位置、条件合宜 → 心性特质"精到、不受阻碍"；不在自己位置 → 仍注入本性，但"模糊而不完整"。若有相反条件压制，倾向会被挫败——善良的人也可能因此被轻视。
- 同章（PAGE 137-141）逐一列出五颗行星单独或两两组合主宰心性时，"得位"与"失位"两种表现；如木星得位慷慨、虔敬、好学，失位则慷慨变挥霍、虔敬变偏执、谦逊变怯懦（PAGE 139）。
- 同章末（PAGE 141）：月亮渐盈且在上升 → 增加机敏与坚定；渐亏或不可见 → 更迟重、更犹疑。太阳与心性主宰星相连时，得位则增其"正直与荣誉感"，失位则放大缺点。

### I — 白话解释

托勒密把性格看成"思考的发言人（水星）+ 感受的发言人（月亮）+ 管着它们的那颗星"。最有用的是他的写法：**每种特质都成对出现**——同一股力量，条件好是优点，条件差是它的影子（慷慨/挥霍，谨慎/吝啬，机敏/浮躁）。这让解读不落入"你是好人/坏人"，而是"你的这股力量在什么条件下会变形"。

### A1 — 书中应用（转述）

- 水星单独主宰且得位：审慎、聪明、善学、善论证、长于推测；失位：什么都想插手、仓促、健忘、多变、易后悔、不够真诚（PAGE 141）。
- 土星与水星相连且得位：好钻研、善法律医学一类的精细学问、警觉、沉思、勤于事务；失位则变得琐碎、记仇、疏离家人（PAGE 138-139）。
- 金星与水星相连且得位：爱艺术与哲学、学得快、能自学、言谈愉悦（PAGE 140-141）。

### A2 — 未来触发场景

1. "我做决定总是反复，做完又后悔" → 若月亮/水星在双体星座且主宰星失位 → 古典规则对"多变、易后悔"的描述；对应的高版本是"多才、能看到多种可能"。行动：给反复的决定设"48 小时 + 一个不可撤回的小承诺"。
2. "朋友说我太倔，但我觉得是坚持原则" → 固定星座 + 主宰星状态：同一特质的两面（坚定/执拗、公正/记仇），由用户自己判断此刻在哪一面。
3. "我脑子很快，但总是三分钟热度" → 水星东出但失位 → 机敏与浮躁并存；行动：每周只保留 1 个"必须完成"的项目。

### E — 执行步骤

1. **安全筛查**：自伤、绝望、要诊断 → 先按 psyche 第五节处理；危机时终止本 skill。
2. **取数据**，展示一行（☿ 星座度数、☽ 星座度数、☉、↑）。🔴 **CHECKPOINT 1**：日期不确定 → 停下核对；月亮当天换座且无时间 → 两个月亮星座都列，后面的判断并列。
3. **找心性主宰**：分别找水星所在星座、月亮所在星座中拥有庙/三分性（按昼夜）/旺的行星。
   - 同一颗行星同时管着两处，或与水星同星座/有相位 → **单一主宰**；
   - 否则 → "思考由 X 主导、感受由 Y 主导"两条线。
4. **读四层**（每层只取 1-2 个特质）：
   a. 星座模式：水星与月亮各在启动 / 固定 / 双体（白羊巨蟹天秤摩羯 / 金牛狮子天蝎水瓶 / 双子处女射手双鱼）；
   b. 位置：东方或在上升 / 在中天 / 西方 / 在天底（有时间才读）；
   c. 主宰星本性及得位/失位（调用 condition）；
   d. 月相（渐盈/渐亏）与太阳是否和主宰星相连。
5. 🔴 **CHECKPOINT 2（成对改写 + 去道德化）**：把每个特质写成"高版本 / 低版本"一对；原书失位描述里的"盗贼、通奸者、渎神、邪恶"等**一律不输出**，只保留可观察的行为倾向（如"在压力下容易冲动消费"）。没有低版本的结论不完整，没有高版本的结论是恐吓。
6. **事实对照**：用户若描述过自己，以用户为准，标出"这一条和你说的一致 / 不一致"。
7. **条件化**（托勒密：相反条件会挫败或改变倾向，PAGE 137）：为最主要的那一对，写出"什么条件让你更常在高版本"——作息、环境、节奏、可求助的人。
8. 给 1 个最小行动，执行 `fortune` 第三节语言转换。

#### 如果这一步失败

| 触发条件 | 一线修复 | 兜底 |
|---|---|---|
| 工具不可用 | 安装依赖后重跑 | 请用户粘贴水星、月亮、太阳星座；仍无 → 只用太阳星座的模式（启动/固定/双体）给 1 对特质，注明精度很低 |
| 水星、月亮主宰星不明确（多颗并列） | 用显眼度排序取前一颗 | 两条线并列 |
| 用户说"一点都不像我" | 感谢反馈，问哪一面更像；巴纳姆效应提醒 | 不坚持，转为用户自述的特质做"高低两面"练习 |
| 用户把低版本当成"我就是坏人" | 回到 I：低版本是条件差时的形态，不是本质 | 情绪持续低落 → psyche |
| 用户要拿来判断别人（伴侣、同事） | 说明只读本人、且不作评判依据 | 改为讨论两人的互动情境 |

### B — 边界

- **不是诊断，不是人格测验**。卷三第 19 章用星盘判断癫痫、"疯狂"、"附魔"，以及以古代道德观判断性别气质与性行为——本 skill **完全不使用**（见 REJECTED R8、R9）。
- 不给他人贴性格标签；不评道德好坏；不预测"会犯罪""会出轨"。
- 现代研究不支持星盘与人格的对应；输出必须写"这套古典规则认为"，并邀请用户以亲身经验核对。
- 与 astrology-transit 区分：那边是现代心理占星的三要素速写；这里是古典的"水星-月亮-主宰星"结构与高低两面。

## 💬 输出格式

自然段落，≤450 字，按序：
1. 一行盘面（来源、精度）
2. 心性主宰是谁（1 句，术语 ≤2 个并括注）
3. 2-3 对"高版本 / 低版本"（用"这套规则认为……条件好时……条件差时……"）
4. 与用户自述的对照（有则写）
5. 一条"让高版本更常出现的条件" + 1 个最小行动
6. 结尾："古典象征读法，不是性格测验；你比盘更了解自己。" + 唯一 1 个问题

**示例**（1990-01-08 07:30 上海：水星摩羯 20°，月亮双子 4.5°，太阳摩羯 17°、土星摩羯 16°，昼生，月亮渐盈）：
> 盘面：工具排盘，回归黄道，精度较好。你的水星在摩羯、紧挨土星，月亮在双子，而白天出生时双子的三分性主是土星——所以这套古典规则会说，土星同时管着你的"想"和"感"，是心性的主宰。土星与水星相连，条件好时是钻研、警觉、做事精细；条件差时会变成琐碎、对小事耿耿于怀。水星落在摩羯这种"启动"星座，规则说你会想参与公共的事、爱琢磨新办法；月亮在双子这种"双体"星座，条件好时多才、灵活，条件差时容易反复、事后后悔。你提到过总想太多，这一条和"反复"那一面是吻合的。规则还说，月亮渐盈时比较有韧劲，所以让你更常在好的一面的条件，可能是给决定设截止时间。这周可以试：每个犹豫超过一天的决定，写下"最坏结果"和"可接受的第一步"，然后只做那一步。这是古典的象征读法，不是性格测验，你比盘更了解自己。哪一对最像你？
