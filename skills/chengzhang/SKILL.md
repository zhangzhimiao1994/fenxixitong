# 成长维度 (Chengzhang) —— 心态 路由

## 被总入口调用时：段落契约

- 输入：用户原话、深度等级、本段是完整还是一句带过、主要矛盾是否落在成长、主要矛盾段是否已点出那句自我判决
- 本段必须包含：
  1. 那一刻的解释链："[事] → 读成'[那句评价]' → [之后怎么做]"（"方案被否 → 读成'我不行' → 不再改"）。那句评价已被主要矛盾段引过 → 链里写"读成那句判决"，不再加引号；原话没给"之后怎么做" → 链只写前两环，不补第三环
  2. 卡在哪一步：写"读成"那一下；原话指向别的环节时写那一环
  3. 贯穿解释时：一条链盖住两件事（"两件事都被读成'我不行' → 两边都不动"），并把它标为主要矛盾候选交给总入口；某一头原话只有对方的行为、没有用户自己的反应 → 那一头只写原话里有的，不补"两边都不动"
- 一句带过时写什么：细节取那句评价所指的那件事，再拆掉标签——那句评价是那一刻的解释，不是结论；其余按总入口 4.4，不写"说明的是……"一类填充句
- 主要矛盾落在成长 → 一律按完整写
- 篇幅：完整约占全文 1 成（主要矛盾在成长时约 1.5 成）；一句带过 1 句
- L1 保留：解释链，并成 1 句
- 可提交的候选问题：④"让你最难受的，是哪一刻你对自己的那句评价？"（对不上路由表时）；⑤ 子 skill 的待问项
- 本段禁止：写给用户时用"判决"这个词（说"那句对自己的评价"）；解释自己写法的句子（"虽然那边你只讲到他的反应"）；再引主要矛盾段引过的原话（已点出判决时，直接从解释链写起）；同一句式连用两次；门槛句（能力自评不算情绪低落，门槛只由总入口 STEP 0 写）；`mindset-reaction-diagnosis` 的槽位句和对照句（"把它当信息的人会先问……"）；做法；"固定型/成长型"标签；评论方法本身
- 本维度特有的失败分支：
  - 没给具体时刻（"我什么都做不好"）→ 用他提到的最近一件具体事当那一刻，不追问
  - 只由 1 件事引出、原话只有一个环节 → 降为一句带过
  - 裁员、歧视、贫困等外部结构因素是主因 → 先承认外部因素，链只写用户可控的那一小块
  - 暴力场景 → 按 `guanxi` 契约"各层的边界"
- 选用哪些子 skill：第二节路由表取最靠上的 1 行
- 格式、篇幅、提问、收尾、危机话术：见总入口全局契约（单独使用时也一样）

> 心理维度问"这个声音从哪来"，成长维度问"失败、批评、别人成功的那一刻，你怎么解释，下一步怎么做"。

一句话模型：同一件事，被解释成"证明我不行"就会躲开下一次，被解释成"我还能学"就会再试。来源：《终身成长》Carol Dweck。

## 一、执行顺序

1. 🛑 **STOP 安全筛查**：命中自伤/自杀信号 → 只执行 `cross-system-hub` C5，本轮结束。情绪低落、持续多久的处理归总入口 STEP 0（判据见 `psyche` 契约的归类表）；"我什么都做不好"这类能力自评本身不算情绪低落
2. **选子 skill**：查第二节路由表，选 1 个。行序就是"诊断 → 干预 → 维持"，命中多行时取最靠上的那行。输出：`子 skill：X / 依据原文："…"`
3. 🔴 **CHECKPOINT**：核对用户说的是对**自己能力**的评判；"我想做却做不到" → 转 `xingdong`；"我是谁 / 为什么总是这样" → 转 `psyche`；两边都不像 → 提交候选④
4. **交给子 skill，只取素材**：只返回"那一刻的解释链 + 卡在哪一步"；子 skill 自带的结尾提问（如"脑中第一句话"）作为候选⑤提交

### 失败处理
| 触发条件 | 一线修复 | 仍失败兜底 |
|---------|---------|-----------|
| 裁员、歧视、贫困等外部结构因素是主因 | 先承认外部因素，只看用户可控的一小块 | 用户不想谈心态 → 本段降为一句带过 |
| 用户说"我早知道成长型思维，没用" | 转 `mindset-false-growth-check` | — |
| 用户用"固定型"给别人贴标签（"我老板就是固定型"） | 改为讨论具体那句话、那次反应 | — |
| 子 skill 无法加载 | 用一句话模型扣原话写解释链 | 写不出链 → 降为一句带过 |

## 三、单独使用时

内容按段落契约写，另可把"下次那一刻先说的一句话"放进步骤；格式、篇幅、提问、收尾见总入口全局契约。总入口里只剩本维完整时不转到这里，见总入口 STEP 1。

## 四、边界

1. **不是诊断**：固定型/成长型是"在这件事上的此刻倾向"，不是人格标签
2. **证据强度**：只在用户问"有没有用、有没有依据"时说一句——成长型思维干预的效应量在大规模研究中很小。其余时候不评论方法本身，也不承诺"换个心态就会好"
3. **结构因素优先**：外部压力造成的问题，不归因到心态
4. **节食、体重相关**：先筛"催吐、暴食后补偿、体重快速下降、月经停止"，命中 → 请去医院心理科或进食障碍门诊评估
