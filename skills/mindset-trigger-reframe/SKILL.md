# 触发点识别与转化

> 改变不像换髋关节，旧信念不会被摘掉，新信念长在旁边，越来越强（Ch8 PAGE 117）。本 skill 的目标不是让那个声音消失，而是让它说完之后，你照样做下一步。

版本说明："给固定型人格起名字、列触发点清单"的练习出自 2016 年修订版，本次所用 2006 年初版没有。本 skill 以初版 Ch8 的"内心独白"和困境练习为骨架，触发点识别是据此整合（inference）。

## 🧭 决策树

```
用户想改一个反复出现的反应
│
├── 自伤/自杀念头、长期抑郁焦虑 → 🛑 psyche 第五节 / 转专业帮助
├── 酒精、药物、赌博等成瘾 → 🛑 转介专业帮助，不用本 skill 替代治疗
├── 愤怒已升级为肢体伤害 → 🛑 先处理安全，转介专业帮助
├── 说不出具体触发情境 → ❌ 先用 mindset-reaction-diagnosis
│
└── 能说出至少一个具体触发情境 → ✅ 激活
    ├── 触发后主要是自我贬低 → 步骤 2 改写独白
    ├── 触发后主要是攻击别人 → 步骤 2 + 步骤 4 的"离开—写下—回来"
    └── 改过但反弹 → 步骤 5 维持；若反复反弹 → mindset-false-growth-check
```

## 📥 输入与证据假设

- 必需：一个反复出现的触发情境 + 那一刻脑中的原话 + 通常接着做什么。
- 可选：最近一次发生的时间；用户已经试过什么办法。
- 证据假设：书中的转变故事（学生来信、工作坊）多为作者自选的成功案例；具体计划能提高执行率有独立研究支持（书中引用 Gollwitzer，PAGE 125），但"改思维"本身的长期效应在大规模研究中很小（Sisk et al. 2018；Macnamara & Burgoyne 2023）。所以承诺的只有"一个可执行的下一步"，不承诺"性格改变"。

## 📖 RIA+E+B

### R（原文位置与转述）

- Ch8 PAGE 118：作者借认知疗法的起源说明，人在情绪袭来之前，脑中会闪过一句很快的话；人一直在给发生的事做"实时解说"。固定型的解说是评判（"这说明我是个失败者 / 我比他们强 / 我伴侣自私"），成长型的解说是"我能学到什么、怎么改进、怎么帮对方做好"。
- Ch8 PAGE 118, 124：认知疗法会把"我很蠢"调成"我没那么差"，但仍停在评判框架里；成长型还要多走一步——学习和改进。
- Ch2 PAGE 29：读者告诉作者，知道两种思维后，会在固定型发作时"抓住自己"——错过学习机会、被失败贴标签、需要大量努力时泄气——然后切换去接受挑战、从失败中学、继续努力。
- Ch8 PAGE 124–125：被心仪研究生院拒绝后，"成长一步"是打电话询问怎样改进申请；关键动作是那通电话。
- Ch8 PAGE 125：发誓没用，具体到"何时、何地、怎样做"的计划执行率高；情绪很差也可以照计划做。
- Ch8 PAGE 123–124：改变难，因为固定型曾经给过人一条获得自尊和爱的路；放下时会不安，旧声音会说"你什么都不是"，催你赶紧去赢一把。
- Ch8 PAGE 131–133：节食和控制愤怒，固定型把它当"有没有意志力"，一失败就骂自己；成长型把它当要学的策略，提前计划、预期挫折、问"下次在这个情境我怎么做"。愤怒时可以先离开、写下最难听的想法和"其实可能发生了什么"，冷静后再回来。
- Ch8 PAGE 133–134：改善后常常停止做那件有效的事，于是反弹；要问"我需要做什么来维持"。
- 引用 1 处：作者让读者在镜子上贴一句，"Regardless of how bad you may feel, do it!"（Ch8 PAGE 134）

### I（白话解释）

触发点是那种"一碰就切回打分模式"的情境：被排名、被拒、出错、被比下去、破戒。切回去的标志是脑中那句自动解说——它不是在描述事情，而是在给你定性。

转化分三步：①听见那句话（命名它）；②在它旁边写一句学习式的话（不必相信得很满，只要能指向下一步）；③把下一步写成具体计划，并预先想好"失败了怎么办"和"成功了怎么维持"。重点在第三步：作者反复强调，真正起作用的是那通电话、那张写好的计划，而不是想法本身。

### A1（书中案例）

- 作者的学生论文被顶级期刊审稿意见批得体无完肤，几个月不敢碰；作者告诉她"挑毛病是审稿人的工作，你的工作是用意见把论文改好"，她几小时内就开始修改，之后再收到批评都用这句话提醒自己（Ch8 PAGE 123）。
- 申请被拒的人先自我安慰"太竞争了"，又被内心声音推翻"你就是平庸"；作者指出这只是自我对话，真正的一步是打电话问改进方法（Ch8 PAGE 124–125）。
- 朋友想在同学会前减肥，只靠"少吃一点"的意志力，一破戒就说"我搞砸了"然后点甜点；作者建议提前把一半饭菜打包等具体办法，他坚持"我要靠意志力"，最后速成节食后反弹（Ch8 PAGE 131）。
- 伴侣没倒垃圾引发人格攻击的困境：先弄清自己为何被激怒（感觉不被重视），再直说感受、请求对方的回应，必要时离开写下想法再回来（Ch8 PAGE 132–133）。

### A2（未来触发场景）

1. 周一部门公布业绩排名，用户排在后三分之一，脑中立刻响起"你就是不如别人"。
2. 投稿或面试被拒，用户想直接放弃这个方向。
3. 戒夜宵第五天破戒，用户想"反正已经破了，今天干脆吃个够"。

### E（执行步骤）

1. **定位触发点**：请用户说出最近一次的具体情境（时间、地点、谁在场、发生了什么）。只处理一个触发点。
2. **记下原话并改写**：
   - 原话（评判式）："这说明我……"
   - 改写（学习式）：一句指向下一步的话，例如"这次排名告诉我哪个指标落后了""被拒说明申请材料里有可以改的地方""破戒是一次数据，说明晚上十点是高危时段"。
   - 不要求用户"相信"改写句，只要能指向一个动作。
3. 🔴 **CHECKPOINT**：改写句里不能出现"我是……的人"（无论褒贬），也不能只是更乐观的安慰（"其实我也不差"）；必须包含一个可学、可改的对象。不过关回到步骤 2。
4. **写成具体计划**：何时（具体时间点）、何地、怎样做（第一个动作是什么），用户能在脑中"看见"自己在做。攻击别人型的触发点，加一条"离开—写下最难听的想法和可能的真实情况—冷静后回来"的预案。
5. **预设挫折和维持**：
   - "如果下次又被触发、又按老路做了，我会问：我从这次学到什么？下次在同样情境改哪一步？"
   - "如果有效了，我要继续做的是……"（防止见效即停）
6. **安排回看**：约定一到两周后回看一次计划执行情况，只看做了没有，不看人格好坏。

#### 如果这一步失败

| 触发条件 | 一线修复 | 兜底 |
|---|---|---|
| 用户说"那个声音太强了，改写句我根本不信" | 说明不需要相信，作者本人至今仍会有短暂的无力感（PAGE 117） | 跳过改写，直接执行第 4 步的具体动作 |
| 计划太大（"我要彻底变自信"） | 缩成一个本周能做、十分钟以内的动作 | 只保留"何时"和"第一个动作" |
| 用户执行一次失败就说"我果然不行" | 把这次失败当作步骤 5 的材料，问"卡在哪一步" | 降低难度，重新写计划 |
| 情绪低到无法行动，且持续多日 | 不再要求"照样做"，询问睡眠和日常功能 | 转 psyche；有危机信号按第五节 |
| 触发点涉及伴侣反复争吵 | 本 skill 只处理用户自己的独白和预案 | 关系循环转 eft- |
| 触发点涉及成瘾行为 | 不替代治疗 | 转介专业帮助 |

### B（边界）

- **证据强度**：书中转变故事是作者挑选的成功案例；思维干预的平均效应很小（Sisk et al. 2018；Macnamara & Burgoyne 2023 在控制偏倚后接近零）。"具体计划提高执行率"有较好的独立支持，但也不保证结果。
- **版本**：给固定型"人格"起名、触发点清单是 2016 修订版内容（reliable-secondary），不在本文本，不得引用页码。
- **不是治疗**：本 skill 不处理临床抑郁、焦虑障碍、创伤、成瘾。书中"越难受越行动"的研究（PAGE 24–25）不适用于抑郁用户。有自伤 / 自杀信号 → psyche 第五节危机话术；用户问诊断 → 不做诊断。
- **安全**：愤怒已导致肢体冲突或威胁 → 先保证安全，转介专业帮助，不只做认知练习。
- **不是什么都要改**：作者说并非所有能改的都该改，有些不伤害自己和他人的不完美可以接受（PAGE 31）。
- 失效情形：触发情境是真实的持续伤害（霸凌、职场羞辱）时，首要任务是离开或改变环境，而不是改自己的解读。

## 💬 输出格式

1. 一句接住（承认这个声音很有力）。
2. 把用户那句原话写出来，点明它在给自己定性。
3. 给一句学习式改写。
4. 给一个"何时—何地—第一步"的计划，加一句"如果又被打回去，就问……"。
5. 一个问题（全文只这一个），用来确定计划的时间点或第一步。

不写 skill 名，不讲认知疗法理论，不写长清单。

**示例**（用户："每次月度排名出来我都在后面，脑子里就一句'你就是不如别人'，然后整天没心思干活。我想改掉这个。"）

```
排名一出来就被那句话压住一整天，挺消耗人的。
"你就是不如别人"不是在说排名，是在给你下结论。
可以在它旁边放一句："这张表告诉我哪一项落后了。"不用马上相信它，它的作用只是把你带到下一步。
计划可以这么定：排名公布当天下午三点，花十五分钟只看自己最弱的那一项，写下一个这周能试的改法，周五找做得好的同事问一句他怎么做的。如果哪天又被那句话拖走一整天，就问自己：这次是在哪一刻被拖走的？
排名一般是哪天、什么时间公布的？
```
