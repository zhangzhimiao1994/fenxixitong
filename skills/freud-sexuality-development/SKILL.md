# 力比多发展与性心理模型

**基于**：*Three Essays on the Theory of Sexuality* (1905d)

## 触发条件
- 用户问「我为什么总是这样」「我的性格是怎么形成的」
- 用户注意到反复出现的关系模式（过度依赖、控制欲、洁癖等）
- 用户询问性取向、性心理相关的问题
- 用户的症状涉及基本生理功能的丧失或异常（厌食、暴食、性欲丧失）
- 用户提到早期家庭关系对现在的影响

## 失败模式

| 如果… | 那么… | 理由 |
|-------|-------|------|
| 用户描述的模式明显是短期压力反应 | 走 `freud-anxiety-civilization` | 焦虑信号模型更适合区分现实/神经症性 |
| 「我不够好」+ 自我理想过度苛责 | 走 `freud-narcissism-identification` | 性格模式如果根在自我理想冲突，自恋模型更准 |
| 模式涉及强迫性重复 + 自我破坏 | 走 `freud-death-drive-repetition` | 性心理固着 vs 强迫重复需要区分 |
| 前两步映射不确定 → 用户无法把模式和阶段联系起来 | 不要强行映射；回归现象描述——「先描述你注意到的模式，不急着归因」 | 避免用理论套活人的陷阱 |
| 以上所有路由均未匹配或仍无法分类 | 退回到 `freud-development-overview` 全景导航，让用户自行选择对应 skill | 不强行分类 |

## 不触发
- 纯生理疾病的诊断（需先排除器质性）
- 用户没有主动探寻性格来源
- 简单的行为习惯问题（没有深层心理困扰）

## 核心模型

### 三大颠覆

**颠覆一**：性欲不是青春期才出现——婴儿从一开始就有性欲。
**颠覆二**：性对象和性目的是分开的、可以变异的——不是天然绑定的。
**颠覆三**：神经症的核心是性冲突——症状是被压抑的性冲动的替代表达。

### 力比多（Libido）的定义
力比多 = 性本能的能量形式。像液压系统——可以转移、被压抑、可量化。
> 流向对象越多，留给自我的越少——反之亦然。
> 升华 = 力比多从性目标转向非性目标（艺术、工作、创造）。
> 被堵住的力比多 = 症状。

### 性心理发展阶段

```
口欲期（0-1岁）
  快感区：口唇
  心理主题：接受、依赖、吸收
  固着后果 → 过度依赖、被动、口欲性格（吸烟、暴食、话多）
  
肛欲期（1-3岁）
  快感区：肛门
  心理主题：控制、清洁/脏乱、施虐快感
  固着后果 → 过度控制/洁癖（肛欲滞留）或混乱无序（肛欲爆发）
  
阴茎期（3-6岁）
  快感区：生殖器
  心理主题：俄狄浦斯情结、阉割焦虑、竞争与认同
  固着后果 → 与权威的持续冲突、竞争焦虑、性身份困惑
  
潜伏期（6岁-青春期）
  性欲休眠，能量转向学习和社会化
  
生殖期（青春期+）
  各成分整合，指向完整的对象关系
```

### 固着如何形成
某个阶段获得过多或过少的满足 → 力比多「粘」在那个阶段 → 成年后压力下退行到该阶段。

### 升华
性冲动可以被引向「更高」的社会目标：「文明本身就是性欲被压抑和升华后的产物。」
升华是健康的——但过度压抑会导致神经症。

### 双性恋
「所有人在原初意义上都是双性恋的——最终对象选择取决于发展中的多种因素。」
同性恋 ≠ 退化/疾病——弗洛伊德明确反对病理化。

## 执行步骤

### 第一步：识别性格模式
帮助用户描述他们注意到的模式：
- 「我总是……」→ 过度控制？过度依赖？反复竞争？
- 这个模式对应哪个发展阶段？

### 第二步：映射到发展期
| 模式 | 可能的发展期固着 |
|------|-----------------|
| 过度依赖、被动、「没有你我活不了」 | 口欲期 |
| 过度控制、洁癖、完美主义 | 肛欲期 |
| 与权威持续冲突、竞争焦虑 | 阴茎期（俄狄浦斯未解决） |
| 性欲丧失或性功能问题 | 可能多个阶段 |

### 第三步：寻找退行信号
当用户处于压力时——他回到了哪个阶段的行为？
- 压力下暴食 → 口欲退行
- 压力下变得控制狂 → 肛欲退行
- 压力下对领导异常愤怒 → 俄狄浦斯退行

### 🔴 检查点 1（进入第四步前必须确认）
- [ ] 用户是否处于严重退行（丧失基本身体快感、暴食/厌食）？
  - 是 → 第四步优先于所有其他步骤——先恢复身体，不分析
  - 否 → 跳过第四步，走第五步
- [ ] 如用户有进食障碍（厌食/暴食）且体重显著变化 → **停止自助，引导就医**

### 第四步：恢复基本身体快乐
如果用户处于严重退行（如抑郁期食欲丧失）：
- 不先解决心理——先恢复身体的基本快感
- 吃一点想吃的东西、温暖的触感、阳光 → 口欲/皮肤快感的恢复
- 「恢复的第一步是从最基本的身体快乐开始」

### 🔴 检查点 2（第五步后，给出升华建议前必须确认）
- [ ] 用户当前是否有自杀意念或自伤行为？
  - 有 → **停止分析，立即提供：400-161-9995（心理援助热线）**
  - 否 → 继续
- [ ] 升华建议是否指向了用户不可得的资源（如「你应该去学画画」，但用户没钱/没时间）？
  - 是 → 调整建议，匹配用户当前可及资源
  - 否 → 继续

### 第五步：找到健康的升华出口
- 不是压抑本能——是给它一个社会可接受的方向
- 创造力、学习、运动都可以是力比多的健康出口

## 反例——不要做的事

1. ❌ **不要把每个性格特征都硬套到性心理阶段。** 人是复杂的——性格由遗传、环境、文化、经历共同塑造。此模型提供一个视角，不是唯一解释。
2. ❌ **不要暗示同性恋与某个「固着阶段」有关。** 弗洛伊德本人明确反对病理化，任何暗示「某种性取向 = 发展失败」的解读都是对理论的滥用。
3. ❌ **不要在用户处于进食障碍急性期时继续心理分析。** 体重显著下降/上升时，生理优先于心理——先救身体。
4. ❌ **不要用「你妈妈/你爸」解释一切。** 性心理阶段是隐喻性框架，不是精确时间线——「你的问题是肛欲期固着」这种说法毫无帮助且冒犯人。
5. ❌ **不要暗示「你应该克服这个阶段」。** 本模型是理解工具，不是规范工具。不存在「应该达到生殖期才是健康的」这种价值判断。

## 边界
- 性阶段理论是隐喻性的，不是精确的生物时间表
- 弗洛伊德对女性的性心理发展论述有明显缺陷（阴茎嫉羡等）——后来被大量修正
- 「所有问题都源自性」是早期极端主张——弗洛伊德自己后来扩展了焦虑来源
- 同性恋不是疾病——这一点弗洛伊德本人已明确表态
- 不是所有性格特征都能追溯到婴儿期性心理——这是弗洛伊德的简化
