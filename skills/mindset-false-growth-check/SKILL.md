# 假成长型思维审计

> "我是成长型"一旦变成身份声明，就又回到了固定型的逻辑。本 skill 只看做法和效果之间的落差，不判定人。

## 🧭 决策树

```
用户说"我/我们已经是成长型了，但……"
│
├── 自伤信号、躯体症状、失眠≥2 周、拿概念指责具体的人 → 🛑 步骤 1（规则只写在步骤 1）
├── 只在某类事件后失眠、未满 2 周 → ✅ 继续激活，输出第 4 条加一句睡眠提醒
├── 说不出"说法"或"现实"其中之一 → 🔴 步骤 3：先给通用替换动作，用唯一问题补
│
└── 有"说法 vs 行为 / 结果"的落差 → ✅ 步骤 2–8
    ├── 个人层面 → 检查 1–4
    └── 家庭 / 学校 / 团队层面 → 检查 1–5
```

## 📥 输入

- 必需：用户口中的"成长型做法"具体是什么（说了什么、做了什么制度），以及没变化的证据（行为、结果或气氛）。
- 可选：持续时间；出现落差的具体时刻（如犯错后、考核前）。

## 📖 RIA+E+B

### R（原文位置与转述）

- Ch2 PAGE 28：很多固定型的人读过"失败是机会、努力是关键"之类的书却做不到，因为底层信念在说相反的话。——**知道 ≠ 换了框架**。
- Ch2 PAGE 30–31：拼命工作、也接受挑战的人仍可能是固定型：仍在展示天赋、受不了错误和批评。——**高努力 ≠ 成长型**。
- Ch2 PAGE 30：作者明确否认"失败就是你不够努力"，并指出有资源的努力更容易成功。——**只夸努力会把结构问题个人化**。
- Ch8 PAGE 130–131：高努力可能是在证明自己、怕失去认可（胃溃疡女儿，见 A1）。——**努力跑偏**。
- Ch8 PAGE 133–134：仍在固定型里却使用成长型策略，可能适得其反（父亲 Wes，见 A1）；改变不是挑几个窍门，而是从"评判与被评判"转向"学习与帮助学习"。——**只学技巧不换框架、见效即停**。
- Ch7 PAGE 113：教练对球员潜力是成长型，对自己执教能力却是固定型，球队得每场替他证明。——**对别人成长型、对自己固定型**。
- Ch7 PAGE 115–116：连续成功会让团队觉得"我们有天赋所以会继续赢"。——**成功后回落**。
- 引用 1 处：作者说思维改变不是"picking up a few tricks"（Ch8 PAGE 133）。

### I（白话解释）

真正的检验只看两件事：①出错、被批评、看到别人更强的时候，第一反应是不是还在打分；②除了"努力"之外，有没有换方法、找帮助、看结果。

组织里的常见版本：墙上写"拥抱失败"，考核里犯错的人被点名。员工信制度，不信标语。

### A1（书中案例）

- 父亲 Wes 在用了尊重孩子努力、表扬共情的做法后，儿子行为大有好转；他觉得问题解决了就停下，孩子再犯时他更生气，因为"已经证明能做到却不做"（Ch8 PAGE 133–134）。
- 拌嘴的夫妻咨询后互相肯定、感情回温，又因"好关系不该这么费力"停下，再吵更凶（Ch8 PAGE 134）。
- 优秀女儿的胃溃疡：父母只让她早睡、没减少要求，于是更糟；有效的是暂停长笛课、为理解而学、换压力更小的学校（Ch8 PAGE 130–131）。

### E（执行步骤）

1. 🛑 **STOP 安全与越界筛查**
   - 输入：用户描述。
   - 核对并分流（本 skill 唯一的安全规则处，只有这里能整轮停下）：自伤/自杀信号 → 只输出 psyche 第五节危机话术，停止；躯体症状（胃痛、呕吐、心悸）或失眠≥2 周且影响白天功能 → 健康优先，先减负，转 psyche，第一句写"先照顾身体，去医院消化科/心理科或睡眠门诊"，停止审计；事件后失眠未满 2 周（含连续几晚到一周多） → 继续，输出第 4 条加睡眠提醒，并写明"满两周或影响白天上班就先去睡眠门诊"；用户要拿"假成长型"指责具体某人 → 不做人身判定，改看用户自己能做的就事论事反馈。
   - 输出：停止 / 继续（附安全句或越界说明）。
2. **写下"说法"和"现实"**
   - 输入：用户描述。
   - 做法：由你各提炼一句——"以为自己在做的成长型做法是……"，"但实际看到的是……"，不让用户填写。
   - 输出：说法句 + 现实句。
3. 🔴 **CHECKPOINT 1（信息核对）**
   - 核对：说法和现实是否都有？
   - 缺一项 → 仍给可用内容：第 1 条 + 按已知信息给一个通用替换动作 + 唯一问题（缺说法问"你们具体是怎么做的？"，缺现实问"哪件事让你觉得没变？"）；用户回答后从步骤 4 继续。
   - 用户其实没有自认成长型，也说不出出问题的时刻 → 转 mindset-reaction-diagnosis。
   - 输出：继续 / 只给通用版 / 转出。
4. **逐项检查**
   - 输入：说法句 + 现实句。
   - 做法：由你根据用户已给信息判定"是 / 否 / 不确定"，不向用户逐项提问；只有判为"不确定"且最关键的那一项，才用输出第 5 条的唯一问题去问；各项都已确定时，那个问题改问一个让替换动作落地的细节。每项"判为是的最低证据"写在箭头后：
     1. **口头化**：出错、被批评、看到别人更强的那一刻，第一反应还是"这说明我不行 / 他比我强"吗？（PAGE 28）→ 用户描述了出错后的自评句或回避行为（失眠、想辞职、躲）。
     2. **只夸努力**：表扬里有没有点到具体策略、求助和结果变化？努力没换来进步时，有没有换方法？（PAGE 30；Dweck 2015/2016）→ 用户引用的表扬语只有努力词、没有策略词。
     3. **努力为证明服务**：高投入背后是"想学会"，还是"怕被看不起 / 怕失去认可"？身体或睡眠是否在报警？（PAGE 30–31, 130）→ 用户说出"怕被看不起/怕失去认可"，或提到躯体症状。
     4. **只换技巧、见效即停**：方法见效后是否停用了？回落时是否更生气？（PAGE 133–134）→ 用户提到"后来没那么注意了/停了"。
     5. **制度与标语不一致**（组织层面）：犯错、提出异议、承认不会的人实际受到什么对待？排名、分层、公开比较是否仍是主要激励？对员工/学生是成长型，对管理者自己是固定型吗？（PAGE 113, 134）→ 用户提到犯错被罚、排名公示或分层照旧。
   - 输出：每项一个判定。
5. 🔴 **CHECKPOINT 2（定性之前）**
   - 输入：五项判定。
   - 核对：判"是"的项必须有上面的最低证据。全部为"否"时，不硬找问题——告诉用户可能是干预本身效应很小，或真正卡点在外部（资源、制度、健康）。多项同时为"是"时按优先级取一项：3（努力为证明/健康）> 5（制度）> 2（只夸努力）> 4（见效即停）> 1（口头化）。
   - 输出：一项偏离 / 全否。
6. **选一个最先改的**
   - 输入：选定的一项。
   - 做法：给一个具体替换动作（例：把"你很努力"改成"你这次换了什么方法？结果比上次怎样？"；把"允许试错"落成"每月例会第一个议题是一个失败复盘，主讲人不受考核影响"）。组织层面按输出第 3 条的组织槽位写（例：教研组长牵头、作业讲评只评策略、看换方法的学生人数；可能抵消它的是排名公示）。
   - 输出：一项偏离 + 机制一句 + 一个替换动作。
7. **设回看点**
   - 输入：替换动作。
   - 做法：写进输出第 3 条末尾，并约定"见效后继续做"（PAGE 133）。回看时长按层级取：个人 2–4 周（看同类事件后第一句话、当晚能否入睡）；团队一个绩效周期或 8 周（看敢开口的人数）；学校一个学期，用期中、期末两次数据（看换方法的学生人数）。
   - 输出：一句回看点。
8. 🔴 **CHECKPOINT 3（发送前）**
   - 输入：整段回复。
   - 核对：全文 ≤300 字；只有第 5 条一个问号；没有列出五项清单；组织场景第 3 条含谁来做 + 制度改动 + 指标 + 可能抵消它的现行制度；回看时长与层级一致。
   - 输出：可发送 / 按输出格式的删减顺序压缩后再核对。

#### 如果这一步失败

| 步骤 | 触发条件 | 一线修复 | 仍失败兜底 |
|---|---|---|---|
| 1 安全 | 用户回答"不安全"或说出具体方法 | 重复 120/110，请对方现在就打给身边的人 | 陪着聊到对方说已联系上，之后不做审计 |
| 1 睡眠 | 失眠介于偶发与 2 周之间（如连续一周） | 继续审计，第 4 条写明"满两周或影响白天就去睡眠门诊" | 用户说已影响上班 → 按 2 周规则转 psyche |
| 1 安全 | psyche 不可用而出现危机信号 | 直接给：全国心理援助热线 12356、希望24热线 400-161-9995，紧急拨 120/110 | 请用户现在联系一个信任的人 |
| 1 越界 | 用户坚持要"证明他是假成长型"的论据去怼人 | 指出这会把概念变成新的标签，不提供攻击论据 | 只讨论用户自己能做的就事论事反馈，转 mindset-process-praise 场景 D |
| 3 信息 | 说法或现实缺一项 | 给通用替换动作 + 唯一问题 | 第二轮仍缺：按个人层面检查 1 给替换动作，标"推测" |
| 4 证据 | 组织用户给不出犯错后的真实处理 | 请他回想最近一次谁在会上承认失误、后来怎样 | 按检查 2 给通用替换动作并标注推测 |
| 5 多项 | 多项同时为"是" | 按 CHECKPOINT 2 的优先级取一项 | 只选用户原话里证据最直接的那项 |
| 5 否认 | 用户坚持"我们做得很对，就是没效果" | 请他举出最近一次有人犯错后的真实处理 | 说明干预平均效应本来很小，结果不变不等于做错 |
| 6 越界 | 用户要的是推行方案而非审计 | 先给五项检查作为方案的验收标准 | 说明具体课程方案超出本书范围，只给"先改一个处理犯错的规则" |
| 6 权限 | 组织问题用户无权改变 | 把范围缩到用户能影响的小团队或自己的反馈方式 | 交给 mindset-process-praise 改个人措辞；不可用时只给一句替换话术 |
| 6 自责 | 用户因"原来我是假的"而更自责 | 说明作者本人也长期在两种思维间来回（PAGE 117） | 只留一个小动作，不再列检查项 |

### B（边界）

- **术语使用**："假成长型思维"一词不在 2006 初版，提到它时只说"作者后来补充的说法"，不配页码；五项检查后的页码均指初版原文。
- **证据强度**：大规模研究显示思维干预效应很小（Sisk et al. 2018 元分析；Macnamara & Burgoyne 2023 元分析在控制研究质量后效应接近零；Yeager et al. 2019 显示效应集中在低成就学生且依赖学校氛围）。所以"没效果"可能是正常的，不要把责任全推给执行者。
- **结构优先**：资源不足、考核机制、歧视造成的问题，靠改心态解决不了（PAGE 30）。
- **安全**：见步骤 1。
- 失效情形：用户只想要推行方案而非审计 → 本 skill 只能给检查清单（处理见失败表"6 越界"行）。

## 💬 输出格式

分支输出：步骤 1 停止 → 只输出安全句与去处；步骤 3 缺信息 → 第 1 条 + 通用替换动作 + 一个问题。

常规回复顺序固定，全文 ≤300 字，每段 ≤2 句（第 2 条的术语半句、第 4 条的睡眠提醒不计入句数；步骤 6–7 → 第 3 条）：
1. 一句承认落差令人困惑。
2. 指出最可能的一项偏离（只说一项），扣回用户原话，并用一句话说出机制（如"知道 ≠ 那一刻的第一反应""标语 ≠ 犯错后的真实后果""夸努力 ≠ 帮他换方法"）。用到"假成长型"一词时，附半句"这是作者后来补充的说法，不是说你假"。
3. 二选一：个人 → 一个具体替换动作 + 回看点；组织 → 谁来做 + 一个制度改动 + 衡量指标 + 回看点，并点出一个可能抵消它的现行制度。
4. 一句诚实提醒：这类做法本身效应不大，别期待一夜见效；个人场景有失眠时再加一句睡眠提醒（持续两周以上就先照顾睡眠、去心理科或睡眠门诊）。
5. 一个问题（全文只这一个，前四条不出现问号）。

**保留常识**：baseline 里常见、不冲突的实用常识（如"找领导确认改进方向""看教学本身有没有给挑战和反馈"）压成半句并进第 3 或第 4 条。

**超过 300 字时的删减顺序**：先删保留常识半句 → 术语说明半句压成"这是作者后来的说法" → 效应提醒压成"效果本身不大"。睡眠提醒和安全句永不删。

不写 skill 名，不列五项清单给用户，除非用户要求完整审计。

**示例 1：个人**（用户："我一直说失败是成长的机会，可健身教练一纠正我的动作，我就想换一家健身房。"）

```
嘴上说失败是机会，一被纠正就想走，这种落差确实让人困惑。
最可能的偏离是口头化：你说的"失败是机会"停在了"知道"，教练开口那一刻的第一反应还是"这说明我不行"——知道 ≠ 那一刻的第一反应。
下次被纠正后，当场只问教练一句"这个动作我先改哪一处"，练完在手机上记一行；三周后看被纠正时还想不想走，见效也别停。
这类调整效果本身不大，别期待一次就不难受。
教练纠正你时，你脑子里闪过的第一句话是什么？
```

**示例 2：组织**（用户："我们部门年初就说要建立成长型文化，鼓励大家试错，可到现在没人敢在周会上讲自己搞砸的事。"）

```
口号喊了大半年，大家还是不敢讲失败，确实让人泄气。
最可能的卡点不在口号，而在大家看到的真实后果：标语 ≠ 犯错后的真实待遇。
先改一个规则：由你本人牵头，周会第一项固定为"搞砸了学到什么"且不进考核，一个绩效周期后看主动讲的人数，见效也别停；绩效里的"零失误"加分会把它抵消。
也诚实说一句：这类改变效果有限，别期待一两次就扭转。
上一次在周会上承认失误的人，后来发生了什么？
```

## 反例黑名单

| # | 反模式 | 为什么 | 替代做法 |
|---|---|---|---|
| 1 | "你这就是假成长型思维" | 人身判定，把概念变成新标签 | "这个做法和你想要的效果之间有落差" |
| 2 | 把只夸努力当成长型 | 努力无效时没人帮着换方法 | 夸具体策略，并看结果有没有变 |
| 3 | 见效就停 | 书中父亲停用后孩子回落、他更愤怒（PAGE 133–134） | 设回看点，约定继续 |
| 4 | 墙上贴标语，考核照旧罚错 | 员工信制度不信标语 | 先改一个处理犯错的真实规则 |
| 5 | 把成绩不变全怪执行者 | 干预平均效应本来就小 | 说明效应小，再排查做法 |
| 6 | 对高努力 + 胃痛失眠的人说"方向对就继续" | 安全风险：书中女儿已是胃溃疡（PAGE 130–131） | 先减负、就医、转 psyche |
| 7 | 用"我已经是成长型了"当身份标签自我安慰 | 身份声明本身就是固定型逻辑 | 只看出错那一刻的第一反应和是否换了方法 |
| 8 | 一次向用户列出五项检查清单 | 信息过载，用户不知道先改哪个 | 只说最可能的一项，完整清单仅在用户要求审计时给 |
