# Response Action

## R - 原文

> 九二：履道坦坦，幽人贞吉。

> 九四：履虎尾，愬愬，终吉。
> 九五：夬履，贞厉。

## I - 方法论骨架

《周易》对危机响应的讨论不是"要不要反应"，而是"怎么反应才是对的"。

**履卦**：行动本身就是踩在虎尾上——任何行动都有风险。关键区别：素履（朴素直接）、坦履（正道而行）、夬履（决断但危险）、愬愬（战战兢兢、反而终吉）。履不是不怕虎，是知道自己在虎尾上还能不惊慌。

**震卦**：突发的冲击。方法论是"不丧匕鬯"——震来时守住手中的祭祀器具（核心职责）。震不是让你跑，是让你在该在的位置上不丢手。从"震来虩虩"（惊慌）到"笑言哑哑"（恢复从容），从"震苏苏"（吓得发抖）到"震行无眚"（在震动中继续走）。

**噬嗑卦**：咬合与清除障碍。六个爻刻画了处置难啃问题的不同难易度——从咬皮肤（容易）到咬腊肉（中毒）、咬干肉带骨头（费力但得金矢）、咬到最后刑具加身（过头了反而凶）。核心智慧：处置要匹配硬度，咬太轻无效，咬太过自伤。

**夬卦**：决断。核心张力在"扬于王庭"（公开宣告）和"不利即戎"（不要直接开战）之间。决断不是冲上去干，而是五步法——宣告立场→警惕夜袭→独自坚持→牵羊（以小代价转移注意力）→中行（不偏激）。上六"无号，终有凶"警告：决断不能没有宣告和信号。

这个 skill 帮用户做四件事：
1. 校准行动的风险意识和心态（履——踩虎尾）
2. 判断危机冲击中的稳定点（震——不丧匕鬯）
3. 匹配处置力度到问题硬度（噬嗑——咬合）
4. 执行有节制的决断（夬——决而不莽）

## A1 - 书中的应用

### 案例 1：履卦的行动心态

- 问题：每次行动都像踩虎尾一样危险。
- 文本动作：六三"眇能视，跛能履"——一只眼看不清，一条腿走路，还去踩虎尾，必被咬。九四"履虎尾，愬愬，终吉"——知道危险所以战战兢兢，反而没事。
- 方法论：危险不是问题，对危险的无知才是问题。敬畏导致谨慎，谨慎导致安全。
- 结果：现实中做高风险决策时，恐惧本身不是负面信号——它让你"愬愬"（警惕），从而"终吉"。

### 案例 2：震卦的核心稳定

- 问题：突发冲击来了怎么办。
- 文本动作："震惊百里，不丧匕鬯"——百里之内都被震动了，但主事者手里的祭祀器具没掉。六二"亿丧贝，跻于九陵，勿逐，七日得"——大量财产丢了，但不追，先往高处去，七天后自然回来。
- 方法论：危机第一反应不是追损失、不是找原因、不是指责。第一反应是：我手里最核心的东西（职责、底线、关键人）还在不在？丢了的东西"勿逐"——不要追着过去的损失跑。
- 结果：现实中面对危机时，先问"我现在最不能丢的是什么"，而不是"损失了什么"。

### 案例 3：噬嗑的咬合力度

- 问题：遇到障碍不知道该用多大力。
- 文本动作：四个难度等级——噬肤（容易，无咎）→噬腊肉遇毒（中等难度，会中毒，但仍无咎）→噬干胏得金矢（难啃，但得到金箭头，有回报）→何校灭耳（咬太过，刑具加身，凶）。
- 方法论：不是所有障碍都要全力去啃。先判断硬度：浅层问题轻处理，中等问题预期有代价但值得，深层问题需要付出代价但有收获，但如果咬到了自己承受范围之外就该收手。
- 结果：现实中处理违规、冲突、坏账、烂项目时，先判断"硬度"再匹配"力度"。

### 案例 4：夬卦的五步决断

- 问题：该决断的时候怎么决断。
- 文本动作：
  1. 扬于王庭——公开宣告意图
  2. 惕号——保持警戒（"莫夜有戎，勿恤"）
  3. 独行遇雨——独自坚持（"若濡有愠，无咎"）
  4. 牵羊悔亡——用小代价换取主动权
  5. 中行无咎——走中间路线不极端
  6. 上六警告：无号终有凶——不宣告等于没决断
- 方法论：决断不是冲动的一刀切，而是宣告→警戒→坚持→迂回→中行的完整流程。
- 结果：现实中做重大决断（裁员、分手、辞职、起诉）时，对照这五步检查是否缺了哪步。

## A2 - 触发场景

### 用户会在什么情境下需要这个 skill?

1. 突发事件或危机需要立即响应策略。
2. 面对高风险行动，需要校准心态和风险意识。
3. 需要做一个重要决断但不确定该怎么做。
4. 在处理障碍/冲突/违规时，不确定该用多大力度。
5. 用户读到履、震、噬嗑、夬等卦想转成行动框架。

### 语言信号

- "突然出事了怎么办"
- "这件事我该不该硬干"
- "震卦的危机应对怎么做"
- "决断是不是就是冲上去"
- "处理这个人/这件事该用多大劲"
- "踩虎尾是什么意思"
- "噬嗑的咬合怎么用"

### 与相邻 skill 的区别

- 与 `advance-retreat-boundary` 的区别：本 skill 处理"怎么响应"，后者处理"能不能动"。
- 与 `line-position-timing` 的区别：本 skill 处理突发响应，后者处理阶段判断。
- 与 `humility-overreach-check` 的区别：本 skill 处理危机中的决断力度，后者处理成功后的过度。

## E - 可执行步骤

1. **判断冲击类型**
   - 完成标准：区分是履（行动本身有风险）、震（突发冲击）、噬嗑（需要清除障碍）、夬（需要做决断）中的哪种。
2. **确定核心稳定点**
   - 完成标准：在冲击中，列出最不能丢的 1-3 样东西（类似震卦的"匕鬯"）。
   🔴 **CHECKPOINT**：在进入下一步之前，将分析结果展示给用户，等待确认后再继续。

3. **匹配响应力度**
   🛑 **STOP**：请确认上一步的分析结果后再继续。

   - 完成标准：
     - 如果履：选素履/坦履/愬愬/夬履之一
     - 如果震：给出"勿逐"的清单和"守住"的清单
     - 如果噬嗑：判断障碍硬度，匹配力度（轻/中/重/过头）
     - 如果夬：按五步法给出宣告→警戒→坚持→迂回→中行的具体动作
4. **设定退出信号**
   - 完成标准：明确什么信号出现时应该收手（噬嗑上九的"何校灭耳"信号，夬上六的"无号"信号）。

## B - 边界

### 不要在以下情况使用

- 没有紧迫性的日常规划和战略思考。
- 用户需要的是情绪安抚而非行动框架。
- 涉及法律诉讼、医疗急救等需要专业意见的场景。
- 用户的问题纯属假设性讨论，没有现实危机。

### 反例黑名单（不做什么，什么情况下这个 skill 不灵）

| # | 反例模式 | 为什么危险 | 正确姿势 |
|---|---------|-----------|---------|
| 1 | **把所有行动都说成履虎尾** | 制造不必要恐慌，让用户对常规行动也过度敬畏 → 行动瘫痪 | 只有"后果严重且不可逆"才是履卦场景。日常决策不需要履虎尾 |
| 2 | **噬嗑判断力度过重** | 对小问题下重手（跳过屦校灭趾直接到何校灭耳）→ 关系破裂 | 严格按阶梯：初九警告 → 六二轻罚 → 六三中等 → 九四攻坚 → 六五重手。不可跳级 |
| 3 | **夬卦决断变成鼓励冲动** | 跳过"告自邑"步骤直接公开宣告 → 内部分裂 | 夬卦五步不可跳：告自邑（内部统一）→ 孚号（警戒）→ 即戎（行动）→ 牵羊（迂回）→ 中行（守中） |
| 4 | **震卦"勿逐"被理解成放弃追索** | 时间轴混淆：危机中 = 勿逐 ≠ 永久放弃 → 丧失合法权利 | 时间轴要分：危机当下（勿逐）vs 危机过后（追索）。两个阶段处理方式不同 |
| 5 | **把无关问题判为"危机"** | 过度使用震卦框架 → 用户长期处于应激状态 | 震卦核心测试："你手里最不能丢的东西还在吗？" 还在 → 不是真危机 |

### 失败模式

- 把所有行动都说成履虎尾，制造不必要的恐慌。
- 噬嗑判断力度过重，鼓励用户对小问题下重手。
- 夬卦的决断变成鼓励冲动，跳过了宣告和警戒步骤。
- 震卦的"勿逐"被理解成完全放弃追索合理权益。

### 来源边界

本 skill 依据履、震、噬嗑、夬四卦经文，不延伸到后世兵法或危机管理理论。

### Fallback（if-then 三段式）

| 触发条件 | 一线修复 | 仍失败 → 兜底 |
|---------|---------|-------------|
| 用户把履虎尾的敬畏变成行动瘫痪 | 纠正：愬愬不是不行动，是行动时保持觉知。问："如果你知道风险但还是必须做，最小的一步是什么？" | 如果用户仍不敢动 → 用履卦初九"素履往，无咎"——什么都不带、最朴素地走一步 |
| 噬嗑的力度判断让用户对小问题下重手 | 回撤：噬嗑从轻到重有阶梯。"屦校灭趾"（治小错轻罚）排第一。大多数问题"噬肤"层面就能解决 | 如果用户认为"不下重手对方不听" → 检查是否跳过了初九（轻罚警告）直接到了六五（重度处置）。初九没做就上六五 = 程序错误 |
| 震卦"勿逐"被理解成放弃合理追索 | 纠正："勿逐"是危机当下的第一反应——不要追着损失跑。时间轴要分清：危机中=勿逐，危机后=追索 | 如果危机已过但用户仍"勿逐" → 判定：现在处于哪个时间轴？危机中还是危机后？不同阶段不同策略 |
| 夬卦决断五步中跳过了"告自邑"（内部宣告）就去"扬于王庭"（公开宣告） | 停止：这是顺序错误。先内部统一再向外宣告 | 如果内部有反对者 → 夬九三"君子夬夬，独行遇雨，若濡有愠，无咎"——坚持但允许自己被淋湿（被抱怨）。先统一到"至少不拆台"级别再宣告 |
| 把所有问题都判为"震"（危机），制造过度恐慌 | 不是所有突发都是震卦。检查：这真的是"震惊百里"级别吗？如果影响范围局限、核心未受威胁 → 可能是履卦级别的常规行动风险 | 如果用户持续恐慌 → 用震卦核心测试："你手里的匕鬯（最不能丢的东西）还在吗？"还在 → 不是真危机，是焦虑 |
| 震卦"不丧匕鬯"被理解成"什么都不用做只管守住" | 守住核心职责后要做第二步：六二"跻于九陵"——往高处去（看到全局）；六三"震行无眚"——在震动中继续走 | 如果用户说"我守住了但不知道该做什么" → 给两个动作：① 站高处看全局（什么变了什么没变）② 走一步小行动 |
