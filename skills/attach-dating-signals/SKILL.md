## 🧭 决策树

```
用户在约会初期 / 单身择偶
│
├── 有自伤信号？ → 🛑 psyche 第五节
├── 对方已有威胁、跟踪、强迫？ → 🛑 安全优先（B 段）
├── 已经确立关系很久？ → ❌ attach-style-reading 或 attach-anxious-avoidant-trap
│
└── ✅ 约会几次到几个月 / 单身中
    ├── "他忽冷忽热要不要继续" → 步骤 2–5
    ├── "好人没感觉，坏人放不下" → 步骤 2 + 6
    ├── "错过他就没人了" → 步骤 5（丰富心态）
    └── 用户自己总在亲近后想逃 → 回避分支（步骤 7）
```

## 📥 输入与证据假设

- 需要：认识多久、见过几次、对方具体做了什么（回复节奏、计划方式、对用户提出的事怎么回应）、用户自己的感受变化。
- 约会初期信息少，判断要轻；但作者认为初期恰恰最该对所有信号一视同仁，而不是只看好的（PAGE 51）。
- 默认用户是在相互自愿、未承诺排他的阶段；同时认识几个人要合乎双方约定，不欺骗。

## 📖 RIA+E+B

### R（原文位置 + 转述）

- 第5章 PAGE 90–91：和若即若离的人在一起，混合信号让依恋系统一次次被拉响，偶尔的甜头带来极高的快乐，久了人会把这种焦虑、着迷和短暂狂喜当成爱。作者明说"an activated attachment system is not passionate love"（PAGE 91）。真正的爱更像内心安定。
- 第5章 PAGE 93–95：遇到安全型的人，信息一致、不玩游戏，警报不响，焦虑型的人反而觉得"没火花"。Chloe 就这样错过了 Trevor，后来在一段贬低她的婚姻里吃了很多苦。
- 第5章 PAGE 96：常见约会建议（别太主动、装忙、等对方先联系）确实让人更有吸引力，但吸引来的多是回避型，因为你把"多近多远"的决定权交给了对方。
- 第5章 PAGE 97–103 约会五步：①承认并接纳自己对亲密和安全的需要；②及早识别并排除回避信号；③做真实的自己，直接表达需要；④丰富心态：同时认识多个人，别太早押注一个；⑤遇到安全型，给他一点时间，别因"平淡"就放弃。
- 第5章 PAGE 97–98 "冒烟的枪"：混合信号；渴望理想关系但暗示不会是你；总能挑出毛病让承诺不可能；无视你的感受，被指出后依然无视；说你太敏感、太黏；对不方便的话题不回应或转移；像在法庭上一样只回应事实；你的话怎么说都传不过去。作者强调看的是**情感立场**，不是某个具体行为。
- 第5章 PAGE 92–93：作者推理，约会池里回避型的比例比人群里高（他们更常分手、更快回到约会市场，安全型一旦稳定就很少再出来）。这是推理，不是测量。
- 第7章 PAGE 132–134：安全型择偶的做法：很早识别信号并当作出局理由；从第一天起就表达需要；相信合适的人很多；不为对方的冒犯行为自责；期待被尊重地对待。
- 第11章 PAGE 207–208 与尾声 PAGE 236：对方事先声明"我没准备好承诺"，并不意味着你就只能接受他的条件。

### I（白话解释）

心跳加速、整天想他、一条消息就能让你开心一整天又失落一整天，这不一定是"很爱"，也可能是警报一直在响。平静、可预期的人，开始可能显得"没劲"，但那是因为你的警报终于停了。择偶时要问的不是"他喜不喜欢我"，而是"他能不能给我我需要的东西"（PAGE 50、97）。

### A1（书中案例的应用）

- Janet 被前男友甩后，对方回来求复合。她选择"让他定节奏、给足空间"，结果关系慢慢淡掉，对方连分手都没说就消失了。作者建议她当时直接说清楚自己需要什么，这样要么对方站出来，要么早点结束（PAGE 99–100）。
- Nicky 每次感情都撑不过几周，她让朋友帮忙介绍、同时用几个交友平台，一年里见了很多人。她不再把每次失败当成自己有问题，遇到冷淡的人能直接放下，最后遇到了温暖稳定的 George（PAGE 101–103）。
- Tanya 只和一开始就明确表示兴趣、不玩游戏的人继续；对方怠慢她时，她认为这说明的是对方，而不是她自己的价值（PAGE 132–133）。
- Jena 40 岁后在第一次约会就说明想尽快要孩子，吓退了一些人，但遇到了想法一致的 Nate（PAGE 201）。

### A2（未来触发场景）

1. 用户和一个"超有感觉"的人约会一个月，对方回复时快时慢、从不提前约。
2. 用户相亲认识一个稳定体贴的人，"挑不出毛病但不心动"，想拒绝。
3. 用户总怕"错过这个就没人要了"，对一个不太在乎她的人一再迁就。

### E（执行步骤）

1. **安全筛查**：威胁、跟踪、强迫 → B 段；自伤 → psyche 第五节。
2. **区分"心动"和"警报"**：问三个问题：和他在一起后，你平时是更安定还是更焦虑？你的好心情是不是主要取决于他有没有回？你是否常在猜他的意思？多数是后者 → 很可能是被激活，不等于爱。
3. **对照"冒烟的枪"**：逐条对照，每条要有具体事件。看的是"你的感受对他重不重要"这一立场，单次回复慢不算。
   🔴 **CHECKPOINT**：命中的信号是否有 ≥2 条、来自不同场合？是 → 进入步骤 4 测试；否 → 信息不足，继续观察，不急着下结论。
4. **做一次直接表达测试**：选一个具体、合理的需要（比如"我希望约会能提前一两天定"），用 attach-secure-communication 的方式说。看对方是认真接住还是闪躲、嘲笑、说你想太多。两三次闪躲，基本可以作为出局理由（PAGE 204）。
5. **丰富心态**：在合乎约定的前提下，多认识人，别在只见过几次时就把全部希望押在一个人身上。这样依恋系统不会被一个人牢牢牵住，也更敢直说需要（PAGE 100–101）。
6. **给安全型一点时间**：对方一致、守时、愿意回应你，只是"没火花"时，先多约两三次再决定，留意你是不是把"平静"误读成"没感觉"（PAGE 103）。但这不是逼自己接受真的不喜欢的人。
7. **回避分支**（用户自己一靠近就想逃）：当突然觉得"他不对劲"时，先停一下，问这是不是在找理由拉开距离；别拿前任或理想型来比；每天记一件对方让你受益的小事；一起做事时更容易放下防备（PAGE 120–122）。

#### 如果这一步失败

| 触发条件 | 一线修复 | 兜底 |
|---|---|---|
| 用户只说"有感觉/没感觉"，没有事实 | 问最近三次见面或聊天的具体经过 | 先做步骤 2 的三个问题 |
| 用户不敢做直接表达测试 | 从最小、最不敏感的需要开始 | 请朋友帮忙改词，先对朋友说一遍 |
| 测试后对方回应模糊 | 一次不够，换个时机再试一次 | 两三次都模糊，就按"没接住"处理 |
| 用户觉得同时认识几个人"不道德" | 尊重其价值观，说明核心是"别太早押注"，不一定要同时约会 | 改为放慢排他速度、多看对方的一致性 |
| 用户反复回到同一个冷淡的人 | 指出这可能是警报在驱动，不是判断 | 转 attach-anxious-avoidant-trap 的离开分支 |

### B（边界）

- **回避不等于坏人**：作者也说回避者有依恋需要，只是在压抑（第6章）。本 skill 判断的是"合不合适你"，不是给对方定性。
- "约会池里回避者更多"是作者的推理（inference），不能当成统计事实，更不能用来解释每一次约会失败。
- "冒烟的枪"不能凭一次行为成立；对方可能在抑郁、离婚后、或另有隐情（Hillary 案例，PAGE 200–201）。
- 给安全型时间，不等于说服用户和不喜欢的人在一起。
- "同时认识多人"受文化、价值观和双方约定限制，不能欺骗任何一方。
- 书中多为异性恋、西方约会文化的例子，其他情境要按用户实际调整。
- 依恋只是择偶的一个角度，价值观、生活目标、安全等同样重要。
- 对方有跟踪、威胁、强迫性行为 → 不讨论"合不合适"，先保护自己，必要时拨 110。
- 出现自伤或"没人要就不想活"类信号 → psyche 第五节危机话术。

## 💬 输出格式

按顺序：
1. 一句接住。
2. 一句点出这是"心动"还是更像"警报在响"，扣回原话。
3. 已看到的信号（最多 2–3 条）和还缺的信息。
4. 一个具体的下一步（一次直接表达，或放慢、多认识人）。
5. 一句边界（不是给对方定性 / 信息还少）。
6. 一个问题（全文只问这一个）。

**示例**（"约会一个月，他有时秒回有时两天不回，从不提前约，但见面时特别热情，我该继续吗？"）
```
忽冷忽热最磨人，你会不停地在"他喜欢我"和"他不在乎"之间来回跳。
从你说的看，你的心情很大程度上取决于他回没回，这更像警报一直在响，不一定代表你们特别合适。
不提前约、回复忽快忽慢，是值得留意的信号；但还不知道你提过需要时他怎么回应。
下一步可以直接说："我更喜欢提前一两天约好，这样我心里踏实。你觉得可以吗？"看他是认真接住，还是一笑带过。
这不是在给他定性，只是看他能不能给你需要的东西。
如果他答应了却还是临时约，你打算给几次机会？
```

## 反例黑名单

| # | 反模式 | 替代做法 |
|---|---|---|
| 1 | 教用户"欲擒故纵、别太主动、装忙" | 直接表达需要，这才能筛掉不合适的人（PAGE 96） |
| 2 | 把"整天想他、患得患失"当成爱得深 | 区分警报与心动（PAGE 90–91） |
| 3 | 凭一次回复慢就判"回避型" | 至少两条、不同场合的信号 |
| 4 | 劝用户"他说了不想认真，你就别要求" | 对方的免责声明不等于你只能接受（PAGE 207–208、236） |
| 5 | 用户被冷落后，帮她分析"是不是我哪里做错了" | 对方的怠慢更多说明对方（PAGE 133–134） |
| 6 | 劝用户放弃"没火花"的人或硬撑下去 | 多约两三次再决定，不强迫 |
