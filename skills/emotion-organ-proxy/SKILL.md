# 情志脏腑关联模型 (Emotion-Organ Proxy)

## R — 原文 (Reading)

> 怒伤肝,悲胜怒;喜伤心,恐胜喜;思伤脾,怒胜思;忧伤肺,喜胜忧;恐伤肾,思胜恐。百病生于气也,怒则气上,喜则气缓,悲则气消,恐则气下,寒则气收,炅则气泄,惊则气乱,劳则气耗,思则气结。
>
> — 《素问·阴阳应象大论篇第五》/《素问·举痛论篇第三十九》

---

## I — 方法论骨架 (Interpretation)

情绪不是单纯的心理现象,而是有明确生理方向的气机运动。每种核心情绪对应一个脏腑,
且有特定的气机方向:怒→气上(肝)、恐→气下(肾)、喜→气缓(心)、悲→气消(肺)、
思→气结(脾)、惊→气乱。长期处于某种情绪,对应的脏腑就会因气机偏颇而受损。
反过来,利用五行相克的原理,可以用一种情绪来制约另一种情绪——悲胜怒(金克木)、
恐胜喜(水克火)、怒胜思(木克土)、喜胜忧(火克金)、思胜恐(土克水),
这就是"以情胜情"的调节术。但这不是简单的"用开心对抗悲伤",
而是有一套严格的情绪→脏腑→气机→调节策略的分析链。

## A1 — 书中的应用 (Past Application)

### 案例 1: 怒则气上的生理路径
- **问题**: 愤怒为什么会导致具体身体症状
- **方法论的使用**: 举痛论详述:怒则气逆,甚则呕血及飧泄。气机向上冲逆,上则呕血(气迫血上溢),下则飧泄(肝木乘脾土)
- **结论**: 一次暴怒就可能导致气血上逆(头痛面红)和消化紊乱的双重症状
- **结果**: 形成了"情绪→气机方向→具体症状"的完整推理链

### 案例 2: 恐则气下的生理路径
- **问题**: 恐惧为什么会导致下肢和泌尿问题
- **方法论的使用**: 恐则精却,却则上焦闭,闭则气还,还则下焦胀。恐惧使精气下退,上焦不通,气机全部下坠,导致下腹胀满、二便失常
- **结论**: 恐惧的气机方向是"向下向内收缩",对应肾的封藏功能过度
- **结果**: 解释了极度恐惧时"腿软""失禁"等现象的气机机制

### 案例 3: 以情胜情的治疗术
- **问题**: 如何不用药物调节情绪过激造成的脏腑损伤
- **方法论的使用**: 阴阳应象大论给出五组"以情胜情"关系。例如:一个人过度愤怒伤肝,可以用悲来制约(悲胜怒,金克木);一个人过度思虑伤脾,可以激发怒来破除(怒胜思,木克土)
- **结论**: 情绪本身既是致病因素,也是治疗工具,关键是利用五行相克来制约
- **结果**: 形成了一套不依赖药物的纯情绪调节疗法

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 长期处于某种强烈情绪中(持续愤怒/焦虑/悲伤/恐惧),开始出现身体症状
2. 出现不明原因的身体不适,怀疑可能与近期情绪状态有关
3. 想了解特定情绪会对身体造成什么长期影响,以便自我觉察
4. 需要用一种情绪来化解另一种过激情绪(如用运动发泄愤怒来破除过度思虑)

### 语言信号 (用户的话里出现这些就应激活)

- "我最近一直在生气/焦虑,感觉身体也出问题了"
- "情绪不好的时候身体也跟着不舒服"
- "为什么我一生气就头疼/胃疼"
- "有没有办法不靠药物调节情绪"
- "长期焦虑/悲伤对身体有什么影响"
- "我控制不住自己的情绪,怎么办"

### 与相邻 skill 的区分

- 与 `observation-inference` 的区别: 以外测内推理法是从**外部可观察信号**(面色/脉象/声音)推断内部状态,情志脏腑模型是从**情绪**推断脏腑状态。两者都是推断内部的方法,但信号来源不同——前者是物理信号,后者是情绪信号。
- 与 `seasonal-regimen` 的区别: 四时调养中的情志调节是**按季节方向调整**(春天生发、冬天收敛),情志脏腑模型是**按具体情绪类型分析脏腑影响并选择调节策略**。前者是时间驱动的,后者是情绪驱动的。

## E — 可执行步骤 (Execution)

当 skill 被激活后, agent 应按以下步骤执行:

1. **识别用户当前的主导情绪**
   - 完成标准: 已从用户描述中识别出当前最强烈、最持续的情绪类型(怒/喜/悲/恐/思/惊中的一种或几种)

2. **映射到对应脏腑和气机方向**
   - 完成标准: 已将主导情绪映射到对应脏腑(怒→肝、喜→心、悲→肺、恐→肾、思→脾)和气机方向(上/下/缓/消/结/乱),并指出可能的身体症状

   🔴 **CHECKPOINT**：在进入下一步之前，将分析结果展示给用户，等待确认后再继续。

3. **选择调节策略(疏导或以情胜情)**
   🛑 **STOP**：请确认上一步的分析结果后再继续。

   - 完成标准: 已根据情绪类型给出两种调节路径:
     - 疏导:让该情绪自然流动而非压抑(如允许悲伤哭泣而非强行振作)
     - 以情胜情:利用五行相克关系选择制约情绪(如悲胜怒、恐胜喜),并说明如何安全地引入制约情绪
   - 判停条件:若用户情绪状态极度不稳定,直接中断本分析,输出以下固定话术: "你当前情绪极度不稳定，以情胜情方法有加重风险。请先拨打 400-161-9995（24小时心理危机干预热线）寻求专业帮助，稳定后再回来。"

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 严重的心理疾病(抑郁症、焦虑症、创伤后应激障碍等)需要专业心理/精神科干预,以情胜情不能替代治疗
- 急性身体症状(突然剧烈头痛、胸痛等),即使与情绪相关也应先排除器质性病变
- 用户没有明确的情绪背景,只是单纯的身体症状——不要强行用情绪解释所有身体问题

### 作者在书中警告的失败模式

- 以情胜情操作不当可能加重病情:用喜悦压制悲伤,看似有效实则可能导致"火克金"过度,肺气郁结更深
- 情绪调节不是压抑:素问讲的是"胜"而非"灭",是用制约情绪来平衡过激情绪,而不是消灭某种情绪
- 九气(怒喜悲恐寒炅惊劳思)中寒、炅、劳不是情绪而是物理/行为因素,不要把所有气机变化都归结为情绪
- **误把"以情胜情"当成即时开关**: 情绪调节是渐进过程, 不是"说个笑话就消除了悲伤"。急功近利的应用会适得其反, 引发情绪反弹。
- **"悲伤时不要哭" = 情绪压抑**: "悲则气消"意味着悲伤本身就是一种气机释放。强迫"坚强"阻止流泪, 反而让气机郁结不散。

### Fallback（if-then 三段式）

| 触发条件 | 一线修复 | 仍失败 → 兜底 |
|---------|---------|-------------|
| 用户主导情绪不清晰，同时存在多种情绪 | 不强行归入单一情绪。按频率和强度排序列出，优先处理频率最高+身体症状最明显的那一种 | 多种情绪相互交织且强度相当 → 退出本 skill，考虑 `five-elements-network` 分析多情绪的互动网络和相克链 |
| 使用「以情胜情」后 24h 内用户反馈情绪更糟 | 立即停用以情胜情，切回「疏导」路径：让当前情绪自然流动而非压制。告知：「情绪调节不是一蹴而就的。你的反应比预期强烈，接下来只做疏导——想哭就哭，想说就说」 | 情绪持续恶化 → 提供心理援助热线 400-161-9995，不继续深入分析 |
| 用户表现出自伤/自杀念头或严重抑郁症状 | 不进入任何分析。直接提供心理危机干预热线，建议立即联系专业医生。本 skill 不处理临床级别的心理危机 | 热线：400-161-9995（全国心理援助热线）。告知用户：「你现在需要的不是我，是专业的人」 |
| 用户把所有身体症状归因于情绪 | 身体症状先排除器质性原因再走情志-脏腑通路。问：「最近有没有体检？这些症状是什么时候开始的？」排除器质后再分析情绪 | 用户无法排除器质性 → 建议先做基础检查（血常规/心电图/血压），等结果出来后带着数据回来分析 |
| 「以情胜情」被误解为即时开关 | 纠正：情绪调节是渐进过程，不是「说个笑话就消除了悲伤」。告知：「这不是开关，是坡度。预计需要 3-7 天才能看到明显变化」 | 用户仍期待即时效果 → 不推荐以情胜情。改用情绪疏导：「今天只做一件事——把心里最堵的那句话写下来。不用解决它，写出来就行」 |
| 「悲则气消」被误解为压抑悲伤 | 纠正：悲伤本身就是气机释放。「坚强不哭」= 让气机郁结。给允许：「想哭就哭，哭完反而通畅。强行憋回去才会伤身」 | 用户说「哭了也没用」→ 不是因为哭没用，而是因为深层原因没变。从「允许哭」升级到「哭完之后我们看看能做点什么」 |

### 作者的盲点 / 时代局限

- 情志脏腑的对应关系基于五行推演和临床观察,现代身心医学有更精确的神经-内分泌机制解释
- 以情胜情缺乏系统化的操作规范和适应症界定,实际应用中风险较高
- 素问没有区分正常情绪反应和病理性情绪障碍,现代人面临的心理问题复杂度远超古代

### 容易混淆的邻近方法论

- "情绪管理"是现代心理学的概念,关注的是**调节情绪本身**,情志脏腑模型关注的是**情绪对身体脏腑的影响以及反向利用情绪来调节身体**
- "身心一体"是一种哲学立场,情志脏腑模型是一套**可操作的分析-调节框架**:情绪→脏腑→气机→调节策略,每一步都有具体的对应关系
