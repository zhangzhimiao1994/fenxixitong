# 找到雷区，重温低谷

> 先找到被碰到的那块皮，再回到那一刻，把当时没说的话补上。

## 🧭 决策树

```
用户在讲一次和伴侣的失控时刻 / 想复盘一次争吵
│
├── 任何安全信号？                        → 🛑 E1 STOP
├── 还说不清两人一般怎么吵？              → ❌ 先用 eft-demon-dialogues
├── 卡在一次“再也不信你了”的重大伤害？    → ❌ 转 eft-forgiving-injuries
│
└── ✅ 能说出某个触发瞬间
      ├── 想弄清“我为什么反应这么大”     → 模块一：拆雷区（E1 → E2–E6）
      └── 想把一次具体争吵复盘、降温      → 模块二：重温低谷（E1 → E7–E12；E13 当面做）
```


## 📥 输入与证据假设

- 需要：一个具体时刻（一句话、一个表情、一次没回消息），以及用户当时的身体感受和第一反应。
- 雷区既可能来自过去（父母、前任），也可能在当前关系里新形成（如生病、失业、生孩子时没得到支持，PAGE 74–75）。不预设一定是童年。
- 复盘先选“不太难的”近期小事练手，再碰大事（PAGE 102–103）。
## 📖 RIA+E+B

### R（原文位置与转述）

- 作者把雷区定义为：依恋需要曾被反复忽视、否定或打发后形成的过敏点，核心是两种感受——被剥夺、被抛弃（“2 Ds”）（PAGE 73、84）。
- 认出雷区被碰的两个信号：对话情绪突然变调；反应和事情大小明显不成比例（PAGE 77）。
- 雷区被碰时的四个环节：依恋线索抓住注意 → 身体先反应 → 大脑随后赋予意义 → 准备向对方靠近、远离或对抗（PAGE 78–79）。
- 愤怒和退缩是表层，遮住了悲伤、羞耻，尤其是恐惧（PAGE 75）。作者说伴侣碰到彼此的雷区，原因很简单：彼此相爱，"You rub these raw spots simply because you love each other"（PAGE 88）。
- 说出脆弱可以从“这对我来说很难开口”开始（PAGE 82）。
- 重温低谷七步：停止游戏（把“我/你”换成“我们”）；认领自己的步子；认领自己的感受（可用“我有一部分……”）；承认自己怎样影响了对方；好奇对方的深层情绪；说出自己的深层情绪；站在一起（PAGE 92–94）。
- 热度太高时做不到，冷静后再说“我们能倒带重来一次吗”（PAGE 95）。

### I（白话解释）

小事引爆大火，是因为碰到的不是这件事，而是一块旧伤。身体比脑子快：语气一变，胃先缩、声音先尖，几百毫秒后脑子才给出一个解释——“他看不起我”“我又被丢下了”。然后人要么冲上去，要么缩回去，对方只看到这个动作，看不到底下的害怕。复盘就是事后把慢镜头放一遍：我做了什么、我其实怕什么、我的动作又怎么碰到了你的伤，最后两个人站到同一边。

### A1（书中案例，转述）

- **Anne 与 Patrick**（PAGE 79–81）：Anne 讲功课压力，Patrick 用讲课腔说“你这样钻牛角尖我帮不了你”。Anne 当场暴怒，冷战好几天。拆开后：触发是那个语气；表面是愤怒，底下是害怕和孤单；她渴望的是“担心没关系，你会帮我”；根源是母亲总说她不会有出息。
- **Vincent 与 James**（PAGE 83–86）：James 一皱眉，Vincent 就觉得“我完了”，胃里发紧，于是一动不动等风暴过去；James 只看到一面墙。Vincent 说出“焦虑”这个词后，James 第一次看见了他的害怕，也说出了自己“被事业抛下”的雷区。
- **Kerrie 与 Sal**（PAGE 95–102）：两人为她晚睡反复吵。作者往下问，Sal 从讽刺变成说出“等她上床很煎熬，我觉得自己在她生活的边上”。Kerrie 第一次意识到自己的回避会碰到他的雷区；后来在“裙子事件”的复盘里，两人自己认出了“推—退”的步子并停下来。

### E（执行步骤）

除 E1 外，任何步骤都不整轮停下：先按已知信息给出可用内容，缺的那一项用结尾唯一的问题去补。

**共用**

1. 🛑 **STOP·安全筛查**（两个模块都先做）— 输入：用户原话。核对：暴力、怕对方、严重成瘾、长期出轨、自伤自杀。输出：
   - 暴力、成瘾、长期婚外情（作者声明不适用，PAGE 11）→ 只说明不适合用雷区来理解，给出去处（咨询师、反家暴求助、成瘾治疗机构；危险时拨 110），不鼓励袒露脆弱，结束。
   - 实际上害怕伴侣 → 不要向他袒露，去找治疗师，甚至重新考虑这段关系（PAGE 82），结束。
   - 自伤自杀，或对方以自杀威胁 → 只输出 `cross-system-hub` C5 危机话术，不做复盘，结束。
   - 信号模糊（“他吼的时候我会发抖”）→ 本轮只问“他提高声音时，你会担心自己的安全吗？”，等用户回答再继续；出现过推、打、摔东西威胁，一律按本步处理，不以用户自评为准。
   - 有严重创伤史 → 继续，只做轻量识别并附一句转介个体创伤治疗师。

**模块一：拆雷区**

2. **定位线索** — 输入：用户讲的触发时刻。输出：对方的 1 个具体动作（语气、表情、一个词、一个转身）。用户没讲 → 用他讲到的场景先拆，结尾问“触发前一秒，他做了什么？”。
3. **身体** — 输入：用户描述。输出：1 个身体反应（发热、胸口紧）；用户没说 → 写“可能”并标推测。
4. **意义与动作** — 输入：线索 + 身体。输出：脑子里第一句话（“他嫌我烦”）+ 动作（冲上去 / 躲开 / 对着干）。
5. 🔴 **CHECKPOINT·定性之前** — 填句：“触发是___；表面上我表现出___；底下我其实感到___；我渴望的是___；我对这段关系得出的结论是___。”（PAGE 80）核对“底下”一格：①用户本轮已自报一个底层情绪词（“我其实很委屈”）→ 直接用这个词填，结尾问题改问 E2 缺的触发细节（不缺就问脑子里第一句话）；②没报 → 不由回复填，从短表给 2–3 个候选词，照常给出说明句（情绪处留空），结尾唯一的问题请用户选词。

   **底层情绪短表**（转述自 PAGE 87，共 8 个）：孤单｜被忽视｜不重要｜被拒绝｜无能为力｜怕被丢下｜羞愧｜委屈

6. **雷区说明句** — 输入：E2–E5 + 用户选的词（未选就留空）。输出：一句 ≤ 60 字、以“这对我有点难开口”起头、可对伴侣说的话。

**模块二：重温低谷（复盘一次争吵）**

7. **只讲画面** — 输入：用户讲的争吵。输出：一句不带评价的复述（PAGE 102–103）。
8. **停止游戏** — 输入：用户叙述里的“你总是”。输出：改写成“我们又进了那个圈”。
9. **认领自己的步子** — 输入：画面。输出：用户自己的 1 个动作（提高音量、走开、讽刺）。
10. **认领自己的感受** — 输入：E9。输出：表层情绪 + “我有一部分很生气，也有一部分___”；空格用 E5 用户选的词；没选过 → 留空，下一轮用户补词后再填，不回 E5。
11. **承认影响** — 输入：E9 的动作。输出：它可能怎样碰到对方的雷区（例：我一走开，你会觉得被丢下），标“推测，可以去问他”。
12. 🔴 **CHECKPOINT·给复盘第一句之前** — 核对 E9，分三种：①有用户自己的动作 → 输出“我们”开头的复盘第一句 + 一句倒带语 + 给对方的好奇句“那一刻你心里是什么感觉？”；②没提自己的动作、也没指责对方 → 照常输出，第一句里留空“我先说我那部分：当时我___了”，结尾问用户失控前自己说的最后一句话；③通篇指责对方 → 本轮只问“那一刻你做了什么？”，等用户回答再继续。
13. **站在一起**（两人当面做，不在单轮回复中输出）— 输入：复盘对话。输出：用户自己补完“如果当时我们站在一起，我会说___”，回复不代写。用户补不出 → 停在 E11，下次再继续。

#### 如果这一步失败

| 触发条件 | 一线修复 | 仍失败兜底 |
|---------|---------|-----------|
| E2 信息不足：只说“他总惹我” | 问“触发前一秒他做了什么” | 给三个选项让用户挑：一句话 / 一个表情 / 一次没回应 |
| E3/E5 “我不知道自己什么感觉” | 从身体问起：“那一刻胸口、胃、手是什么感觉？” | 从短表给 2–3 个词，让用户圈一个最接近的；都不贴切 → 用用户自己的话 |
| E5 用户不认同候选词（“我就是生气，没别的”），或一说到底层就翻回愤怒（像 James，PAGE 86） | 接受，指出“刚才有一瞬间是难过的”，问“生气里有没有很小的一块别的？” | 允许今天只说到表层，说明这很正常 |
| E12 只讲对方的动作，或只想让对方改、拒绝认领自己那一步 | 先给不评价对方的“我们”开场句，自己那部分留空；句子改成“当我听到___，我感到___” | 只做模块一，拆对方那个动作落下时用户自己的反应 |
| 当下仍很激动：原话出现“现在还在气头上”“一想就火”，或刚吵完不到一小时 | 先暂停，约定冷静后再“倒带重来”（PAGE 95） | 只给一句当下能说的降温语 |
| E1 用户否认危险：“他推过我但不算暴力” | 只问安全问题，不拆雷区 | 按 E1 处理，不以用户自评为准 |
| 雷区深、来自严重创伤（如虐待史，PAGE 76–77） | 说明这需要更长时间和专业陪伴 | 去个体创伤治疗师或伴侣治疗师 |
| 用户坚持越界要求：诊断自己或伴侣、列一张“他必须绕开”的清单 | 说明这里不做诊断，雷区是地图不是禁令 | 诊断 → psyche 第五节第 2 条原话 |
| `cross-system-hub` C5 不可用 | 直接说：“你的安全最重要，现在有危险就拨 110 或 120。” | 给当地心理援助热线，并请用户把一句话发给信任的人：“我现在状态不好，能陪我一下吗？” |

### B（边界）

- **不做诊断**：不判断用户或伴侣是否有创伤后应激、人格障碍、抑郁。用户要诊断时用 psyche 第五节第 2 条原话。
- **创伤史**：作者说受过严重伤害的人雷区更大更深，过程更长（PAGE 76–77）；本 skill 只做识别，不做创伤处理。
- **证据局限**：四环节模型来自作者对情绪研究的通俗整理；七步降级来自治疗录像观察，自助效果未经研究。

## 💬 输出格式

通用规则：严格按顺序，全文 ≤ 270 字，只在最后问 1 个问题，不写 skill 名和“雷区/七步/模块”等术语。底层情绪一律不下定论：用“会不会有一点___、___或___”给 2–3 个短表候选词，由用户选。缺信息时照常给出第 1–4 条，只把第 5 条换成补缺问题；只有 E1 和 E12 情况③整轮只问一句。单轮只执行到 E12，E13 不输出。

**模块一（拆一个失控瞬间，对应 E2–E6）**

1. 接住（≤ 40 字），扣住触发细节；用户问了“为什么”（“不知道自己为什么那么生气”）→ 加半句“反应比事情大，多半是这句话碰到了一块旧的痛处”。
2. 拆开那一刻（≤ 60 字）：触发 → 身体 → 脑子里的结论 → 你的动作。
3. 表层 + 候选底层（≤ 50 字）：“表面是___；底下会不会还有一点___、___或___，这是我的猜测。”（用句号，不占用唯一的问题）
4. 一句“太激动时先停下、慢呼吸几次” + 一句可对伴侣说的说明（共 ≤ 80 字），情绪处留空“___”。
5. 一个问题：引用用户原话，请他从第 3 条候选里选一个或换成自己的词。用户已自报情绪词 → 第 3 条直接用他的词、第 4 条填上，本条按 E5① 改问触发细节。

**模块二（复盘一次争吵，对应 E7–E12）**

1. 接住（≤ 30 字），肯定愿意回头看。
2. 只讲画面（≤ 50 字）：用一句不带评价的话复述从起点到失控。
3. 你那一步 + 它可能怎样碰到对方（≤ 60 字，标“推测，可以去问他”），二选一：用户讲了自己的动作 → 直接写；没讲 → 写“你那一步可能是提高声音、说了句重话或转身不理中的一个，它也许让他觉得又被指责”（不写问号）。
4. 挑两人都放松的时间，用“我们”开头、含“不是要分对错”的复盘第一句 + 一句太热时的倒带语（共 ≤ 90 字）；没讲自己的动作时，第一句里写“我先说我那部分：当时我___了”。
5. 一个问题：问用户失控前自己说的最后一句话或做的最后一个动作。

**示例·模块一**（“我发了一大段话，他只回了个‘嗯’，我当场就想把手机摔了，也不懂自己怎么这么大火。”）

```
一大段话换来一个“嗯”，火一下就上来了；反应比事情大，多半是这个“嗯”碰到了一块旧的痛处。
拆开看：触发是那个“嗯”；身体可能先一紧、手发烫；脑子里冒出“他根本没在看”；然后你想摔手机、想冲他发火。
表面是生气；底下会不会还有一点被忽视、不重要或孤单，这是我的猜测。
太激动时先放下手机，慢呼吸几次。等你们都放松时可以说：“这对我有点难开口。你只回‘嗯’的时候，我会觉得___，所以一下就急了。”
他回“嗯”的那一刻，被忽视、不重要、孤单里哪个最接近，或者是别的词？
```

**示例·模块二**（“周日在超市为买什么吵起来，我把购物车一推先走了，现在想跟她聊聊。”）

```
冷静下来还想回头聊，这一步不容易。
先只讲画面：从挑东西意见不合，到你推开购物车先走。
你那一步是“先走”；它可能让她觉得被丢在原地（推测，可以去问她）。
挑个两人都放松的时间开口：“周日我们又进了那个圈，我想一起看看，不是要分对错。我先说我那部分：我走开了，其实当时心里有点___。”说着又热起来，就说：“我们先停，改天倒带重来。”
你把购物车推开之前，说的最后一句话是什么？
```

## 反例黑名单

| # | 反模式 | 为什么 | 替代做法 |
|---|-------|-------|---------|
| 1 | 直接归因童年（“这是你母亲留下的伤”） | 雷区也可能在当前关系里形成（PAGE 74–75） | 先拆当下四环节，来源让用户自己找 |
| 2 | 把底层情绪说成定论（“你其实是害怕”） | 替用户命名会让他防御或顺从，失去自己的体验 | 用“会不会有一点……”，从短表给 2–3 个候选词让用户选 |
| 3 | 说“你这是创伤后应激”“你是焦虑型” | 单次描述撑不起诊断，标签替代了理解 | 只描述四环节；要诊断走 B 段原话 |
| 4 | 给对方开改进方案、分析对方原生家庭（Sal 的错误，PAGE 96） | 把复盘变成审判，对方更防御 | 只说“你的动作可能怎样碰到他” |
| 5 | 激动时硬推复盘 | 热度太高时七步做不到（PAGE 95） | 先暂停，约定“倒带重来” |
| 6 | 把雷区当成对方必须永远绕开的规则 | 雷区不是借口：不等于对方要永远绕开，也不等于伤人的行为可被原谅 | 雷区是地图，告诉两人危险点在哪 |
| 7 | 有恐惧或暴力时仍劝袒露脆弱 | 作者明确说怕伴侣就不要袒露（PAGE 82） | 按 E1 |
