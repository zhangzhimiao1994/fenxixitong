# 找到雷区，重温低谷

> 先找到被碰到的那块皮，再回到那一刻，把当时没说的话补上。

## 🧭 决策树

```
用户在讲一次和伴侣的失控时刻 / 想复盘一次争吵
│
├── 暴力、恐惧对方、严重成瘾、长期出轨？ → ❌ 走 B 段转介
├── 自伤自杀信号？                      → 🛑 psyche 第五节危机话术
├── 还说不清两人一般怎么吵？              → ❌ 先用 eft-demon-dialogues
├── 卡在一次“再也不信你了”的重大伤害？    → ❌ 转 eft-forgiving-injuries
│
└── ✅ 能说出某个触发瞬间
      ├── 想弄清“我为什么反应这么大”     → 模块一：拆雷区（E1–E5）
      └── 想把一次具体争吵复盘、降温      → 模块二：重温低谷（E6–E12）
          （没做过模块一也可以，但第 10 步会更难）
```

## 📥 输入与证据假设

- 需要：一个具体时刻（一句话、一个表情、一次没回消息），以及用户当时的身体感受和第一反应。
- 雷区既可能来自过去（父母、前任），也可能在当前关系里新形成（如生病、失业、生孩子时没得到支持，PAGE 74–75）。不预设一定是童年。
- 复盘最好选“不太难的”近期小事练手，再碰大事（PAGE 102–103）。
- 若只有用户一方，模块二里关于对方的部分一律写成“可以去问他”。

## 📖 RIA+E+B

### R（原文位置与转述）

- 作者把雷区定义为：依恋需要曾被反复忽视、否定或打发后形成的过敏点，核心是两种感受——被剥夺、被抛弃（“2 Ds”）（PAGE 73、84）。
- 认出雷区被碰的两个信号：对话情绪突然变调；反应和事情大小明显不成比例（PAGE 77）。
- 雷区被碰时的四个环节：依恋线索抓住注意 → 身体先反应 → 大脑随后赋予意义 → 准备向对方靠近、远离或对抗（PAGE 78–79）。
- 愤怒和退缩是表层，遮住了悲伤、羞耻，尤其是恐惧（PAGE 75）。作者说伴侣碰到彼此的雷区，原因很简单：彼此相爱，"You rub these raw spots simply because you love each other"（PAGE 88）。
- 说出脆弱可以从“这对我来说很难开口”开始（PAGE 82）。
- 重温低谷七步：停止游戏（把“我/你”换成“我们”）；认领自己的步子；认领自己的感受（可用“我有一部分……”）；承认自己怎样影响了对方；好奇对方的深层情绪；说出自己的深层情绪；站在一起（PAGE 92–94）。
- 热度太高时做不到，冷静后再说“我们能倒带重来一次吗”（PAGE 95）。

### I（白话解释）

小事引爆大火，是因为碰到的不是这件事，而是一块旧伤。身体比脑子快：语气一变，胃先缩、声音先尖，几百毫秒后脑子才给出一个解释——“他看不起我”“我又被丢下了”。然后人要么冲上去，要么缩回去，对方只看到这个动作，看不到底下的害怕。复盘就是事后把慢镜头放一遍：我做了什么、我其实怕什么、我的动作又怎么碰到了你的伤，最后两个人站到同一边。

### A1（书中案例，转述）

- **Anne 与 Patrick**（PAGE 79–81）：Anne 讲功课压力，Patrick 用讲课腔说“你这样钻牛角尖我帮不了你”。Anne 当场暴怒，冷战好几天。拆开后：触发是那个语气；表面是愤怒，底下是害怕和孤单；她渴望的是“担心没关系，你会帮我”；根源是母亲总说她不会有出息。
- **Vincent 与 James**（PAGE 83–86）：James 一皱眉，Vincent 就觉得“我完了”，胃里发紧，于是一动不动等风暴过去；James 只看到一面墙。Vincent 说出“焦虑”这个词后，James 第一次看见了他的害怕，也说出了自己“被事业抛下”的雷区。
- **Kerrie 与 Sal**（PAGE 95–102）：两人为她晚睡反复吵。作者往下问，Sal 从讽刺变成说出“等她上床很煎熬，我觉得自己在她生活的边上”。Kerrie 第一次意识到自己的回避会碰到他的雷区；后来在“裙子事件”的复盘里，两人自己认出了“推—退”的步子并停下来。

### A2（未来触发场景）

1. “他说‘你又来了’三个字，我就整个人炸了，事后想想其实没多大事。”→ 模块一。
2. “昨晚为谁洗碗吵到他摔门，现在冷静了，想知道怎么跟他聊这件事。”→ 模块二。
3. “她一说累我就觉得她是不想要我了，然后就冷下来。”→ 模块一 + 模块二。

### E（执行步骤）

**模块一：拆雷区**

1. **安全筛查**：暴力、恐惧、成瘾、长期出轨、自伤信号 → 走 B 段。
2. **定位线索**：请用户说出触发前一秒，对方具体做了什么或没做什么（语气、表情、一个词、一个转身）。
3. **身体**：当时身体有什么反应（发热、发冷、胸口紧、想跑、空白）。
4. **意义与动作**：脑子里第一句话是什么（“他嫌我烦”）；然后你朝他冲过去、躲开还是对着干。
5. 🔴 **CHECKPOINT**：能否填出这句——“触发是___；表面上我表现出___；底下我其实感到___（悲伤 / 羞耻 / 恐惧 / 孤单之一）；我渴望的是___；我对这段关系得出的结论是___。”（PAGE 80）填不出“底下”那一格 → 用书中情绪词表让用户挑（孤单、被忽视、无能为力、被拒绝、不重要……PAGE 87），不要替他填。

**模块二：重温低谷（复盘一次争吵）**

6. **只讲画面**：像墙上的苍蝇一样描述发生了什么，不带评价（PAGE 102–103）。
7. **停止游戏**：把叙述里的“你总是”改成“我们又进了那个圈”。
8. **认领自己的步子**：我做了什么动作（提高音量、走开、讽刺）。
9. **认领自己的感受**：先说表层（生气、烦），可用“我有一部分很生气，也有一部分慌了”。
10. **承认影响**：我的动作可能怎样碰到了对方的雷区（例：我一走开，你会觉得被丢下）。
11. **好奇与袒露**：问对方当时底下是什么；再说出自己底下的害怕（可先说“这对我来说很难开口”）。
12. 🔴 **CHECKPOINT**：两人能否一起写出“如果当时我们站在一起，结尾会是怎样的一句话”？写不出 → 先停在第 10 步，下次再继续。

#### 如果这一步失败

| 触发条件 | 一线修复 | 兜底 |
|---------|---------|------|
| “我不知道自己什么感觉” | 从身体问起：“那一刻胸口、胃、手是什么感觉？” | 给书中情绪词表，让用户圈一个最接近的 |
| 讲着讲着又变成控诉对方 | 提醒“先讲你那一步”，把句子改成“当我听到___，我感到___” | 只做模块一，暂不复盘双方 |
| 一说到底层情绪就翻回愤怒（像 James，PAGE 86） | 指出“刚才有一瞬间是难过的”，邀请停在那一瞬间 | 允许今天只说到表层，说明这很正常 |
| 当下仍很激动、无法复盘 | 先暂停，约定冷静后再“倒带重来”（PAGE 95） | 只给一句当下能说的降温语 |
| 雷区深、来自严重创伤（如虐待史，PAGE 76–77） | 说明这需要更长时间和专业陪伴 | 转介个体或伴侣治疗师 |

### B（边界）

- **作者声明不适用**（PAGE 11）：有虐待或暴力、严重成瘾、长期婚外情的关系。回复只说明不适合用雷区来理解，建议先联系专业人员（咨询师、反家暴求助、成瘾治疗机构；危险时拨 110），不鼓励袒露脆弱。
- **怕对方就别袒露**：作者写明，如果你实际上害怕伴侣，就不要向他袒露，应找治疗师甚至重新考虑这段关系（PAGE 82）。
- **自伤自杀**：出现信号，或对方以自杀威胁，按 psyche 第五节危机话术处理，不做复盘。
- **不做诊断**：不判断用户或伴侣是否有创伤后应激、人格障碍、抑郁。用户要诊断时用 psyche 第五节第 2 条原话。
- **雷区不是借口**：理解雷区不等于对方必须永远绕开，也不等于伤人的行为可以被原谅；它只是让两人知道危险点在哪里。
- **创伤史**：作者说受过严重伤害的人雷区更大更深，过程更长（PAGE 76–77）；本 skill 只做识别，不做创伤处理。
- **证据局限**：四环节模型来自作者对情绪研究的通俗整理；七步降级来自治疗录像观察，自助效果未经研究。

## 💬 输出格式

按顺序，全文只问 1 个问题，不写 skill 名：

1. 一句接住，扣住触发细节。
2. 用一句话把那一刻拆开：触发 → 身体 → 脑子里的结论 → 你的动作。
3. 点出表层和底层：表面是___，底下可能是___（标推测）。
4. 一步可做的事：模块一给一句可以对伴侣说的“雷区说明”；模块二给复盘的下一步和一句“我们”开头的话。
5. 一个问题，引用用户原话。

**示例**（“他一用那种不耐烦的语气说‘你又来了’，我就炸了，事后又觉得不至于。”）

```
那三个字落下来的一瞬间就失控，事后又自责，挺累的。
拆开看：触发是那个不耐烦的语气；身体可能先热起来；脑子里冒出来的大概是“他又嫌我烦了”；然后你就冲上去了。
他看到的是你在发火，但底下可能是“我说的话对他不重要”带来的委屈和慌。这是我的推测，你自己最清楚。
等你们都平静时，可以试着说：“这对我有点难开口。你说‘你又来了’的时候，我会一下子觉得自己很烦人、不被在乎，所以我会炸。”
他说“你又来了”的那一刻，你最先冒出来的念头是什么？
```
