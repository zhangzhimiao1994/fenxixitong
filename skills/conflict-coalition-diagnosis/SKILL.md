# Conflict Coalition Diagnosis

## R — 原文引用

### 争端与裁决
> 讼：有孚，窒惕，中吉，终凶。利见大人，不利涉大川。（第六卦）
> 讼·初六：不永所事，小有言，终吉。 — 不纠缠，小的口舌之争最终会好
> 讼·九二：不克讼，归而逋，其邑人三百户，无眚。 — 打不赢就退，还能保全
> 讼·九五：讼，元吉。 — 位置正当时的诉讼反而是好的
> 噬嗑：亨。利用狱。（第二十一卦） — 咀嚼式裁决，需要咬碎障碍

### 组织动员
> 师：贞，丈人吉，无咎。（第七卦）
> 师·初六：师出以律，否臧凶。 — 行动必须有纪律
> 师·六五：长子帅师，弟子舆尸，贞凶。 — 指挥权必须统一

### 结盟与依附
> 比：吉。原筮元永贞，无咎。不宁方来，后夫凶。（第八卦）
> 比·初六：有孚比之，无咎。有孚盈缶，终来有它，吉。 — 诚心诚意地比附
> 比·九五：显比，王用三驱，失前禽。邑人不诫，吉。 — 结盟要宽容来去自由
> 比·上六：比之无首，凶。 — 依附没有首领是危险的

### 共同目标与信任
> 同人：同人于野，亨。利涉大川，利君子贞。（第十三卦）
> 同人·初九：同人于门，无咎。 — 从门槛/入口开始聚合
> 同人·六二：同人于宗，吝。 — 仅与宗族/小圈子聚合是局促的
> 大有·六五：厥孚交如，威如，吉。（第十四卦） — 信任与威严并存
> 中孚：豚鱼吉，利涉大川，利贞。（第六十一卦）
> 中孚·九二：鸣鹤在阴，其子和之。我有好爵，吾与尔靡之。 — 信任产生共鸣

### 分歧与化解
> 睽：小事吉。（第三十八卦）
> 睽·九四：睽孤，遇元夫，交孚，厉无咎。 — 分歧中遇到志同道合者
> 睽·上九：匪寇婚媾，往遇雨则吉。 — 看似敌人其实是盟友
> 解：利西南，无所往，其来复吉。有攸往，夙吉。（第四十卦）
> 解·九二：田获三狐，得黄矢，贞吉。 — 解除障碍、清理隐患

### 聚合与涣散
> 萃：亨。王假有庙，利见大人，亨，利贞。用大牲吉，利有攸往。（第四十五卦）
> 萃·初六：有孚不终，乃乱乃萃。若号，一握为笑。 — 信任不持久聚合会乱
> 涣：亨。王假有庙，利涉大川，利贞。（第五十九卦）
> 涣·六四：涣其群，元吉。涣有丘，匪夷所思。 — 解散小圈子、建立大共识

### 愉悦与沟通
> 兑：亨，利贞。（第五十八卦）
> 兑·初九：和兑，吉。 — 和谐的愉悦
> 兑·九二：孚兑，吉，悔亡。 — 有信任的愉悦
> 兑·六三：来兑，凶。 — 谄媚式的取悦是危险的

## I — 方法论骨架

《周易》把关系问题细分为多种结构，每种都有自己的逻辑和风险：

| 关系结构 | 卦象 | 核心逻辑 | 主要风险 |
|---------|------|---------|---------|
| 争端 | 讼、噬嗑 | 有合理诉求，但升级有限度 | 终凶（拉到底双输） |
| 组织动员 | 师 | 要有纪律、统一指挥 | 无律则凶、指挥分裂 |
| 结盟依附 | 比 | 诚心比附、来去自由 | 无首则凶、后至则凶 |
| 共同目标 | 同人、大有 | 广泛共识、跨圈子 | 仅限宗族则吝 |
| 信任核心 | 中孚 | 信任产生共鸣和共振 | 孚不持久则乱 |
| 分歧 | 睽 | 小事可做，分歧中找共同点 | 过度解读对方意图 |
| 化解 | 解 | 解除障碍，及时行动 | 该解不解错失时机 |
| 聚合 | 萃 | 有核心人物和祭祀（共同目标） | 孚不终则散 |
| 涣散 | 涣 | 解散旧结构、建立新共识 | 涣而不聚 |
| 愉悦关系 | 兑 | 和谐的愉悦、信任的愉悦 | 谄媚式取悦则凶 |

**核心检查项**：
1. 有孚否？（信任基础存不存在）
2. 有律否？（规则和纪律是否到位）
3. 有大人否？（是否有公正的第三方/领袖）
4. 会终凶否？（持续下去是否会双输）

## A1 — 源文件应用案例

### 案例 1：讼 — 争端可控但不能无限升级
- **文本**："中吉，终凶。"
- **解读**：在合理范围内处理争端有好处，但拉到底就会毁灭关系。
- **应用**：纠纷中先设定"止争点"——不永所事、不克讼就归而逋。

### 案例 2：师 — 组织力量必须有纪律
- **文本**："师出以律，否臧凶。"
- **解读**：动员不是人多就行，没有规则就是一群人互相伤害。
- **应用**：团队行动前先检查角色分配、命令链和规则，缺一环就补。

### 案例 3：同人 vs 比 — 广泛共识 vs 依附结盟
- **同人**："同人于野"——超越宗族和圈子的广泛认同，可以涉大川。
- **比**："不宁方来，后夫凶"——不安定的人来依附，但要警惕后来者。
- **应用**：同人是"我们为共同目标走到一起"；比是"我们选择依附同一个首领"。

### 案例 4：睽 — 分歧中找同盟
- **文本**："睽孤，遇元夫，交孚，厉无咎。""匪寇婚媾。"
- **解读**：在分歧和孤立中，看似敌人的人可能是盟友。
- **应用**：团队内部分裂时，不要急着认定谁是敌人；先找那个"遇元夫"——能彼此交孚的人。

### 案例 5：萃 — 聚合可能散，信任要持续
- **文本**："有孚不终，乃乱乃萃。"
- **解读**：信任不能持久，聚合就会混乱。
- **应用**：团队联盟形成后，信任建设是持续工作，不能只在开头做一次。

## A2 — 触发场景

### 适合触发
1. 用户在冲突、诉讼、谈判、团队内耗中。
2. 用户想判断该和解、升级、找第三方还是退出。
3. 用户考虑联盟、合作、加入组织或建立共同体。
4. 用户读到讼、师、比、同人、睽、解、萃、中孚、兑。

### 不适合触发
1. 用户问题完全是单人效率问题。
2. 需要具体法律策略且缺乏专业信息。
3. 只想查某卦原文。

## E — 执行步骤

### 模板：关系结构诊断表

| 检查项 | 你的回答（选项） | → 自动判定 |
|--------|---------------|-----------|
| 你们之间有没有信任基础？ | 有（互相信任）/ 部分（单向/不确定）/ 没有 | 没有→孚未立，先建信任再推进 |
| 有没有共同目标或规则？ | 有明确共识 / 有模糊共识 / 没有 | 有→同人/比；没有→先确立共识 |
| 现在的关系状态是？ | 争端/对抗 / 合作/联盟 / 分裂/隔阂 / 聚合中 / 已涣散 | → 对应讼师/同人比/睽/萃/涣 |
| 如果继续当前走向会怎样？ | 可控（中吉）/ 不确定 / 终凶（双输） | 终凶→必须设止争点/退出线 |
| 有没有公正的第三方/规则体系？ | 有（大人/法律/上级）/ 部分（模糊规则）/ 没有 | 有→可借助第三方裁决；没有→不能正式开战，先建规则 |
| 你在关系中的位置？ | 主导方 / 平等方 / 依附方 | 依附方→比卦逻辑；平等方→同人逻辑；主导方→需检查孚与律 |

**推导规则**：第 3 项锁定核心卦象（讼/师/比/同人/睽/萃/涣/兑），第 1-2 项判断是否满足该卦的积极条件，第 4 项决定动作边界。

### 步骤

1. **填表诊断**：输出 `关系结构：[卦名] | 核心风险：[X] | 信任：[有/部分/无] | 规则：[有/部分/无]`
2. **三问检查**：依次回答 ①有孚否？②有律否？③有大人否？缺什么补什么。
   🔴 **CHECKPOINT**：展示诊断+三问结果，等待确认。
3. **设定止争点/退出线**：根据「中吉终凶」逻辑，定义两件事——
   - 止争点：`到 [X条件] 时停止升级，转为和解/仲裁`
   - 退出线：`到 [Y条件] 时退出关系，不再追加投入`
4. **输出关系动作**：格式 `动作：[和解/仲裁/立规则/缩小战线/公开结盟/降级合作/退出] | 前提：[满足X条件] | 验证时间：[N天/周后复查]`
   🛑 **STOP**：输出动作前确认上一步。

## B — 边界与 Fallback

### 失败模式
- 把所有冲突都劝和，忽略师卦式的必要组织对抗。
- 把所有联盟都当好事，忽略"无孚""不终"。
- 忽视"终凶"的升级边界。

### Fallback（if-then 三段式）

| 触发条件 | 一线修复 | 仍失败 → 兜底 |
|---------|---------|-------------|
| 所有冲突都判和解，忽视必要对抗 | 检查是否存在"师卦"条件：对方是否有不公正行为？有则不先和解，先组织力量（师出以律） | 判断不了对方是否不公正 → 不判断道德，只判断"继续和解你是否持续受损？"。是 → 停止和解，设底线 |
| 联盟"无孚"但用户已深度绑定 | 不拆联盟。先做"孚"的基础建设：小范围信任确认行为（一次可靠合作/坦诚沟通） | 信任建设也失败 → 联盟关系降级为"弱合作"：降低投入、减少依赖、设定退出条件，但不说破 |
| "终凶"条件已触发——争讼已无益 | 不是继续还是停的问题，是"停在哪一步损失最小"。画一条停止线 | 用户说"我不甘心，已经投入这么多了" → 区分"沉没成本"和"未来追加成本"。画两条线：已丢的 X vs 再丢的 Y |
| 把联盟都当好事，忽略"不终"的风险 | 比卦初始友好不代表能走到底。检查：联盟有没有共同的外部目标？目标达成后联盟是否还有存在理由？ | 没有长期共同目标 → 标注有效期："此联盟的自然寿命约为 X 周期，到期后需重新评估" |
| 把"睽"（分裂）判断为必须马上修复的危机 | 睽 = 小事吉，小规模的沟通调整就够了。不要大动作 | 用户坚持大动作修复 → 警告："睽卦提示小事吉——大动反而可能扩大裂痕。你确定要放弃小事策略吗？" |
| 争讼中只教策略不管情绪 | 讼卦的核心智慧不是"怎么赢"，而是"什么时候不讼了"。问用户："继续讼下去，你真正想得到的是什么？那个东西一定要通过讼才能拿到吗？" | 用户给不出非讼不可的理由 → 建议中止诉讼过程，转为谈判或调解 |

### 来源边界
依据经文中关系结构，不提供现代法律意见。
