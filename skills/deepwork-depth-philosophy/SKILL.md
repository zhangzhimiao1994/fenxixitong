## 🧭 决策树

```
用户：想做一件需要长时间专注的事，但挤不出 / 守不住整块时间
│
├── 主诉是"怎么每天坚持做某件事"（运动、背单词、早起）？ → ❌ habit-starter-design / habit-streak-plateau
├── 有时间段，但一坐下就想刷手机、专注不了几分钟？ → ❌ deepwork-embrace-boredom
├── 日程被会议/消息填满，想先压缩浅层事务？ → ❌ deepwork-shallow-shutdown（可回到本 skill）
├── 角色的价值就是随时响应（CEO 决策、值班、客服、部分销售）？
│      → ⚠️ 特异性检查：先确认是否真有一项"需要深度"的产出，没有就说明本方法不适用
├── 出现耗竭、抑郁、自伤信号？ → 🛑 psyche（自伤信号走 psyche 第五节危机话术）
│
└── 有一项明确的深度产出 + 日程至少部分可控 → ✅ 激活
       ├── 还没想过"用哪种方式排深度" → 步骤 1–2
       ├── 选好了但每次开工都磨蹭 → 步骤 3（仪式）
       └── 能开工但时断时续、几周就散 → 步骤 4（4DX 记分板）
```

## 📥 输入与证据假设

**需要从用户处拿到（缺了就在唯一的问题里问最关键的一项）**：
1. 深度产出是什么：能否一句话说清，是否"离散、清晰、主要靠个人完成"；
2. 日程自主度：能否整天/连续几天消失？能否每天固定 1–2 小时不被打扰？还是只能捡空当？
3. 熟练度与信心：以前是否在碎片时间里成功切换进深度状态过；
4. 现有约束：照护责任、老板对回复速度的期待、通勤；
5. 当前基线：最近一周大约有几小时真正不受打扰的专注。

**证据假设（必须如实对用户说）**：
- 四种方式是作者从 Knuth、荣格、Adam Grant、Chappell、Isaacson 等案例归纳的分类，**不是实验比较的结果**；名人案例有幸存者偏差。
- "意志力有限所以要靠惯例"这一前提里，自我损耗效应在大规模重复研究中站不住；但"别每次临时决定、用固定安排代替决心"仍是合理的工作假设。
- 4DX 来自企业咨询实务；作者论文从 4 篇到 9 篇是 n=1 自述，同期有终身教职压力等混杂因素。

## 📖 RIA+E+B

### R（Reading，转述）
- 规则1 开头（PAGE 59–60）：作者认为人整天都在和"去做点轻松事"的欲望较劲，所以要把深度工作交给惯例和仪式，而不是靠临时下决心。
- 四种哲学（PAGE 60–70）：**禁欲式**把浅层义务砍到极少，适合贡献"离散、清晰、个人化"的人（Knuth 不用邮件，信件由助手每季度批处理）；**双峰式**划出至少一整天的闭关段，其余时间开放（荣格的塔楼、Grant 把教学压进一个学期、深度期挂自动回复）；**节奏式**每天固定时段（Chappell 每天 5:30–7:30 写论文，此前临时找空当排 90 分钟块几乎没进展）；**新闻记者式**随时切入，作者明说不适合新手，需要熟练和对项目的信心。作者提醒：选错方式会让习惯还没扎根就垮掉。
- 仪式化（PAGE 70–72）：引 Currey 的观察——"waiting for inspiration to strike is a terrible, terrible plan"（等灵感是个糟糕的计划）。有效仪式要回答三问：在哪做、做多久；开始后按什么规则做（如禁网、每 20 分钟字数）；用什么支撑（咖啡、食物、散步、材料摆放）。
- 宏大姿态（PAGE 72–74）：罗琳住进酒店写完终章、Shankman 往返东京的航班上写完书稿；重点不是环境本身，而是投入带来的"这件事很重要"的心理。
- 4DX（PAGE 79–84）：只盯少数极其重要的目标；以"投入该目标的深度工作小时"作领先指标；墙上贴一张按周分行的卡片计数，产出里程碑时把对应那一小时圈出来；每周复盘。

### I（Interpretation，白话）
难的不是"知道要专注"，而是每天都要重新决定"今天什么时候、在哪、做多久"，这个决定很容易输给眼前的消息。四种方式其实是在回答同一个问题：**你的日程能给出多大、多规律的整块？** 能砍掉杂务就禁欲，能整天消失就双峰，只能每天挤一小段就节奏，日程完全不可预测但你很熟练就新闻记者。仪式解决"开工内耗"，记分板解决"时间一长就散"：结果指标（论文数、字数）几个月才动一次，深度小时数每天都会动。

### A1（书中应用，转述）
- Chappell：全职工作 + 新生儿，临时找空当一年只写出一章；改成每天清晨固定两小时后，每两三周一章初稿（节奏式胜过随缘）。
- Adam Grant：学年尺度上把课集中在秋季，研究学期内每月 1–2 次闭关 2–4 天、邮件自动回复，其余时间对学生开放（双峰式两层嵌套）。
- 作者本人：用新闻记者式写书，但并非完全随缘——每周初预排深度时段、每天早上微调；用纸卡记分板记录深度小时，一年接收论文 9 篇，同时承认这一年非常消耗（PAGE 83–84、154）。

### A2（未来触发场景）
1. 在职研究生："白天上班晚上带娃，论文半年没动，我该怎么排？" → 多半是节奏式（清晨或午休固定段）+ 链条打叉。
2. 独立开发者："我能控制自己的时间，但总是被客户消息拖着走。" → 评估双峰式（每周两整天关闭消息）或接近禁欲式。
3. 产品经理："会多到没法固定时段，但偶尔会突然空出一两个小时。" → 新闻记者式只在其有过成功切换经验时推荐；否则先用 deepwork-shallow-shutdown 抢出固定段。

### E（Execution，执行步骤）
1. **特异性检查 + 锁定一项深度产出**：请用户用一句话说出"接下来 1–3 个月最需要深度的那件事"及其可见成果。若用户的价值主要来自随时响应且说不出深度产出，告知本方法可能不适用并停止。
   🔴 CHECKPOINT 1：产出是否具体到别人能判断"做完没有"？
2. **匹配深度方式**（对照下表，取第一个成立的行）：

   | 条件 | 推荐 | 最小单位 |
   |---|---|---|
   | 贡献离散清晰、个人化，且能砍掉大部分浅层义务 | 禁欲式 | 常态 |
   | 有必要的浅层职责，但能整天或连续几天消失（并提前告知） | 双峰式 | ≥1 整天 |
   | 每天都有甩不掉的浅层工作，或自律需要外部结构 | 节奏式 | 每天固定 60–120 分钟 |
   | 日程不可预测 + 曾多次在碎片时间成功进入深度 + 对项目有信心 | 新闻记者式（仍建议每周初预排） | 随时 |

   🔴 CHECKPOINT 2：用户是否愿意承担该方式的代价（例如对同事声明"周三全天不在线"、每天早起）？不愿意就降一级（双峰→节奏）。
3. **设计仪式**：写出三行——地点与时长（每次都有明确结束点）；进行中的规则（是否断网、手机放哪、什么指标）；支撑（开工前的固定动作、所需材料提前备好）。若项目卡死且资源允许，可加一次性宏大姿态（短期包场图书馆/酒店），代价须用户能承受。
4. **4DX 记分板**：目标 ≤2 个；领先指标 = 投入该目标的深度小时；做一张按周分行的纸卡或表格贴在工作位，完成里程碑时圈出对应小时；每周固定 10 分钟复盘：上周几小时、什么挡住了、下周排在哪。深度块总量参考每日 1–4 小时上限，新手从每天约 1 小时起。
5. **两周后校准**：比较实际深度小时与计划；连续两周达不到一半，回到步骤 2 换方式，而不是加大决心。
   🔴 CHECKPOINT 3：调整依据是记分板数据，而不是"感觉没做好"。

**如果这一步失败**

| 步骤 | 触发条件 | 一线修复 | 兜底 |
|---|---|---|---|
| 1 | 说不出深度产出，只说"想更专注" | 问"如果三个月后只能拿出一样成果，是什么？" | 先转 deepwork-shallow-shutdown 做时间盘点，再回来 |
| 2 | 选了双峰式但老板不允许整天消失 | 降为节奏式，用固定早段或午后段 | 用"每周一次半天"做试点，带着数据再谈 |
| 2 | 新手想用新闻记者式 | 说明切换成本高，先用节奏式练 4–6 周 | 允许"节奏为主 + 捡到的空当为辅" |
| 3 | 仪式越做越复杂、开工前准备半小时 | 删到只剩三行，准备动作 ≤5 分钟 | 只保留"固定地点 + 固定结束时间" |
| 4 | 记分板记了几天就忘 | 放到抬眼可见的位置，和每周复盘绑在同一时间 | 改为每天收工时补记一次（并入停工仪式） |
| 5 | 记分板显示达标，但成果没进展 | 检查深度块是否被用在了浅层事务上 | 用应届生培训月数法（deepwork-shallow-shutdown）给块内任务打分 |

### B（Boundaries，边界）
- **不是普适药方**：作者自己的特异性规则——高管、部分销售、游说者等靠持续连接创造价值，不应外推（PAGE 28–30）。但也别太快给自己贴"我的岗位不需要深度"的标签，Perlow 的 BCG 实验显示很多"必须随时在线"的假设经不起测试。
- **自主度门槛**：日程完全由他人决定（一线服务、轮班、入门级岗位）、重度照护者，只能取局部（如固定一个短段），并要承认结构性限制，不把失败归咎于个人意志。
- **防过度**：每日深度上限约 1–4 小时只是粗略经验值；作者坦言极端深度的那一年让他精疲力竭。若用户为了深度牺牲睡眠、健康、家庭，提醒降量。
- **证据强度**：四种方式与仪式来自案例归纳，4DX 是咨询框架 + 作者自述，均无对照研究；"意志力耗竭"前提存疑。对用户说"值得试两周看数据"，不说"科学证明"。
- **协作型深度**：有些问题和搭档一起在白板前轮流深挖效果更好（书中贝尔实验室例子，史料来源需谨慎），本 skill 默认个人排程，协作情境需另外商量。
- **安全**：出现耗竭、长期失眠、情绪低落 → 建议找专业人士；出现自伤或自杀信号 → 立即停止，按 psyche 第五节危机话术回应。用户要诊断（"我是不是 ADHD"）→ 不做诊断，建议去精神科或心理门诊评估。

## 💬 输出格式

给用户的回复按序：
1. 一句话复述用户的关键约束（用他的原话）；
2. 推荐的一种方式 + 两句理由（扣回他的自主度和产出），并点出最可能失败的地方；
3. 仪式三行（地点时长 / 规则 / 支撑）；
4. 记分板一句话（记什么、贴哪、每周何时复盘）；
5. 一句证据提醒（这是可试验的做法，两周后看数据调整）；
6. 全文只问 1 个问题（通常问最缺的输入）。

不写 skill 名、不罗列四种方式的全部定义。

**示例**（用户："在职读博，白天上班晚上带娃，论文半年没动。"）
```
白天上班、晚上带娃，你能自己掌控的大概只剩清晨。
建议每天固定一段清晨时间写论文，比如 6:00–7:30，周末也不例外。比"等有空再写"靠谱，因为不用每天重新决定什么时候写。最容易垮在头两周的早起，所以前一晚就把明天要写的那一节打开放好。
仪式：书桌一角，90 分钟到点就停；开写前手机放到客厅，不开浏览器；先倒一杯水，再看一眼昨天停下的那一句。
记分：一张按周分行的卡片贴在显示器旁，每写满半小时画一笔，写完一节就圈起来；周日晚上花 10 分钟看看本周画了几笔。
这套做法来自作者和受访者的经验，没有严格实验，先试两周，看笔数再调。
你家里早上通常几点开始有人需要你？
```
