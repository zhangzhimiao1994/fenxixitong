## 🧭 决策树

```
用户：想做一件需要长时间专注的事，但挤不出 / 守不住整块时间
│
├── 🛑 自伤或自杀信号 → 立即停止，按 psyche 第五节危机话术回应
├── 🛑 为赶进度长期少睡、已有心慌失眠或情绪低落 → 不排深度时段，按步骤 1 转介
├── 主诉是"怎么每天坚持做某件事"（运动、背单词、早起） → ❌ habit-starter-design / habit-streak-plateau
├── 有时间段，但一坐下就想刷手机 → ❌ deepwork-embrace-boredom
├── 日程被会议/消息填满，想先压缩浅层事务 → ❌ deepwork-shallow-shutdown（可回到本 skill）
├── 角色价值就是随时响应（CEO 决策、值班、客服、部分销售）
│      → ⚠️ 步骤 2 特异性检查：说不出一项深度产出就说明本方法不适用
│
└── 有一项明确的深度产出 + 日程至少部分可控 → ✅ 先过步骤 1，再按入口：
       ├── 还没想过"用哪种方式排深度" → 步骤 2–3
       ├── 选好了但每次开工都磨蹭 → 步骤 4（仪式）
       └── 能开工但时断时续、几周就散 → 步骤 5（记分板）
```

## 📥 输入与证据假设

**需要从用户处拿到（缺了就在唯一的问题里问最关键的一项）**：
1. 深度产出是什么：能否一句话说清，是否"离散、清晰、主要靠个人完成"；
2. 日程自主度：能否整天/连续几天消失？能否每天固定 1–2 小时不被打扰？还是只能捡空当？
3. 熟练度与信心：以前是否在碎片时间里成功切换进深度状态过；
4. 现有约束：照护责任、老板或客户对回复速度的期待、通勤；
5. 当前基线：最近一周大约有几小时真正不受打扰的专注。

**证据假设（必须如实对用户说）**：
- 四种方式是作者从 Knuth、荣格、Adam Grant、Chappell、Isaacson 等案例归纳的分类，**不是实验比较的结果**；名人案例有幸存者偏差。
- "意志力有限所以要靠惯例"这一前提里，自我损耗效应在大规模重复研究中站不住；但"别每次临时决定、用固定安排代替决心"仍是合理的工作假设。
- 4DX 来自企业咨询实务；作者论文从 4 篇到 9 篇是 n=1 自述，同期有终身教职压力等混杂因素。

## 📖 RIA+E+B

### R（Reading，转述）
- 规则1 开头（PAGE 59–60）：作者认为人整天都在和"去做点轻松事"的欲望较劲，所以要把深度工作交给惯例和仪式，而不是靠临时下决心。
- 四种哲学（PAGE 60–70）：**禁欲式**把浅层义务砍到极少，适合贡献"离散、清晰、个人化"的人（Knuth 不用邮件，信件由助手每季度批处理）；**双峰式**划出至少一整天的闭关段，其余时间开放（荣格的塔楼；Grant 把课集中在秋季，研究学期内每月 1–2 次闭关 2–4 天、挂邮件自动回复）；**节奏式**每天固定时段（Chappell 全职工作加新生儿，临时找空当一年只写出一章，改成每天 5:30–7:30 后每两三周一章初稿）；**新闻记者式**随时切入，作者明说不适合新手，需要熟练和对项目的信心。作者提醒：选错方式会让习惯还没扎根就垮掉。
- 仪式化（PAGE 70–72）：引 Currey 的观察——"waiting for inspiration to strike is a terrible, terrible plan"（等灵感是个糟糕的计划）。有效仪式要回答三问：在哪做、做多久；开始后按什么规则做（如禁网、每 20 分钟字数）；用什么支撑（咖啡、食物、散步、材料摆放）。
- 宏大姿态（PAGE 72–74）：罗琳住进酒店写完终章、Shankman 往返东京的航班上写完书稿；重点不是环境本身，而是投入带来的"这件事很重要"的心理。
- 4DX（PAGE 79–84）：只盯少数极其重要的目标；以"投入该目标的深度工作小时"作领先指标；墙上贴一张按周分行的卡片计数，产出里程碑时把对应那一小时圈出来；每周复盘。

### I（Interpretation，白话）
难的不是"知道要专注"，而是每天都要重新决定"什么时候、在哪、做多久"，这很容易输给眼前的消息。四种方式在回答同一个问题：**你的日程能给出多大、多规律的整块？** 能砍掉杂务就禁欲，能整天消失就双峰，只能每天挤一小段就节奏，日程完全不可预测但你很熟练就新闻记者。仪式解决"开工内耗"，记分板解决"时间一长就散"：结果指标（论文数、字数）几个月才动一次，深度小时数每天都会动。

### A1（书中应用，转述）
- 作者本人：用新闻记者式写书，但并非完全随缘——每周初预排深度时段、每天早上微调；用纸卡记分板记录深度小时，一年接收论文 9 篇，同时承认这一年非常消耗（PAGE 83–84、154）。

### E（Execution，执行步骤）
1. **🛑 STOP 安全筛查**
   输入：用户原话。核对：自伤或自杀信号；长期少睡、心慌、失眠、情绪低落；是否在要诊断（"我是不是 ADHD"）。
   输出：通过，或转介去向。自伤 → 按 psyche 第五节危机话术；少睡心慌、情绪低落 → 停止排程，先降量，去医院心内科、精神心理科或心理咨询机构；要诊断 → 不做诊断，去精神科或心理门诊评估。全部不命中才进入步骤 2。
2. **特异性检查 + 锁定一项深度产出**
   输入：用户的岗位与想做的事。输出：一句话深度产出 + 可见成果（对应输出格式第 1 项）。
   请用户说出"接下来 1–3 个月最需要深度的那件事"。价值主要来自随时响应且说不出深度产出 → 告知本方法可能不适用并停止。
   🔴 CHECKPOINT 1：核对产出是否具体到别人能判断"做完没有"。不具体 → 先按用户原话里最像产出的那件事给出完整方案，把"如果三个月后只能拿出一样成果，是什么？"作为唯一问题；下一轮仍说不出 → 转 deepwork-shallow-shutdown 先做时间盘点。
3. **匹配深度方式**
   输入：产出、自主度、熟练度、约束。输出：方式名 + 最小单位 + 代价（对应输出格式第 2 项）。对照下表，取第一个成立的行：

   | 条件 | 推荐 | 最小单位 |
   |---|---|---|
   | 贡献离散清晰、个人化，且每周必须响应的浅层事务 ≤2 小时、无需对客户/上级保持当日回复 | 禁欲式 | 常态 |
   | 有必要的浅层职责，但能整天或连续几天消失（并提前告知） | 双峰式 | ≥1 整天 |
   | 每天都有甩不掉的浅层工作，或自律需要外部结构 | 节奏式 | 每天固定 60–120 分钟 |
   | 日程不可预测 + 曾多次在碎片时间成功进入深度 + 对项目有信心 | 新闻记者式（每周初预排） | 随时 |

   独立开发者、自由职业者只要有客户沟通义务，第 1 行不成立，从第 2 行起判。自主度信息缺失 → 默认按节奏式给方案，把自主度作为唯一问题。

   🔴 CHECKPOINT 2：给方案前核对用户能否承担该方式的代价（对同事声明"周三全天不在线"、每天早起）。用户已表示做不到 → 降一级（双峰→节奏）；用户没提 → 照常给出完整方案，在第 2 项点明代价；代价能否承受不单独再问。
4. **设计仪式**
   输入：步骤 3 的方式与时段。输出：仪式三行（对应输出格式第 3 项）——地点与时长（每次都有明确结束点）；进行中的规则（是否断网、手机放哪、什么指标）；支撑（开工前的固定动作、所需材料提前备好）。项目卡死且用户能承受代价时，加一次性宏大姿态（短期包场图书馆/酒店）。完成判据：三行各 ≤20 字，第一行含明确结束时刻。
5. **4DX 记分板**
   输入：目标与每周可用深度时段。输出：记什么、贴哪、每周何时复盘（对应输出格式第 4 项）。
   目标 ≤2 个；领先指标 = 投入该目标的深度小时；按周分行的纸卡或表格贴在工作位，完成里程碑时圈出对应小时；每周固定 10 分钟复盘：上周几小时、什么挡住了、下周排在哪。深度块总量以每日 1–4 小时为上限，新手从每天约 1 小时起。完成判据：写明贴在哪（具体位置）和复盘时间（周几几点）。
6. **两周后校准**
   输入：两周记分板数据。输出：维持 / 回到步骤 3 换方式。连续两周达不到计划的一半 → 回到步骤 3 换方式，而不是加大决心。
   🔴 CHECKPOINT 3：核对调整依据是记分板数据，而不是"感觉没做好"。用户只有感觉、没有数据 → 先补记两周再讨论换方式。

**如果这一步失败**

| 步骤 | 触发条件 | 一线修复 | 仍失败兜底 |
|---|---|---|---|
| 1 | 用户否认疲劳，但提到每天只睡五六小时 | 复述他的睡眠时长，说明先恢复睡眠再排深度 | 坚持要排 → 只排每天 1 小时并写明就医渠道 |
| 1 | psyche 无法调用 | 直接给当地心理援助热线（如 12356），紧急情况拨 120 或 110 | 停止本 skill 其余内容 |
| 2 | 说不出深度产出，只说"想更专注" | 问"如果三个月后只能拿出一样成果，是什么？" | 先转 deepwork-shallow-shutdown 做时间盘点，再回来 |
| 3 | 选了双峰式但老板不允许整天消失 | 降为节奏式，用固定早段或午后段 | 用"每周一次半天"做试点，带着数据再谈 |
| 3 | 新手想用新闻记者式 | 说明切换成本高，先用节奏式练 4–6 周 | 允许"节奏为主 + 捡到的空当为辅" |
| 3 | 照护责任让任何固定段都排不出 | 找每天最稳定的 30 分钟（孩子午睡、通勤后）作最小固定段 | 只排周末一次半天，并承认这是结构性限制、不是意志问题 |
| 3 | 用户否定所有方式（"都不现实"） | 只保留仪式 + 记分板，固定段压到每天 30 分钟试两周 | 两周数据出来后回到步骤 3 重选 |
| 4 | 仪式越做越复杂、开工前准备半小时 | 删到只剩三行，准备动作 ≤5 分钟 | 只保留"固定地点 + 固定结束时间" |
| 5 | 记分板记了几天就忘 | 放到抬眼可见的位置，和每周复盘绑在同一时间 | 改为每天收工时补记一次（并入停工仪式） |
| 5 | 用户要求每天排 6 小时以上深度 | 说明每日深度上限约 1–4 小时，按 4 小时排 | 不加码；超出部分排浅层或休息 |
| 6 | 记分板显示达标，但成果没进展 | 检查深度块是否被用在了浅层事务上 | 用应届生培训月数法（deepwork-shallow-shutdown）给块内任务打分 |

### B（Boundaries，边界）
- **不是普适药方**：作者自己的特异性规则——高管、部分销售、游说者等靠持续连接创造价值，不应外推（PAGE 28–30）。但也别太快给自己贴"我的岗位不需要深度"的标签，Perlow 的 BCG 实验显示很多"必须随时在线"的假设经不起测试。
- **自主度门槛**：日程完全由他人决定（一线服务、轮班、入门级岗位）、重度照护者，只取局部（固定一个短段），并承认结构性限制，不把失败归咎于个人意志。
- **防过度**：每日深度上限约 1–4 小时只是粗略经验值；作者坦言极端深度的那一年让他精疲力竭。用户为了深度牺牲睡眠、健康、家庭 → 先降量。
- **证据强度**：四种方式与仪式来自案例归纳，4DX 是咨询框架 + 作者自述，均无对照研究；"意志力耗竭"前提存疑。对用户说"值得试两周看数据"，不说"科学证明"。
- **协作型深度**：有些问题和搭档一起在白板前轮流深挖效果更好（书中贝尔实验室例子，史料来源需谨慎），本 skill 默认个人排程，协作情境另行商量。
- **安全**：见决策树前两行与步骤 1。

## 💬 输出格式

给用户的回复按序（第 1–4 项分别对应步骤 2–5 的输出）：
1. 一句话复述用户的关键约束（用他的原话）；
2. 推荐的一种方式（按步骤 3 匹配表得出），必须含一个具体时段（几点到几点，或周几）+ 一句理由（扣回他的自主度和产出）+ 一句为什么不选相邻方式（如"先试一整天，而不是直接闭关两天"），并点出最可能失败的地方；若推荐双峰式，补一句：Perlow 的实验显示，多数客户和同事能接受提前明确告知的不在线时段；
3. 仪式三行（地点时长 / 规则 / 支撑）；
4. 记分板一句话（记什么、贴哪、每周何时复盘）；
5. 一句证据提醒（这是可试验的做法，两周后看数据调整）；
6. 全文只问 1 个问题（通常问最缺的输入）。

**保留常识**（baseline 常见、本 skill 容易漏的，命中时各加半句，不另起一项）：
- 有家人照护 → 在第 2 项里加一句"和家人约好这段时间由谁接手"；
- 有客户或同事要找你 → 给一个紧急通道（"急事打电话"），并提前告知统一回复时间；
- 仪式的"支撑"一行里写明每次开工先定一个本次小目标（如"写完 300 字""改完一节"）。

**写法限制**：全文 ≤400 字；不写 skill 名、不罗列四种方式，不说"节奏式""4DX"等术语。

**示例**（用户："我是中学老师，想利用课余写一本教辅书，课表是固定的，可空课总被学生和杂事占掉，写了三个月才两页。"）
```
课表固定、空课却总被学生和杂事占掉——你缺的不是时间，是一段别人默认不会来找你的时间。
每周固定两段空课专门写书，比如周二第三、四节和周四第二节，像上课一样写进课表；不等寒暑假集中写，因为平时的学生和杂事甩不掉。最容易垮在头两周被学生"就问一题"打断，所以提前跟学生说"这两段我在备课，有问题放学后来"，急事请班长来找。
仪式：图书馆角落或空教室，到下课铃就停；手机静音放包里，只开书稿文档；每次开写前先写一句"这节课写完第几题的讲解"。
记分：一张按周分行的卡片夹在教案里，每写满一节课画一笔，写完一章圈起来；周五放学后花 10 分钟数笔数。
这套做法来自作者和受访者的经验，没有严格实验，先试两周，看笔数再调。
你的空课里，哪几段最常被临时调去代课或开会？
```
