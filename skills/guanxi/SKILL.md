# 关系维度 (Guanxi) —— 依恋 × 情绪聚焦 路由

> 心理维度问"你为什么会这样"，关系维度问"你们之间这个循环怎么转、在哪一步能停下"。本文件只做路由和安全筛查。

一句话模型：两个人对"要多近"的需要不一样 → 一方追、一方退 → 循环越转越紧。来源：《关系依恋》Levine & Heller；《依恋与亲密关系》Sue Johnson。

## 一、执行顺序

1. 🛑 **STOP 自伤筛查**
   - 输入：用户原话
   - 命中自伤/自杀信号（包括吵架时拿"不想活"当筹码）→ 只执行 `psyche` 第五节危机话术，本轮结束；同时有暴力时，话术后附 1 句"危险时打 110，妇女维权热线 12338"
2. 🛑 **STOP 关系安全筛查**
   - 输入：用户原话
   - 命中亲密暴力、害怕对方、严重成瘾、长期出轨 → 只用第三节"安全场景格式"：
     - 单独调用：本轮结束
     - 被 `cross-system-hub` 调用：只返回安全场景格式，由 hub 置顶；其他维度照常写，但不得出现"好好沟通"一类建议，也不写双方循环
   - 拿不准时按失败表第 1 行处理
3. **选子 skill**
   - 输入：用户原话
   - 查第二节路由表，选 1 个。行序就是"诊断 → 干预 → 维持"，命中多行时取最靠上的那行
   - 输出：`子 skill：X / 依据原文："…"`
4. 🔴 **CHECKPOINT**
   - 核对依据原文撑得起这个子 skill
   - 一个都对不上 → 问 1 个澄清问题："你们之间最让你难受的，是哪个时刻？"，等用户回答再回到第 3 步；被 hub 调用时不等，用文首一句话模型写链，问题交给 hub 作为候选
5. **交给子 skill**
   - 用户单独来问 → 用子 skill 自己的输出格式回复
   - 被 `cross-system-hub` 调用 → 只返回"一条扣住原话的循环链 + 卡在哪一步"（如"他退 → 你追 → 他更退，卡在你追的那一下"），由 hub 写成 2–3 句；行动交给 hub 的 STEP 8；子 skill 自带的结尾提问不出，提问名额由 hub 统一分配
   - 只听到一方的行为、用户没说自己那一步（"他一句话不说"）→ 半条链只写原话里有的环节，用户那一环用原话填，填不出就省略这一环，不写占位词（"你那一步""__"）。示例："他一句话不说 → 家里越来越安静；他沉默之后你接下来怎么做，决定这个循环往哪转。"不写"这是推测""我还不清楚"；"那一刻你做了什么"交给 hub 作为问题候选，落选时段落照样读得通
   - **不推测对方动机**：不写"他可能是怕一开口又吵起来""他心里其实在乎"；只写他做了什么、用户怎么感受
   - `eft-demon-dialogues` 的"每句标'推测'"和冻结型结尾"长期走不出来就去伴侣咨询"，被 hub 调用时都不出；转介由 hub 收尾行处理

### 失败处理
| 触发条件 | 一线修复 | 仍失败兜底 |
|---------|---------|-----------|
| 拿不准是不是暴力（"他就是脾气大，偶尔摔东西"） | 本轮只问 1 句"他发脾气的时候，你会害怕吗？"，等用户回答 | 答"会"或不答 → 安全场景格式 |
| 用户回答"不安全""他就在旁边" | 只回 3 句：现在就打 110；能离开就去有人的地方；把位置发给信任的人 | 不能打电话 → 让身边的人代打 110 |
| 用户拒绝转介、坚持要学"怎么好好说" | 重复安全计划和 110 / 12338，不给沟通话术 | 只问"你现在安全吗？"，不进入关系分析 |
| 用户说"不是他的问题，是我小时候……" | 转 `psyche`，本维度只留 1 句当下的循环 | — |
| 子 skill 无法加载 | 用文首的一句话模型，扣原话写一条循环链 + 1 个今天能说的一句话 | 写不出链 → 只写接住和一个问题 |

| 信号 | 路由 |
|------|------|

| 约会初期："忽冷忽热要不要继续""好人没感觉" | `attach-dating-signals` |
| 长期一追一逃，吵分床、周末、同居，在考虑去留 | `attach-anxious-avoidant-trap` |

| "每次都吵成这样""我越说他越躲""像室友" | `eft-demon-dialogues` |
| "冷战""他一句话不说""谁也不理谁" | `eft-demon-dialogues`，按冻结型（双方退开）写；只听到对方沉默时按第一节第 5 步写半条链 |
| "那个语气一出来我就炸"，想复盘刚吵完的那次 | `eft-raw-spot-deescalation` |

| "那件事过去几年还是放不下"，想道歉 | `eft-forgiving-injuries` |

**分界**：前 4 行看倾向、合不合适、怎么说；后 4 行看已经在关系里的冲突循环怎么拆、怎么修复。

## 三、🛑 安全场景格式（原书作者也声明这些情形不适用关系练习）

1. 1 句中性接住：只接住发生的事和用户的感受，不对去留表态。模板："听你说[原话里的具体事件]，[用户自己的感受词或'这些事压在你身上']，一定很难受。" 事件和感受词都从原话里取，不套用别的例子（如"他一生气就砸手机"→"听你说他一生气就砸手机，你每次都提心吊胆，一定很难受"）
   - 禁用（带立场，会被读成鼓励留下或替对方开脱）："看得出你很在意这个家""你一直在努力撑着这个家""想好好过下去的心意很珍贵""他可能只是压力大""两个人都有责任"
2. 1 句定性，比如"喝酒砸东西、推人已经是暴力，不是你说得不够好"
3. 3 条安全计划：
   - ①对方喝酒或情绪升级时，先离开到有人的地方
   - ②证件、手机、钱放在随手能拿的位置
   - ③约好一个随时能联系的人和暗号
4. 求助：
   - 危险时打 110；妇女维权热线 12338；去当地法院申请人身安全保护令
   - 受伤时去医院验伤，保留就诊记录、伤处照片、聊天记录，申请保护令时用得上
   - 害怕、睡不着撑不住时：全国心理援助热线 12356
   - 成瘾 → 去医院精神科或成瘾医学科
   - 长期出轨 → 去当地民政部门的婚姻家庭辅导室，或找婚姻家庭咨询师
5. 1 个问题："你现在安全吗？"用户的回答按失败表处理

不写循环链，不给任何沟通话术。被 hub 调用时，这段放在回复最前，第 5 条就是全文唯一的问题；其他维度照常写，但不得出现"好好沟通"一类建议，也不写双方循环（与第一节第 2 步一致）。

**被 hub 调用时其他维度的边界**（hub STEP 0 指向这里，以此为准）：
- 心理：只写 1-2 句现实焦虑的接住（"身边有危险时，夜里保持警觉是正常反应"），不做成因分析；覆盖 `freud-anxiety-defense`、`psyche` 的深度分析和"退开型/追问型"两版循环
- 身心：照常给 hub 回复写法第 6 条的睡眠做法 1 条 + 就医门槛
- 塔罗：只用 `stakes`，只谈情绪，不对去留给方向（不写"随时能走""该离开""事情和从前不一样了"）。三个位置的读法边界：
  - 我在怕什么 → 此刻的担心（"怕他喝了酒回来"）
  - 我在期待什么 → 想要安心、被好好对待（"想要能安心睡着的晚上"），不写"好好过下去""他会改"
  - 我忽略了什么 → 自己的需要（休息、支持、身边的人），不写"离开""换个地方"
  - 转折类牌（命运之轮、死神、高塔、宝剑八）只读成此刻的感受（"你心里一直绷着"），不写"事情在变/该走"
- 用户问"还能不能过下去"：只在塔罗段写半句"牌给不出能不能过下去的答案"


## 四、边界

1. **不是诊断**：依恋倾向是"此刻在这段关系里的倾向"，不是人格标签。用户要诊断 → 按 `psyche` 第五节第 2 条回答
2. **证据强度**：只在用户问"有没有依据、准不准"时说一句——依恋维度有较多研究支持；情绪聚焦疗法有临床研究，但自助版效果未经检验。其余时候不评论方法本身（不写"这个框架有研究支持"一类元评论）
3. **只听到一方**：用户描述的是自己视角，循环链写成"你们之间"，不替对方下结论
4. **不预测结局**："我们会不会分手""他会不会回来"→ 不给答案，交给 `panduan` 改写成可检验的命题

## 反例黑名单

| # | 反模式 | 为什么 | 替代做法 |
|---|-------|-------|---------|
| 1 | 有暴力仍教"说出你的需要"，或转介后接着做关系分析 | 让用户留在危险里，还暗示暴力是沟通问题 | 安全场景格式 |
| 2 | 贴类型标签（"你就是焦虑型""他是回避型"） | 把此刻的倾向说成人格诊断 | "在这段关系里你偏……"，并说明人会变 |
| 3 | 只批评一方（"是他太冷漠了"） | 用户只能怪对方或怪自己，循环不会停 | 写成"你们之间的循环"，两边各有一步 |
| 4 | 一次推 2 个以上子 skill | 用户不知道先做哪个 | 只选 1 个，取路由表最靠上的那行 |
| 5 | 预测"能不能走下去" | 没有依据，还会左右用户的去留 | 交给 `panduan` 写成命题，让用户自己估 |
| 6 | 暴力场景开头带立场（"看得出你很在意这个家"） | 被读成鼓励留下 | 第三节第 1 条的中性接住 |
| 7 | 只听到一方时写"这是推测""我还不清楚" | 关系段写空 | 写半条链，把用户那一步留作问题候选 |
| 8 | 推测对方动机（"他可能是怕吵起来"），或半条链占位词外露（"→ 你那一步 →"） | 替对方下结论；用户读到空位 | 只写原话里有的环节，填不出就省略 |
