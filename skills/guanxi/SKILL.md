# 关系维度 (Guanxi) —— 依恋 × 情绪聚焦 路由

## 被总入口调用时：段落契约

- 输入：用户原话、深度等级、本段是完整还是一句带过、总入口 STEP 0 的结果（普通 / 安全场景 / 经济施压）
- 关系对象分流（先定对象，再按对应一行写；总入口维度表关系行的激活信号与这里一致）：

  | 对象 | 本段必须包含 |
  |---|---|
  | 伴侣（含约会中、前任） | ①一条扣住原话的循环链（"他退 → 你追 → 他更退"），每一环都来自原话 ②卡在哪一环 ③只听到一方 → 半条链（第一节第 5 步） |
  | 家人（父母、兄弟姐妹、子女、亲戚） | ①原话里的那件事：谁做了什么 → 你怎么反应 ②哪条边界被越过（钱、隐私、决定权、时间） ③你想提的沟通请求属于哪一类（停止某件事 / 换一种说法 / 自己做决定） |
  | 上级或同事（含导师；被领导公开点名、派活、抢功等职场冲突都归这里） | ①原话里的事件和后果 ②权力差：对方握着什么（评价、分工、去留），你能自己定的是哪一块 ③能就事论事提的沟通请求（澄清标准、要书面分工、换个场合谈） |
  | 室友或朋友 | ①原话里的事件 ②边界：哪件事是共用的、规则有没有说过 ③你想提的沟通请求 |
  | 暗恋或单向 | ①原话里对方做了什么 ②你的感受（只用原话的感受词） ③你自己能决定的部分（说不说、要多近）；不推测对方心意（按总入口 C9），不给追求策略 |

  非伴侣（家人、上级或同事、室友或朋友）不用依恋、追逃、"你们之间的循环"这类伴侣说法，只用边界、沟通请求、权力差三个视角；沟通请求在本段只写类别，要说的那句话交给总入口的步骤；暴力、经济施压对任何对象都先按下面两条
- 安全场景：本段 = 第三节"安全场景格式"第 1–4 条，整块置顶；第 1 条的接住句就是全文的接住句，主要矛盾紧跟第 2 条定性句写 1 句处境，不再把事件复述一遍
- 经济施压：本段 = 第三节"经济施压格式"，不置顶，放在关系段的位置（主要矛盾之后）
- 环节怎么数：一个人的一个具体行为或反应算一环（"他一句话不说"）；原话里由它带出的后果也算一环（"冷战""家里冷下来"）。对方行为 + 后果 = 两环，按半条链完整写
- 一句带过时写什么：按总入口 4.4 判据——原话那一个环节 + 多说一层（这一环之后原话里接着发生了什么）；写不出这一层 → 把那个环节并进主要矛盾段做一个分句，本段不写
- 对象不明（"关系一团糟"，没说是和谁）：本段不写，在主要矛盾段用一个分句点到"关系这头还没说是和谁"，并提交候选④"你说的关系一团糟，指的是和谁"；不推断对象
- 篇幅：完整约占全文 1 成（主要矛盾在关系时一律完整，约 1.5 成）；一句带过 1 句；安全场景格式、⚖️ 清单不计正文。完整时占 1 个步骤（总入口至少分 1 个步骤落在关系上）
- L1 保留：循环链里卡住的那一环（非伴侣：分流表第②项），并成 1 句
- 可提交的候选问题：①"你现在安全吗？"（安全场景）、"他发脾气的时候，你会害怕吗？"（拿不准是不是暴力）；②经济施压时用 hub 参考文件第四节对应版本"自己填"项的措辞；④"那一刻你做了什么"、"你们之间最让你难受的是哪个时刻？"；⑤ 子 skill 的待问项
- 本段禁止：推测对方动机（"他可能是怕吵起来"）；占位词（"你那一步""__"）；"谁先开头说不清""两个人都有责任"这类泛化句；再引主要矛盾段引过的原话；做法和沟通话术（做法交给总入口的步骤）；转介句；`eft-demon-dialogues` 的推测标注和安慰句；安全、经济施压场景里的双方循环和"好好沟通"
- 本维度特有的失败分支：
  - 只听到对方行为 → 半条链；双方行为都没给 → 一句带过（主要矛盾在关系时仍完整，链只写原话里有的环节）
  - 原话写了双方都退开 → 冻结型；只写了对方沉默 → 半条链（优先）
  - 拿不准是不是暴力 → 提交①"他发脾气的时候，你会害怕吗？"，本段只写原话里发生的事
  - 问"他是不是真心""我该信他吗""会不会分手" → 不答，按总入口 C9
- 选用哪些子 skill：伴侣 → 第二节路由表取最靠上的 1 行，主要矛盾在关系时最多 2 个；其余对象不选子 skill，按分流表那一行写；第一节第 4 步的"一句话模型"只用于伴侣
- 格式、篇幅、提问、收尾、危机话术：见总入口全局契约（单独使用时也一样）

> 心理维度问"你为什么会这样"，关系维度问"你们之间这个循环怎么转、在哪一步能停下"。

一句话模型：两个人对"要多近"的需要不一样 → 一方追、一方退 → 循环越转越紧。来源：《关系依恋》Levine & Heller；《依恋与亲密关系》Sue Johnson。

## 一、执行顺序

1. 🛑 **STOP 自伤筛查**：命中自伤/自杀信号（包括吵架时拿"不想活"当筹码）→ 只执行 `cross-system-hub` C5，本轮结束；同时有暴力时，C5 之后附 1 句"危险时打 110，妇女维权热线 12338"
2. 🛑 **STOP 关系安全筛查**
   - 命中亲密暴力、害怕对方、严重成瘾、长期出轨 → 只用第三节"安全场景格式"；单独调用时本轮结束；被总入口调用时整块置顶，其他维度按第三节"各层的边界"
   - 命中经济施压（反复催要钱、要求取公积金/贷款/替其还债、控制工资卡或收入），且没有暴力、害怕 → 只用第三节"经济施压格式"，不做沟通练习，不回答"他是不是真心"
   - 拿不准时按失败表第 1 行
3. **选子 skill**（只在对象是伴侣时；其余对象按契约的分流表写）：查第二节路由表，选 1 个。行序就是"诊断 → 干预 → 维持"，命中多行时取最靠上的那行。输出：`子 skill：X / 依据原文："…"`
4. 🔴 **CHECKPOINT**：核对依据原文撑得起这个子 skill；一个都对不上 → 用文首一句话模型写链，提交候选④"你们之间最让你难受的，是哪个时刻？"
5. **交给子 skill，只取素材**
   - 只返回"一条扣住原话的循环链 + 卡在哪一步"（"他退 → 你追 → 他更退，卡在你追的那一下"）
   - 只听到一方的行为（"他一句话不说"）→ 半条链只写原话里有的环节，用户那一环用原话填，填不出就省略这一环。写法："[原话里他的行为] → [原话里家里或你感到的变化]"，之后接"[他的行为]之后你怎么接，决定这个循环往哪转"。不写"这是推测""我还不清楚"；"那一刻你做了什么"提交为候选④，落选时段落照样读得通
   - **不推测对方动机**：只写他做了什么、用户怎么感受
   - `eft-demon-dialogues` 输出格式里的推测标注、冻结型安慰句（"这种安静比吵架更难察觉"）、转介句都不出

### 失败处理
| 触发条件 | 一线修复 | 仍失败兜底 |
|---------|---------|-----------|
| 拿不准是不是暴力（"他就是脾气大，偶尔摔东西"） | 提交候选①"他发脾气的时候，你会害怕吗？" | 答"会"或不答 → 安全场景格式 |
| 用户回答"不安全""他就在旁边" | 只回 3 句：现在就打 110；能离开就去有人的地方；把位置发给信任的人 | 不能打电话 → 让身边的人代打 110 |
| 用户拒绝转介、坚持要学"怎么好好说" | 重复安全计划和 110 / 12338，不给沟通话术 | 只提交候选①，不进入关系分析 |
| 用户说"不是他的问题，是我小时候……" | 转 `psyche`，本维度只留 1 句当下的循环 | — |
| 子 skill 无法加载 | 用文首的一句话模型扣原话写一条循环链 | 写不出链 → 降为一句带过 |

## 二、子 skill 路由表（行序 = 诊断 → 干预 → 维持）

| 信号 | 路由 |
|------|------|
| "我是不是焦虑型""他是不是回避型"，已交往一段时间 | `attach-style-reading` |
| 约会初期："忽冷忽热要不要继续""好人没感觉" | `attach-dating-signals` |
| 长期一追一逃，吵分床、周末、同居，在考虑去留 | `attach-anxious-avoidant-trap` |
| 想把一个具体需要说出口，不显得黏人 | `attach-secure-communication` |
| "每次都吵成这样""我越说他越躲""像室友" | `eft-demon-dialogues` |
| "冷战""他一句话不说""谁也不理谁" | `eft-demon-dialogues`：原话写了双方都退开 → 冻结型；只写了对方沉默 → 第一节第 5 步的半条链（优先） |
| "那个语气一出来我就炸"，想复盘刚吵完的那次 | `eft-raw-spot-deescalation` |
| 不吵了但还是很远，想说"我怕失去你" | `eft-hold-me-tight-talk` |
| "那件事过去几年还是放不下"，想道歉 | `eft-forgiving-injuries` |

**分界**：前 4 行看倾向、合不合适、怎么说；后 4 行看已经在关系里的冲突循环怎么拆、怎么修复。

## 三、🛑 安全场景格式（原书作者也声明这些情形不适用关系练习）

1. 1 句中性接住：只接住发生的事和用户原话里的感受词，不对去留表态。写法："听你说[原话里的具体事件]，[原话里的感受词]。" 原话没有感受词 → 只写事件，不补"一定很难受"（"睡不着"是症状，当事件写）
   - 禁用（带立场，会被读成鼓励留下或替对方开脱）："看得出你很在意这个家""你一直在努力撑着这个家""想好好过下去的心意很珍贵""他可能只是压力大""两个人都有责任"
2. 1 句定性，比如"喝酒砸东西、推人已经是暴力，不是你说得不够好"
3. 3 条安全计划：
   - ①对方喝酒或情绪升级时，先离开到有人的地方
   - ②证件、手机、钱放在随手能拿的位置
   - ③约好一个随时能联系的人和暗号
4. 求助：
   - 危险时打 110；妇女维权热线 12338；去当地法院申请人身安全保护令
   - 受伤时去医院验伤，保留就诊记录、伤处照片、聊天记录，申请保护令时用得上
   - 害怕、睡不着撑不住时：全国心理援助热线 12356
   - 成瘾 → 去医院精神科或成瘾医学科
   - 长期出轨 → 去当地民政部门的婚姻家庭辅导室，或找婚姻家庭咨询师
5. 问题"你现在安全吗？"：提交为候选①，由总入口放在问题位；用户的回答按失败表处理

不写循环链，不给任何沟通话术。

**被总入口调用时各层的边界**（hub STEP 0 指向这里，以此为准；按维度表的"层"列适用，新增维度自动套用）：
- 观察层的其他入口：每个只写 1 句，接住现实里的焦虑或身体反应（"身边有危险时，夜里保持警觉是正常反应"这一类，意思自写），不做成因分析、不写双方循环，即使用户点名；入口契约里的常识提示（如睡眠做法）照给；门槛句由总入口写
- 校准层：不对去留、结局给几成
- 象征层：只读情绪和心态，不对去留给方向（不写"随时能走""该离开""事情和从前不一样了"）。用牌阵的入口只用 `stakes`，每个位置写"牌义里一个贴近的词 + 原话里一个细节"，落在位置边界内；原话里没有可扣的细节时，只写牌义那个词，不把原话反过来写成细节：
  - 我在怕什么 → 此刻的担心（"怕他喝了酒回来"）
  - 我在期待什么 → 想要安心、被好好对待，不写"好好过下去""他会改"
  - 我忽略了什么 → 自己的需要（休息、支持、身边的人），不写"离开""换个地方"
  - 转折类牌（命运之轮、死神、高塔、宝剑八）只读成此刻的感受，不写"事情在变/该走"
  - 牌义和位置边界对不上 → 写"这张和你说的关系不明显"
  - 关键张的原因只落在此刻的感受和需要，不提"这段关系在你心里的分量""旧日的温情"一类会被读成去留的话
- 用户问"还能不能过下去"：只在塔罗段写半句"牌给不出能不能过下去的答案"

**经济施压格式**（反复催钱、要你动公积金/贷款/替他还债、控制收入；没有暴力和害怕时用）：
1. 接住由总入口开头那句承担，本段从第 2 条写起
2. 风险信号：只点 ⚖️ 清单"3 个信号"里没有、但原话里出现的那条（如控制工资卡、收入）；"反复催你拿钱"的定性只在清单里写，"要你动公积金"由清单的公积金行处理，都不在本段重复；原话里没有清单外的信号 → 本条省略
3. 事实核对清单由总入口放在最后一个象征段之后（hub 参考文件第四节"替伴侣还债 / 取公积金"），本段不重复清单内容
4. 他人内心不答：不回答"他是不是真心""我该信他吗"，只看能核对的事实（"真不真心看不出来，账单和借条看得出来"）
5. 段末 1 句升级出口："如果他威胁你、用分手相逼，或者你开始害怕，打妇女维权热线 12338。"真出现这些 → 转上面的安全场景格式

不给沟通练习和"怎么跟他谈"的话术；只为核对事实的那句话（请对方提供账单和借条）交给总入口的步骤。塔罗 `stakes` 读法边界：怕 → 原话里出现过的那件事（如被催），原话没有怕的对象时按 `tarot` 契约只写牌义词；期待 → 不再被催、账看清楚；忽略 → 自己的钱和规则；转折牌只读成感受；对不上写"这张和你说的关系不明显"。

## 四、单独使用时

内容按段落契约写；格式、篇幅、提问、收尾见总入口全局契约。总入口里只剩本维完整时不转到这里，见总入口 STEP 1。

## 五、边界

1. **不是诊断**：依恋倾向是"此刻在这段关系里的倾向"，不是人格标签。用户要诊断 → 按 `psyche` 第五节第 2 条回答
2. **证据强度**：只在用户问"有没有依据、准不准"时说一句——依恋维度有较多研究支持；情绪聚焦疗法有临床研究，但自助版效果未经检验。其余时候不评论方法本身
3. **只听到一方**：循环链写成"你们之间"，不替对方下结论
4. **不预测结局**："我们会不会分手""他会不会回来"→ 被总入口调用时按 C9 改写；单独使用时交给 `panduan` 写成可检验的命题
