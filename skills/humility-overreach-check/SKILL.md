# Humility Overreach Check

## R — 原文引用

### 高位过度
> 乾·上九：亢龙有悔。（第一卦）
> 乾·用九：见群龙无首，吉。

### 力量撞墙
> 大壮·九三：小人用壮，君子用罔，贞厉。羝羊触藩，羸其角。（第三十四卦）
> 大壮·上六：羝羊触藩，不能退，不能遂，无攸利，艰则吉。

### 丰盛遮蔽
> 丰：亨，王假之，勿忧，宜日中。（第五十五卦）
> 丰·六二：丰其蔀，日中见斗，往得疑疾。
> 丰·上六：丰其屋，蔀其家，窥其户，阒其无人，三岁不觌，凶。

### 成功后混乱
> 既济：亨，小利贞，初吉终乱。（第六十三卦）
> 既济·上六：濡其首，厉。

### 谦虚的力量
> 谦：亨，君子有终。（第十五卦）
> 谦·初六：谦谦君子，用涉大川，吉。 — 最谦虚的人能涉大川
> 谦·九三：劳谦君子，有终吉。 — 有功劳而谦虚
> 谦·六四：无不利，撝谦。 — 发挥谦虚精神，无往不利
> 谦·上六：鸣谦，利用行师，征邑国。 — 谦不是不行动，是可以行动

### 坤的收敛智慧
> 坤·六四：括囊，无咎无誉。（第二卦） — 封口收缩，不求赞美也不犯错

### 蓄积未满
> 小畜·上九：既雨既处，尚德载，妇贞厉。月几望，君子征凶。（第九卦） — 满月之前行动危险

## I — 方法论骨架

《周易》反复提醒：强≠可以继续强推，高位≠无风险，成功≠结束。

**过盛风险的三种来源**：

| 类型 | 卦象 | 症状 | 本质 |
|------|------|------|------|
| 力量过盛 | 乾·上九 | 以为力量越大越好 | 冲到没有落点 |
| 繁荣遮蔽 | 丰 | 光芒太盛反而看不清 | 光变成了障 |
| 完成后松懈 | 既济 | 以为结束就安全 | 尾部风险被忽视 |

**谦的两种误解**：
1. ❌ 谦 = 退缩、示弱、不做
2. ✅ 谦 = 有实力但不仗势，保持实力但降低攻击性（谦·上六"利用行师"）

**坤的收敛**：
- 坤·六四"括囊"是主动选择缩小暴露面，不是被迫退让。

## A1 — 源文件应用案例

### 案例 1：亢龙有悔 — 最高处的风险
- **文本**："亢龙有悔。"
- **解读**：龙飞到最高处，再往上没有空间了，继续冲只会后悔。
- **应用**：成功者最大的风险不是能力不够，而是不清楚自己已经到顶。检查：继续推能落在哪里？

### 案例 2：羝羊触藩 — 力量越大，卡住越疼
- **文本**："羝羊触藩，羸其角。""不能退，不能遂。"
- **解读**：羊用角撞篱笆，角卡住了，进退两难。
- **应用**：强力推进前先看边界——制度、资源、关系、合规——哪个可能是那排"藩"？

### 案例 3：丰其屋，蔀其家 — 繁荣自蔽
- **文本**："丰其屋，蔀其家，窥其户，阒其无人。"
- **解读**：房子很大很华丽，但里面被遮蔽了，看进去一个人都没有。
- **应用**：组织大了、业绩好了，要检查：信息是否还能穿透？底层声音还听得到吗？

### 案例 4：既济初吉终乱 — 完成后的松懈
- **文本**："初吉终乱。"
- **解读**：刚完成时一切看起来都好，但松懈下来就是混乱的开始。
- **应用**：项目上线、融资成功、升职后，反而是最需要复盘和戒备的时刻。

### 案例 5：谦 — 有实力时的选择
- **文本**："谦谦君子，用涉大川，吉。""劳谦君子，有终吉。"
- **解读**：谦让的人反而能做成大事（涉大川）；有功劳而谦让的人有善终。
- **应用**：在高位时，谦不是不做，是不靠力压人、不独占功劳、给他人留空间。

## A2 — 触发场景

### 适合触发
1. 用户已取得阶段性胜利，想继续加码。
2. 用户处在权力、名声、资源或情绪高位。
3. 用户担心"太顺了会不会有问题"。
4. 用户读到乾·上九、大壮、丰、既济、谦、小畜。

### 不适合触发
1. 用户处在初创、低能量阶段，核心问题不是过盛。
2. 用户只想获得情绪鼓励。
3. 需要精确财务或法律结论。

## E — 执行步骤

### 模板：过盛风险检查表

| 检查项 | 你的回答（选项） | → 自动判定 |
|--------|---------------|-----------|
| 权力/地位是否到了顶峰？ | 还在上升 / 已到顶 / 过了顶 | 已到顶→亢龙有悔；过了顶→可能已失控 |
| 最近有没有人反对/质疑你？ | 没有（一片赞同） / 少数反对 / 多方反对 | 一片赞同→警惕：是真没问题还是没人敢说？ |
| 资源/速度/投入是否超出了承载？ | 余裕很多 / 刚好满载 / 已超载 | 已超载→大壮/大过，不是继续加码的问题 |
| 情绪是否处于持续的亢奋/自信/愤怒中？ | 冷静平和 / 略微兴奋 / 持续亢奋/易怒 | 持续亢奋→判断力可能被情绪裹挟 |
| 是否已经忽略了一些早期预警信号？ | 没发现 / 有信号但压下去了 / 信号越来越明显 | 有信号但压下去→丰卦「日中见斗」：日全食正在发生，但假装看不见 |
| 继续加码最可能的结果是？ | 更好 / 持平 / 更差（物极必反） | 更差→立即收 |

**推导规则**：4 项以上命中「过盛侧」→ 判高危；2-3 项 → 判黄色预警；0-1 项 → 正常，但需继续监测。

### 步骤

1. **填表评估**：输出 `过盛等级：[🔴高危/🟡预警/🟢正常] | 最脆弱的维度：[X] | 最可能的反转点：[Y]`
2. **标出「藩」在哪**（障碍/边界）：列出可能卡住的硬边界——制度、现金流、团队承载力、关系反弹、合规风险。
   🔴 **CHECKPOINT**：展示评估+边界，等待确认。
3. **给出明确指令**（不允许模糊建议）：`动作：[继续推进/降速X%/分权给[某人]/止盈/退出] | 原因：[Z] | 不做的代价：[W]`
4. **谦抑动作**：给一个立即可执行的降低过盛风险的小动作——比如延迟发布、减少一个承诺、公开归功于团队、引入一个反对意见。
   🛑 **STOP**：动作确认。

## B — 边界与 Fallback

### 失败模式
- 把所有成功都说成危险，压制正常进展。
- 只说"谦虚"，不指出具体过盛变量。
- 忽略用户仍可能需要推进的窗口。

### Fallback（if-then 三段式）

| 触发条件 | 一线修复 | 仍失败 → 兜底 |
|---------|---------|-------------|
| 把所有成功都说成危险，压制正常进展 | 不全盘否定。区分：是整体过头还是某一方面过头？财务可能到顶但产品还有空间——分开判断 | 分不清 → 跑 3 个维度的过盛检查：资源/影响力/速度。哪个维度过线了只约束那个维度 |
| "谦"被误解为"什么都别做了" | 纠正：谦不是退缩，是"有实力但不仗势"。保持实力降低攻击性，保持目标不强制推进 | 用户无法区分"谦"和"退缩" → 测试题："如果有人挑战你的核心利益，你会不会反击？"会 → 是谦；不会 → 可能是退缩 |
| 刚经历失败就被判"谦"，感觉被伤口撒盐 | 失败后的收敛不等于谦。先确认是"主动收敛"还是"被打后不得不退"。后者是创伤恢复期，不是谦 | 用户坚持说"我就是不行了" → 不纠正。先做恢复确认："现在你的基础功能还在吗？核心资源还在吗？" |
| 只判断"过头了该收"，不给"收多少"的具体度量 | 收不是全收。给出收的刻度：收 20%？收 50%？全收？每个刻度对应不同的代价和安全性 | 用户要确定性度量但信息不足 → 给范围而非单点："建议收 20%-40%，先试 20%，观察一个月" |
| 用户已经非常成功但拒绝收，说你嫉妒 | 不争论。反向测试："如果你不收，接下来 3 个月最坏会发生什么？那个结果你能承受吗？" | 用户说能承受 → 不再劝收。转给一条预警线："当 X 发生时，你需要在 24 小时内做出收缩决定" |
| "亢龙有悔"的提醒被当耳边风 | 不必重复提醒。换方式：不讲后果，讲同类的失败案例。"跟你处境相似的人，不收敛的，后来遇到了 A/B/C" | 用户说"我跟他们不一样" → 接受。最后一句："你是对的，你可能确实是例外。但请把 A/B/C 作为预警信号记下来" |
