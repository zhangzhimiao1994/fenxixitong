## 🧭 决策树

```
用户想"说出来"或"不再吵崩"
│
├── 对方有暴力、威胁？ → 🛑 不建议当面摊牌，先安全转介（B 段）
├── 用户现在正在气头上 / 准备发难？ → 先做步骤 1 冷静，不写脚本
├── 关系整体是追逃、在想去留？ → ❌ attach-anxious-avoidant-trap
│
└── ✅ 有一个具体需要想表达 / 有一场具体冲突
    ├── 想表达需要 → 步骤 2–5（有效沟通）
    ├── 正处在一场冲突里 → 步骤 6（五条安全冲突原则）
    └── 想当更安心的伴侣 → 步骤 7（安全基地三行为）
```

## 📥 输入与证据假设

- 需要一个**具体**的场景：什么事、对方做了或没做什么、用户想要什么。
- 用户偏焦虑时，常在"快要做抗议行为"时来问；偏回避时，常在"特别想逃"时来问。两者的入口不同（PAGE 205）。
- 我们无法替用户保证对方的反应。本 skill 的价值之一，恰恰是让对方的反应变得**可读**。

## 📖 RIA+E+B

### R（原文位置 + 转述）

- 第11章 PAGE 196–197：有效沟通有两个目的：一是选对人，对方几分钟内的反应比几个月的猜测更能说明问题；二是让需要被满足，对方不必再猜。
- 第11章 PAGE 198：判断回应的五个问题：对方是想弄清你的担心，还是在躲；是认真对待，还是让你显得可笑；是在想办法让你好受，还是只顾辩解；是像法庭一样只回应事实，还是也顾及你的感受。
- 第11章 PAGE 205：偏焦虑的人，在快要做抗议行为时用它，但要等彻底平静后（可能需要一两天）；偏回避的人，在特别想逃时用它，说明自己需要空间，并提出照顾到对方的几种方式。
- 第11章 PAGE 206–207 五原则：①"Wear your heart on your sleeve"（PAGE 206），真诚、情感上勇敢；②聚焦自己的需要，多用"我需要、我感到、我想要"；③具体；④不指责，选平静的时候说；⑤坚定、不道歉，需要本身是正当的。
- 第12章 PAGE 215 安全型化解冲突五原则：关心对方的福祉；盯住眼前的问题；不把冲突扩大化；愿意留下来谈；有效表达感受和需要。PAGE 225 列出要避免的六种做法：跑题、不说需要、人身攻击、以牙还牙、退缩、忘了对方的感受。
- 第7章 PAGE 130–131：给伴侣当安全基地的三个行为：在对方需要时可得、在背后支持而不接管、鼓励对方成长。第2章 PAGE 25：人的需要被满足得越早，越不"黏"，作者说人"only as needy as their unmet needs"（PAGE 25）。

### I（白话解释）

不安全的表达是"绕着说"：暗示、试探、冷战、发火，对方怎么反应都说明不了什么。有效沟通是"直接说"：我要什么、为什么、具体是哪件事。这样对方答应了，你得到了；对方躲了，你也看清了。两种结果都比继续猜好。

### A1（书中案例的应用）

- Greg 想和女友一起过独立日，却只会暗示"我有好几个邀约还没定"，女友当真了还帮他参谋。改成直接问"我想和你一起过，你想来我这边还是我去你那边"后，一句话就解决了（PAGE 203–204）。
- Larry 收到工作坏消息，女友要去健身，他脱口而出"你又要出门"；冷静后他道歉，说明自己其实是需要她在身边。女友给了安慰，他反而让她去健身了（PAGE 205–206）。说明**晚了也来得及**。
- Rebecca 平时不要求丈夫陪她去姐姐家，一周没见到他后突然逼他去，还骂他自私。如果她直说"这周几乎没见到你，这次你能陪我去吗"，丈夫哪怕不去，也能提出"晚上我们俩单独出去"（PAGE 219–220）。
- Andres 确诊慢性病后，妻子不停让他查资料、找二诊，他终于说明这样只会不断提醒他生病。妻子明白这是她的应对方式而不是他的，冲突随之减少（PAGE 202–203）。这是回避一方用有效沟通要空间的例子。

### A2（未来触发场景）

1. 异地恋，用户希望每天睡前视频，但怕对方觉得烦。
2. 用户需要每周一晚独处，以前都是突然消失，这次想好好说。
3. 吵架时对方翻旧账，用户想知道怎么接才不升级。

### E（执行步骤）

1. **先冷静，再开口**：如果用户正在气头上或想"让他知道厉害"，先停。偏焦虑：等到心跳和念头都慢下来再说，必要时隔一天（PAGE 205）。偏回避：在想逃的那一刻先别走，先说"我需要一点时间，晚上八点回来谈"。
2. **找出真实需要**（PAGE 209 练习）：是对方的哪些具体做法让你不安？对方做什么会让你觉得更安全、更被爱？其中哪一条你最敢先说？
3. **写脚本**，套五原则：
   - 我感到……（具体事件：当你……的时候）
   - 我需要/我想要……（具体、可执行）
   - 不加"你总是""你根本"；不加"对不起我太黏了"。
   - 偏回避者加一句："这是我自己在任何关系里都有的需要，不是你的问题"（PAGE 202）。
   🔴 **CHECKPOINT**：逐条检查脚本：有没有指责词？有没有道歉式开头？是不是具体到对方明天就能做？不过关就改。
4. **选时机说**：平静、不赶时间、不当着别人。
5. **读回应**：用 PAGE 198 的五个问题打分。对方认真回应 → 绿灯，一起想办法；对方回避、嘲笑、只讲事实 → 记下来。作者的建议是一次不代表全部，但连续两三次这样，就是很重要的信号（PAGE 204）。
6. **冲突进行中**：盯住这一件事；不扩大成"你这个人"；不以牙还牙；不走开（要暂停就说清何时回来）；先问对方"你最担心的是什么"。一句真诚的道歉往往就够了（PAGE 233）。
7. **当安全基地**：对方难过时先在场；支持但不接管；鼓励对方的目标。早一点的小安抚，比事后救火省力得多（PAGE 85）。

#### 如果这一步失败

| 触发条件 | 一线修复 | 兜底 |
|---|---|---|
| 用户说不出具体需要，只有"我就是难受" | 用 PAGE 209 的三个问题逐个问 | 先只说感受："最近我有点不安，想和你聊聊" |
| 脚本一写就变成控诉 | 把每个"你"开头的句子改成"我"开头 | 只保留一句需要，其他删掉 |
| 说完对方当场反驳"你想多了" | 不争对错，重复一次需要："我不是要你认错，我是需要……" | 记录这次回应，过几天换个时机再说一次 |
| 用户怕一说就失去对方 | 说明：如果一句正常的需要就能吓跑对方，早知道比晚知道好（PAGE 196–197） | 先从最小、最不敏感的那条需要练起 |
| 双方都在气头上 | 约定暂停时间，不在气头上谈 | 请一位冷静的朋友或 ADP 帮忙改词（PAGE 209） |

### B（边界）

- 有效沟通**不保证**问题马上解决，作者自己也这么说（PAGE 212）。它能保证的是你知道了对方在不在乎。
- **不适用于暴力或高控制关系**：在可能被报复的情况下直接摊牌有风险。先安全，紧急拨 110，可拨 12338，联系信任的人或反家暴机构。
- 不是"每个念头都要说"：先说最重要、最反复的那一个。
- 不是操控技巧：目的不是让对方就范，而是让需要被看见、让回应可读。对方说"不"也是有效信息。
- 直接程度可以按文化和关系阶段调整，但核心（具体、不指责、不道歉）不变。
- 对方长期贬低、无视用户需要时，问题已不在表达方式，转 attach-anxious-avoidant-trap 或专业咨询。
- 出现自伤信号 → psyche 第五节危机话术。

## 💬 输出格式

按顺序：
1. 一句接住。
2. 一句点出用户真正的需要（扣回原话）。
3. 一段可以直接说出口的话（2–4 句，用引号）。
4. 一句提示：说完看对方哪一个反应最关键。
5. 一句边界（不保证解决 / 气头上先别说）。
6. 一个问题（全文只问这一个）。

**示例**（"我想让男朋友每天跟我说晚安，但怕显得太黏"）
```
想要一点每天都在的确认，一点也不过分。
你要的其实不是那句"晚安"，而是睡前能确定你们还连在一起。
可以这样说："我发现睡前收到你的消息，我会睡得踏实很多。我希望我们每天睡前都互相说一声晚安，哪怕就一句。你觉得可以吗？"
说完留意他是认真接住，还是开玩笑带过、说你想多了，这比他答不答应更能说明问题。
这不保证他一定答应，但你会比继续猜更清楚。
你最担心他听到后会有什么反应？
```

## 反例黑名单

| # | 反模式 | 替代做法 |
|---|---|---|
| 1 | 用暗示代替请求（"我有好几个邀约还没定"） | 直接问（Greg 案例，PAGE 203–204） |
| 2 | 开口先道歉、说自己太黏 | 需要是正当的，不道歉（PAGE 207） |
| 3 | 半开玩笑地讽刺（"你是不是怕和我单独待着"） | 直接说想要什么（Mia 案例，PAGE 229–230） |
| 4 | 对方一反驳就退让道歉 | 不然就默认了"我的感受不重要"（Daria 案例，PAGE 227） |
| 5 | 气头上谈、翻旧账、"你总是" | 冷静后谈，只谈这一件 |
| 6 | 建议用户让对方吃醋、冷处理来"测试" | 那是抗议行为，回应无法解读（PAGE 199–200） |
