# 过程反馈改写

> 每句话都在传递一个讯息：要么"你有固定的特质，我在给它打分"，要么"你在成长，我关心你怎么长"（Ch7 PAGE 96）。本 skill 只改说话方式，不评判说话的人。

## 🧭 决策树

```
用户想调整对别人的一句反馈
│
├── 涉及打骂、羞辱、威胁、家暴 → 🛑 转介专业帮助（家庭咨询/当地求助渠道），不只改措辞
├── 对方（孩子/员工）出现自伤、厌世信号 → 🛑 psyche 第五节
├── 用户想改自己内心的自我批评 → ❌ mindset-trigger-reframe
├── 用户说"我们一直夸努力，但没用" → ❌ mindset-false-growth-check
│
└── 有一个具体场景要说话 → ✅ 激活
    ├── 对方成功了 → 场景 A：表扬
    ├── 对方要上场 / 考试 → 场景 B：安慰与打气
    ├── 对方失败了 → 场景 C：失败讯息
    └── 对方做得不好需要批评 → 场景 D：建设性批评
```

## 📥 输入与证据假设

- 必需：对象（年龄、关系）、具体事件、用户原本想说或已经说的那句话。
- 可选：对方当时的情绪状态；这件事对对方的重要性。
- 证据假设：作者报告的表扬实验（七个实验、数百名儿童，PAGE 97）显示能力表扬让孩子回避挑战、遇难后表现下降、约四成谎报分数（PAGE 43）。但这些实验后来有独立重复研究未能复现主要效应（如 Li & Bates 2019），整体干预效应很小（Sisk et al. 2018；Macnamara & Burgoyne 2023）。所以本 skill 把它当**一种更稳妥的沟通习惯**，不当作"换句表扬就能提高智商"。

## 📖 RIA+E+B

### R（原文位置与转述）

- Ch3 PAGE 42–43：被夸"你一定很聪明"的孩子更倾向拒绝能学到东西的新挑战；被夸"你一定很努力"的孩子大多选了更难的任务，遇到难题也只觉得要再加把劲。
- Ch7 PAGE 96：作者列出几句常见夸奖（学得快真聪明、下一个毕加索、不学也拿 A），指出孩子听到的反面讯息：学得慢就是不聪明、别碰难的、最好别学习。
- Ch7 PAGE 98：可以尽情赞赏的，是通过练习、学习、坚持和好策略取得的东西；可以带着欣赏去问对方的做法和选择。也别当着孩子给别人贴"天生的废物 / 天才"标签；讲榜样时讲投入，不讲天生。
- Ch7 PAGE 98：孩子又快又完美地做完时，作者会说"看来太简单了，换个你能学到东西的"。
- Ch7 PAGE 99：考前对孩子说"你那么聪明，肯定没问题"反而抬高了赌注；更好的说法是表明"我们不是在评判你，我们在意你学了什么，为你坚持下来骄傲"。
- Ch7 PAGE 99–100：女儿体操比赛没拿到奖，五种常见回应（你最棒、被裁判坑了、体操不重要、你有能力下次肯定赢、你不配赢）中，父亲选了最接近最后一种但带着共情的版本：理解失望，说明别人练得更久更苦，想赢就要更努力；只为好玩也完全可以。
- Ch7 PAGE 100：建设性批评是"帮对方修好一件事"，不是"你要么笨要么不负责"。
- Ch7 PAGE 106–110：降低标准换不来自尊，只提高标准不教方法会把人推出局；好老师是高标准、真关怀、手把手教方法三者同时在。
- 引用 1 处：书中一位父亲教孩子对洒了的钉子说一句平常话，"the nails spilled—I'll pick them up!"（Ch7 PAGE 101）

### I（白话解释）

夸"你真聪明"是在给一个对方改变不了的东西打分。分数高的时候很舒服，可一旦遇到难题，同一套逻辑就会翻过来：做不出来 = 不聪明。夸"你换了三种方法才做出来"是在讲一个对方下次还能用的东西，失败时也站得住。

安慰和批评同理：别替对方否认现实（你最棒、裁判不公），也别给对方定性（你就是粗心），而是说清楚差距在哪里、下一步怎么补，同时让对方感到"我站在你这边"。

### A1（书中案例）

- 能力表扬组在难题之后觉得自己不聪明，表现掉到比开始还差，近四成在给"其他学校孩子"的信里把分数往高了写（Ch3 PAGE 43）。
- 一个成绩顶尖的五年级男孩，被父亲长期夸聪明，结果不愿碰难任务、嘴上夸大自己却从不真去试（Ch7 PAGE 97）。
- 体操女孩失利后，父亲没有说"你最棒"，而是说"你还没挣到它"，并说明怎么挣；她后来大量练习薄弱项（Ch7 PAGE 99–100）。
- 父亲看到儿子作业潦草，骂"你要么笨要么不负责"；作者给出几种替代：说出自己的感受并问何时补完、问是否有没懂的地方、承认作业无聊并一起想办法（Ch7 PAGE 100）。

### A2（未来触发场景）

1. 家长：孩子钢琴考级通过，家长想发朋友圈写"我家天才"，想先改一句当面说的话。
2. 管理者：新人的季度报告结构混乱，周五要做一对一反馈。
3. 教练 / 老师：队员连续三场失误，赛前想给他打气又不想加压。

### E（执行步骤）

1. **取原句**：请用户写下原本想说或已经说过的那句话。
2. **标讯息**：判断这句话在给什么打分——特质（聪明、天赋、粗心、懒）还是过程（策略、投入、选择、进步）。对方听到的反面讯息是什么？
3. **按场景改写**：
   - A 表扬：点出一个具体做法 + 一个开放问题（"你这段颜色怎么想的？"）。完成得太轻松时，不夸快和零错误，改给更有挑战的任务。
   - B 打气：去掉"你那么聪明肯定行"，换成"我们不是在给你打分，我们在意你学到了什么"。
   - C 失败：先共情失望 → 如实说差距（不说"你最棒"、不怪裁判、不贬低这件事）→ 说明要什么投入才能补上 → 给退出或只为好玩的选项。
   - D 批评：去掉人格词 → 说出自己的感受或观察 → 指出一个具体可修处 → 问对方打算怎么修或要不要帮忙。
4. 🔴 **CHECKPOINT**：改写后的话里是否还残留"你是……的人"式定性词？是否保留了标准（没有为了好听把问题说没）？两项任一不过，回到第 3 步。
5. **补一句关系信号**：高标准必须配关怀，加一句让对方知道"我在你这边"。
6. **建议一个日常小习惯**：如晚饭时轮流说"今天学到什么 / 犯了什么有用的错 / 在什么上很努力"（Ch8 PAGE 129），或每天记下自己给出的一句过程反馈（Ch7 PAGE 116）。

#### 如果这一步失败

| 触发条件 | 一线修复 | 兜底 |
|---|---|---|
| 用户说"我就是想让他自信，夸聪明有什么错" | 承认动机是好的；解释这句话在难题时会反转成"我不聪明" | 只要求把"聪明"后面加上"你是怎么做到的？" |
| 改写后变成空洞的"你真努力" | 要求点出一个具体动作或策略 | 改成提问："你最难的是哪一步？" |
| 对方确实没尽力，用户怕说实话伤人 | 用体操父亲的结构：共情 + 如实 + 怎么补 + 可退出 | 只说感受和一个具体可修处 |
| 对方是焦虑、自我否定很重的孩子 | 先降低评判感（"我们不是在打分"），暂不加大挑战 | 情绪持续影响生活时建议找学校心理老师或咨询师 |
| 用户习惯性当面夸别人"天才"或贬别人"笨" | 提醒孩子会想"下一个是不是我"（PAGE 98） | 把评价改为描述对方做了什么 |

### B（边界）

- **证据强度**：表扬实验来自作者团队，独立重复有失败报告；思维干预总体效应很小（Sisk et al. 2018；Macnamara & Burgoyne 2023）。不承诺"这样夸孩子成绩会提高"。
- **只夸努力是误用**：只说"你好努力"而不管策略和结果，是作者后来批评的"假成长型"做法（Dweck 2015/2016，reliable-secondary）。遇到这种情况转 mindset-false-growth-check。
- **"太简单了换难的"有前提**：对正在建立信心、焦虑或刚经历挫败的孩子，先别加难度。
- **不替代对现实的处理**：孩子被欺负、员工被不公平对待、团队资源不足时，先处理事，再谈措辞。
- **安全**：涉及体罚、羞辱、家暴 → 转介专业帮助（家庭咨询、当地妇联/社工/求助热线）；对方有自伤信号 → psyche 第五节危机话术。
- 失效情形：成年人之间存在明显权力冲突或敌意时，措辞技巧不能修复关系，需要先处理信任问题。

## 💬 输出格式

1. 一句肯定用户想改的动机。
2. 指出原句里孩子/对方可能听到的那层讯息（一句）。
3. 给 1–2 个改写版本，直接可说。
4. 一句提醒：保留标准，配一句"我在你这边"。
5. 一个问题（全文只这一个）。

不写 skill 名，不讲实验细节，除非用户问。

**示例**（用户："女儿英语竞赛只拿了三等奖，回家哭了。我想跟她说'你其实是最棒的，评委没眼光'，可以吗？"）

```
想第一时间护住她，这份心意很好。
不过"你最棒、评委没眼光"里，她可能听到的是：问题在别人，我不用变。
可以这样说："我知道你很失望，你准备了那么久。拿一等奖的同学可能练得比你更久，如果你还想冲，我们一起看看哪一部分最值得加练；如果你只是喜欢英语，那也完全可以。"
标准不用降，最后补一句"不管拿几等奖，我都陪你"就够了。
她哭的时候，最在意的是名次，还是觉得自己白准备了？
```
