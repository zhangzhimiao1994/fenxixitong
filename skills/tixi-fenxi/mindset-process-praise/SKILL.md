# 过程反馈改写

> 每句话都在传递一个讯息：要么"你有固定的特质，我在给它打分"，要么"你在成长，我关心你怎么长"（Ch7 PAGE 96）。本 skill 只改说话方式，不评判说话的人。

## 🧭 决策树

```
用户想调整对别人的一句反馈
│
├── 打骂、羞辱、家暴，或对方有自伤信号 → 🛑 步骤 1（安全规则只写在步骤 1）
├── 用户想改自己内心的自我批评 → ❌ mindset-trigger-reframe
├── 用户说"我们一直夸努力，但没用" → ❌ mindset-false-growth-check
├── 没有具体对象或事件 → 🔴 步骤 3：给通用改写 + 一个问题
│
└── 有一个具体场景要说话 → ✅ 步骤 2–8
    ├── 对方成功了 → 场景 A：表扬
    ├── 对方要上场 / 考试 / 提案 → 场景 B：安慰与打气
    ├── 对方失败了 → 场景 C：失败讯息
    └── 对方做得不好需要批评 → 场景 D：建设性批评
```

## 📥 输入

- 必需：对象（年龄、关系）、具体事件、用户原本想说或已经说的那句话。
- 可选：对方平时遇到难题、失手、被批评时的反应；当时的情绪状态。

## 📖 RIA+E+B

### R（原文位置与转述）

- Ch3 PAGE 42–43：被夸"你一定很聪明"的孩子更倾向拒绝新挑战；被夸"你一定很努力"的孩子大多选了更难的任务，遇难题只觉得要再加把劲。
- Ch7 PAGE 96：几句常见夸奖（学得快真聪明、下一个毕加索、不学也拿 A），孩子听到的反面讯息是：学得慢就是不聪明、别碰难的、最好别学习。
- Ch7 PAGE 98：尽情赞赏练习、坚持和好策略换来的东西，问对方的做法和选择；别当着孩子给别人贴"天才 / 废物"标签。又快又完美地做完时，说"看来太简单了，换个你能学到东西的"。
- Ch7 PAGE 99：考前说"你那么聪明，肯定没问题"反而抬高赌注；更好的是"我们不是在评判你，我们在意你学了什么"。
- Ch7 PAGE 100：建设性批评是"帮对方修好一件事"，不是"你要么笨要么不负责"。
- Ch7 PAGE 106–110：降低标准换不来自尊，只提标准不教方法会把人推出局；好老师是高标准、真关怀、教方法三者同在。
- 引用 1 处："the nails spilled—I'll pick them up!"（Ch7 PAGE 101）

### I（白话解释）

夸"你真聪明"是在给对方改变不了的东西打分，一遇难题就翻成"做不出来 = 不聪明"。同一句话怎么被听，取决于对方状态：一遇难题就放弃的孩子会把"天才"听成"不能出错"，正紧张的孩子会把"有天分"听成"这场在验证我"。所以先预判听法，说完再看一个信号。

### A1（书中案例）

- 能力表扬组在难题后表现掉到比开始还差，近四成在给"其他学校孩子"的信里谎报分数（Ch3 PAGE 43）。
- 被父亲长期夸聪明的五年级尖子生，不愿碰难任务，嘴上夸大自己却从不真去试（Ch7 PAGE 97）。
- 女儿体操失利，五种常见回应（你最棒、裁判坑了、体操不重要、下次肯定赢、你不配赢）中，父亲选了带共情的最后一种："你还没挣到它"，说明想赢要怎么挣，只为好玩也可以（Ch7 PAGE 99–100）。
- 父亲骂潦草作业的儿子"你要么笨要么不负责"；作者的替代：说出感受并问何时补完、问有没有没懂的地方、承认作业无聊并一起想办法（Ch7 PAGE 100）。

### E（执行步骤）

1. 🛑 **STOP 安全筛查**（本 skill 唯一的安全规则处）
   - 输入：用户消息。
   - 核对并分流：已打骂、羞辱 → 回复第一句必须是"打和骂需要先停下来"，并给去处（家庭教育/亲子咨询、学校心理老师、医院儿童心理科），然后才进入改写，不羞辱用户；持续暴力、威胁、家暴 → 只转介（当地妇联、社工、求助热线，有危险拨 110），不改措辞；对方有自伤、厌世信号 → 只输出 psyche 第五节危机话术；用户此刻仍怒气很大 → 先给"先离开 10 分钟，冷静后再开口"。
   - 输出：停止 / 继续（附安全句）。
2. **取原句、场景和待问项**
   - 输入：用户消息。
   - 做法：取原本想说或已经说过的那句话，判定场景 A/B/C/D。用户给了多句话 → 只改最带特质打分的那一句。原句是对第三方评价孩子（"我家这个是天才"）→ 照样改写。本步不提问，只定下全文唯一的待问项：缺原句 → 问原句；缺对方的状态 → 问对方平时遇到难题或失手时的反应；都齐 → 问一个让改写落地的细节。
   - 输出：原句 + 场景 + 待问项。
3. 🔴 **CHECKPOINT 1（信息核对）**
   - 输入：步骤 2 的结果。
   - 核对：是否有具体对象和具体事件？两者都没有（"怎么夸孩子比较好"）→ 给第 1 条 + 场景 A 通用改写（"你是怎么做到的？"）+ 待问项"最近一次你想夸或想批评他，是因为什么事？"；用户回答后从步骤 2 继续。
   - 输出：继续 / 只给通用版。
4. **预判听法**（→ 输出第 2 条）
   - 输入：原句 + 对方状态。
   - 做法：判断这句话在给什么打分——特质（聪明、天赋、粗心、懒、不靠谱）还是过程（策略、投入、选择、进步）。再结合对方的具体状态写出他可能听成什么，以及它会在哪个具体时刻反转；反转时刻必须用用户场景里的名词（"最后那道大题做不出""弹错一个音""客户当场提问答不上"），禁止"遇到困难时"这类通用句。对方状态未知时，按场景默认：A → 下次碰到做不出的题；B → 上场后第一个失误；C → 下一次比赛前；D → 下一次交同类东西时。原句已是过程式（点到具体做法或策略）→ 本条改为"这句已经点到了做法，可以直接用"，跳过步骤 5，只补一个开放问题或关系信号。
   - 输出：一句听法 + 反转时刻 / 已是过程式。
5. **按场景改写**（→ 输出第 3 条）
   - 输入：场景 + 听法。
   - A 表扬：点出一个具体做法 + 一个开放问题（"你这段颜色怎么想的？"）。完成得太轻松时，不夸快和零错误，改给更有挑战的任务。
   - B 打气：去掉"你那么聪明肯定行"，换成"我们不是在给你打分，我们在意你练了 / 准备了什么"。
   - C 失败：先共情失望 → 如实说差距（不说"你最棒"、不怪裁判、不贬低这件事）→ 说明要什么投入才能补上 → 给退出或只为好玩的选项。
   - D 批评：去掉人格词 → 说出自己的观察 → 指出一个具体可修处 + 期限 → 问对方打算怎么修或要不要帮忙。
   - 输出：1–2 个改写版本。
6. 🔴 **CHECKPOINT 2（改写核对，给出改写之前）**
   - 输入：改写版本。
   - 核对：①没有残留"你是……的人"式定性词；②保留了标准（没有为了好听把问题说没）；③按场景再核一项——A：提"换更难的"时对方状态稳定、不焦虑；B：没有"肯定行 / 肯定赢"这类结果承诺；C：没有否认现实或怪裁判；D：有一个具体可修处和期限。
   - 输出：通过 / 回步骤 5。
7. **关系信号 + 观察信号**（→ 输出第 4 条）
   - 输入：改写版本 + 反转时刻。
   - 做法：加一句让对方知道"我在你这边"；再给一个说完后看什么的信号，用来判断这句话被怎么听了（例：A → 下次会不会主动挑难题；B → 赛后第一句是"我是不是不适合"还是"那段还能怎么练"；D → 下次是不是先改了那一处）。用户问"平时怎么做"时，本条再加一句日常习惯：晚饭时轮流说"今天学到什么 / 犯了什么有用的错 / 在什么上很努力"（Ch8 PAGE 129），或每天记下自己给出的一句过程反馈（Ch7 PAGE 116）。
   - 输出：关系信号 + 观察信号（+ 日常习惯）。
8. 🔴 **CHECKPOINT 3（发送前）**
   - 输入：整段回复。
   - 核对：①全文 ≤280 字；②向用户只有 1 个问题，问的是步骤 2 的待问项（改写句里供用户对孩子/下属说的问句不计）；③第 2 条的反转时刻含用户场景名词；④打骂场景第一句是"打和骂需要先停下来"。
   - 输出：可发送 / 回对应条改写。

#### 如果这一步失败

| 步骤 | 触发条件 | 一线修复 | 仍失败兜底 |
|---|---|---|---|
| 1 安全 | 用户说"打几下没什么，我小时候也被打" | 不争论教养观，说明打骂会让孩子只学会躲，先停下来 | 给去处：家庭教育/亲子咨询、学校心理老师 |
| 1 安全 | 对方已说出想死或具体方法（不安全），或 psyche 不可用 | 直接给：全国心理援助热线 12356、希望24热线 400-161-9995，请用户现在陪在对方身边 | 紧急拨 120/110，不让对方独处 |
| 1 越界 | 用户坚持要"更狠一点、让他长记性"的话 | 说明不提供羞辱性措辞，给场景 D 的批评结构 | 只保留"一个具体可修处 + 期限" |
| 2 原句 | 多句话，或原句是对第三方说的 | 按步骤 2 规则处理 | 提醒孩子在场时会听到 |
| 3 信息 | 没有具体对象或事件 | 给场景 A 通用改写 + 待问项 | 第二轮仍无事件：只给"描述做法 + 问怎么做到的"这一条规则 |
| 4 听法 | 用户说"我就是想让他自信，夸聪明有什么错" | 承认动机是好的；用他场景里的反转时刻说明这句会翻成"我不聪明" | 只要求把"聪明"后面加上"你是怎么做到的？" |
| 4 听法 | 用户原句已是过程式 | 直接肯定这句可以用，只补开放问题或关系信号 | 不改写，只回答用户顺带的疑问 |
| 5 改写 | 改写后变成空洞的"你真努力" | 要求点出一个具体动作或策略（理由见 B 段"只夸努力是误用"） | 改成提问："你最难的是哪一步？" |
| 5 改写 | 对方确实没尽力，用户怕说实话伤人 | 用体操父亲的结构：共情 + 如实 + 怎么补 + 可退出 | 只说感受和一个具体可修处 |
| 5 改写 | 对方是成年下属，且双方已有明显权力冲突或敌意 | 只改一句事实型反馈，不做关系修复 | 先处理信任问题（找第三方如 HR 或上级在场） |
| 6 前提 | 对方是焦虑、自我否定很重的孩子 | 先降低评判感（"我们不是在打分"），暂不加大挑战 | 情绪持续两周以上影响上学或睡眠 → 去学校心理老师或医院儿童心理科 |
| 7 观察 | 用户回来说"他听完反而更不敢做难题了" | 说明这正是听成了打分，换成只问做法、不评价结果 | 一周内只描述过程，不夸也不批 |
| 转介 | mindset-false-growth-check 不可用而用户说"夸努力没用" | 按 B 段"只夸努力是误用"说明 | 只给一句替换："你这次换了什么方法？" |

### B（边界）

- **证据强度**：作者报告的表扬实验（七个实验、数百名儿童，PAGE 97）显示能力表扬让孩子回避挑战、遇难后表现下降、约四成谎报分数（PAGE 43）。但这些实验来自作者团队，独立重复研究有未能复现主要效应的报告（如 Li & Bates 2019），思维干预总体效应很小（Sisk et al. 2018；Macnamara & Burgoyne 2023）。本 skill 把过程反馈当一种更稳妥的沟通习惯，不承诺"这样夸孩子成绩会提高"。
- **只夸努力是误用**：只说"你好努力"而不管策略和结果，是作者后来批评的"假成长型"做法（Dweck 2015/2016，reliable-secondary）。遇到这种情况转 mindset-false-growth-check。
- **不替代对现实的处理**：孩子被欺负、员工被不公平对待、团队资源不足时，先处理事，再谈措辞。
- **安全**：见步骤 1。
- 失效情形：成年人之间有明显权力冲突或敌意时，措辞技巧不能修复关系，处理见失败表"5 改写"行。

## 💬 输出格式

分支输出：步骤 1 只转介 → 只输出转介句；步骤 3 无事件 → 第 1 条 + 通用改写 + 一个问题。

常规回复顺序固定，全文 ≤280 字，每段 ≤2 句（第 3 条改写本身不计句数）：
1. 一句肯定用户想改的动机；打骂场景按步骤 1 换成安全句。
2. 预判听法：对方可能听成什么 + 会在哪个具体时刻反转（步骤 4）。
3. 1–2 个可直接说的改写版本（步骤 5）。baseline 常见、不冲突的实用常识（如赛前一起深呼吸、表扬后问哪道题最难）压成半句并进本条。
4. 关系信号 + 观察信号（步骤 7）；"换更难的"只在对方状态稳定时提，并写明前提。
5. 一个问题：步骤 2 定下的待问项（全文向用户只问这一个；第 3 条改写句里供用户对孩子/下属说的问句不计入）。

不写 skill 名，不讲实验细节，除非用户问。

**示例 1：场景 C**（用户："女儿英语竞赛只拿了三等奖，回家哭了。我想跟她说'你其实是最棒的，评委没眼光'，可以吗？"）

```
想第一时间护住她，这份心意很好。
"你最棒、评委没眼光"里，她可能听到的是：问题在别人，我不用变——下次比赛前，她会更怕输，因为输了只能怪评委。
可以这样说："我知道你很失望，你准备了那么久。拿一等奖的同学可能练得更久，如果你还想冲，我们一起看看哪一部分最值得加练；如果你只是喜欢英语，那也完全可以。"
补一句"不管拿几等奖，我都陪你"；之后留意她是主动问"哪里能加练"，还是说"我不想再比了"。
她哭的时候，最在意的是名次，还是觉得自己白准备了？
```

**示例 2：场景 B**（用户："下属明天第一次给客户提案，我想跟他说'你能力强，肯定没问题'。"）

```
想在他上场前给点底气，这个出发点很好。
"能力强、肯定没问题"里，他可能听到的是：这次是在验证我的能力——客户当场提一个答不上的问题，他就会读成"我其实不行"。
可以这样说："明天不是考你，我在意的是你把客户最关心的那三点讲清楚；答不上的问题记下来，会后我们一起补。"
补一句"我会在会上坐你旁边"；提案后留意他先说"哪里没讲好"还是"我是不是不适合做提案"。
客户那边最可能追问的是哪一块？
```

## 反例黑名单

| # | 反模式 | 为什么 | 替代做法 |
|---|---|---|---|
| 1 | "你真聪明 / 你是天才" | 给特质打分，遇到难题会反转成"我不聪明"（PAGE 42–43） | "你是怎么想到这个办法的？" |
| 2 | 失利后说"你其实最棒""裁判不公" | 否认现实，对方学不到怎么补 | 共情 + 如实说差距 + 怎么补 |
| 3 | "你就是粗心 / 懒 / 不靠谱" | 贴人格标签，对方只能辩解或放弃 | 说观察到的具体问题 + 问怎么修 |
| 4 | 把"你真努力"当万能替换 | 只夸努力不管策略和结果，是作者后来批评的误用 | 点出一个具体做法，并问结果比上次怎样 |
| 5 | 为了不伤自尊把标准降下来 | 降低标准换不来自尊（PAGE 106–110） | 高标准 + 关怀 + 教方法 |
| 6 | 对已经焦虑的孩子立刻"换更难的" | 加重压力，前提不成立 | 先降低评判感，再慢慢加挑战 |
| 7 | 用户已打骂孩子，只给更好的话术 | 安全问题：话术掩盖了体罚本身 | 第一句先说停止体罚并给去处，再改措辞 |
| 8 | 对下属反馈只改语气、把问题说没 | 失去标准，问题下次照样出现 | 保留一个具体可修处 + 期限 |
