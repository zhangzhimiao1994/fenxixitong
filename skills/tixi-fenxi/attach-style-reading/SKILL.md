## 🧭 决策树

```
用户问"我/他是什么依恋类型"
│
├── 有自伤/轻生信号？ → 🛑 停，执行 psyche 第五节危机话术
├── 提到被打、被威胁、被控制？ → 🛑 先安全与转介（见 B 段），不做风格分析
├── 要"诊断"（"我是不是有病/人格障碍"）？ → 先说不能诊断，再给倾向视角
├── 刚认识几周，真正想问的是"值不值得继续"？ → ❌ 转 attach-dating-signals
├── 已确认一追一逃，想改关系？ → ❌ 转 attach-anxious-avoidant-trap
│
└── ✅ 想了解自己或一个相处过一段时间的人
    ├── 看自己 → 步骤 2A（两维度自查）
    ├── 看对方 → 步骤 2B（五条法则）
    └── 两个都高 / 说不清 → 步骤 3 情境过滤后再定
```

## 📥 输入与证据假设

- 用户讲的是**单方面叙述**。看对方时，我们只有用户转述的行为，没有对方的内心感受。
- 需要至少 **3 个具体行为**，并且来自 **2 种以上情境**（如争吵、分开时、谈未来时）。只有形容词（"他很冷漠"）不算证据。
- 先确认：交往多久；用户现在是不是正"上头"（书里说兴奋时客观性会下降，PAGE 51）；近期有没有离婚、丧亲、重病、生孩子这类大事（会让人暂时变样，PAGE 109、136）。
- 书里的自评问卷是图片，原文缺失，而且是作者改编版，没有报告信效度。**本 skill 不计分**，只用正文讲到的维度和规则。

## 📖 RIA+E+B

### R（原文位置 + 转述）

- 第3章 PAGE 46–48：风格由两个维度决定，一是对亲密有多不自在，二是对伴侣的爱和关注有多焦虑。两个都低偏安全；想亲近但很焦虑偏焦虑；不想太近也不太操心偏回避；两个都高是少数的混合型。
- 第3章 PAGE 39 与第9章 PAGE 148：作者反复强调风格"stable but plastic"（PAGE 39）。第1章 PAGE 17：平均每四个人里有一个在四年左右发生变化。第7章 PAGE 129–130：童年照料与成年风格只有弱关联，基因和成年后的强烈恋爱经历也会改变它。
- 第4章 PAGE 64–67：判断对方的五条黄金法则：①他是否寻求亲密（最重要）；②他对关系有多操心、对拒绝有多敏感；③不靠单个"症状"，看整体模式；④看他对你直接表达需求的反应；⑤听他没说的、看他没做的。
- 第4章 PAGE 65 与第7章 PAGE 124–125：任何性格的人都可能是任何风格，外向、自信、笨拙都不能当线索。第5章 PAGE 103：别把回避等于男性、焦虑等于女性，多数男女都是安全型。

### I（白话解释）

依恋风格像一个"警报器的灵敏度设置"：焦虑的人警报调得很灵，一点风吹草动就响；回避的人警报也在，但习惯把它按掉；安全的人警报正常，响了也容易平复。看风格，不是看一个人"好不好"，而是看他**在靠近和分离时会自动做什么**。

### A1（书中案例的应用）

- Paul 一直说在找"命中注定的人"，听起来渴望亲密，但作者判他偏回避：每次一靠近就开始挑对方毛病，还把单身归因于外部（PAGE 73–74）。说明"嘴上想要亲密"要和"靠近时的实际反应"对照看。
- Bella 直接在床上指导男友，作者判她偏安全：遇到问题就直接、不带贬低地处理（PAGE 71–72）。说明直接沟通本身就是线索。
- Emily 和若即若离的 David 交往后变得"像有病"，分析师差点给她贴上受虐、边缘人格的标签；作者认为这只是被持续激活的依恋系统，换成稳定伴侣后她恢复了原样（PAGE 78–84）。说明**同一个人在不同伴侣面前会很不一样**。

### A2（未来触发场景）

1. 用户做了网上的依恋测试，结果"焦虑 + 回避都高"，很慌。
2. 用户结婚多年，丈夫一谈感情就转移话题，想知道是不是"回避型"。
3. 用户发现自己每段恋爱后期都想逃，想知道原因。

### E（执行步骤）

1. **安全与意图筛查**：有自伤信号 → psyche 第五节；有暴力/控制 → B 段转介；要诊断 → 先说"我不能做诊断"。
2. **收集行为证据**
   - 2A 看自己：问三个情境：对方半天不回消息时你会做什么；关系变得很近时你什么感觉；吵架后你先找对方还是先退开。
   - 2B 看对方：逐条过五条法则，每条至少举一个具体例子。法则①不成立（明显不寻求亲密），基本可判偏回避；成立，再用法则②区分安全和焦虑（PAGE 64–65）。
3. 🔴 **CHECKPOINT**：证据是否有 ≥3 个具体行为、≥2 种情境？不够 → 只说"目前看不出"，给一个可以观察的点，不下结论。
4. **情境过滤**：现在是不是正上头；是不是处在重大生活事件里；是不是只在这一个伴侣面前才这样（安全的人和不合适的人在一起也会变得焦虑或防备，PAGE 136）。
5. **给出倾向**：用"偏向 / 有点像 / 看不出"三档，附上依据、什么证据会改变判断，以及下一步该看什么（约会中 → 约会信号；已在追逃循环 → 陷阱；想说出需求 → 沟通）。

#### 如果这一步失败

| 触发条件 | 一线修复 | 兜底 |
|---|---|---|
| 用户只给形容词（"他就是冷"） | 问一个具体时刻："最近一次你觉得他冷，是什么场景？" | 只讲两个维度的含义，请他回去观察一周 |
| 两个维度都高、说不清 | 说明这是少数的混合倾向，两边的资料都可参考（PAGE 48） | 建议找心理咨询师一起梳理，不硬分类 |
| 用户想拿结论去"定罪"伴侣 | 指出法则③：一个人在不同关系里会变；标签不能替代对话 | 转 attach-secure-communication，先说需求再看反应 |
| 对方处在离婚、丧亲等大事后 | 说明压力下的反应不代表长期风格（PAGE 109） | 建议三个月后再看 |
| 用户坚持要分数 | 说明书中问卷原文缺失且未验证，不计分 | 推荐研究版 ECR-R，提醒自评也有偏差 |

### B（边界）

- **不是诊断**。依恋风格不是精神科诊断，也不对应人格障碍。用户要诊断时，原样回答："我不能做诊断。你描述的这些值得认真对待，持续两周以上或影响生活时，建议去精神科或心理门诊评估。"
- **自评问卷有局限**：书中问卷是改编版，没给信效度；自评受当下情绪影响；回避倾向的人常低报自己的不安（书中实验显示，回避者要在分心时才显露依恋焦虑，PAGE 108–109）。
- **类别是简化**：研究上更支持把依恋看成连续维度（reliable-secondary），"你就是 X 型"太绝对。只说"偏向"。
- **人会变**：约四分之一的人几年内会变；遇到稳定的伴侣、做咨询、经历大事都可能改变。今天的结论有保质期。
- **混合/恐惧型**和涉及创伤的情况，书几乎没写，建议专业帮助。
- **亲密暴力**：出现打人、威胁、控制财务或行踪，不用依恋框架解释。告诉用户这不是"风格不合"，建议先确保安全，紧急拨 110，可拨全国妇联维权热线 12338，并联系信任的人或专业机构。
- 不用于亲子、职场等非恋爱关系的定性判断。

## 💬 输出格式

按顺序：
1. 一句接住（不评判）。
2. 两个维度上，用户/对方各自大概在哪，每点扣回用户原话里的具体行为。
3. 倾向结论（偏向 / 有点像 / 看不出）+ 一句"什么情况会改变这个判断"。
4. 一句边界：不是诊断，人会变。
5. 一个今天能做的观察或行动。
6. 一个问题（全文只问这一个）。

不写 skill 名，不列术语清单。

**示例**（"我老公一谈感情就转移话题，他是不是回避型？"）
```
被一次次岔开，确实会让人觉得自己的感受不重要。
从你说的看，他在"谈感情"这一类时刻明显想退开，这是亲密回避高的表现；但你还没提到他对你离开、生气时的反应，所以关系焦虑那一面还看不出来。
目前可以说"有点像偏回避"，但只凭一个场景不够。如果他在你难过时会主动靠近，判断就要改。
这不是诊断，人在不同阶段也会变。
这周可以留意两个时刻：你主动说想他时，以及你们吵完以后，他分别怎么反应。
他转移话题时，通常是你说到哪一类事情？
```

## 反例黑名单

| # | 反模式 | 替代做法 |
|---|---|---|
| 1 | 凭一个行为下结论（"不让见孩子＝回避"） | 至少 3 个行为、2 种情境（PAGE 65–66） |
| 2 | 用性格、外表、性别猜风格 | 只看靠近和分离时的反应（PAGE 65、103） |
| 3 | 说"你就是焦虑型"，像下诊断 | 说"偏向"，并写明会改变判断的证据 |
| 4 | 给用户计分、报百分比 | 不计分，书中问卷缺失且未验证 |
| 5 | 把被不稳定伴侣激活的反应当成人格缺陷 | 先做情境过滤（Emily 案例，PAGE 78–84） |
| 6 | 在暴力情境里讨论"他是什么依恋类型" | 先安全、转介 |
