## 🧭 决策树

```
用户要一个"几成把握 / 多少 / 多久"
│
├── 钟表型（查得到确定答案：日出时间、法规条文）？ → ❌ 直接查
├── 云型（>5 年、混沌系统如汇率走势）？ → ⚠️ 只给 35%-65% 内的保守区间或改成情景准备，说明原因
├── 命题还没定义清楚（没阈值/没日期）？ → 先 forecast-calibrate-claim 第 3 步
│
└── 金发姑娘区的可定义命题 → ✅ 本工具
    ├── 有现成同类数据 → 第 2 步直接取基率
    ├── "史无前例" → 第 2 步用费米上下界造基率
    └── 时间估计（"要多久"）→ 规划谬误：外部视角优先
```

## 📥 输入与证据假设

- 必需：一个已定义的命题（事件+阈值+时间窗）。可选：用户掌握的细节、他人的估计。
- 假设：直觉数字来自黑箱，会被无关数字锚住且调整不足；先用有意义的锚（基率）能减少这种误差。
- 每个"盲猜"都要写出来——拆解不能消灭猜测，只是把猜测摊在明处，便于检查。

## 📖 RIA+E+B

### R（原文位置，转述）
- 第 5 章（PDF 124-128 / p.110-114）：芝加哥钢琴调音师问题——把一个答不出的问题换成四个可以分别猜的问题，每个猜测给 90% 区间取中点，粗糙假设拼出的结果却很接近实际。
- 第 5 章（PDF 129-131 / p.115-117）：阿拉法特钋检测题，多数人回答的是"以色列有没有下毒"这个更容易的替代问题；弗拉克先问"答案为'是'需要什么条件"，发现第一步是科学问题（钋衰变后还能否测出），还发现了多条通往"是"的路径。
- 第 5 章（PDF 131-134 / p.117-120）：伦泽蒂一家养宠物的概率——先查美国家庭养宠比例（约 62%），再收窄到独栋住宅（假设 73%），再用家庭细节调；外部视角必须先行，因为锚定导致调整不足。找不到基率时，用"不可能低于/不可能高于"框出 20%-80%，取中点。
- 第 5 章（PDF 136 / p.122）：罗格估欧洲恐袭——维基列表数出近五年 6 次即每年 1.2 次，去掉旧数据得 1.5，考虑威胁上升与安保加强只上调到 1.8，乘以剩余 69 天/365，得 34%。
- 第 5 章（PDF 137-139 / p.123-125）："内心的群体"：假设第一判断是错的再估一次，两次平均几乎和请教别人一样有效；把问题反过来问（"会被拒签吗"）抵消确认偏差；多只手的正反推理后合成"偏向否，80%"。
- 第 3 章（PDF 82-91 / p.68-77）：狐狸（多工具、多来源、常说"但是""另一方面"）在校准和区分度上都胜过刺猬（一个大理论、常说"而且""更何况"、爱说"不可能/必然"）；刺猬在自己专业上反而更差。蜻蜓眼 = 在一个脑子里聚合多视角。
- 第 11 章（PDF 249-250 / p.235-236）：问"阿萨德政权 3 个月内倒台"与"6 个月内倒台"，普通预测者给 40% 和 41%，超级预测者给 15% 和 24%——时间窗就是问题的"范围"。
- 附录 (3)：萨默斯把下属的工期估计翻倍再升一个时间单位，是用外部视角纠正规划谬误，但遇到真准时的下属也会调回来。

### I（白话）
先别讲故事。第一，把问题拆成"要成立必须同时满足的几件事"，每件单独猜。第二，问一句"这种情况下，这类事一般多常发生？"，拿这个数当起点。第三，才看这件事的特殊之处，但每一条特殊之处都要说清是往上推还是往下拉、推多少。第四，故意站到反方再算一遍，把两次合起来。最后给一个刻度细的数，而不是"五五开"。

### A1（书中应用，转述）
- 弗拉克在阿拉法特题里先读了瑞士团队的检测报告，确认"死后多年仍可检出"才进入政治分析，最终给出约 60%，事后被证明方向正确（PDF 130, 167 / p.116, 153）。
- 罗格的 34% 是"基率 → 剔除过时数据 → 正反力量各打折 → 按剩余天数折算"的教科书式合成（PDF 136 / p.122）。

### A2（未来触发场景）
1. "我的小店开业一年内能盈亏平衡吗？"→ 基率先查同类小店一年存活/盈亏平衡比例，再按选址、现金流调。
2. "这次考研上岸几成？"→ 拆成"初试过线 × 复试通过"，各取往年比例，再用自己的模考成绩调。
3. "装修多久能完工？"→ 先问同城同类装修的通常超期比例，再看本次合同条款与工队档期。

### E（执行步骤）
1. **拆解**：问"答案为'是'必须哪些事同时成立？"列 2-5 个子条件；再问"有哪几条路径都能通向'是'？"——条件相乘会降低概率，路径相加会提高概率。每个子数用 90% 区间（我很确定不低于 X、不高于 Y）取中点。
   🔴 CHECKPOINT 1：重读原题一字一句——你现在回答的是原题，还是一个更容易的替代题？
2. **外部视角（基率）**：选参照类"这种情况下的这类事"，从宽到窄选 1-2 个（越贴近本案越好，但样本别太小）。没有现成数据 → 用"不可能低于/高于"框上下界取中点。时间类问题先查同类项目的超期情况。
3. **内部视角**：把本案细节写成 2-3 个具体假设，每个假设再拆"要为真需要什么"，找正反证据；每条只做有界的调整（先定"最多改几个点"，再收窄）。
4. **正反力量与反问**：分别列"推高"与"拉低"的力量各 2-3 条；把题目反过来问一遍；假设自己的第一个数是错的，说出最可能错在哪，再给第二个数，取两者平均。若有他人估计，纳入一起平均。
5. **范围检查**：把截止日改成一半和两倍，概率应随之变化；不变说明在回答替代题。
   🔴 CHECKPOINT 2：两个时间窗给出几乎同一个数 → 回到第 1 步。
6. **合成落数**：精确到 5%（有把握时 1%）；云型问题初值留在 35%-65%；避免用 50% 代表"不知道"。写下"基率 X → 调整后 Y"的完整链条，交给 forecast-calibrate-claim 登记。

#### 如果这一步失败
| 触发条件 | 一线修复 | 兜底 |
|---|---|---|
| 找不到任何参照类（"我这情况很特殊"） | 提示独特性只是程度问题，放宽一级找更大的类（"新开的餐饮店"而非"我这种日料店"） | 用上下界中点作基率，并标注"基率粗糙" |
| 两个参照类给出差距很大的基率 | 两个都写出，按贴近度加权，或取中点 | 把差距本身告诉用户：这是不确定性的一部分 |
| 内部细节太多，越看越乱 | 只保留能写成"若为真需要……"的假设，其余放一边 | 停在基率+一条最强理由 |
| 用户坚持一个故事（刺猬式"肯定"） | 请他说出"什么证据会让你改口"；说不出 → 标记为高风险判断 | 把他的数和基率都登记，到期比较 |
| 子条件高度相关，不能直接相乘 | 用"在前一条成立的前提下，这条成立的概率"来估 | 直接对整体做上下界估计 |

### B（边界）
- 拆解与基率适合"金发姑娘区"问题；钟表型直接查，云型（长期汇率、5 年以上的社会走向）拆得再细也难胜过随机，给区间并转为情景准备。
- 用户要据此做投资或换汇决定 → 说明我不是持牌顾问，不给买卖方向或时点，只说明问题的不确定性有多大。
- 基率不是宿命：它是起点，本案证据足够有诊断力时要敢于大幅偏离（萨默斯也会为准时的下属调回）。
- 参照类可以被"挑"出想要的结果。至少写出两个候选类并说明为什么选这个。
- 数字精细只在有依据时才有意义；作者也警告"用精确数字唬人"的伪精确（PDF 159 / p.145）。
- 涉及他人能否被"预测"成坏人（例如以刻板印象推断某人是否会伤害孩子）→ 不做；书中正是用这类例子说明刻板印象的误导（PDF 177-178 / p.163-164）。

## 💬 输出格式

回复按顺序：
1. 一句话说清你在估的到底是什么（防止替代题）。
2. 拆解：2-4 个子问题，各自的猜测值，一行一个。
3. 基率：参照类 + 数字 + 来源（查到的/上下界推的）。
4. 调整：推高的 1-2 条、拉低的 1-2 条，各标幅度。
5. 结论数字 + "基率 X → Y"的链条。
6. 只问 1 个问题（通常是最能改变数字的那个缺失信息）。

**示例**（"我下个月的线上课程能卖出 100 份吗？"）
```
先说清楚：估的是 11 月 30 日前付费订单 ≥100 份，不是"课程会不会火"。
拆开看：触达人数 ≈ 你粉丝里能看到推送的人（约 8000×20%≈1600）；点开详情页 ≈ 1600×15%≈240；付费 ≈ 240×10%≈24。按这条线，100 份需要额外渠道。
基率：你过去两次上新首月分别卖了 30 和 45 份；用这个作参照，首月破百的把握偏低。
推高：这次有合作方转发（+）；拉低：定价比上次高（−）。
结论：从"过去两次都没到 100"出发，加减后约 20%。
合作方那边，大概能带来多少次曝光？
```
