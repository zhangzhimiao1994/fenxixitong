# 抱紧我对话

> 先说我怕什么，再说我需要你什么；听的人不用完美，只要在场。

## 🧭 决策树

```
用户想对伴侣说出需要 / 想回应伴侣的袒露
│
├── 暴力、恐惧对方、严重成瘾、长期出轨？   → ❌ 走 B 段转介
├── 自伤自杀信号？                        → 🛑 psyche 第五节危机话术
├── 两人一开口就吵、还停不下来？            → ❌ 先降级：eft-demon-dialogues / eft-raw-spot-deescalation
├── 一靠近就提到某次旧伤、“再也不信你”？    → ❌ 转 eft-forgiving-injuries
├── 还没在一起 / 想表白？                  → ❌ 不适用
│
└── ✅ 能停下争吵，但想真正靠近
      ├── 我是说的人 → 第一段“我最怕什么” → 第二段“我最需要你什么”
      └── 我是听的人 → A.R.E. 回应清单（E8–E9）
```

## 📥 输入与证据假设

- 前提：两人至少有过一次能停下来、不升级的复盘（作者说这个对话建立在前三个对话的安全感之上，PAGE 105）。没有这个前提，先做降级。
- 需要：用户在最近一次低谷里出现过的“把手”词（如“碎掉”“被丢下”“像个外人”），这些词是往下走的入口（PAGE 108）。
- 一般由更退缩的一方先开口，因为追的一方很难在没有对方投入迹象时先伸手（PAGE 112）。若只有一方读者，就从读者开始。
- 不假设对方一定接得住；要预备对方第一次没接住的情况。

## 📖 RIA+E+B

### R（原文位置与转述）

- A.R.E. 三要素：可及——即使不安也对伴侣保持敞开；回应——让对方看到他的情绪对你有影响，并发出清楚的安慰信号；投入——只给所爱之人的那种专注与在场（PAGE 40）。
- 抱紧我对话分两段：“我最怕什么”，往下走到最底层的情绪；“我最需要你什么”，直接、连贯地说出只有对方能满足的需要，它是 EFT 的转折点（PAGE 105–106、113）。
- Charlie 的做法：先看是什么挡住了自己；拿出之前的“把手”词；列出“可怕的如果”找到核心恐惧；告诉对方，并说说说出来是什么感觉（PAGE 111–112）。
- 一方冒险打开后，另一方的反应很关键；常见的失败是回“那你证明给我看”，然后掉回循环；打开的一方可能需要反复说几次（PAGE 110）。
- 听的一方不确定怎么回时，就说出这份不确定；作者写道 "Being present is the secret here, rather than responding in any set way"（PAGE 120）。
- 太难时先迈小一步：先谈“说出需要有多难”（PAGE 120）。
- 书中提供的需要清单：我对你是特别的；我被你需要；我带着缺点也被接受；我需要你的时候你会在；我可以请你抱我，并请你理解开口本身就很难（PAGE 119–120）。

### I（白话解释）

吵架时我们说的是“你为什么总加班”，心里想说的是“我怕我对你不重要了”。只要后半句不出口，对方就只能回应前半句——于是他解释加班，你更失望。这场对话要做的，是把后半句说出来，而且说给对方听，不是说给空气听。说的人往下走两层：先找到怕，再找到要。听的人不需要标准答案，只要让对方看到“你的话打到我了，我在这儿”。

### A1（书中案例，转述）

- **Charlie 与 Kyoko**（PAGE 106–114）：Charlie 习惯讲道理、给建议。他从“我需要掌控”往下走到“如果我听她难过，我会碎掉，会失去她”，然后哭着说出“我不知道怎么做，我需要确定你在”。Kyoko 回应“我不需要完美的丈夫”。轮到 Kyoko 时，她一开始用第三人称对着天花板说，作者请她转过椅子看着他说；她说出“我要你靠近我、抱着我、告诉我我重要”，Charlie 才发现最简单的路一直在旁边。
- **Tim 与 Sarah**（PAGE 43–44）：Tim 承认自己“吓瘫了”，说出“我需要你，给我一个机会”。Sarah 先回了一句带刺的试探，Tim 继续说，Sarah 才慢慢软下来，说出“我需要你的安慰，你能抱住我吗”。
- **Phillipe 与 Tabitha**（PAGE 115–117）：每到同居就反悔的 Phillipe 说出小时候母亲生病时被赶走，所以“永远别把所有鸡蛋放一个篮子”；Tabitha 说出“我需要你为我去对抗那份害怕”。

### A2（未来触发场景）

1. “我们最近能不吵了，可我还是觉得他离我很远，我想告诉他我需要什么，但一开口就变成抱怨。”
2. “她昨晚哭着说怕我哪天不要她了，我当时只会说‘别想太多’，现在想补救。”
3. “我是那个总躲的人，我想先迈一步，但不知道说什么。”

### E（执行步骤）

1. **安全与前提筛查**：暴力、恐惧、成瘾、长期出轨、自伤信号 → B 段。最近一个月一开口就升级 → 先去降级。
2. **定谁先开口**：更常退开的一方先说（PAGE 112）；只有一方在读时，从读者开始。
3. **看挡路的东西**：说出“现在什么让我很难谈感受”（怕失控、怕被笑、觉得自己不该需要）。
4. **拿把手**：从最近的低谷里找出 1–2 个让自己心头一紧的词。
5. **列可怕的如果**：“如果我承认这些，最坏会怎样？”一条条写下，直到落到一个核心恐惧（通常是被抛下、不被需要、不够好、会失去对方）。
6. 🔴 **CHECKPOINT 1**：能否说出一句“我最怕的是___”，且主语是“我”、不含对对方的指责？不能 → 回到第 3 步，或先只说“这对我很难”。
7. **说需要**：转向对方、看着对方，用一句具体的话说出“我需要___”，可从书中清单挑一句改写。避免第三人称、避免“你应该”。
8. **听的一方回应**（A.R.E.）：先确认听到了（可及）；说出“听你这样说，我心里___”（回应）；用身体靠近或一个具体承诺表示“我在”（投入）。不知道怎么回，就说“我不太会，但我想学”。
9. 🔴 **CHECKPOINT 2**：听的一方有没有出现“证明给我看”“你想太多了”“我们不是在努力吗”这类回应？有 → 暂停，指出这是循环回来了；打开的一方可以再说一次。
10. **换边**：听的一方重复第 3–7 步。
11. **记下关键句**：两人各写下自己说过的那一句，留到下次（PAGE 120）。

#### 如果这一步失败

| 触发条件 | 一线修复 | 兜底 |
|---------|---------|------|
| 说着说着变成控诉 | 把“你从来不___”改成“当你___时，我怕___” | 只说“我很难开口告诉你我需要什么” |
| 找不到底层恐惧，只有“烦”“累” | 从“如果你一直这样下去，最坏会怎样？”往下问 | 用书中需要清单，让用户挑一句最刺中的 |
| 对方接不住、回讽刺或讲道理 | 说明第一次没接住很常见，打开的一方可以再说一次（PAGE 110） | 回到复盘，先处理这次没接住 |
| 一谈靠近就被旧伤打断 | 承认那次伤还没愈合 | 转 eft-forgiving-injuries，抱紧我对话延后 |
| 用户觉得“需要别人太软弱” | 说明作者的观点：依赖伴侣是天生的需要，不是不成熟（PAGE 39、63） | 先只练对自己说出这句需要 |

### B（边界）

- **作者声明不适用**（PAGE 11）：虐待或暴力、严重成瘾、长期婚外情。此时不鼓励袒露核心恐惧，回复只说明不适合并建议先联系专业人员（咨询师、反家暴求助、成瘾治疗机构；危险时拨 110）。
- **害怕伴侣**：袒露脆弱等于把武器交给对方；作者明确说身体上害怕伴侣就不要这样做（PAGE 82）。
- **自伤自杀**：有信号，或对方用“没有你我活不下去”“我去死”作为抗议，按 psyche 第五节危机话术处理。
- **不做诊断**：不判断谁是回避型、焦虑型或有何障碍；用户要求类型判断 → attach-*；要求临床诊断 → psyche 第五节第 2 条原话。
- **需要不等于命令**：说出需要后，对方可以有自己的节奏；对方一次没做到，不等于关系失败。不要把需要清单变成考核表。
- **A.R.E. 问卷**（PAGE 45–46）只作自查参考，不报分数、不拿来给对方打分；书中 7 分阈值没有效度说明。
- **证据局限**：作者用镜像神经元和催产素解释对话的效果，这部分是她的推测（PAGE 117–119），本 skill 不以此为依据；自助版效果没有研究支持。

## 💬 输出格式

按顺序，全文只问 1 个问题，不写 skill 名：

1. 一句接住（扣原话）。
2. 先说怕：帮用户把“抱怨句”翻成“我最怕___”的一句（标推测，让用户改）。
3. 再说要：给一句可以直接对伴侣说的“我需要___”，口语、具体。
4. 预备对方的反应：说明第一次可能接不住，以及到时可以再说一次的那句话；若用户是听的一方，给一句 A.R.E. 式回应。
5. 一个问题，引用用户原话。

**示例**（“我想让他知道我需要他，可一开口就变成‘你为什么老不陪我’。”）

```
想说“我需要你”，出口却变成“你为什么不陪我”，这种拧巴很常见。
“你为什么老不陪我”底下，可能是“我怕我在你心里排得越来越靠后”。这只是我的猜测，你可以换成自己的话。
找一个不赶时间的时候，看着他说：“这话我说出来有点难。我最近很怕自己对你不重要了。我需要你偶尔放下手机，抱我一下，告诉我你还在。”
他第一次可能会解释工作有多忙，这很正常。你可以再说一次：“我不是在怪你，我是在告诉你我怕。”
你说的“不陪我”，最让你难受的是哪个时刻？
```
