# 抱紧我对话

> 先说我怕什么，再说我需要你什么；听的人不用完美，只要在场。

## 🧭 决策树

```
用户想对伴侣说出需要 / 想回应伴侣的袒露
│
├── 任何安全信号，或一开口就吵、停不下来？  → 🛑 E1 STOP
├── 一靠近就提到某次旧伤、“再也不信你”？    → ❌ 转 eft-forgiving-injuries
├── 还没在一起 / 想表白？                  → ❌ 不适用，转 attach-dating-signals
│
└── ✅ 能停下争吵，但想真正靠近 → E2 定角色
      ├── 我是说的人 → 说者路线 E3–E7（先说怕，再说要）
      └── 我是听的人 → 听者路线 E8–E9（在场、回应、靠近）
      E10 换边留给两人当面做
```

文中 slug 指 `skills/tixi-fenxi/<slug>/SKILL.md`（`skills/<slug>/` 是镜像）。

## 📥 输入与证据假设

- 前提：两人至少有过一次能停下来、不升级的复盘（作者说这个对话建立在前三个对话的安全感之上，PAGE 105）。
- 需要：用户在最近一次低谷里出现过的“把手”词（如“碎掉”“被丢下”“像个外人”），这些词是往下走的入口（PAGE 108）。
- 一般由更退缩的一方先开口，因为追的一方很难在没有对方投入迹象时先伸手（PAGE 112）。只有一方在对话里时，就从这一方开始。
- 不假设对方一定接得住；预备对方第一次没接住的情况。

## 📖 RIA+E+B

### R（原文位置与转述）

- A.R.E. 三要素：可及——即使不安也对伴侣保持敞开；回应——让对方看到他的情绪对你有影响，并发出清楚的安慰信号；投入——只给所爱之人的那种专注与在场（PAGE 40）。
- 抱紧我对话分两段：“我最怕什么”，往下走到最底层的情绪；“我最需要你什么”，直接、连贯地说出只有对方能满足的需要，它是 EFT 的转折点（PAGE 105–106、113）。
- Charlie 的做法：先看是什么挡住了自己；拿出之前的“把手”词；列出“可怕的如果”找到核心恐惧；告诉对方，并说说说出来是什么感觉（PAGE 111–112）。
- 一方冒险打开后，另一方的反应很关键；常见的失败是回“那你证明给我看”，然后掉回循环；打开的一方可能需要反复说几次（PAGE 110）。
- 听的一方不确定怎么回时，就说出这份不确定；作者写道 "Being present is the secret here, rather than responding in any set way"（PAGE 120）。
- 太难时先迈小一步：先谈“说出需要有多难”（PAGE 120）。
- 书中提供的需要清单：我对你是特别的；我被你需要；我带着缺点也被接受；我需要你的时候你会在；我可以请你抱我，并请你理解开口本身就很难（PAGE 119–120）。

### I（白话解释）

吵架时我们说的是“你为什么总加班”，心里想说的是“我怕我对你不重要了”。只要后半句不出口，对方就只能回应前半句——于是他解释加班，你更失望。这场对话要做的，是把后半句说出来，而且说给对方听，不是说给空气听。说的人往下走两层：先找到怕，再找到要。听的人不需要标准答案，只要让对方看到“你的话打到我了，我在这儿”。

### A1（书中案例，转述）

- **Charlie 与 Kyoko**（PAGE 106–114）：Charlie 习惯讲道理、出主意。他从“我需要掌控”往下走到“如果我听她难过，我会碎掉，会失去她”，然后哭着说出“我不知道怎么做，我需要确定你在”。Kyoko 回应“我不需要完美的丈夫”。轮到 Kyoko 时，她一开始用第三人称对着天花板说，作者请她转过椅子看着他说；她说出“我要你靠近我、抱着我、告诉我我重要”，Charlie 才发现最简单的路一直在旁边。
- **Tim 与 Sarah**（PAGE 43–44）：Tim 承认自己“吓瘫了”，说出“我需要你，给我一个机会”。Sarah 先回了一句带刺的试探，Tim 继续说，Sarah 才慢慢软下来，说出“我需要你的安慰，你能抱住我吗”。
- **Phillipe 与 Tabitha**（PAGE 115–117）：每到同居就反悔的 Phillipe 说出小时候母亲生病时被赶走，所以“永远别把所有鸡蛋放一个篮子”；Tabitha 说出“我需要你为我去对抗那份害怕”。

### E（执行步骤）

除 E1 外，任何步骤都不整轮停下：先按已知信息给出可用内容，缺的那一项用结尾唯一的问题去补。

1. 🛑 **STOP·安全与前提筛查** — 输入：用户原话。输出：
   - 暴力、严重成瘾、长期婚外情（作者声明不适用，PAGE 11）→ 不鼓励袒露核心恐惧，只说明不适合，并给出去处（咨询师、反家暴求助、成瘾治疗机构；危险时拨 110），结束。
   - 身体上怕伴侣 → 不袒露（袒露等于把武器交给对方，PAGE 82），只给安全与转介信息，结束。
   - 自伤自杀，或对方用“没有你我活不下去”“我去死”作为抗议 → 只输出 psyche 第五节危机话术，结束。
   - 前提判据：原话出现“又吵”“一开口就吵”“天天吵”，或最近一次吵架既没在 20 分钟内停下、事后也没能一起聊过 → 只输出一句“先把吵法停下来，再谈靠近”+ 转 eft-demon-dialogues / eft-raw-spot-deescalation，不给需要句；原话说“不吵了”或没提到吵法 → 视为通过，不追问。
   - 信号模糊（“他喝多了会有点吓人”）→ 本轮只问“跟他在一起时，你会担心自己的安全吗？”，等用户回答再继续；出现过推、打、摔东西威胁，一律按本步处理。
2. **定角色** — 输入：用户原话。输出：说的人 / 听的人。分不出 → 按用户最后一句的诉求定：“我想告诉他”= 说的人，“我该怎么回”= 听的人；两样都要 → 先走听者路线。

**说者路线**（E3–E5 不单列成段：E3 的结论落在输出第 3 条的起头句“这话我说出来有点难”，E4–E5 的结论落在输出第 2 条“我最怕___”）

3. **看挡路的东西** — 输入：用户描述。输出：一句“现在什么让我很难谈感受”（怕失控、怕被笑、觉得自己不该需要）。
4. **拿把手** — 输入：最近的低谷。输出：1–2 个让用户心头一紧的词或抱怨句。
5. **列可怕的如果** — 输入：把手。输出：“如果我承认这些，最坏会怎样？”往下推到一个核心恐惧（被抛下、不被需要、不够好、失去对方）。
6. 🔴 **CHECKPOINT 1·说需要之前** — 核对：①用户原话里有没有可翻译的抱怨句或把手词；②译出的“我最怕的是___”主语是“我”、不含指责。缺① → 用用户讲到的处境给一个候选“我最怕___”（标推测），照常往下给需要句，结尾问“最近哪一刻，你心里一紧？”；不符合② → 重写，或先只说“这对我很难”。
7. **说需要** — 输入：核心恐惧。输出：一句转向对方、看着对方说的“我需要___”，至少含一项可观察的东西：时间（每周一晚、晚归前）、动作（抱我一下、发一句）或频率；不写“多关心我”“多陪我”，不用第三人称、不用“你应该”。用户卡住时，从需要清单的白话版里挑一句再加具体动作（转述自 PAGE 119–120）：“我想确定我对你是特别的”｜“我想被你需要”｜“我想带着缺点也被你接受”｜“我需要你的时候，想知道你会在”｜“我想请你抱我，也请你知道开口很难”。

**听者路线**

8. **回应** — 输入：对方袒露的原话 + 用户已有的回应。输出：确认听到了 + “听你这样说，我心里___” + “我在”，加 1 个身体动作；不知道怎么回，就说“我不太会，但我想学”。
9. 🔴 **CHECKPOINT 2·给回应句之前** — 核对：①用户是否给了对方原话；②用户已有的回应里有没有“证明给我看”“你想太多了”“我们不是在努力吗”。缺① → 按用户转述的大意给回应句，结尾问“她原话是怎么说的？”；有② → 先指出那句让循环回来了，回应句以“刚才我没接好，对不起”开头。

**收尾·不输出**

10. **换边与记关键句**（两人当面做，不在单轮回复中）— 输入：说出的需要句或回应句。输出：两人各记下自己说过的那一句；听的一方重复 E3–E7（PAGE 120）。

#### 如果这一步失败

| 触发条件 | 一线修复 | 仍失败兜底 |
|---------|---------|-----------|
| E4 信息不足：只说“我们就是很远” | 问“最近哪一刻，你最觉得他离你很远？” | 只说“我很难开口告诉你我需要什么” |
| E6 说着说着变成控诉 | 把“你从来不___”改成“当你___时，我怕___” | 只说“这对我很难开口” |
| E6 用户否认翻译：“我不是怕，我就是烦他” | 接受，问“如果一直这样下去，最坏会怎样？” | 从 E7 的白话需要清单里让用户挑一句最刺中的 |
| E7 对方接不住、回讽刺或讲道理 | 说明第一次没接住很常见，打开的一方可以再说一次（PAGE 110） | 回到复盘，先处理这次没接住（eft-raw-spot-deescalation） |
| E8 用户作为听者被对方袒露刺到、想反驳 | 先说“我需要一分钟，我不是要走” | 约定当天晚些时候再回应，先不辩解 |
| 一谈靠近就被旧伤打断 | 承认那次伤还没愈合 | 转 eft-forgiving-injuries，抱紧我对话延后 |
| 用户觉得“需要别人太软弱” | 说明作者的观点：依赖伴侣是天生的需要，不是不成熟（PAGE 39、63） | 先只练对自己说出这句需要 |
| E2 用户既想说出需要、又想回应对方 | 先走听者路线接住对方 | 本轮只给听者回应句，说者路线下一轮再做 |
| E1 用户否认危险：“他摔东西但没打我” | 只问安全问题，不引导袒露 | 按 E1 处理 |
| E1 前提说不清：“不太吵了，偶尔还会吵” | 照常给内容，结尾问“最近一次吵完，你们能坐下来聊吗？” | 用户答“不能” → 按 E1 前提未通过处理 |
| 用户坚持越界要求：写一段让对方内疚的话、判定对方是不是回避型 | 说明需要句是邀请，不是施压；这里不判类型 | 类型 → attach-style-reading；临床诊断 → psyche 第五节第 2 条原话 |
| psyche 第五节不可用 | 直接说：“你的安全最重要，现在有危险就拨 110 或 120。” | 给当地心理援助热线，并请用户把一句话发给信任的人 |

### B（边界）

- **不做诊断、不打分**：不判断谁是回避型、焦虑型或有何障碍；用户要求类型判断 → attach-style-reading；要求临床诊断 → psyche 第五节第 2 条原话。书中的回应度问卷（PAGE 45–46）不拿来给对方打分，7 分阈值没有效度说明。
- **需要不等于命令**：说出需要后，对方可以有自己的节奏；对方一次没做到，不等于关系失败。不要把需要清单变成考核表。
- **证据局限**：作者用镜像神经元和催产素解释对话的效果，这部分是她的推测（PAGE 117–119），本 skill 不以此为依据；自助版效果没有研究支持。

## 💬 输出格式

通用规则：E2 定角色后只用对应那一套；E6 或 E9 缺信息时照常给出第 1–4 条，只把第 5 条换成补缺问题。严格按顺序，全文 ≤ 260 字，只在最后问 1 个问题，不写 skill 名，不说“A.R.E./把手/抱紧我对话”等术语，改用“在场、回应、靠近”等白话。

**说的人（对应 E3–E7）**

1. 接住（≤ 30 字），扣原话；用户提到“最近不吵了” → 顺带肯定这点进步。
2. 先说怕（E4–E5，≤ 50 字）：把抱怨句翻成“我最怕___”（标推测，让用户改）。
3. 再说要（E3 + E7，≤ 70 字）：挑两人都放松、不赶时间的时候，说一句以“这话我说出来有点难”起头的“我需要___”，含时间、动作或频率之一。
4. 预备反应（≤ 50 字）：对方第一次可能接不住 + 到时再说一次的那句话。
5. 一个问题，引用用户原话。

**听的人（对应 E8–E9）**

1. 接住（≤ 30 字），肯定他想补救。
2. 点出刚才那句回应在对方听来意味着什么（≤ 50 字，标推测）。
3. 一句回应（≤ 80 字）：确认听到了 + “听你这样说，我心里___” + “我在”；再加 1 个身体动作（靠近、握手、抱住），先不给方案。
4. 预告对方可能再试探或再难过一次，接着待在旁边就好；之后用日常小行动持续兑现（≤ 50 字）。
5. 一个问题，引用用户原话。

**示例·说的人**（“她每次跟闺蜜玩到很晚，我就冷着脸不理她，其实我想让她知道我需要她。”）

```
心里想的是“我需要你”，脸上却冷下来，这种拧巴很常见。
冷脸底下，可能是“我怕在你心里我没那么要紧”。这是我的猜测，你可以换成自己的话。
挑个都不累的晚上，看着她说：“这话我说出来有点难。你晚回来的时候，我会怕自己没那么要紧。我需要你晚归前给我发一句，回来抱我一下。”
她第一次可能会说“我又没干什么”，这很正常。你可以再说一次：“我不是要管你，我是在告诉你我怕。”
你说“冷着脸”的那一刻，心里最先冒出来的是哪句话？
```

**示例·听的人**（“他说今天在公司被当众骂了，觉得自己很没用，我马上给他列了三条办法，他就不说话了。”）

```
你是想帮他，只是快了一步，回头看见了就还来得及。
三条办法在他听来，可能像“你的难受先放一边”（推测）。
先说：“刚才我急着出主意，没接好，对不起。你被当众骂，听着我心里也揪了一下。我在，你想说就说，不想说我就陪你坐会儿。”说完坐到他旁边，握住他的手，办法先不提。
他可能一时还不想开口，或者又说一句“我就是没用”，接着陪着就好。
他说“觉得自己很没用”时，你心里第一下冒出来的是什么？
```

## 反例黑名单

| # | 反模式 | 为什么 | 替代做法 |
|---|-------|-------|---------|
| 1 | 跳过降级，在激烈循环里直接做这个对话 | 没有安全感，袒露会被当成新弹药（PAGE 105） | 先确认能停下争吵 |
| 2 | 用第三人称或对着空气说需要（Kyoko 一开始，PAGE 114） | 对方接收不到这是说给他的 | 转向对方，用“我需要你” |
| 3 | 听的一方回“证明给我看”“你想太多” | 这会让循环立刻回来（PAGE 110） | 先确认听到了，再说自己的感受 |
| 4 | 听的一方立刻给解决方案 | 方案跳过了情绪，对方觉得没被接住（PAGE 63） | 先回应情绪，方案放后面 |
| 5 | 把需要清单当成要求对方达标的考核 | 需要变成命令，对方会防御 | 需要是邀请，不是合同 |
| 6 | 判定“他是回避型所以接不住” | 单方描述撑不起类型判断，标签会堵住回应 | 只描述行为；类型问题转 attach-style-reading |
| 7 | 有恐惧或暴力时仍鼓励袒露 | 作者明确说怕伴侣就不要袒露（PAGE 82） | 按 E1 转介 |
| 8 | 对用户说出“A.R.E.”“把手”等术语、一次问 2 个以上问题 | 术语和多问让用户更难开口 | 用“在场、回应、靠近”等白话，只留 1 个问题 |
| 9 | 替用户写一段长篇消息或信让对方读 | 作者要的是转向对方、看着对方说（PAGE 114），文字会变成单向宣读 | 只给 1 句能当面说出口的话 |
