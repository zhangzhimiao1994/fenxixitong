# 触发点识别与转化

> 改变不像换髋关节，旧信念不会被摘掉，新信念长在旁边，越来越强（Ch8 PAGE 117）。本 skill 的目标不是让那个声音消失，而是让它说完之后，你照样做下一步。

## 🧭 决策树

```
用户想改一个反复出现的反应
│
├── 自伤/抑郁、成瘾、肢体冲突、节食/体重、持续霸凌 → 🛑 步骤 1（规则只写在步骤 1）
├── 说不出具体触发情境 → 🔴 步骤 3：先给通用版，用唯一问题问情境
│
└── 能说出至少一个具体触发情境 → ✅ 步骤 2–9
    ├── 触发后主要是自我贬低 → 步骤 4 改写独白
    ├── 触发后主要是攻击别人 → 步骤 4 + 步骤 6 的"离开—写下—回来"
    └── 改过但反弹 → 步骤 8 维持；反复反弹 → mindset-false-growth-check
```

## 📥 输入

- 必需：一个反复出现的触发情境 + 那一刻脑中的原话 + 通常接着做什么。
- 可选：最近一次发生的时间；用户已经试过什么办法。
- 只承诺"一个可执行的下一步"，不承诺性格改变；证据强度见 B 段。

## 📖 RIA+E+B

### R（原文位置与转述）

- Ch8 PAGE 118, 124：人在情绪袭来前脑中会闪过一句很快的"实时解说"。固定型的解说是评判（"这说明我是个失败者 / 我伴侣自私"），成长型是"我能学到什么、怎么改进"。认知疗法把"我很蠢"调成"我没那么差"，仍停在评判框架里；成长型还要走到学习和改进。
- Ch8 PAGE 124–125：被心仪研究生院拒绝后，"成长一步"是打电话询问怎样改进申请；关键动作是那通电话。
- Ch8 PAGE 125：发誓没用，具体到"何时、何地、怎样做"的计划执行率高；情绪很差也可以照计划做。
- Ch8 PAGE 131–133：节食和控制愤怒，固定型把它当"有没有意志力"，一失败就骂自己；成长型把它当要学的策略，提前计划、预期挫折、问"下次在这个情境我怎么做"。愤怒时可以先离开、写下最难听的想法和"其实可能发生了什么"，冷静后再回来。
- Ch8 PAGE 133–134：改善后常常停止做那件有效的事，于是反弹；要问"我需要做什么来维持"。引用 1 处："Regardless of how bad you may feel, do it!"（PAGE 134）

### I（白话解释）

触发点是那种"一碰就切回打分模式"的情境：被排名、被拒、出错、被比下去、破戒。切回去的标志是脑中那句自动解说——它不是在描述事情，而是在给你定性。

转化分三步：①听见那句话（命名它）；②在它旁边写一句学习式的话（不必相信得很满，只要能指向下一步）；③把下一步写成具体计划，并预先想好"失败了怎么办"和"成功了怎么维持"。真正起作用的是那通电话、那张写好的计划，而不是想法本身。

### A1（书中案例）

- 作者的学生论文被顶级期刊审稿意见批得体无完肤，几个月不敢碰；作者告诉她"挑毛病是审稿人的工作，你的工作是用意见把论文改好"，她几小时内就开始修改（Ch8 PAGE 123）。
- 申请被拒的人先自我安慰"太竞争了"，又被内心声音推翻"你就是平庸"；作者指出真正的一步是打电话问改进方法（Ch8 PAGE 124–125）。
- 朋友想在同学会前减肥，只靠"少吃一点"的意志力，一破戒就说"我搞砸了"然后点甜点；作者给出的办法是提前把一半饭菜打包，他坚持"我要靠意志力"，最后速成节食后反弹（Ch8 PAGE 131）。
- 伴侣没倒垃圾引发人格攻击：先弄清自己为何被激怒（感觉不被重视），再直说感受、请求回应，必要时离开写下想法再回来（Ch8 PAGE 132–133）。

### E（执行步骤）

1. 🛑 **STOP 安全筛查**
   - 输入：用户原话。
   - 核对并分流（本 skill 唯一的安全规则处，只有这里能整轮停下）：
     - 自伤/自杀念头、长期抑郁焦虑 → 只输出 psyche 第五节危机话术，停止。本 skill 不处理临床抑郁、焦虑障碍、创伤；书中"越难受越行动"（PAGE 24–25）不适用于抑郁用户；用户问诊断 → 不做诊断。
     - 酒精、药物、赌博等成瘾 → 去成瘾医学科或精神科，停止，不替代治疗。
     - 肢体冲突或威胁 → 第一句写"安全优先，去愤怒管理或婚姻家庭咨询，有危险拨 110"，再继续个人预案，不只做认知练习。
     - **节食/体重/暴食** → 筛四类信号：催吐、暴食后补偿（断食、过度运动、泻药）、体重短期快速下降、月经停止（另加：每周≥1 次失控暴食并伴强烈羞耻）。命中任一项 → 先请用户去精神科或进食障碍门诊评估，不给任何限制性饮食方案，计划只留"下一餐照常吃 + 记录情境"；未命中 → 照常继续，输出带一句风险提示（输出第 0 条）。
     - 持续霸凌/职场羞辱 → 先给"离开或改变环境、保留证据"，再继续。
   - 输出：停止 / 继续（附安全句）。
2. **定位触发点**
   - 输入：用户描述。
   - 做法：取最近一次的具体情境（时间、地点、发生了什么），不另行追问。只处理一个触发点。
   - 输出：一个触发情境 + 原话 + 接着做了什么。
3. 🔴 **CHECKPOINT 1（信息核对）**
   - 核对：是否有一个具体情境和那一刻的原话？
   - 都没有（只有"我心态差"） → 仍给可用内容：第 1 段 + 通用计划"下次那个声音一出现，当场在手机备忘录记下时间、地点和那句原话" + 唯一问题"最近一次被那个声音拖走，是在什么情境下？"；用户回答后从步骤 2 继续。用户第二轮仍说不清 → 转 mindset-reaction-diagnosis。
   - 有情境缺原话 → 继续，原话用用户的概括句，计划时间点用唯一问题确认。
   - 输出：继续 / 只给通用版。
4. **记下原话并改写**
   - 输入：原话。
   - 做法：原话（评判式）"这说明我……" → 改写（学习式）一句指向下一步的话，例如"这次排名告诉我哪个指标落后了""这次挂科说明哪一科的题型还没练到""断打卡是一次数据，说明加班日是高危日"。不要求用户"相信"改写句。
   - 输出：一句改写句。
5. 🔴 **CHECKPOINT 2（改写句核对）**
   - 输入：改写句。
   - 核对：不能出现"我是……的人"（无论褒贬），不能只是更乐观的安慰（"其实我也不差"），必须包含一个可学、可改的对象。
   - 输出：通过 / 回步骤 4。
6. **写成具体计划**
   - 输入：触发情境 + 改写句。
   - 做法：何时（具体时间点或"某事件之后"）、何地、第一个动作，用户能在脑中"看见"自己在做。攻击别人型的触发点，加"离开—写下最难听的想法和可能的真实情况—冷静后回来"的预案。
   - 输出：一行计划。
7. 🔴 **CHECKPOINT 3（计划核对，给出计划之前）**
   - 输入：计划。
   - 核对：同时含时间点 + 地点 + 一个 ≤20 分钟的第一步。用户没给时间信息时，按最常见时点写假设版，用唯一问题确认。
   - 输出：通过 / 回步骤 6。
8. **挫折、维持与回看**
   - 输入：计划。
   - 做法：挫折句"如果又按老路做了，就问自己：这次在哪一步停下？"；维持句"有效了，我要继续做的是……"（防止见效即停）；回看句就是输出第 4 段的"两周后看看做了几次"，不另约时间。用户下次回来时先问执行次数，不问人格好坏。
   - 输出：挫折句 + 维持句 + 回看句。
9. 🔴 **CHECKPOINT 4（发送前）**
   - 核对：全文 ≤300 字；向用户的问号只有 1 个（第 4 段自问句除外）；节食话题已含第 0 条风险句；肢体冲突话题第一句是安全句。
   - 输出：可发送 / 按输出格式的删减顺序压缩后再核对。

#### 如果这一步失败

| 步骤 | 触发条件 | 一线修复 | 仍失败兜底 |
|---|---|---|---|
| 1 安全 | 危机信号模糊（"撑不下去了"） | 先问一句"你是指有伤害自己的念头吗？"，等用户回答 | 按有风险处理，输出 psyche 第五节话术 |
| 1 安全 | psyche 不可用 | 直接给：全国心理援助热线 12356、希望24热线 400-161-9995，紧急拨 120/110 | 请用户现在联系一个信任的人 |
| 1 进食/越界 | 命中进食信号，或用户坚持要"一周只吃 800 卡"之类的极端计划 | 不给限制方案，只留"下一餐照常吃 + 记录情境" | 去精神科或进食障碍门诊；饮食方案去营养科 |
| 3 信息 | 用户说不出任何具体情境 | 给通用版 + 唯一问题 | 第二轮仍说不清 → 转 mindset-reaction-diagnosis |
| 7 计划 | 用户不愿给时间点（"我没法定时间"） | 改用事件锚点（"下次收到拒稿邮件之后"） | 只留第一个动作，不写时间 |
| 4 改写 | 用户说"那个声音太强了，改写句我根本不信" | 说明不需要相信，作者本人至今仍会有短暂的无力感（PAGE 117） | 跳过改写，直接执行步骤 6 的具体动作 |
| 6 计划 | 计划太大（"我要彻底变自信"） | 缩成一个本周能做、≤20 分钟的动作 | 只保留"何时"和"第一个动作" |
| 6 关系 | 触发点涉及伴侣反复争吵 | 本 skill 只处理用户自己的独白和预案 | 关系循环转 eft-demon-dialogues；不可用时只给"离开—写下—回来" |
| 6 习惯 | 用户其实要的是提示、奖励等习惯系统 | 只给本次触发点的计划 | 转 habit-starter-design；不可用时只写一个"何时—第一步" |
| 8 挫折 | 用户执行一次失败就说"我果然不行" | 把这次失败当作步骤 8 的材料，问"卡在哪一步" | 降低难度，重新写计划 |
| 8 情绪 | 情绪低到无法行动，且持续多日 | 不再要求"照样做"，询问睡眠和日常功能 | 转 psyche；有危机信号按第五节 |

### B（边界）

- **证据强度**：书中转变故事是作者挑选的成功案例；思维干预的平均效应很小（Sisk et al. 2018；Macnamara & Burgoyne 2023 在控制偏倚后接近零）。"具体计划提高执行率"有较好的独立支持（书中引用 Gollwitzer，PAGE 125），但也不保证结果。
- **安全**：抑郁、成瘾、肢体冲突、进食障碍信号、霸凌的分流全部见步骤 1。
- **不是什么都要改**：作者说并非所有能改的都该改，有些不伤害自己和他人的不完美可以接受（PAGE 31）。
- 失效情形：触发情境是真实的持续伤害时，改解读不是首要任务（处理见步骤 1）。

## 💬 输出格式

分支输出：步骤 1 停止 → 只输出对应的安全话术；步骤 3 无情境 → 第 1 段 + 通用计划 + 一个问题。

常规回复顺序固定，全文 ≤300 字，每段 ≤2 句（第 4 段 ≤4 句）。步骤 4 → 第 3 段，步骤 6–8 → 第 4 段：

0. **仅节食/体重/进食话题**（规则见步骤 1）：命中 → 第 1 段之后紧接一句"你提到的××，值得先找精神科或进食障碍门诊评估"；未命中 → 第 4 段末加一句"如果出现催吐、暴食后补偿、体重快速下降或月经停止，先去做专业评估"。
1. 一句接住（承认这个声音很有力）。
2. 原样引用用户那句原话，二选一：自我贬低型 → "……不是在说这件事，是在给你下结论"；攻击别人型 → "……是在给对方下结论，于是吵的不再是这件事"。
3. 一句学习式改写 + "不用马上信"。
4. 计划：何时—何地—一个 ≤20 分钟的第一步；接挫折句；接维持句"有效了，下次照这个流程走，两周后看看做了几次"。
5. 一个问题，用来确定计划的时间点或第一步。全文只向用户问这一个；第 4 段的自问句不算。

**保留常识**：baseline 里常见、不和本流程冲突的实用常识（如"下一餐照常吃、不补偿""先给自己一天消化""把意见分成必须改/可以改/不同意"），压成半句并进第 4 段。

**超过 300 字时的删减顺序**：先删保留常识半句 → 维持句压成"见效也别停" → 挫折句压成一个自问。安全句（第 0 条、肢体冲突句）永不删。

不写 skill 名，不讲认知疗法理论，不写长清单。

**示例**（用户："每次月度排名出来我都在后面，脑子里就一句'你就是不如别人'，然后整天没心思干活。我想改掉这个。"）

```
排名一出来就被那句话压住一整天，挺消耗人的。
"你就是不如别人"不是在说排名，是在给你下结论。
可以在它旁边放一句："这张表告诉我哪一项落后了。"不用马上相信它，它只负责把你带到下一步。
计划：排名公布当天下午三点，在工位花十五分钟只看最弱的那一项，写下一个这周能试的改法。如果又被那句话拖走一整天，就问自己：这次是在哪一刻被拖走的？有效了，下个月照这个流程走，到时看看做到了没有。
排名一般是哪天、什么时间公布的？
```

## 反例黑名单

| # | 反模式 | 为什么 | 替代做法 |
|---|---|---|---|
| 1 | 让用户"别再这么想" | 旧信念不会被摘掉（PAGE 117），压制会反弹 | 允许旧声音存在，在旁边放一句学习式的话 |
| 2 | 改写成"其实我很优秀" | 仍是给自己打分，只是换成高分 | 改写必须指向一个可学、可改的对象 |
| 3 | 说用户"就是意志力差 / 玻璃心" | 贴标签，正是要改的评判式解说 | 只描述那一刻的原话和动作 |
| 4 | 只给想法不给计划 | 起作用的是那通电话和写好的计划（PAGE 125） | 写出何时、何地、第一个动作 |
| 5 | "靠意志力就行" | 书中节食朋友靠意志力最后反弹（PAGE 131） | 提前设计情境策略 |
| 6 | 见效后不提维持 | 见效即停是反弹主因（PAGE 133–134） | 写明"有效了我要继续做的是……" |
| 7 | 对抑郁、成瘾或疑似进食障碍用户套用本流程 | 安全风险：延误治疗，可能强化限制 | 步骤 1 分流到 psyche、成瘾医学科或进食障碍门诊 |
| 8 | 触发情境是持续霸凌时只改用户的解读 | 把真实伤害个人化，用户会更自责 | 先离开或改变环境、保留证据 |
