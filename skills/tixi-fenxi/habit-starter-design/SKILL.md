## 🧭 决策树

```
用户想开始一个新行为
│
├── 自伤信号 → 🛑 psyche 第五节；成瘾/进食障碍相关的"新习惯" → 转介
├── 这个行为已经在做、只是不稳定 → ❌ habit-four-laws-audit 或 habit-streak-plateau
├── 要排的是深度工作/写作的整块时段 → ❌ deepwork-depth-philosophy
│
└── 行为尚未建立 → ✅ 激活
    ├── 不知道何时何地做 → 步骤 1（提示）
    ├── 知道但起步太大 → 步骤 2（两分钟版）
    ├── 一直在"研究/计划"不动手 → 先点出"忙碌 vs 行动"，再步骤 2
    └── 两分钟版已稳定 2 周以上 → 步骤 3（塑形升级）
```

## 📥 输入与证据假设

- **需要**：想养成的行为；用户每天**必然发生**的固定动作（起床、刷牙、通勤下车、合上电脑、晚饭后）；可用时间段。
- **可选**：以前失败的方式（从多大起步、坚持了几天）。
- **证据假设**：执行意图有较强证据（书中 Milne 等实验 91% vs 35–38%，PAGE 64；外部元分析支持，reliable-secondary）。习惯堆叠来自 Fogg 的 Tiny Habits，是执行意图的变体，专门研究较少；两分钟规则是**经验法则**，不是实验得出的阈值（inference）。习惯形成看次数不看天数（PAGE 124–125），"21 天"没有依据。
- 用户说不出任何固定日常动作时，先问一天的时间线。

## 📖 RIA+E+B

### R（原文转述）
- 第5章（PAGE 64–66）：英国研究中，只被要求写下"下周我会在[某天][某时][某地]运动至少20分钟"的那组，执行率是另外两组的两倍多；作者据此说，很多人以为缺动力，其实缺的是**清晰**。
- PAGE 68–73：习惯堆叠是执行意图的特殊形式——"在我[现有习惯]之后，我会[新习惯]"。提示要**具体、可立即执行、频率匹配**；作者把"午休时做俯卧撑"改成"合上电脑去午休时，在桌边做十个"，含糊才消失。
- 第13章（PAGE 138）：两分钟规则——"When you start a new habit, it should take less than two minutes to do."（PAGE 138）重点不是做一件小事，而是先学会"出现"；先标准化，再优化（PAGE 139）。
- PAGE 140–141：觉得像在骗自己，就真的两分钟就停；之后用"习惯塑形"一级一级升级，每一级都只专注于前两分钟。
- 第11章（PAGE 121）：计划、研究是"忙碌"，产出结果的是"行动"；忙碌常是推迟失败的方式。

### I（白话解释）
新习惯死在两个地方：不知道**什么时候**做（于是永远"有空再说"），和**一上来太大**（于是三天就累垮）。解决办法是一句话把它钉在一个每天必然发生的动作后面，再把它缩到小得不好意思不做。真正要练的是"每天都出现"，规模以后再长。

### A1（书中案例应用）
- **运动实验**（PAGE 64）：动机讲座组和对照组差不多（35–38%），写下时间地点的那组 91%——动机不是瓶颈，清晰才是。
- **作者的俯卧撑**（PAGE 72）：模糊提示"午休时"→ 具体提示"合上电脑时，在桌边"。
- **Twyla Tharp 的出租车**（PAGE 135）：她每天的仪式不是两小时训练，而是坐上去健身房的出租车并报出地址——习惯是入口，不是终点（PAGE 138）。
- **只准待五分钟的读者**（PAGE 140）：每天去健身房只练五分钟就走，几周后自然想多待，几年后减掉百磅以上。

### A2（未来触发场景）
1. "想每天读书一小时，但一直没开始。" → "晚上刷完牙后，我会坐到沙发上读一页。"
2. "定了每天跑 5 公里，第三天就放弃了。" → 两分钟版是"下班回家换上跑鞋"；塑形：换鞋 → 出门走 10 分钟 → 跑 10 分钟 → 每周 3 次 5 公里。
3. "想学英语，App 下了一堆，资料收藏了几百条。" → 点出这是"忙碌"；启动句："坐上地铁后，我会打开单词 App 背 5 个词。"

### E（执行步骤）

**步骤 1：选锚点，写启动句**
1. 和用户列出两栏：①每天必做的动作；②每天必然发生的事（太阳落山、收到消息）（PAGE 71–72）。
2. 选一个**频率相同、此时不忙、地点合适**的锚点。
3. 写成二选一的句式：
   - 执行意图："我会在[时间]于[地点]做[行为]。"
   - 习惯堆叠："在我[现有习惯]之后，我会[新习惯]。"

🔴 **CHECKPOINT 1**：读这句话的人能否准确说出"那一刻我该站在哪、做哪个动作"？锚点是否每天都发生？

**步骤 2：缩到两分钟**
1. 把目标放到"很容易 → 很难"的梯子上（PAGE 138–139），取最容易的那一级。
2. 检查：坏日子、累的日子能不能做到？不能 → 再缩。
3. 顺带预置环境：前一晚把需要的东西放在锚点旁边（PAGE 132）。

🔴 **CHECKPOINT 2**：入口动作是否 ≤2 分钟、零准备？用户是否理解"做完两分钟可以停"？

**步骤 3：塑形升级（两分钟版稳定后）**
1. 列 3–5 个阶段，每级只比上一级多一点（参考 PAGE 141 早起、运动的阶段表）。
2. 升级条件：当前级连续两周基本做到、且不觉得费力。

🔴 **CHECKPOINT 3**：每一级是否都保留了同一个启动锚点？升级标准是否可观察？

#### 如果这一步失败

| 触发条件 | 一线修复 | 兜底 |
|---|---|---|
| 锚点那一刻总有别的事（早上孩子闹） | 换一个此时空闲的锚点（PAGE 71） | 改用固定时间的执行意图 |
| 用户觉得两分钟"太可笑" | 解释目标是练"出现"；真的两分钟就停（PAGE 140） | 允许 5 分钟版，但必须坏日子也能做到 |
| 一直在研究最佳方案 | 指出"忙碌 vs 行动"；今天先做一次最小版 | 设"研究截止时间"，到点必须做一次 |
| 一次想启动 4 个习惯 | 只选 1 个，其他排队 | 用习惯堆叠串成一条链，但每个都是两分钟版 |
| 选的习惯版本用户本身讨厌 | 换一个符合性格的版本（PAGE 183：不爱举铁就去攀岩、骑车） | 退回第2定律的诱惑捆绑（habit-four-laws-audit） |

### B（边界与失效情形）
- **两分钟是入口不是终点**：长期停在两分钟版不会带来结果目标，需要塑形；但起步期不要急着升级。
- **提示太模糊是最常见失败**（PAGE 72）："有空时""午休时"都不算提示。
- **频率不匹配会失效**（PAGE 71）：每天的习惯不能挂在每周一次的锚点上。
- **证据层级**：执行意图证据强；习惯堆叠、两分钟规则是经验法则，用 1–2 周的实际执行来检验。
- **不处理结构性缺时**：照护、轮班导致没有稳定锚点时，先承认约束，用"每周 3 个固定时点"代替"每天"。
- **不是深度工作规划**：要排每日专注块、开工磨蹭、处理会议与浅层工作 → deepwork-depth-philosophy 等 deepwork- 系列。本 skill 针对运动、阅读、早起、学习打卡等一般日常习惯。
- **成瘾替代行为、医疗/饮食处方**（如糖尿病饮食）→ 遵医嘱，本 skill 只辅助启动提示。

## 💬 输出格式

按顺序：
1. 一句话说明为什么之前没启动（缺清晰提示 / 起步太大 / 在忙碌不在行动），扣用户原话。
2. 给 1 句启动句（"在我…之后，我会…"）。
3. 给两分钟入口版，并说明"做完可以停"。
4. 给 2–3 级塑形的方向（一行即可）。
5. 只问 1 个问题，用于确认锚点是否每天都发生。

不写 skill 名，不讲研究细节，除非用户问。

**示例**（"想养成读书习惯，但一直没开始"）
```
"一直没开始"多半不是不想读，而是"读书"没有一个固定的时刻，于是永远排在"有空再说"。
启动句：晚上刷完牙后，我会坐到床边读一页书。
一页就够，读完想停就停——这阶段要练的是每天都出现，而不是读多少。
两周稳定后再升级：一页 → 10 分钟 → 一章。今晚就把书放在洗手台旁边。
你每天晚上刷牙的时间大概是固定的，还是经常变？
```
