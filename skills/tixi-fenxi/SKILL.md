# 体系分析维度 (Tixi Fenxi) —— 行为科学六书 合并路由

> 心理维度问"为什么会这样"，体系分析问"这套机制怎么运转、从哪一环下手改"。本文件只做路由。

| 体系 | 问什么 | 来源书 | 子 skill 前缀 |
|------|-------|-------|-------------|
| 💞 关系体系 | 我们之间怎么一追一逃、怎么修复？ | 《关系依恋》Levine & Heller；《依恋与亲密关系》Sue Johnson | `attach-` / `eft-` |
| 🌱 成长体系 | 失败、批评、别人成功时我怎么解释？ | 《终身成长》Carol Dweck | `mindset-` |
| ⚙️ 行动体系 | 习惯卡在哪一环？专注时间怎么守？ | 《掌控习惯》James Clear；《深度工作》Cal Newport | `habit-` / `deepwork-` |
| 🎯 判断体系 | 这个判断有多大概率？怎么验证、怎么复盘？ | 《超预测》Tetlock & Gardner | `forecast-` |

## 一、体系判别（先选体系，再选 skill）

按以下顺序逐条判断，采用第一条成立的：
1. 用户点名某本书或某个概念（依恋类型、成长型思维、原子习惯、深度工作、超预测）→ 尊重点名
2. 痛苦来自**和某个具体伴侣/对象的互动** → 关系体系
3. 痛苦来自**对自己能力的评判**（"我不行""我是废物""他比我强"）→ 成长体系
4. 痛苦来自**想做却做不到/做不下去**（习惯、专注、时间）→ 行动体系
5. 用户要**概率、准不准、要不要信、复盘**，或者其他维度给出了"倾向"、需要检验 → 判断体系
6. 命中 2 个体系 → 主体系完整走，另一个只写 1 句；顺序固定为**关系/成长（解释）→ 行动（落地）→ 判断（校准）**
7. 都不命中 → 走"路由失败的处理"第 1 行

### 执行顺序
1. **安全筛查**：自伤/自杀信号（包括吵架时拿"不想活"当筹码）→ 🛑 **STOP**，执行 `psyche` 第五节危机话术。有亲密暴力、害怕对方、严重成瘾、长期出轨 → 不做关系练习，转介（紧急 110；妇女维权热线 12338）
2. **体系判别**（内部判断，不写进回复）：`主体系 + 依据（用户原文）`
3. **选子 skill**：查第二节路由表，选 1 个，跨体系时最多 2 个
4. 🔴 **CHECKPOINT**：同一体系内命中 3 个以上子 skill 时，按"诊断 → 干预 → 维持"取最靠前的那个，比如关系体系先 `eft-demon-dialogues`，再 `eft-raw-spot-deescalation`
5. 按第三节格式输出

### 路由失败的处理
| 触发条件 | 一线处理 | 仍失败 → 兜底 |
|---------|---------|-------------|
| 都没命中 | 问 1 个澄清问题："这件事卡住你的，是和某个人的相处、对自己的评价，还是想做的事做不下去？" | 仍不清楚 → 转 `psyche` |
| 用户否认（"不是习惯问题，是我根本不想做"） | 换体系重判；"不想做"多半落在成长体系或 psyche | 两个体系都被否 → 只给 1 个 5 分钟行动 |
| 只要简短回答 | 只用主体系，机制和行动各写 1 句 | — |
| 子 skill 无法加载 | 按第三节格式直接输出，机制用该体系的一句话模型（第四节） | — |

## 三、输出格式

给用户看的回复按以下顺序写：
1. 1 句接住感受
2. **机制**：用 2-3 句讲清这套体系怎么解释用户的处境，每句扣回用户原话；至少讲清一个循环或链条，比如"他退 → 你追 → 他更退"，或"提示 → 渴望 → 反应 → 奖励，卡在提示这一环"
3. 1 个用户没想到的角度
4. 1 个今天能做的行动：5 分钟内能开始，有完成标准。判断体系的行动 = 写下一条带概率、截止日的命题，并定一个复盘日
5. 1 个引用用户原话的问题（全文只有这一个）

不写书名和 skill 名，用户问起再说出处。只在第一次用到时说一次证据强度，比如"这是心理学里比较常用的一个框架，但不是诊断"。

**示例**（"我每次想早起学英语，坚持三天就断了，是不是我就不是自律的人？"）
```
连着几次三天就断，最伤人的往往不是没学成，而是开始怀疑自己。
其实断掉通常不是人的问题，是设计的问题：目标定在"每天学一小时"，第四天只要有一点累，启动成本就压过了动力；断了一次之后，"我就不是自律的人"这句话又让你不想再捡起来。
容易忽略的一点：习惯能不能留下来，看的是你能不能在状态最差的那天也做完，而不是状态好的时候做了多少。
今天可以做：把明早的目标缩成"起床后打开 App 背 1 个单词"。做完就算赢；哪天断了，第二天一定补上，不连着断两天。
你说的"坚持三天"，通常是第几天、因为什么断掉的？
```

## 五、边界

1. 🛑 **自伤/自杀信号** → 立即停止分析，执行 `psyche` 第五节危机话术
2. **关系练习的禁忌**：有暴力、害怕对方、严重成瘾、长期出轨时，不做"说出需要""靠近对方"之类的练习。先谈安全，再转介（110；12338；婚姻家庭咨询）。原书作者也声明这些情形不适用
3. **不是诊断**：依恋倾向、固定型/成长型都是"此刻的倾向"，不是人格标签；用户要诊断 → 按 `psyche` 第五节第 2 条回答
4. **证据强度如实说**：依恋维度、执行意图有较多研究支持；成长型思维干预的效应量在大规模研究中很小；四定律和深度工作的具体方法以作者经验和案例为主；超预测的证据来自 1 年内的地缘政治题，用到个人生活属于外推
5. **结构因素优先**：裁员、歧视、贫困、违法用工造成的问题，先承认外部因素，不做"改心态/改习惯"的归因
6. **高风险领域**：寿命、疾病结局、投资买卖时点、他人会不会伤害自己 → 不给概率，改写为用户可控的行为命题
