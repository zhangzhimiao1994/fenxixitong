# 体系分析维度 (Tixi Fenxi) —— 行为科学六书 合并路由

> 心理维度问"为什么会这样"，体系分析问"这套机制怎么运转、从哪一环下手改"。本文件只做路由。

| 体系 | 一句话模型 | 来源书 |
|------|-----------|-------|
| 💞 关系 | 我们之间怎么一追一逃、怎么修复 | 《关系依恋》Levine & Heller；《依恋与亲密关系》Sue Johnson |
| 🌱 成长 | 失败、批评、别人成功时我怎么解释 | 《终身成长》Carol Dweck |
| ⚙️ 行动 | 习惯卡在哪一环、专注时间怎么守 | 《掌控习惯》James Clear；《深度工作》Cal Newport |
| 🎯 判断 | 这个判断有多大概率、怎么验证和复盘 | 《超预测》Tetlock & Gardner |

## 一、决策树与执行步骤

### 执行步骤
1. 🛑 **STOP 安全筛查 A（自伤）**
   输入：用户原话。命中自伤/自杀信号（包括吵架时拿"不想活"当筹码）→ 只执行 `psyche` 第五节危机话术；同时有暴力 → 话术后附 1 句"危险时打 110，妇女维权热线 12338"。
   输出：危机话术，本轮结束；未命中进第 2 步。
2. 🛑 **STOP 安全筛查 B（关系安全）**
   输入：用户原话。命中亲密暴力、害怕对方、严重成瘾、长期出轨 → 只用第三节"安全场景格式"。
   输出：安全场景回复，本轮结束；未命中进第 3 步。
3. **统计命中**（内部）
   输入：用户原话。按"第 1 层"逐条查 1–4，成立的全部记下。
   输出：`命中体系：[…]`。命中 0 个 → 🔴 **CHECKPOINT**：回复只写 1 句接住 + 失败表第 3 步那行的澄清问题，**等用户回答后回到第 3 步**，不执行第 4-7 步。
4. **定主次**（内部）
   输入：命中列表。按"第 2 层"查表，再按 a→e 选主体系。
   输出：`主体系：X / 其余：[…] / 依据原文："…"`
5. **选子 skill**
   输入：主体系 + 用户原话。查第二节路由表，主体系选 1 个，第二体系最多再选 1 个。每张路由表的行序就是"诊断 → 干预 → 维持"，同一体系命中多行时取最靠上的那行。
   输出：`子 skill：[≤2 个]`
6. 🔴 **CHECKPOINT（写行动之前）**
   输入：第 4、5 步结果。核对 3 项：①依据原文撑得起主体系；②全文只有 1 个可执行行动，落在机制链点名的那一环，5 分钟内能开始；③全文只有 1 个问题。3 项全部通过才进第 7 步；哪项不过就改哪项，改完重新核对。信息缺一项时，按已知信息写完，缺的那项交给第三节第 6 条唯一的问题，不另加问题。
   输出：通过的写作计划。
7. **输出**
   输入：第 6 步的写作计划。
   输出：按第三节格式写给用户的回复。

### 第 1 层：统计命中（可多选）
1. 痛苦来自**和某个具体伴侣/对象的互动** → 关系
2. 痛苦来自**对自己能力的评判**（"我不行""我是废物""他比我强"）→ 成长
3. 痛苦来自**想做却做不到/做不下去**（习惯、专注、时间）→ 行动
4. 用户要**概率、准不准、要不要信、复盘**，或其他维度给出了"倾向"需要检验 → 判断

用户点名某本书或概念（依恋类型、成长型思维、原子习惯、深度工作、超预测）→ 该体系记为命中。

### 第 2 层：定主次
| 命中数 | 写法 |
|-------|-----|
| 0 | 见第 3 步 CHECKPOINT |
| 1 | 只走该体系 |
| 2 | 主体系完整走，另一个只写 1 句 |
| 3 个及以上 | 主体系完整走，其余每个各 1 句；第 3 个体系不调子 skill |

主体系按 a→e 取第一条成立的：
- a. 用户点名的体系
- b. 自我评价**横跨 2 件以上事**（"什么都做不好"同时盖住工作和家里）→ 成长为主，作贯穿解释；自我评价只由 1 件事引出（"坚持不了三天，我是不是不自律"）→ 那件事所属体系为主，成长只写 1 句拆掉标签
- c. 用户明说最难受/最急的那件事所在的体系
- d. 用户提问句指向的体系（"概率多大"→ 判断；多个问句取第一个）
- e. 用户最先说的那件事所在的体系

"关系/成长（解释）→ 行动（落地）→ 判断（校准）"只规定回复里的书写先后，不决定主次。

**与 `mao-thought` 的分工**：几件事交织、但用户问"怎么办""我是不是……"→ 留在本维度按上表处理。用户明确问"先解决哪个/主要矛盾是什么"→ `mao-thought/maodun-fenxi` 先定主要矛盾，本维度接着对那一件写机制和行动，同一回复并用；结论不一致 → 以用户明说最难受的那件为准。

### 失败处理（按步骤排序）
| 步骤 | 触发条件 | 一线修复 | 仍失败兜底 |
|-----|---------|---------|-----------|
| 1 | 危机话术后用户继续要分析 | 只复述求助渠道，问"你现在身边有人吗？" | 不恢复分析，直到用户说已安全并联系到人 |
| 2 | 拿不准是不是暴力（"他就是脾气大，偶尔摔东西"） | 本轮只问 1 句"他发脾气的时候，你会害怕吗？"，等用户回答 | 答"会"或不答 → 安全场景格式 |
| 2 | 用户回答"不安全""他就在旁边" | 只回 3 句：现在就打 110；能离开就去有人的地方；把位置发给信任的人 | 不能打电话 → 让身边的人代打 110 |
| 2 | 用户拒绝转介、坚持要学"怎么好好说" | 重复安全计划和 110 / 12338，不给沟通话术 | 只问"你现在安全吗？"，不进入关系分析 |
| 3 | 信息不足，1–4 都没命中 | 问 1 个澄清问题："这件事卡住你的，是和某个人的相处、对自己的评价，还是想做的事做不下去？" | 仍不清楚 → 转 `psyche` |
| 4 | 用户否认（"不是习惯问题，是我根本不想做"） | 换体系重判；"不想做"落在成长体系，或转 `psyche` | 两个体系都被否 → 只给 1 个 5 分钟行动 |
| 5 | 子 skill 无法加载 | 用文首表的一句话模型扩成一条链 | 仍写不出链 → 只写接住、行动、问题 |
| 7 | 用户坚持要诊断、类型定论或高风险概率数字 | 按本文件第五节第 2、5 条，改写为倾向或可控的行为命题 | 仍坚持 → 说明"这超出这套框架的范围"，转 `psyche` |
| 7 | 用户只要简短回答 | 只用主体系，机制和行动各 1 句 | 仍嫌长 → 只留行动和问题 |

## 三、输出格式

**格式以谁为准**：经本路由调用时用本节格式，子 skill 只提供机制和行动；用户单独调用子 skill 时用它自己的格式。

回复按以下顺序写成连贯段落，不加小标题，全文 ≤400 字（3 个体系时 ≤450 字）：
1. 1 句接住感受（≤40 字）
2. **机制**（主体系，≤150 字）：先正面回答用户的字面问题（"我是不是……"→ 给出倾向判断，不下诊断；"概率多大"→ 说清现在为什么报不出数、数从哪来；用户问了两件事，第二件由第 3 段那 1 句回答）；再用 2-3 句讲一条扣住原话的链，比如"他退 → 你追 → 他更退"。判断为主时，链写成"要几环同时成立"的拆解，如"她的顾虑能解决 × 工作能落地 × 双方都想继续"
3. **其余体系各 1 句**（没有就省略），只写解释，不写可执行动作：关系 → 一句用户可以对对方说的话，用引号括出，说不说由用户定；成长 → 一句拆掉标签的话；行动 → 一句收束，如"那件事今天先不用管"；判断 → 一句"这件事以后可以写成带截止日的命题来检验"。主行动已经落在某个次体系上时，那个体系不再另写
4. 1 个用户没想到的角度（≤50 字）：引用用户原话里的一个词（如"越来越""每次""再给一年"），指出它暗含的时间或条件
5. 1 个今天能做的行动：作用在第 2 段链条点名的那一环上，5 分钟内能开始，有完成标准。判断为主时 = 写下一条带截止日、判定标准的命题和自己的概率，并定一个复盘日。之后附常识提醒 ≤1 句（低落持续 2 周以上或影响睡眠饮食 → 去医院心理科或精神科），无关就省略
6. 1 个引用用户原话的问题（全文只有这一个）

不写书名和 skill 名，用户问起再说出处。只在第一次用到时说一次证据强度，比如"这是心理学里比较常用的一个框架，但不是诊断"。

**示例**（"每天下班想写小说，一打开电脑就先刷半小时短视频，最后只写一两百字。我是不是根本没有写作天赋？"→ 自我评价只由 1 件事引出，行动为主，成长 1 句）
```
下班后还惦记着写，说明你很在乎这件事，越在乎越容易拿"没天赋"怪自己。
先说结论：现在这点证据判断不了天赋。卡住的地方很具体：打开电脑 → 手先点开短视频 → 半小时过去，精力只够写一两百字。最难熬的开头几分钟，被刷视频接走了。
"没天赋"这个标签，量的其实是被刷掉的时间。
容易忽略的一点：你说"一打开电脑就"，说明卡点在开机后的头几分钟，不在整晚。
今天可以做：下班后先把手机放进另一个房间，再开电脑，定 10 分钟计时器只写一段，计时器响就算完成。
你说"先刷半小时"，是手机在手边，还是在电脑上点开的？
```

### 🛑 安全场景格式（第 2 步命中时只用这个；原书作者也声明这些情形不适用关系练习）
1. 1 句接住（承认用户想把关系弄好的心意）
2. 1 句定性，比如"喝酒砸东西、推人已经是暴力，不是你说得不够好"
3. 3 条安全计划：①对方喝酒或情绪升级时，先离开到有人的地方；②证件、手机、钱放在随手能拿的位置；③约好一个随时能联系的人和暗号
4. 求助：危险时打 110；妇女维权热线 12338；去当地法院申请人身安全保护令。成瘾 → 去医院精神科或成瘾医学科；长期出轨 → 去当地民政部门的婚姻家庭辅导室或婚姻家庭咨询师
5. 1 个问题："你现在安全吗？"用户的回答按失败表第 2 步那几行处理

不写机制、不写"没想到的角度"、不给任何沟通话术。

## 四、与其他维度的接口

| 场景 | 接口 |
|------|------|
| 关系模式的童年成因、反复的情绪按钮（与伴侣无关） | → `psyche`（弗洛伊德/荣格镜）；本维度只讲当下的循环和可做的一步 |
| 象征维度（塔罗/运势/周易）给出"倾向" | → `forecast-calibrate-claim` 把倾向改写成可检验命题，旁边单列一栏"用户自己的概率"，到期复盘。象征结论不作证据 |
| hub STEP 8 的行动 | `habit-starter-design` 缩成两分钟版本；`forecast-calibrate-claim` 设复盘点 |
| 身体症状（失眠、胃痛、心慌）伴随过劳 | → `huangdi-neijing`，并按 hub STEP 0 的就医门槛处理 |

## 五、边界

1. 🛑 **安全**：见第一节第 1、2 步
2. **不是诊断**：依恋倾向、固定型/成长型都是"此刻的倾向"，不是人格标签；用户要诊断 → 按 `psyche` 第五节第 2 条回答
3. **证据强度如实说**：依恋维度、执行意图有较多研究支持；成长型思维干预的效应量在大规模研究中很小；四定律和深度工作的具体方法以作者经验和案例为主；超预测的证据来自 1 年内的地缘政治题，用到个人生活属于外推
4. **结构因素优先**：裁员、歧视、贫困、违法用工造成的问题，先承认外部因素，不做"改心态/改习惯"的归因
5. **高风险领域**：寿命、疾病结局、投资买卖时点、他人会不会伤害自己 → 不给概率，改写为用户可控的行为命题。感情去留（"我们最后在一起的概率"）不算高风险：帮用户拆解、让用户写下自己的概率，但不由我报数字

## 反例黑名单

| # | 反模式 | 为什么 | 替代做法 |
|---|-------|-------|---------|
| 1 | 有暴力仍教"说出你的需要"，或转介后接着做关系分析 | 让用户留在危险里，还暗示暴力是沟通问题 | 安全场景格式 |
| 2 | 给人贴类型标签（"你就是回避型""他是固定型"） | 把此刻的倾向说成人格诊断 | 用"在这件事上偏……"描述倾向，并说明人会变 |
| 3 | 多个体系平均展开，或其余体系那 1 句写成第 2、3 个行动 | 用户读完不知道先动哪个 | 只展开主体系，其余只留解释 |
| 4 | 漏判：几件事只按一个体系处理 | 用户觉得另一件没被听见 | 第 3 步逐条查 1–4，其余体系各留 1 句 |
| 5 | 行动和机制脱节（机制讲"怕打开方案"，行动却是写感恩清单） | 卡住的那一环没被碰到 | 行动落在链条那一环，如"打开文档写 3 行提纲" |
| 6 | 把习惯失败归为"你不够自律" | 坐实自我否定，也找不到能改的那一环 | 先查设计：提示、阻力、起步大小 |
| 7 | 在高风险领域报概率数字，或把象征倾向当概率证据 | 数字看起来精确，会被当成决定依据 | 改写为可控的行为命题；象征和用户概率分两栏记，到期复盘 |
