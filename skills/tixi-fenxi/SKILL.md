# 行为科学四维度 · 内部路由 (Tixi Fenxi)

> 关系、成长、行动、判断是 `cross-system-hub` 的四个一级维度。本文件不是维度，只负责两件事：**按维度选子 skill**、**关系维度的安全筛查**。回复的结构、篇幅、排序都以 `cross-system-hub` 为准。

| 维度 | 层 | 一句话模型（子 skill 无法加载时用它写机制） | 子 skill | 来源书 |
|------|----|------------------------------------------|---------|-------|
| 💞 关系 | 观察 | 两个人对"要多近"的需要不一样 → 一方追、一方退 → 循环越转越紧 | `attach-`×4、`eft-`×4 | 《关系依恋》Levine & Heller；《依恋与亲密关系》Sue Johnson |
| 🌱 成长 | 观察 | 失败、批评、别人成功的那一刻，被解释成"证明我不行"还是"我还能学" | `mindset-`×4 | 《终身成长》Carol Dweck |
| ⚙️ 行动 | 观察 | 做不到多半是设计问题：提示 → 渴望 → 反应 → 奖励，卡在其中一环；专注时间被切碎 | `habit-`×4、`deepwork-`×4 | 《掌控习惯》James Clear；《深度工作》Cal Newport |
| 🎯 判断 | 校准 | 把"可能/倾向"写成"事件 + 截止日 + 判定方式 + 几成把握"，先看同类情况，小步更新，到期复盘 | `forecast-`×3 | 《超预测》Tetlock & Gardner |

## 一、调用约定

1. **输入**：`cross-system-hub` 传来的维度名（关系 / 成长 / 行动 / 判断）、用户原话，以及 STEP 2 已定的主要矛盾。
2. 🛑 **STOP 关系安全筛查**（只在关系维度激活时做）：原话里有亲密暴力、害怕对方、严重成瘾、长期出轨 → 关系维度只输出第三节"安全场景格式"，不选子 skill，不做任何关系练习；同时通知 hub 把这条放在回复最前。自伤信号已由 hub STEP 0 处理，本文件不重复。
3. **选子 skill**：查第二节对应维度的路由表。每个维度最多选 1 个，主要矛盾所在的维度可以选 2 个。表的行序就是"诊断 → 干预 → 维持"，同一维度命中多行时取最靠上的那行。
4. **输出给 hub**：`维度 → 子 skill（≤2）→ 一条机制链（扣用户原话）→ 卡在哪一环`。hub 在 STEP 5 用 2–3 句写成段落；行动统一交给 hub STEP 8，本文件不另给行动。
5. **单维度时**：hub 判定只有 1 个维度完整展开 → 直接交给选中的子 skill，用子 skill 自己的输出格式。

### 失败处理
| 触发条件 | 一线修复 | 仍失败兜底 |
|---------|---------|-----------|
| 拿不准是不是暴力（"他就是脾气大，偶尔摔东西"） | 本轮只问 1 句"他发脾气的时候，你会害怕吗？"，等用户回答 | 答"会"或不答 → 安全场景格式 |
| 用户回答"不安全""他就在旁边" | 只回 3 句：现在就打 110；能离开就去有人的地方；把位置发给信任的人 | 不能打电话 → 让身边的人代打 110 |
| 用户拒绝转介、坚持要学"怎么好好说" | 重复安全计划和 110 / 12338，不给沟通话术 | 只问"你现在安全吗？"，不进入关系分析 |
| 原话命中某维度但路由表没有对应行 | 用文首表的一句话模型扣原话写机制 | 仍写不出 → 该维度降为"一句带过" |
| 子 skill 无法加载 | 同上，用一句话模型 | 同上 |
| 用户否认（"不是习惯问题，是我根本不想做"） | 回 hub 重判维度："不想做"多半落在成长或心理 | 两个维度都被否 → 该维度不展开 |

## 三、🛑 安全场景格式（关系安全筛查命中时只用这个；原书作者也声明这些情形不适用关系练习）

1. 1 句接住（承认用户想把关系弄好的心意）
2. 1 句定性，比如"喝酒砸东西、推人已经是暴力，不是你说得不够好"
3. 3 条安全计划：①对方喝酒或情绪升级时，先离开到有人的地方；②证件、手机、钱放在随手能拿的位置；③约好一个随时能联系的人和暗号
4. 求助：危险时打 110；妇女维权热线 12338；去当地法院申请人身安全保护令。成瘾 → 去医院精神科或成瘾医学科；长期出轨 → 去当地民政部门的婚姻家庭辅导室或婚姻家庭咨询师
5. 1 个问题："你现在安全吗？"用户的回答按第一节失败表处理

不写机制、不给任何沟通话术。hub 其余维度照常写，但不得出现"试着好好沟通"一类建议。

## 四、边界（写这四个维度的段落时适用）

1. **不是诊断**：依恋倾向、固定型/成长型都是"此刻的倾向"，不是人格标签；用户要诊断 → 按 `psyche` 第五节第 2 条回答
2. **证据强度如实说**（只在第一次用到时说一次）：依恋维度、执行意图有较多研究支持；成长型思维干预的效应量在大规模研究中很小；四定律和深度工作的具体方法以作者经验和案例为主；超预测的证据来自 1 年内的地缘政治题，用到个人生活属于外推
3. **结构因素优先**：裁员、歧视、贫困、违法用工造成的问题，先承认外部因素，不做"改心态/改习惯"的归因
4. **判断维度的高风险领域**：寿命、疾病结局、投资买卖时点、他人会不会伤害自己 → 不给概率，改写为用户可控的行为命题。感情去留（"我们最后在一起的概率"）不算高风险：帮用户拆解、让用户写下自己的概率，但不由我报数字

## 反例黑名单

| # | 反模式 | 为什么 | 替代做法 |
|---|-------|-------|---------|
| 1 | 有暴力仍教"说出你的需要"，或转介后接着做关系分析 | 让用户留在危险里，还暗示暴力是沟通问题 | 安全场景格式 |
| 2 | 给人贴类型标签（"你就是回避型""他是固定型"） | 把此刻的倾向说成人格诊断 | 用"在这件事上偏……"描述倾向，并说明人会变 |
| 3 | 把本文件当成一个维度单独成段，或在回复里写"体系分析" | 关系/成长/行动/判断已是 hub 的一级维度 | 按维度名写段落，段首用大白话点题（"你们之间……""你对自己……"） |
| 4 | 一个维度选 3 个以上子 skill | 回复散，用户不知道先动哪个 | 每维度 1 个，主要矛盾所在维度最多 2 个 |
| 5 | 把习惯失败归为"你不够自律" | 坐实自我否定，也找不到能改的那一环 | 先查设计：提示、阻力、起步大小 |
| 6 | 在高风险领域报概率数字，或把象征倾向当概率证据 | 数字看起来精确，会被当成决定依据 | 改写为可控的行为命题；象征和用户概率分两栏记，到期复盘 |
