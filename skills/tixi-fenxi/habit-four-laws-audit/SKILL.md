## 🧭 决策树

```
用户描述一个反复出现、自己想改的行为
│
├── 自伤/自杀信号？ → 🛑 psyche 第五节危机话术，停止分析
├── 物质/赌博成瘾、暴食催吐、戒断反应？ → ❌ 转介（可补一句"环境线索"视角，不给方案）
├── 要诊断？ → ❌ 不诊断，再按习惯视角继续
│
├── 行为还不存在，只想"怎么开始" → ❌ habit-starter-design
├── 已有习惯中断/没效果/厌倦 → ❌ habit-streak-plateau
├── 是"一天怎么排专注时间" → ❌ deepwork-depth-philosophy
├── 是"工作/学习时一无聊就分心"的注意力训练 → ❌ deepwork-embrace-boredom
├── 是多个大问题纠缠、不知先抓哪个 → ❌ maodun-fenxi
│
└── 一个具体行为"做不到"或"戒不掉" → ✅ 激活
    ├── 好习惯做不到 → 正向四定律（步骤 2A）
    └── 坏习惯戒不掉 → 反向四定律（步骤 2B）
```

## 📥 输入与证据假设

- **需要**：①具体行为（不是"变自律"）；②它通常在什么时间、地点、情绪、在谁身边发生；③做完/没做后的感受。
- **可选**：已经试过的方法；家里/工位/手机的布局。
- **证据假设**：四步回路与四定律是作者整合 Skinner、Duhigg、Fogg 的**启发式框架**，作者自承不是穷尽框架（PAGE 53）。其中"情境线索驱动习惯""高自控者更少面对诱惑""执行意图有效"有较好研究支持（reliable-secondary）；多巴胺解释是通俗化简述，不作依据。
- 缺②时先问场景；没有场景就无法定位提示。

## 📖 RIA+E+B

### R（原文转述）
- 第3章（PAGE 47–48）：每个习惯都走"提示 → 渴望 → 反应 → 奖励"四步；任何一步不足，行为就不会成为习惯。
- PAGE 52–53：由此得出四定律——让它显而易见、有吸引力、简便易行、令人愉悦；戒坏习惯则反向：隐形、没吸引力、困难、不愉悦。改变任何行为都可以问这四个问题。
- 第7章（PAGE 84–86）：自控力强的人往往更少置身诱惑；习惯能断，但很难被忘掉，所以靠硬扛诱惑不可靠。作者的结论："It's easier to avoid temptation than resist it."（PAGE 87）
- 第15章（PAGE 155–158）：被**即时**奖励的会重复，被**即时**惩罚的会避免；好习惯的代价在当下，坏习惯的代价在未来。
- 结论（PAGE 209–210）：在四定律之间轮转，找下一个瓶颈。

### I（白话解释）
"做不到"通常不是人不行，而是四个开关里有一个关着：没看见（提示）、不想要（渴望）、太麻烦（反应）、没爽到（奖励）。先找到是**哪一个**，再动那一个——比全面加强意志力省力得多。戒坏习惯同理，只是把开关往反方向拨，最省力的通常是第一个：让它别出现在眼前。

### A1（书中案例应用）
- **医院餐厅加水**（PAGE 74–75）：没人劝说，只是在每个饮料点加了瓶装水，三个月汽水销量降 11.4%、水升 25.8%——第1定律（显而易见）的环境设计。
- **越南老兵**（PAGE 83–84）：在越南高比例使用海洛因的士兵，回国后复吸率远低于常规戒毒后回到原环境的人——环境线索变了，习惯跟着变（注意：这不意味着普通成瘾者换环境就能戒，见 B）。
- **卡拉奇洗手**（PAGE 152–154）：居民早知道洗手重要，问题是不持续；换成起泡好、气味好的香皂后，洗手变"爽"，腹泻率降 53%，六年后多数家庭仍保持——第4定律。
- **重置社交媒体密码**（PAGE 148）：作者让助理每周一改密码、周五再给他——反向第3定律，把坏习惯变得不可能。

### A2（未来触发场景）
1. "每晚躺床上刷手机到两点。" → 反向第1/3定律：手机在客厅充电，卧室只放纸质书。
2. "买了跑鞋，三个月没跑过。" → 问：鞋放哪了？（第1定律）出门步骤几步？（第3定律）跑完有什么即时好处？（第4定律）
3. "下班一到家就点外卖。" → 找决定性时刻（进门那一刻），反向第3定律：删掉外卖 App 首屏，周末预备好食材。

### E（执行步骤）

**步骤 1：用一个具体场景还原四步**
1. 让用户描述最近一次发生（或没发生）的完整过程。
2. 填写：提示（时间/地点/情绪/人/前一个动作）→ 渴望（想改变成什么状态）→ 反应（具体行为）→ 奖励（得到了什么感受）。
3. 坏习惯特别要找"渴望背后的深层动机"（缓解焦虑、获得认可、减少不确定，PAGE 112）。

🔴 **CHECKPOINT 1**：四格是否都填上了**具体内容**而非"因为懒"？坏习惯的渴望是否写到了"想变成什么感受"？

**步骤 2A：好习惯——找关着的那个开关**
| 定律 | 诊断问题 | 首选工具（书中位置） |
|---|---|---|
| 1 显而易见 | 是不是常常"忘了"？ | 提示放进视线、执行意图、习惯堆叠（PAGE 64–79） |
| 2 有吸引力 | 想到就觉得是负担？ | 诱惑捆绑、加入以此为常态的群体、"必须"改"可以"（PAGE 95–117） |
| 3 简便易行 | 步骤太多、要准备？ | 减少摩擦、预置环境、两分钟规则（PAGE 129–141） |
| 4 令人愉悦 | 做完没感觉？ | 即时奖励、习惯追踪（PAGE 158–165） |

**步骤 2B：坏习惯——反向**
| 反向定律 | 诊断问题 | 首选工具 |
|---|---|---|
| 1 隐形 | 触发物是否随手可见？ | 减少暴露：移走、藏起、取关（PAGE 86） |
| 2 没吸引力 | 是否高估了它的好处？ | 重述它真正的代价与放弃它的收益（PAGE 111、117） |
| 3 困难 | 是否一步就能做到？ | 增加步骤、承诺装置、一次性设置（PAGE 133、143–147） |
| 4 不愉悦 | 做了有无即时代价？ | 问责伙伴、习惯契约（PAGE 172–175） |

原则：**优先动第1、3定律（环境与摩擦），最后才用第4定律的惩罚**。

🔴 **CHECKPOINT 2**：是否只选了 1 个瓶颈定律、1–2 个工具？工具是否改变的是**环境或流程**，而不是"再努力一点"？

**步骤 3：写成一条可检验的改动**
1. 句式："从___起，我会把___改成___（改变的是提示/摩擦/奖励）。"
2. 约定观察期：7 天，记录发生次数，不评判。

🔴 **CHECKPOINT 3**：7 天后如何知道有效？若无效，下一个要试的定律是哪个？

#### 如果这一步失败

| 触发条件 | 一线修复 | 兜底 |
|---|---|---|
| 用户说不出提示（"就是突然想"） | 做 3 天"习惯记分卡"：每次发生记下时间地点情绪（PAGE 60–62） | 用"指认呼唤"：做之前大声说出"我要做 X，后果是 Y" |
| 四个定律看起来都有问题 | 先选第3定律（最容易改环境的那个） | 只改"提示是否可见"这一件事 |
| 环境改不了（合租、宿舍、工位共享） | 划分"活动区"：一把椅子只用来读书（PAGE 81） | 改数字环境：一台设备只做一件事 |
| 用户要用重罚逼自己 | 提醒惩罚强度要匹配、要可执行（PAGE 172–173），先试环境法 | 只用轻量、非羞辱的代价，并有人共同知情 |
| 7 天后没变化 | 回到步骤 1，检查渴望是否找错 | 换下一个定律；仍无改善 → 考虑是否涉及情绪/临床问题，建议专业帮助 |

### B（边界与失效情形）
- **成瘾与临床**：作者明说这些小摩擦"不太可能遏制真正的成瘾"（PAGE 133）；越南老兵案例有特殊历史情境。物质/赌博成瘾、进食障碍、强迫行为 → 转介专业帮助，本 skill 不给戒断方案。
- **羞辱会反噬**（PAGE 85）：吓唬、羞辱会升高焦虑，反而触发用来缓解焦虑的坏习惯。
- **惩罚的伦理**：习惯契约只用于自己并有知情同意；不要用来控制伴侣、孩子、员工。
- **自动化的反面**（PAGE 147–148）：方便一旦为坏习惯服务（自动播放、外卖一键下单），同样的设计会加速坏习惯。
- **框架非定律**：四定律是诊断启发，不保证每个行为都能拆干净；情绪性进食等可能同时卡在多环。
- **专注力训练与时段安排**不在此：工作时一无聊就分心 → deepwork-embrace-boredom；排深度工作块 → deepwork-depth-philosophy。本 skill 处理的是固定场景里的具体行为（如"躺床上刷手机"）。

## 💬 输出格式

按顺序：
1. 一句话复述用户场景里的四步（提示 → 想要 → 做了什么 → 得到什么），扣用户原话。
2. 指出**一个**瓶颈环节及理由。
3. 给 1–2 个改环境/改流程的具体改动，写清"从哪天起、改成什么"。
4. 一句边界提醒（如涉及成瘾/情绪则转介，或提醒别靠硬扛）。
5. 只问 1 个问题，用于补齐最关键的缺失信息。

不写 skill 名，不列全部四定律清单。

**示例**（"每晚躺床上刷手机到两点，道理都懂就是停不下来"）
```
你的循环大概是：躺上床（提示）→ 想放松、不想面对明天（想要）→ 拿起枕边的手机（反应）→ 暂时不焦虑了（得到）。
卡点在第一步：手机就在手边，提示太显眼，靠"忍住"每晚都要打一场硬仗。
今晚开始：手机在客厅充电，床头只放一本纸质书；闹钟用一个便宜的独立闹钟代替。
不需要逼自己"更自律"，把诱惑挪远比扛住它容易得多。
睡前拿起手机的那一刻，你最常是想逃开什么——明天的事、还是一天的疲惫？
```
