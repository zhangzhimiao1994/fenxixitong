# 假成长型思维审计

> "我是成长型"一旦变成身份声明，就又回到了固定型的逻辑。本 skill 只看做法和效果之间的落差，不判定人。术语来源见来源追溯的版本说明。

## 🧭 决策树

```
用户说"我/我们已经是成长型了，但……"
│
├── 自伤/自杀信号 → 🛑 步骤 1：psyche 第五节
├── 躯体症状（胃痛、呕吐、心悸）或失眠≥2 周且影响白天功能 → 🛑 步骤 1：先转 psyche（"努力跑偏"可能已是健康问题）
├── 只在某类事件后偶发失眠（如被点名当晚） → ✅ 继续激活，输出第 4 条加一句睡眠提醒
├── 想用这个概念批评某个具体的人（"他就是假成长型"） → ⚠️ 步骤 1：不做人身判定，改看具体行为
├── 说不出"说法"或"现实"其中之一 → 🔴 步骤 3 CHECKPOINT 1：只问一个问题
├── 还说不出在什么时刻出问题 → ❌ mindset-reaction-diagnosis
│
└── 有"说法 vs 行为 / 结果"的落差 → ✅ 步骤 2–7
    ├── 个人层面 → 检查 1–4
    └── 家庭 / 学校 / 团队层面 → 检查 1–5
```

## 📥 输入

- 必需：用户口中的"成长型做法"具体是什么（说了什么、做了什么制度），以及没变化的证据（行为、结果或气氛）。
- 可选：持续时间；出现落差的具体时刻（如犯错后、考核前）。
- "推行了但没效果"不一定是做错了，证据强度见 B 段；输出最后必须提醒这一点。

## 📖 RIA+E+B

### R（原文位置与转述）

- Ch2 PAGE 28：很多固定型的人读过"成功是做最好的自己、失败是机会、努力是关键"之类的书，却做不到，因为底层信念在说相反的话。——**知道 ≠ 换了框架**。
- Ch2 PAGE 30–31：有很多拼命工作、也接受挑战的人仍是固定型：他们不认为努力代表没能力，但仍在展示天赋、觉得自己高人一等、受不了错误和批评。——**高努力 ≠ 成长型**。
- Ch2 PAGE 30：作者明确否认"失败就是你不够努力"，并指出有资源的努力更容易成功。——**只夸努力会把结构问题个人化**。
- Ch8 PAGE 130–131：成绩全 A 的女儿每天早上胃痛呕吐，后来被诊断胃溃疡；她的高努力是在证明自己、怕失去父母认可。——**努力跑偏**。
- Ch8 PAGE 133：如果人仍在固定型里却使用成长型策略，可能适得其反。一位父亲用了尊重和表扬策略后孩子明显好转，他就停下来，孩子再出问题时他比之前更愤怒。——**只学技巧不换框架、见效即停**。
- Ch8 PAGE 134：改变不是挑几个窍门，而是从"评判与被评判"转向"学习与帮助学习"。
- Ch7 PAGE 113：一位教练对球员的潜力是成长型，对自己的执教能力却是固定型，所以球队必须每场替他证明。——**对别人成长型、对自己固定型**。
- Ch7 PAGE 115–116：连续成功会让团队觉得"我们有天赋所以会继续赢"。——**成功后回落**。
- 引用 1 处：作者说思维改变不是"picking up a few tricks"（Ch8 PAGE 133）。

### I（白话解释）

"我是成长型"很容易变成一句身份声明，反而又回到了固定型的逻辑：我**是**某种人。真正的检验只看两件事：①出错、被批评、看到别人更强的时候，第一反应是不是还在打分；②除了"努力"之外，有没有换方法、找帮助、看结果。

组织里的常见版本是：墙上写着"拥抱失败"，考核里却是犯错的人被点名。员工会相信制度，而不是标语。

### A1（书中案例）

- 父亲 Wes 在用了尊重孩子努力、表扬共情的做法后，儿子行为大有好转；他觉得问题解决了就停下，孩子再犯时他更生气，因为"已经证明能做到却不做"（Ch8 PAGE 133–134）。
- 一对总在拌嘴的夫妻经咨询后开始互相肯定，感情回温，随后又停下，因为"好关系不应该这么费力"，再吵时更凶（Ch8 PAGE 134）。
- 优秀女儿的胃溃疡：父母照医生要求让她早睡，却没减少要求，于是更糟；真正有效的是暂停长笛课、改为为理解而学、换压力更小的学校（Ch8 PAGE 130–131）。

### A2（未来触发场景）

管理者宣布"允许试错"，但第一个公开报告失败的人被调岗；用户常说"失败是机会"，可健身教练一纠正动作就想换健身房。

### E（执行步骤）

1. 🛑 **STOP 安全与越界筛查**
   - 输入：用户描述。
   - 核对并分流：自伤/自杀信号 → 只输出 psyche 第五节危机话术，停止；躯体症状（胃痛、呕吐、心悸）或失眠≥2 周且影响白天功能 → 先转 psyche，第一句写"先照顾身体，去医院消化科/心理科或睡眠门诊"，停止审计；偶发的事件后失眠 → 继续，输出第 4 条加睡眠提醒；用户要拿"假成长型"指责具体某人 → 不做人身判定，改看用户自己能做的就事论事反馈。
   - 输出：停止 / 继续（附安全句或越界说明）。
2. **写下"说法"和"现实"**
   - 输入：用户描述。
   - 做法：由你各提炼一句——"以为自己在做的成长型做法是……"，"但实际看到的是……"，不让用户填写。
   - 输出：说法句 + 现实句。
3. 🔴 **CHECKPOINT 1（信息核对）**
   - 核对：说法和现实是否都有？
   - 缺一项 → 只输出第 1 条 + 一个问题（缺说法问"你们具体是怎么做的？"，缺现实问"哪件事让你觉得没变？"），**等用户回答再继续**。
   - 说不出出问题的时刻 → 转 mindset-reaction-diagnosis。
   - 输出：继续 / 等用户回答。
4. **逐项检查**
   - 输入：说法句 + 现实句。
   - 做法：由你根据用户已给信息判定"是 / 否 / 不确定"，不向用户逐项提问；只有判为"不确定"且最关键的那一项，才用输出第 5 条的唯一问题去问。
     1. **口头化**：出错、被批评、看到别人更强的那一刻，第一反应还是"这说明我不行 / 他比我强"吗？（PAGE 28）
     2. **只夸努力**：表扬里有没有点到具体策略、求助和结果变化？还是只有"你很努力"？努力没换来进步时，有没有换方法？（PAGE 30；Dweck 2015/2016）
     3. **努力为证明服务**：高投入背后是"想学会"，还是"怕被看不起 / 怕失去认可"？有没有身体或睡眠在报警？（PAGE 30–31, 130）
     4. **只换技巧、见效即停**：方法见效后是否停用了？回落时是否更生气？（PAGE 133–134）
     5. **制度与标语不一致**（组织层面）：犯错、提出异议、承认不会的人，实际受到什么对待？排名、分层、公开比较是否仍是主要激励？对员工/学生是成长型，对管理者自己是固定型吗？（PAGE 113, 134）
   - 输出：每项一个判定。
5. 🔴 **CHECKPOINT 2（定性之前）**：至少一项要有用户描述里的具体例子支撑才判定为"是"。全部为"否"时，不硬找问题——告诉用户可能是干预本身效应很小，或真正卡点在外部（资源、制度、健康）。
6. **选一个最先改的**
   - 输入：判为"是"的项。
   - 做法：只挑一项，给一个具体替换动作（例：把"你很努力"改成"你这次换了什么方法？结果比上次怎样？"；把"允许试错"落成"每月例会第一个议题是一个失败复盘，主讲人不受考核影响"）。
   - 输出：一项偏离 + 机制一句 + 一个替换动作。
7. **设回看点**
   - 输入：替换动作。
   - 做法：写进输出第 3 条末尾一句——两到四周后看什么指标（个人：同类事件后第一句话有没有变、当晚能不能睡；组织：敢开口/换方法的人数），并约定"见效后继续做"（PAGE 133 的教训）。
   - 输出：一句回看点。

#### 如果这一步失败

| 步骤 | 触发条件 | 一线修复 | 仍失败兜底 |
|---|---|---|---|
| 1 安全 | 检查发现高努力伴随胃痛、失眠、焦虑 | 优先降低压力和要求，去医院消化科/心理科或找咨询师 | 转 psyche |
| 1 安全 | psyche 不可用而出现危机信号 | 直接给：全国心理援助热线 12356、希望24热线 400-161-9995，紧急拨 120/110 | 请用户现在联系一个信任的人 |
| 1 越界 | 用户坚持要"证明他是假成长型"的论据去怼人 | 指出这会把概念变成新的标签，不提供攻击论据 | 只讨论用户自己能做的就事论事反馈，转 mindset-process-praise 场景 D |
| 3 信息 | 说法或现实缺一项 | 只问一个问题，等用户回答 | 按个人层面检查 1 给通用替换动作 |
| 5 否认 | 用户坚持"我们做得很对，就是没效果" | 请他举出最近一次有人犯错后的真实处理 | 说明干预平均效应本来很小，结果不变不等于做错 |
| 6 越界 | 用户要的是推行方案而非审计 | 先给五项检查作为方案的验收标准 | 说明具体课程方案超出本书范围，只给"先改一个处理犯错的规则" |
| 6 权限 | 组织问题用户无权改变 | 把范围缩到用户能影响的小团队或自己的反馈方式 | 交给 mindset-process-praise 改个人措辞；不可用时只给一句替换话术 |
| 6 自责 | 用户因"原来我是假的"而更自责 | 说明作者本人也长期在两种思维间来回（PAGE 117） | 只留一个小动作，不再列检查项 |

### B（边界）

- **术语来源**："假成长型思维"不在本版文本中，是作者 2015/2016 年的补充（reliable-secondary）。不要声称"书中第 X 页说"。
- **证据强度**：大规模研究显示思维干预效应很小（Sisk et al. 2018 元分析；Macnamara & Burgoyne 2023 元分析在控制研究质量后效应接近零；Yeager et al. 2019 显示效应集中在低成就学生且依赖学校氛围）。所以"没效果"可能是正常的，不要把责任全推给执行者。
- **不做人身判定**：不说"你/他是假成长型的人"，只说"这个做法偏离了"。
- **结构优先**：资源不足、考核机制、歧视造成的问题，靠改心态解决不了（PAGE 30）。
- **健康优先**：努力跑偏伴随躯体症状、失眠≥2 周时，先减负、就医，转 psyche。
- 失效情形：用户只是想要一个推行成长型思维的方案而非审计 → 本 skill 只能给检查清单，具体方案超出本书范围。

## 💬 输出格式

分支输出：步骤 1 停止 → 只输出安全句与去处；步骤 3 等待 → 只输出第 1 条 + 一个问题。

常规回复顺序固定，全文 ≤300 字，每段 ≤2 句：
1. 一句承认落差令人困惑。
2. 指出最可能的一项偏离（只说一项），扣回用户原话，并用一句话说出机制（如"知道 ≠ 那一刻的第一反应""标语 ≠ 犯错后的真实后果""夸努力 ≠ 帮他换方法"）。用到"假成长型"一词时，附半句"这是作者后来补充的说法，不是说你假"。
3. 一个具体替换动作 + 回看点（几周后看什么）。
4. 一句诚实提醒：这类做法本身效应不大，别期待一夜见效；个人场景有失眠时再加一句睡眠提醒（持续两周以上就先照顾睡眠、去心理科或睡眠门诊）。
5. 一个问题（全文只这一个，前四条不出现问号）。

**保留常识**：baseline 回答里常见的实用常识（如"难受不等于没成长，关键是难受之后做什么""找领导确认改进方向""看教学本身有没有给挑战和反馈"），只要不和第 3 条冲突，压成半句并进第 3 或第 4 条，不另列清单。

不写 skill 名，不列五项清单给用户，除非用户要求完整审计。

**示例**（用户："我们部门年初就说要建立成长型文化，鼓励大家试错，可到现在没人敢在周会上讲自己搞砸的事。"）

```
口号喊了大半年，大家还是不敢讲失败，确实让人泄气。
最可能的卡点不在口号，而在大家看到的"真实后果"：标语 ≠ 犯错后的真实待遇，员工通常信制度，不信标语。
可以先改一个小规则：周会第一项固定为一个"搞砸了学到什么"，由你本人先讲一次，并明确这部分不进考核；一个月后看主动讲的人有没有变多，见效了也别停。
也要诚实说一句：这类文化改变见效慢、效果有限，别期待一两次就扭转。
上一次在周会上承认失误的人，后来发生了什么？
```

## 反例黑名单

| # | 反模式 | 为什么 | 替代做法 |
|---|---|---|---|
| 1 | "你这就是假成长型思维" | 人身判定，把概念变成新标签 | "这个做法和你想要的效果之间有落差" |
| 2 | 把只夸努力当成长型 | 不点策略和结果，努力无效时没人帮着换方法 | 夸具体策略，并看结果有没有变 |
| 3 | 见效就停 | 书中父亲停用后孩子回落、他更愤怒（PAGE 133–134） | 设回看点，约定继续 |
| 4 | 墙上贴标语，考核照旧罚错 | 员工信制度不信标语 | 先改一个处理犯错的真实规则 |
| 5 | 把成绩不变全怪执行者 | 干预平均效应本来就小，有条件才明显 | 说明效应小，再排查做法 |
| 6 | 对高努力 + 胃痛失眠的人说"方向对就继续" | 安全风险：书中女儿已是胃溃疡（PAGE 130–131） | 先减负、就医、转 psyche |
| 7 | 用"我已经是成长型了"当身份标签自我安慰 | 身份声明本身就是固定型逻辑 | 只看出错那一刻的第一反应和是否换了方法 |
