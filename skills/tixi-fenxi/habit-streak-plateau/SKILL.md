## 🧭 决策树

```
用户已经在做某个习惯，出现掉队
│
├── 自伤信号 → 🛑 psyche 第五节；持续低落、失眠 → 建议专业帮助，本 skill 只给最小一步
├── 节食/训练类"平台期"伴随极端限制、催吐、过度运动 → ❌ 转介
├── 习惯从没真正建立过 → ❌ habit-starter-design
├── 一直做不到，原因不明 → ❌ habit-four-laws-audit
│
└── ✅ 激活，先分型
    ├── A 中断型："断了""破功了""打卡断了"         → 步骤 1A
    ├── B 无效型："做了很久没变化""白费了"          → 步骤 1B
    └── C 厌倦型："没劲""想换新方法""一成不变"       → 步骤 1C
    （三型可并存：先处理 A，再 B，再 C）
```

## 📥 输入与证据假设

- **需要**：习惯本身；已经持续多久、实际做了多少次；最近中断或停滞的经过；用户在看什么指标（体重、字数、步数）。
- **可选**：是否在用打卡/追踪；目标版本的难度。
- **证据假设**：书中注释引 Lally 等研究——偶尔漏一次对长期习惯形成几乎无影响，只要回到轨道（注释 PAGE 264，firsthand）；"漏两次就是新习惯的开始"这句，作者自承找不到出处（PAGE 264）。进度监测促进目标达成有元分析支持（reliable-secondary）。潜力平台期是比喻，不是能预测"第几天会突破"的规律（inference）。金发姑娘原则引 Yerkes–Dodson，属于方向性提示；"超出能力 4%"的数字证据弱（reliable-secondary）。

## 📖 RIA+E+B

### R（原文转述）
- 第1章（PAGE 23–25）：进步不是线性的，早中期常有"失望之谷"；效果被储存起来，越过临界点才显现，作者称之为潜力平台期。冰块从 25 度升到 31 度都不化，32 度才开始化。
- 第16章（PAGE 163–166）：习惯追踪同时让行为显而易见、有吸引力、令人愉悦；但要尽量自动化记录，只手动追踪最重要的一两个，做完立刻记。
- PAGE 167–168：作者的规则是不连续两次断——"Missing once is an accident. Missing twice is the start of a new habit."（PAGE 167）问题不在失误，而在"做不完美就干脆不做"；坏日子的训练最重要，因为它保住了复利，也保住了身份。
- PAGE 168–169：古德哈特定律——当指标成为目标，就不再是好指标；体重不动时看"非体重的胜利"。
- 第19章（PAGE 191–195）：难度刚好在能力边缘时动机最高；最大的威胁不是失败而是厌倦；职业者按计划执行，业余者让生活打断。
- 第20章（PAGE 200–203）：习惯自动化后人对反馈变迟钝，需要复盘；作者每年做年度回顾（好/不好/学到什么）与诚信报告（价值观是否一致）。

### I（白话解释）
坚持阶段的崩盘大多不是"不想做了"，而是三种误判：把一次中断当成全盘失败；用一个滞后的、选错的指标判断努力有没有用；把正常的厌倦当成"方法不对、该换新的"。对应的解法分别是：明天就回来哪怕只做一点；换一个能看到进展的指标并接受滞后；把难度调到刚好、按计划出现，并定期复盘而不是天天自审。

### A1（书中案例应用）
- **回形针策略**（PAGE 162）：股票经纪人每天把 120 个回形针一个个从一罐移到另一罐，每打一通电话移一个——进度看得见，本身就是奖励。
- **Seinfeld "别断链"**（PAGE 163）：不管段子好坏，只关注每天写、把链条接上。
- **Steve Martin**（PAGE 189–192）：十几年里每年只给表演加一两分钟新内容，同时保留稳能逗笑的老段子——足够的胜利维持动力，足够的失误维持投入。
- **湖人 CBE 计划**（PAGE 200–202）：先测基线，再要求赛季内提升 1%，按月与去年同期对比——用复盘防止自满。
- **作者的反面经历**（PAGE 165）：他自己记饮食日志只坚持了一顿——追踪本身也是负担。

### A2（未来触发场景）
1. "出差一周没写日记，现在完全不想捡起来。" → 1A：今晚只写一行，接回链条。
2. "健身一个月体重一斤没掉。" → 1B：区分"没效果"和"还在平台期"；换腰围、力量、睡眠等指标。
3. "背单词三个月了，每天一样，越来越烦。" → 1C：调难度到边缘（加入听写、阅读原文），保留稳定的核心部分。

### E（执行步骤）

**步骤 1A：中断型——不连续两次断**
1. 明确告诉用户：一次中断不影响长期习惯形成，关键是下一次。
2. 设计"最低回归版"：当天就能做、两分钟内的版本（"不交白卷"，PAGE 167）。
3. 预先写好"中断协议"：生病/出差/加班时的最小版本是什么。

🔴 **CHECKPOINT 1**：回归动作是否今天或明天就能完成？用户是否从"全或无"转到"有就算"？

**步骤 1B：无效型——平台期还是指标错了**
1. 数实际次数，而非过了多少天（次数太少 → 不是平台期，是还没建立，回 habit-starter-design）。
2. 检查指标：是否只盯一个滞后、易波动的数字？补 1–2 个过程指标或"非体重胜利"（PAGE 169）。
3. 判断方向：过程指标在动 → 平台期，继续；过程指标也不动 → 用 habit-four-laws-audit 检查方法本身。

🔴 **CHECKPOINT 2**：是否区分了"效果滞后"和"方法无效"？是否避免了为数字而采取极端手段（速成节食）？

**步骤 1C：厌倦型——金发姑娘 + 职业者**
1. 判断难度：太容易（无聊）还是太难（焦虑）？调到"努力一下能做到"。
2. 保留核心不变，只在边缘加新意；警惕"刚有点腻就整个换方法"（PAGE 193）。
3. 设定复盘节奏：每月一次短复盘（好/不好/学到什么），而不是每天自我审判（PAGE 203–204）。

🔴 **CHECKPOINT 3**：调整后是否仍保留原习惯的核心与锚点？是否有固定复盘时间？

**步骤 2：轻量追踪（三型通用，可选）**
1. 只追踪 1 个最重要的习惯；能自动记录就不手动（PAGE 165–166）。
2. 用"在我[完成习惯]之后，我会[打一个钩]"把记录绑在完成动作上。

#### 如果这一步失败

| 触发条件 | 一线修复 | 兜底 |
|---|---|---|
| 用户已连续断了很多次 | 不追究，今天重新开始一条新链 | 回 habit-starter-design 重设更小的入口 |
| 追踪本身成了负担 | 改自动追踪或每周回看一次（PAGE 165–166） | 停止追踪，只保留行为 |
| 用户因打卡断了极度自责 | 强调"过半即赢"，身份没有被一次否定 | 转 habit-identity-votes；情绪严重 → psyche |
| 平台期很长、用户要放弃 | 列出过程指标的变化作为"储存的努力" | 设定明确的复评时间点（如再 6 周），到点按数据决定 |
| 用户频繁换方法 | 要求当前方法至少再执行一个完整周期 | 复盘对比新旧方法的实际次数 |

### B（边界与失效情形）
- **不预测突破时间**：平台期是比喻，没有"第几天必突破"；也可能是方法本身无效，需要检查。
- **古德哈特陷阱**（PAGE 168–169）：为了让数字好看而采取伤害性手段（极端节食、带伤训练）→ 立即叫停，必要时转介。
- **"别断链"的副作用**：对完美主义者可能加重焦虑；此时弱化连续天数，强调"回归速度"。
- **"漏两次"是作者经验规则**，出处不明（PAGE 264），不当作科学阈值。
- **厌倦与抑郁要分开**：兴趣全面丧失、持续低落两周以上 → 建议专业评估，不用"职业者心态"硬推。
- **刻意练习与深度专注训练**不在此 → deepwork- 系列（deepwork-depth-philosophy、deepwork-embrace-boredom）。

## 💬 输出格式

按顺序：
1. 一句话判断属于哪一型（中断/无效/厌倦），扣用户原话。
2. 一句"重新定义"：中断不等于失败 / 效果被储存 / 厌倦是常态。
3. 给 1 个今天或明天就能做的最小动作。
4. 给 1 个调整（换指标 / 中断协议 / 难度调整 / 复盘节奏），只给一个。
5. 只问 1 个问题。

不写 skill 名、不讲大道理、不罗列三型。

**示例**（"出差一周没写日记，现在完全不想捡起来"）
```
你现在的感觉不是"不想写"，而是"断了一周，好像前面都白费了"。其实偶尔中断对长期习惯几乎没影响，真正伤害它的是接着断第二次、第三次。
今晚只写一行：今天最记得的一件事。写完就算接上了。
再顺手定一条出差规则：出差时日记只写一行，不追求完整。
你通常是因为"没时间写"断掉，还是因为"写不出完整的一篇就不想写"？
```

| # | 反模式 | 替代做法 |
|---|---|---|
