## 🧭 决策树

```
用户描述一个反复出现、自己想改的行为
│
├── 步骤 1 安全与分流（🛑 安全信号；❌ 近邻诉求按步骤 1 路由表转出）
│
└── 通过 → ✅ 激活
    → 步骤 2 补场景 → 步骤 3 还原四步
    → 步骤 4 定瓶颈（好习惯 4A / 坏习惯 4B）→ 步骤 5 写成改动 → 输出
```

## 📥 输入与证据假设

- **需要**：①具体行为（不是"变自律"）；②它通常在什么时间、地点、情绪、在谁身边发生；③做完/没做后的感受。
- **可选**：已经试过的方法；家里/工位/手机的布局。
- **证据假设**：四步回路与四定律是作者整合 Skinner、Duhigg、Fogg 的**启发式框架**，作者自承不是穷尽框架（PAGE 53）。其中"情境线索驱动习惯""高自控者更少面对诱惑""执行意图有效"有较好研究支持（reliable-secondary）；多巴胺解释是通俗化简述，不作依据。

## 📖 RIA+E+B

### R（原文转述）
- 第3章（PAGE 47–48）：每个习惯都走"提示 → 渴望 → 反应 → 奖励"四步；任何一步不足，行为就不会成为习惯。
- PAGE 52–53：由此得出四定律——让它显而易见、有吸引力、简便易行、令人愉悦；戒坏习惯则反向：隐形、没吸引力、困难、不愉悦。
- 第7章（PAGE 84–86）：自控力强的人往往更少置身诱惑；习惯能断，但很难被忘掉。作者的结论："It's easier to avoid temptation than resist it."（PAGE 87）
- 第15章（PAGE 155–158）：被**即时**奖励的会重复，被**即时**惩罚的会避免；好习惯的代价在当下，坏习惯的代价在未来。
- 结论（PAGE 209–210）：在四定律之间轮转，找下一个瓶颈。

### I（白话解释）
"做不到"通常是四个开关里有一个关着：没看见（提示）、不想要（渴望）、太麻烦（反应）、没爽到（奖励）。先找到是**哪一个**，只动那一个。戒坏习惯把开关往反方向拨，最省力的通常是第一个：让它别出现在眼前。

### A1（书中案例应用）
- **医院餐厅加水**（PAGE 74–75）：只在每个饮料点加了瓶装水，三个月汽水销量降 11.4%、水升 25.8%——第1定律的环境设计。
- **越南老兵**（PAGE 83–84）：回国后复吸率远低于常规戒毒后回到原环境的人——环境线索变了，习惯跟着变（这有特殊历史情境，不意味着普通成瘾者换环境就能戒）。
- **卡拉奇洗手**（PAGE 152–154）：换成起泡好、气味好的香皂后洗手变"爽"，腹泻率降 53%，六年后多数家庭仍保持——第4定律。
- **重置社交媒体密码**（PAGE 148）：作者让助理每周一改密码、周五再给他——反向第3定律。

### E（执行步骤）

**步骤 1：安全与分流筛查**
- 输入：用户原话。
- 输出：继续 / 转出 / 停止 三选一。
1. 自伤、自杀信号 → 🛑 **STOP**：按 `cross-system-hub` C5 危机话术回应，停止分析。
2. 物质/赌博成瘾、暴食催吐、戒断反应 → 🛑 **STOP**：输出"这类情况去医院精神心理科（成瘾医学科）当面评估"，可补一句"环境线索"视角，不给戒断方案。
3. 习惯性吸烟（社交场合复吸）→ 继续步骤 2–5，只给减少暴露的环境思路，并写明"尼古丁依赖属于成瘾，配合医院戒烟门诊或拨 12320 卫生热线"。
4. 要求诊断 → 说明"我不做诊断"，继续步骤 2。
5. 近邻诉求按下表转出：

| 用户的核心诉求 | 转到 |
|---|---|
| 行为还不存在，只想"怎么开始" | habit-starter-design |
| 已有习惯中断、没效果、做腻了 | habit-streak-plateau |
| "我就是这种人"的自我叙事 | habit-identity-votes |
| 工作/学习时一无聊就分心 | deepwork-embrace-boredom |
| 一天怎么排专注时间 | deepwork-depth-philosophy |
| 纠结要不要卸载某个 App | deepwork-craftsman-tools |
| 多个大问题纠缠、不知先抓哪个 | maodun-fenxi |
| 想改伴侣/孩子/员工的习惯 | 只用于自己或经对方同意共同设计；关系冲突 → eft-demon-dialogues（争吵循环）或 eft-hold-me-tight-talk |

| 触发条件 | 一线修复 | 仍失败兜底 |
|---|---|---|
| 用户坚持"教我怎么让老公不打游戏" | 复述边界：不设计针对他人的惩罚或诱导；给"两人一起商量规则"的谈话开头 | 转 eft-demon-dialogues，本轮不给四定律方案 |
| 吸烟者说"我不想去门诊，只要环境办法" | 给环境思路，同时保留一句门诊/12320 渠道 | 不删转介句；出现戒断不适 → 按第 2 条 |
| 信号模糊（"压力大就猛吃，吃完很后悔"） | 本轮只问一句："吃完会不会想吐掉，或一周有好几次停不下来？" | 用户回答确认 → 按第 2 条；回答否认 → 继续步骤 2 |
| psyche 不可用 | 给危机话术要点：表达关心、确认安全、去最近医院急诊或拨 12356 心理援助热线 | 停止本 skill |

**步骤 2：补齐场景**
- 输入：用户对行为的描述。
- 输出：时间、地点、情绪、在场的人、前一个动作中已知的项。
1. 至少有一项 → 进入步骤 3，缺的项按该行为最常见的情形补，输出里用"大概"标明。
2. 一项都没有 → 进入步骤 3，按 CHECKPOINT 1 的规则处理。

| 触发条件 | 一线修复 | 仍失败兜底 |
|---|---|---|
| 用户说"每次都不一样" | 只取最近一次或最常发生的一次 | 做 3 天"习惯记分卡"：每次发生记下时间、地点、情绪（PAGE 60–62） |
| 用户说不出提示（"就是突然想"） | 用"指认呼唤"：做之前大声说出"我要做 X，后果是 Y" | 先按反应格（具体行为）诊断第3定律 |

**步骤 3：用一个具体场景还原四步**
- 输入：步骤 2 的场景。
- 输出：四格（提示 / 渴望 / 反应 / 奖励）各一句具体内容，并标出哪几格有用户原话支撑。
1. 直接用用户原话填四格，不追问完整过程。
2. 提示：时间/地点/情绪/人/前一个动作；渴望：想变成什么状态；反应：具体行为；奖励：得到了什么感受。
3. 坏习惯要找"渴望背后的深层动机"（缓解焦虑、获得认可、减少不确定，PAGE 112）。

🔴 **CHECKPOINT 1（定瓶颈前）**：核对提示格是否有用户原话支撑。
- 有 → 进入步骤 4。
- 没有（用户只说"我戒不掉 X"）→ 本轮不下瓶颈判断：只给一个对任何场景都成立的减少暴露动作（让触发物离开视线），输出第 6 条的唯一问题改问"最近一次是在什么时候、在哪、当时什么心情？"，等用户回答再进入步骤 4。

| 触发条件 | 一线修复 | 仍失败兜底 |
|---|---|---|
| 用户否认四步还原（"我不是想放松，就是习惯了"） | 请用户说出做之前一秒在想什么 | 渴望格记为"未知"，按提示格和反应格诊断 |
| 渴望明显是情绪困扰（每次都因极度焦虑、失眠） | 写明情绪本身也要照顾 | 低落或焦虑超过两周 → 去医院精神心理科，或转 psyche |

**步骤 4：定瓶颈，选工具**
- 输入：步骤 3 的四格。
- 输出：1 个瓶颈定律 + 1–2 个工具 +（坏习惯）1 个替代反应。
1. 用下方表格的"诊断问题"逐行对照用户原话，第一个答"是"的行就是瓶颈。对照顺序：好习惯 3 → 1 → 2 → 4；坏习惯 1 → 3 → 2 → 4（先拿掉触发物）。
2. 原话对不上任何一行 → 取顺序里的第一行，输出第 6 条的问题用来核对。
3. 坏习惯必须配一个满足**同一渴望**、两分钟内能做的替代反应（压力大想吃零食 → 起身倒杯热水、走两分钟），不能只禁止。

**4A 好习惯——找关着的那个开关**
| 定律 | 诊断问题 | 首选工具与一句话做法（书中位置） |
|---|---|---|
| 1 显而易见 | 是不是常常"忘了"？ | 执行意图："我会在[时间][地点]做 X"；习惯堆叠；把提示放进视线（水杯放键盘旁）（PAGE 64–79） |
| 2 有吸引力 | 想到就觉得是负担？ | 诱惑捆绑：只在跑步机上听最想追的播客；加入以此为常态的群体：报一个每周固定的跑团；"必须"改"可以"（PAGE 95–117） |
| 3 简便易行 | 步骤太多、要准备？ | 减少摩擦：运动服前一晚放门口；两分钟规则：只做第一个两分钟（PAGE 129–141） |
| 4 令人愉悦 | 做完没感觉？ | 即时奖励：每做一次往"旅行罐"转 20 元；习惯追踪：日历打 ✔（PAGE 158–165） |

**4B 坏习惯——反向**
| 反向定律 | 诊断问题 | 首选工具与一句话做法 |
|---|---|---|
| 1 隐形 | 触发物是否随手可见？ | 减少暴露：零食放进高柜不透明盒子、手机放卧室外充电、取关诱惑账号（PAGE 86） |
| 2 没吸引力 | 是否高估了它的好处？ | 重述代价：写下"刷到两点 = 第二天头疼一上午"（PAGE 111、117） |
| 3 困难 | 是否一步就能做到？ | 承诺装置：睡前把手机交给家人或放进定时锁盒；一次性设置：删掉首屏 App（PAGE 133、143–147） |
| 4 不愉悦 | 做了有无即时代价？ | 问责伙伴；习惯契约：写明违约代价（如给朋友转 50 元）并让 1 人签名（PAGE 172–175） |

🔴 **CHECKPOINT 2（给改动前）**：核对只选了 1 个瓶颈、1–2 个工具；工具改变的是**环境或流程**，不是"再努力一点"；坏习惯有替代反应。任一不过 → 回 4.1。

| 触发条件 | 一线修复 | 仍失败兜底 |
|---|---|---|
| 用户不接受替代反应（"喝水又不能解压"） | 问那一刻最想要的感受，换一个给同样感受的动作 | 只做减少暴露，不强加替代 |
| 环境改不了（合租、宿舍、工位共享） | 划分"活动区"：一把椅子只用来读书（PAGE 81） | 改数字环境：一台设备只做一件事 |
| 触发场景由他人控制（朋友聚会喝酒、同事拼单） | 提前定"到场后的第一个动作"（先点无酒精饮料、坐离烟民远的位置） | 减少该场景的出现频率，或提前离场 |
| 用户要用重罚逼自己 | 惩罚强度要匹配、要可执行（PAGE 172–173），先试环境法 | 只用轻量、非羞辱的代价，并有人共同知情 |

**步骤 5：写成一条可检验的改动**
- 输入：步骤 4 的瓶颈与工具。
- 输出：1 句改动 + 7 天观察期 + 无效时的下一个动作。
1. 句式："从___起，我会把___改成___。"
2. 观察 7 天，只数发生次数，不评判；无效时按步骤 4.1 的顺序换下一个定律，写出它对应的一个动作。

🔴 **CHECKPOINT 3**：核对改动写明了起始日和可数的结果（每晚是否发生、一周几次），并写好 7 天无效时的下一个动作。缺任一 → 回 5.1 重写。

| 触发条件 | 一线修复 | 仍失败兜底 |
|---|---|---|
| 7 天后没变化 | 回步骤 3，检查渴望是否找错 | 换下一个定律；仍无改善 → 输出"这可能和情绪或身体状况有关，去医院心理门诊或全科门诊聊一次" |
| 用户中途断了几天 | 不重新诊断，明天接着做 | 转 habit-streak-plateau |

### B（边界与失效情形）
- **小摩擦挡不住真正的成瘾**（PAGE 133）：成瘾一律按步骤 1 第 2 条处理；习惯契约只用于自己并有知情同意。
- **羞辱会反噬**（PAGE 85）：吓唬、羞辱会升高焦虑，反而触发用来缓解焦虑的坏习惯。
- **自动化的反面**（PAGE 147–148）：方便一旦为坏习惯服务（自动播放、外卖一键下单），同样的设计会加速坏习惯。
- **框架非定律**：四定律是诊断启发，不保证每个行为都能拆干净；情绪性进食等可能同时卡在多环。

## 💬 输出格式

步骤 1 触发 🛑 时只输出转介 2–3 句。其余按顺序，全文 ≤250 字：
1. 用白话把四步串成一句，扣用户原话，不加"（提示）（渴望）"之类括号标签（"一躺上床，想放松、不想面对明天，就摸起枕边的手机，刷完暂时不焦虑"）；补出来的部分写"大概"。
2. 点名**决定性的那一刻**和唯一的瓶颈，一句理由。
3. 1–2 个具体改动，写清"从哪天起、改成什么"；坏习惯附替代反应。提示发生在固定地点（家门口、床、工位），且用户有另一条路线或另一个空间可选 → 第一个改动必须是绕开该地点（下班直接去健身房不先回家）。末尾半句："先试 7 天，没变化就改成[步骤 5 的下一个动作]"。
4. 一句边界提醒：涉及成瘾/情绪写转介渠道，否则写"不用硬扛"。行为涉及身体（饮食、运动、睡眠）时，紧跟 1 句与该行为直接相关、普通人都该知道的生理或安全常识。
5. CHECKPOINT 1 走"没有提示"分支时，第 2–3 条换成那一个减少暴露动作。
6. 只问 1 个问题：默认核对四格里最没把握的一格；走"没有提示"分支时问场景。

不写 skill 名，不写"定律/瓶颈/四步"等术语，不列全部工具清单。示例只示范结构，回答必须用用户自己的场景重写，不得套用示例句子。

**示例**（"每天下午同事一拼单我就跟着点奶茶，戒了几次都没戒掉"）
```
大概是这样：下午群里有人发拼单，你想歇口气、也不想显得不合群，就跟着下单，喝到嘴里甜一下，还和同事有了话题。
关键在拼单消息弹出的那一秒——消息一出现，决定就已经做了一半。
从明天起：把拼单群设成免打扰，三点前在工位放好一杯茶；想凑热闹就去茶水间站两分钟，不下单。先试 7 天，没变化就删掉外卖 App，想喝得自己下楼买。
不用硬扛，消息看不见，手就不太会动。一杯全糖奶茶的糖常常接近一天的推荐上限（约 50 克），先换成三分糖也算进步。
你最想要的是那口甜，还是那几分钟和同事一起歇着？
```

## 反例黑名单

| # | 反模式 | 为什么 | 替代做法 |
|---|---|---|---|
| 1 | "你需要更多自律/意志力" | 硬扛诱惑每天都要赢，迟早输（PAGE 86–87） | 改提示与摩擦 |
| 2 | 一次开出四定律全套 12 个工具 | 用户一个都不会做 | 只动瓶颈的 1 个定律 |
| 3 | 只禁止不替代，或替代反应与渴望不匹配（压力大就让去跑步） | 渴望没被满足，坏习惯会回来 | 给满足同一渴望、两分钟内能做的替代反应 |
| 4 | 用羞辱、恐吓式提醒（黑肺图） | 焦虑升高反而触发坏习惯（PAGE 85） | 中性地看见提示 |
