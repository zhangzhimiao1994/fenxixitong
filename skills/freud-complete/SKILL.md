## 一、理论基础骨架

```
创伤事件/持续压力
  ↓
产生强烈情感 → 无法正常释放
  ↓
被压抑 → 进入潜意识（Ucs.）
  ↓
在黑暗中增殖（消耗持续能量来维持压抑）
  ↓
以三种形式重返：
  ├─ 身体症状（转换癔症）
  ├─ 焦虑 + 回避（恐惧症）
  ├─ 强迫仪式 + 反向形成（OCD）
  └─ 自我谴责 + 丧失兴趣（忧郁）
  ↓
治疗：将潜意识意识化 → 重演变为回忆 → 扩大自我疆域
```

## 二、结构模型——自我是三个暴君的奴仆

```
        本我（Id）             超我（Super-ego）
        「我要，现在就要」     「你不配，你应该受罚」
        快乐原则               被内化的父母/权威
            ↓ 压迫                  ↓ 压迫
              → 自我（Ego）←
                   ↑
              现实原则
              「不行，有后果」
```

> 健康 = 自我能成功谈判三方。
> 症状 = 谈判失败 → 焦虑/抑郁/躯体化。

**自我大部分也是潜意识的**——「你不是自己房子的主人。」

## 三、潜意识系统——真正的心理现实

> 「潜意识是真正的心理现实。」

潜意识特征：无时间、无矛盾、无否定、无现实检验。
被压抑的观念不能进入意识，因为缺少**词表象**的连接。

**物表象（潜意识语言）→ 需要词表象（前意识通路）→ 才能进入意识。**

治疗 = 为被压抑的物表象重新找到词——把说不出的变成能说出的。

## 四、性心理发展——成人性格的童年遗产

```
口欲期（0-1）→ 接受/依赖
肛欲期（1-3）→ 控制/清洁vs脏乱
阴茎期（3-6）→ 俄狄浦斯情结 ← 所有神经症的核心
潜伏期（6-12）→ 性欲休眠
生殖期（12+）→ 整合
```

**固着** = 某阶段获得过多或过少满足 → 力比多「粘」在那里 → 压力下退行。

**升华** = 力比多从性目标转向非性目标（艺术、工作）——健康的出口。

## 五、压抑——持续的能量消耗

```
压抑不是一次性动作。维持压抑需要不间断的能量支出。
被压抑物持续向意识施压。
压抑 → 在黑暗中增殖 → 爆发时更可怕。
```

**观念**被推开→替代形成（如恐惧症的替代对象）。
**情感**被抑制→转化为焦虑或躯体化。

## 六、自恋与认同

```
原始自恋（婴儿觉得自己完美）
  ↓ 长大后意识到不完美
自我理想（失去的童年自恋的替代品）
  ↓
永远用不可能达到的理想评判自己 → 你是「不够好」的永恒来源
```

**认同** = 通过「变成」对象来处理丧失——忧郁的核心机制。
**群体的本质** = 所有成员爱同一个领袖 → 在共同的爱上彼此认同。

> 「群体从不渴求真理。它们要求幻觉，不能没有幻觉。」

## 七、哀悼 vs 忧郁——关键区分

| | 哀悼 | 忧郁 |
|---|------|------|
| 知道失去了什么 | ✅ | ❌ |
| 自尊完好 | ✅ | ❌（严重受损） |
| 自我谴责 | 无 | 有——且过度 |
| 自杀风险 | 低 | 高 |

**忧郁的核心**：自我谴责 = 对被内化对象的谴责转移。
> 「对象的影子落在自我上。」

**紧急**：自杀意念 → 立即转介专业帮助（400-161-9995），不分析。

## 八、强迫重复与死本能——最大理论转向

> 「患者不是回忆被压抑的东西——他重演它。」

- 反复陷入同样破坏模式 = 强迫重复（不是「不吸取教训」）
- 创伤梦不是愿望满足（修正了1900年的理论）
- 治疗：把重演变成回忆——命名模式就是打破重复的开始

```
Eros（生本能）——联结、建设、延长通向死亡的路
  ↕ 永恒的战争
Thanatos（死本能）——解体、回归无机、以「自己的方式」死去
```

## 九、焦虑信号理论——第二次修正

> 「焦虑产生压抑，不是压抑产生焦虑。」（1926年彻底翻转）

```
自我感知危险 → 焦虑信号（健康！）→ 部署防御（压抑等）
                                ↓（如果防御来不及）
                            自动焦虑/创伤焦虑（需要紧急稳定）
```

**危险演化序列**：分离 → 阉割 → 超我惩罚 → 社会否定 → 自我解体
→ 所有焦虑可追溯到「丧失/分离」。

**六种防御机制**：压抑、退行、反向形成、撤销、投射、躯体化。

## 十、文明的代价

```
文明给予：安全、秩序、医疗
文明索取：本能压抑 → 攻击性转向内部 → 罪疚感
         → 文明越精致，压抑越强，人越不幸福
```

> 「幸福不在宇宙的设计中。」
> 「你不能像爱自己一样爱你的邻居。」

痛苦的三重来源：自然、身体、社会关系——**只有第三个是人为的**。

## 十一、俄狄浦斯全景

- **个体版本**：每个男孩想杀父娶母 → 情结解体 → 超我形成
- **集体版本**：原始弑父 → 罪疚 → 图腾崇拜 → 文明起源
- **禁忌机制**：禁忌越强 → 潜意识欲望越强
- **治疗目标**：「本我在哪里，自我就应该在那里」
