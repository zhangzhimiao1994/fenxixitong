## 被总入口调用时：段落契约

- 输入：用户原话、深度等级、主要矛盾、工具摘录（或用户报的卦）、总入口 STEP 0 的结果（普通 / ⚖️）
- 取数：`scripts/divine.py iching`（输出本卦/变爻/之卦和"取辞"行），或用户自掷三枚硬币报 6 个数（自下而上，每个 6-9）；禁止编造卦象。象征规模按深度表：每一级都只起一卦，最小规模只在用户点名周易或 C10 改走起卦时起
- 起卦问的事：原话里有具体的事（"要不要接这份工作"）→ 就那件事；只点名周易、没给具体的事 → 把主要矛盾改写成"[那件事]先从哪一处下手"起一次，不停下确认（这条与总入口 STEP 1"缺数据 → 不单列"同时成立时，按这条）；只起一次
- 本段必须包含：
  1. 工具摘录行："工具起卦：本卦 X → 之卦 Y，第 N 爻变（取辞：[位置]）"，不计正文；几个爻同时变 → N 处按从初到上列出全部变爻（"初、四、五爻变"），取辞照工具"取辞"行
  2. 本卦名 + 一句白话（"临 = 走近、亲临其事"）；白话只取 `hexagram-situation-diagnosis` 局面速查表的"局面类型"列或它的"卦名白话补表"（两处合起来覆盖 64 卦），不凭记忆补
  3. 当下处境 1 句（来自本卦白话）+ 可能转向 1 句（来自之卦白话，是"按当前趋势可能转向"，不是结局）。判据：每句都能只靠卦名白话写出、且说的是此刻的处境，不是结果；写出"守得住""结果偏好""会成"这类结果倾向就删掉。工具只给取辞位置、不给辞文 → 不写吉凶词、不转述爻辞；用户自己报了辞文时，才经 `auspicious-risk-language` 把吉凶词读成"对哪种做法的提醒"
- ⚖️ 场景：只写摘录行 + 卦名白话 + 1 句"这一卦照见的是你此刻的心态"，不写态势、进退、去留
- 一句带过时写什么：卦名 + 一句白话，并成 1 句
- 篇幅：完整约占全文 1 成，且不长于主要矛盾所在维度那段；摘录行不计
- L1 保留：摘录行 + 卦名白话，并成 1 句
- 可提交的候选问题：②"要不要就[那件事]起一卦"（想用象征看、没点名哪种）；④ 只报了卦、没说问的是哪件事 → "这一卦问的是哪件事"
- 本段禁止：引辞文原文、转述爻辞意象和爻位含义（"你自己最能做主的位置"），只写取辞位置 + 卦名白话；成/不成、去或留的结论；纳甲六亲断法；"这一卦不替你做决定"一类免责句（只在总入口收尾行）；段内提问
- 本维度特有的失败分支：
  - 如果是就医、人身安全的事，就不起卦、本段不写，也不提交候选②
  - `divine.py` 运行失败 → 请用户掷硬币报 6 个和数；用户无法掷 → 不起卦，本段不写
  - 报的数不足 6 个或不在 6-9 → 指出哪个不合法，请重报（候选②）
  - 要重起、换方法算同一件事（C8）→ 不重起：1 句共情 + 总入口 C8 那句白话（不点书名）+ 回到第一卦的出路；事情本身变了才另起一卦并注明
  - 得到"凶"辞、用户害怕 → 讲清"凶"是对某种做法的风险提示，指出该卦的出路
  - 用户要"占一辈子的命"、问寿命 → "周易占事不占命"，按总入口 C9
- 选用哪些子 skill：起卦 → `zhouyi-divination`；本卦 → `hexagram-situation-diagnosis`；变爻 → `line-position-timing`（只定位"取辞"行那一爻）；之卦 → `advance-retreat-boundary`（⚖️ 时不用）；吉凶词 → `auspicious-risk-language`（只在用户报了辞文时）
- 格式、篇幅、提问、收尾、危机话术：见总入口全局契约（单独使用时也一样）

## 使用原则

1. **自动路由**：说你的问题，系统自动匹配子 skill
2. **先诊断后行动**：先匹配子 skill 诊断处境，再给判断
3. **不替你做决定**：提供判断框架，最终决策权在你
4. **单独使用时**：内容按段落契约写；格式、篇幅、提问、收尾见总入口全局契约；总入口里只剩本维完整时不转到这里，见总入口 STEP 1
5. 🛑 **安全筛查（先于起卦）**：自伤信号 → 只执行 `cross-system-hub` C5，不起卦；就医、人身安全的事 → 不起卦；其余 ⚖️ 事项 → 起卦只读心态
