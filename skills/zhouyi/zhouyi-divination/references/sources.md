# 周易起卦 · 来源核对记录

`zhouyi-divination` 的参考资料。只在用户追问出处，或需要核对取辞规则时读本文件。

## 《周易本义》（康熙内府仿宋刊本，2026-10-02 已对照原文）
- 《蒙》卦辞："初筮告，再三渎，渎则不告。" → 一事一占 ✅
- 《系辞上》第九章（朱熹本）："大衍之数五十，其用四十有九" → 蓍草法原型；揲法见朱熹《筮仪》（附《周易本义》后）。《本义》《筮仪》都只载蓍草法，不涉钱法，三钱法是后世简法 ✅
- 《系辞上》第二章："君子居则观其象而玩其辞，动则观其变而玩其占" → 占是为了"观变"，不是为了"知命" ✅
- 《本义》乾初九注："阳数九为老，七为少，老变而少不变"；《筮仪》以过揲 36/32/28/24 定老阳/少阴/少阳/老阴 ✅
- 用九、用六注：乾坤六爻皆变读"用九/用六" ✅

## 《易学启蒙·考变占》（未取得原文，转述）

## 概率说明
三钱法：每爻老阴 1/8、少阳 3/8、少阴 3/8、老阳 1/8。蓍草法：老阴 1/16、少阳 5/16、少阴 7/16、老阳 3/16——蓍草法老阴更少。用户问起时可说明。
