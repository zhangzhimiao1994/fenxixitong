# Zhouyi Divination — 周易起卦

## R — 来源（逐条出处与核对状态见 `references/sources.md`）
- 一事一占：《蒙》"初筮告，再三渎，渎则不告" ✅；占是为了"观变"，不是"知命"：《系辞上》第二章 ✅
- 老变少不变、乾坤用九/用六：《周易本义》✅；其余变爻取辞规则转述自《易学启蒙》（未取得原文）

## I — 方法论骨架

### 1. 三钱法
- 三枚硬币掷 6 次，**自下而上**成卦；背（阳）=3、字（阴）=2
- 和为 6 老阴（变）、7 少阳、8 少阴、9 老阳（变）
- 老阴变阳、老阳变阴 → 得之卦
- 工具：`python tools/divine.py iching`（OS 级随机，输出本卦/变爻/之卦 + **"取辞"行**，直接告诉你读哪一条辞）

### 2. 变爻取辞规则（工具"取辞"行已按此表输出；用户自报卦时查表）
| 变爻数 | 读什么 |
|:-----:|-------|
| 0 | 本卦卦辞 |
| 1 | 本卦该变爻爻辞 |
| 2 | 本卦两变爻爻辞，以**上面**一爻为主 |
| 3 | 本卦卦辞与之卦卦辞，本卦为主（贞）、之卦为辅（悔） |
| 4 | 之卦两**不变**爻爻辞，以**下面**一爻为主 |
| 5 | 之卦唯一不变爻爻辞 |
| 6 | 乾坤读"用九/用六"，其余读之卦卦辞 |

### 3. 读卦三层
1. **本卦 = 现在的局面**（交给 `hexagram-situation-diagnosis` 做处境归类）
2. **变爻 = 局面中正在变化的那个点**（交给 `line-position-timing` 定位阶段）
3. **之卦 = 如果按当前趋势发展，局面会转向哪里**（不是必然结果）

吉凶词汇统一经 `auspicious-risk-language` 翻译（"凶"= 高风险，"无咎"= 可以做但需要谨慎，"悔"= 会后悔需修正）

## A1 — 应用案例
- 问："要不要接下这个跨城市的新工作？"
- 起卦：本卦"需"（坎上乾下），九三变，之卦"节"
- 取辞：1 个变爻 → 读需卦九三："需于泥，致寇至。"
- 解读：需 = 等待时机的局面；九三 = 已经走到泥泞处，再等下去会招来麻烦；之卦节 = 局面会转向"需要设边界、量力而行"
- 输出："这一卦呈现的不是'去或不去'，而是'等待已经到了临界点'。如果决定，宜设清楚边界（试用期、退路）。"→ 交给 `advance-retreat-boundary`

## A2 — 触发场景
- ✅ "帮我就要不要换工作起一卦""我刚摇到地雷复，九二变"
- ✅ 运势维度：用户不愿提供出生信息但想"看看最近运势" → 改问"最近最在意的一件事是什么"，就那件事起卦
- ❌ "起卦看我一辈子的命"（→ 周易占的是事，不是命）
- ❌ "刚才那卦不好，再起一次"（→ 再三渎）

## E — 执行步骤
1. **高风险过滤**：医疗、法律、投资、人身安全 → 不起卦，原样回答"这类事不起卦，我可以帮你梳理事实与选项"，然后按 `cross-system-hub` 的 ⚖️ 规则处理
2. **定问题**：一件具体的事 + 用户的选项，输出 `所问: __ | 选项: __`
   🔴 **CHECKPOINT 🛑**：所问或选项不清楚时，等用户确认再起卦；用户原话已写明所问之事（如"要不要接这份工作"）或已报出卦象 → 复述后直接起卦，不停
3. **起卦**：用户自己掷硬币报 6 个数（自下而上，每个 6-9），或运行 `python tools/divine.py iching`；**禁止模型编造卦象**
4. **列卦 + 取辞**：原样展示工具输出（含"取辞"行）；用户自报的卦按第 2 节表格定位。引用辞文只短引一句；记不准原文时只写位置（如"需卦九三"），**不编造辞文**
5. **读卦三层**：本卦 → `hexagram-situation-diagnosis`；变爻 → `line-position-timing`（只定位"取辞"行指定的那一爻；取辞为卦辞时跳过本层）；之卦 → `advance-retreat-boundary`
6. **语言转换**：经 `auspicious-risk-language`；所取辞中的吉凶词（无咎、悔、吝）要落到这件事上说一句（"无咎 = 接下这份工作本身没问题，前提是…"）
7. **输出**：先 1 行卦象（注明"工具起卦"或"你自摇"），再用自然段落写：所取之辞 → 当下态势（1 句）→ 可能转向（1 句）→ 最小行动（具体到这件事）→ "这一卦不替你做决定"

## B — 边界与 Fallback
| 触发条件 | 一线处理 | 仍失败 → 兜底 |
|---------|---------|-------------|
| `divine.py` 运行失败 | 请用户掷三枚硬币 6 次，按"背=3、字=2"报 6 个和数；同轮先就这件事给 1-2 句局面梳理；**不得"模拟"起卦** | 用户无法掷 → 不起卦，改用 `hexagram-situation-diagnosis` 做义理诊断 |
| 用户报的数不足 6 个，或出现 6-9 以外的数 | 指出哪一个不合法，请重报该爻 | 仍无法给出 → 不起卦 |
| 用户只报卦名、没有变爻 | 按静卦读本卦卦辞，并说明"未提供变爻" | — |
| 同一问题要求重起 | 共 ≤4 句：1 句共情（"卦不合心意，心里不踏实很正常"）→ 1 句为什么不重起（"再三渎"：再起是在找想要的答案）→ 1 句"把第一卦和变爻发我，我们一起找它的出路"→ 最后只问"如果可以选，你心里希望它告诉你什么？" | 用户提出一个**真正不同**的问题（所问的事或选项变了；只换说法不算）→ 可另起一卦 |
| 得到"凶"辞，用户恐慌 | 讲清"凶"是对**某种做法**的风险提示，指出该卦的出路（每卦都有"利"面） | 恐慌持续 → 转 `psyche`；危机信号 → `cross-system-hub` C5 |
| 用户追问"到底成不成" | "卦呈现的是态势与条件，不是是/否。条件是 X，你能做的是 Y" | — |
| 用户没给出生信息、想"看最近运势" | 问"最近最在意的一件具体的事是什么？"，按第 2 步确认后起卦 | 用户说不出具体事 → 转 `tarot` 看整体状态 |
| 用户要纳甲六亲断法 | 告诉用户"这里只按卦爻辞的义理来读，不用纳甲六亲" | — |
| 用户要"占一辈子的命"、问寿命 | 说明"周易占事不占命"，改问"最近最在意的一件事是什么？"，回到第 2 步（定问题） | 用户坚持 → 不起卦 |
- 三钱法与蓍草法概率不同，用户问起时按 `references/sources.md` 说明
