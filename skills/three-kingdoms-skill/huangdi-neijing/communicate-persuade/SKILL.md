# 师传顺志法: 四步沟通术

## R — 原文 (Reading)

> 入国问俗, 入家问讳, 上堂问礼, 临病人问所便。
> 人之情, 莫不恶死而喜生, 告之以其败, 语之以其善,
> 导之以其所便, 开之以其所苦。
> 虽有无道之人, 恶有不听者乎?
>
> — 黄帝/岐伯, 师传第二十九

---

## I — 方法论骨架 (Interpretation)

师传顺志法是一个用于说服不配合对象的四步沟通框架。

1. **先了解对方**: "入国问俗, 入家问讳, 上堂问礼, 临病人问所便"——进入任何情境先了解对方的文化、禁忌、礼仪和偏好。不理解对方就无法有效沟通。

2. **四步劝导法**:
   - **告以败**(说明危害): "告之以其败"——先让对方看到不改变的后果。
   - **语以善**(讲清好处): "语之以其善"——然后说明改变后的正面结果。
   - **导以便**(引导可行路径): "导之以其所便"——提供对方容易执行的方案。
   - **开以苦**(解除痛苦): "开之以其所苦"——消除对方执行时的顾虑和障碍。



   🔴 **CHECKPOINT**: 在进入下一步之前，将分析结果展示给用户，等待确认后再继续。
3. **人性是切入点**: "人之情, 莫不恶死而喜生"——所有人都趋利避害, 这是沟通的基础。无论对方多么"无道", 只要找到其趋利避害的节点, 就能说服。
   🛑 **STOP**：请确认上一步的分析结果后再继续。


4. **尊重对方意愿**: 不是强加方案, 而是"顺其志"——在尊重对方意愿的前提下引导。"春夏先治其标, 后治其本; 秋冬先治其本, 后治其标"——根据不同情况调整策略顺序。

## A1 — 书中的应用 (Past Application)

### 案例 1: 劝说骄恣的王公大人
- **问题**: 王公大人"骄恣从欲轻人", 不听劝, 禁之则逆其志, 顺之则加其病, 怎么办?
- **方法论的使用**: 用四步法: 告以败(说明继续放纵的后果)→语以善(说明调整的好处)→导以便(提供不痛苦的可执行方案)→开以苦(解除其顾虑)。
- **结论**: 即使是最不配合的人, "虽有无道之人, 恶有不听者乎?"——只要方法得当, 没有人不听。
- **结果**: 通过尊重其意愿的同时引导其行为, 实现了"顺"与"治"的统一。

### 案例 2: 寒热饮食相反的处理
- **问题**: 胃欲寒饮, 肠欲热饮, 两者相逆, 怎么办?
- **方法论的使用**: "食饮衣服, 亦欲适寒温, 寒无凄怆, 暑无出汗"——不是强行统一, 而是找到一个双方都能接受的中间地带。核心是"适"(适度), 不是"禁"(禁止)。
- **结论**: 当对立需求无法同时满足时, 不选边站, 而是找到"适"的平衡点。
- **结果**: "寒温中适, 故气将持, 乃不致邪僻也。"

### 案例 3: 四步法的完整执行
- **问题**: 一个人明知熬夜伤身但改不了, 如何有效说服?
- **方法论的使用**: ①先了解: 问其偏好——为什么熬夜? 是工作压力还是报复性熬夜? ②告以败: "如果你继续每天睡4小时, 三个月后你的免疫力和记忆力会明显下降" (具体后果, 非恐吓) ③语以善: "如果你能提前1小时睡, 早上多出来的精力可以做你想做的事" (好处与对方真正在意的事挂钩) ④导以便+开以苦: "不用一下子11点睡, 先每天提前15分钟, 睡前半小时不刷手机即可" (低门槛路径) + "你担心什么? 怕工作效率下降? 我们试一周, 如果效率真的下降再调整" (消除顾虑)
- **结论**: 四步法层层递进, 每一步都回应了对方的具体顾虑, 而非泛泛说教。
- **结果**: 对方愿意试一周——从"不改"到"试试看"就是四步法的目标: 打开行动窗口。

## A2 — 触发场景 (Future Trigger) ★

1. **说服强势对象**: 面对上级/客户/家人的强势反对, 需要有效说服。
2. **行为改变推动**: 需要推动某人改变习惯/行为, 但对方不配合。
3. **需求冲突调解**: 两个对立需求无法同时满足, 需要找到平衡方案。

### 语言信号

- "怎么说服不听劝的人"
- "对方不配合怎么办"
- "道理都讲了, 就是不听"
- "怎么让对方自愿接受"

---

## E — 可执行步骤 (Execution)

1. **先了解对方**
   - "临病人问所便"——了解对方的偏好、禁忌、顾虑和真正关心的是什么。
   - 完成标准: 列出对方的核心关切和底线。

2. **告以败: 说明不改变的后果**
   - 用对方能理解的方式, 说明如果不改变, 会发生什么对其不利的事。
   - 完成标准: 后果具体、可感知, 不是抽象的威胁。

3. **语以善: 讲清改变的好处**
   - 说明改变后对方能得到什么好处。好处必须与对方的核心关切挂钩。
   - 完成标准: 好处是对方想要的, 不是你以为好的。

4. **导以便+开以苦: 提供可行路径并消除障碍**
   - "导之以其所便"——给出对方容易执行的方案(降低执行门槛)。
   - "开之以其所苦"——逐一消除对方执行时的顾虑和障碍。
   - 完成标准: 方案的具体步骤+每个顾虑的应对策略。

## B — 边界 (Boundary) ★

### 不要在以下情况使用

- **对方已配合**: 不需要说服的人不要过度使用说服技巧, 直接沟通即可。
- **原则性对抗**: 当问题涉及根本价值观冲突时, 沟通技巧可能不够, 需要制度/法律层面的解决。

### 反例黑名单（不做什么，什么情况下这个 skill 不灵）

| # | 反例模式 | 为什么危险 | 正确姿势 |
|---|---------|-----------|---------|
| 1 | **告以败变成恐吓** | 激发对抗情绪 → 对方关闭沟通 | 告以败用客观数据而非威胁。句式：「如果不做这件事，A/B/C 三个风险可能出现」而非「你不做就完蛋了」 |
| 2 | **忽视对方需求** | 只顾推自己的方案 → 对方觉得你不在乎他 | 先问「你最关心的是什么」，确认后把方案映射到对方需求上 |
| 3 | **跳过了解直接说服** | 对方觉得你不了解他 → 所有后续建议都像说教 | 四步顺序不可跳：了解 → 告败 → 语善 → 导便+开苦。跳第一步 = 全盘无效 |
| 4 | **对自毁倾向者强行说服** | 四步法假设「莫不恶死而喜生」，不自毁 → 对方可能根本不在乎后果 | 识别信号：对方反复说「无所谓」「怎样都行」。切换策略：不试图说服，先问「你想要的到底是什么」 |
| 5 | **四步全做完仍无效后继续施压** | 对方已拒绝但你反复循环 → 关系恶化 | 硬上限：两次 full cycle 无效 → 退出框架，考虑第三方介入或等待时机 |

### 失败模式

- **恐吓过度**: "告以败"变成恐吓, 反而激发对抗情绪。
- **忽视对方需求**: 只顾推销自己的方案, 不真正理解对方的需求和顾虑。
- **跳过"先了解对方"直接进入说服**: 对方觉得你不了解他, 所有后续的"败""善""便""苦"都像说教。

### Fallback（if-then 三段式）

| 触发条件 | 一线修复 | 仍失败 → 兜底 |
|---------|---------|-------------|
| 「告以败」引发对方对抗情绪 | 立刻切回步骤1（了解对方），重新确认对方的核心关切。调整表达方式：用数据代替威胁，用「如果...可能出现...」代替「你不做就完蛋了」 | 如果切回步骤1后对方仍然防御 → 退出说服模式，转为纯倾听。问：「你心里最担心的是什么？」不问解法，只听 |
| 四步全做完（两轮 full cycle）对方仍拒绝 | 停止说服。转而询问「你在担心什么？」回到「开以苦」步骤深挖未被识别的障碍 | 连续两次 full cycle 无效 → 退出框架，告知：「现在不是最佳时机。我们先放一放，你可以随时回来找我。」考虑第三方介入或等待时机 |
| 对方需求与你的目标根本冲突 | 不要强行说服。切换到冲突调解模式，寻找共同利益点而非单向说服 | 双方利益根本冲突 → 参考 `conflict-coalition-diagnosis`，从「说服」切换为「谈判」。识别双方都不能退让的底线和可以交换的筹码 |
| 对方有自毁倾向，四步法全部不生效 | 识别信号：对方反复说「无所谓」「怎样都行」。不试图说服，先问「你想要的到底是什么」 | 如果对方仍无反应 → 不适用本框架。告知：「你的状态可能不适合现在做决定。我们先把问题放在一边，等你准备好了再说」 |
| 「语善」步骤变成空洞安慰 | 「别担心会好的」= 无效。改问：「在你现在的情况下，什么算是一个好的结果？」让对方自己定义什么是好 | 对方说不出好结果 → 给三个选项让选而不是让想：「A少一些压力 / B多一个退路 / C有人支持你」，从选中的方向推导可做的动作 |
| 「导以便+开以苦」变成命令 | 对方觉得你在教他做事 → 切换语态：从「你应该做X」变成「如果有办法让你少一点麻烦，你会愿意试试吗？」 | 对方拒绝所有建议 → 停止给建议。问：「如果没有任何限制，你理想中这事怎么解决？」答案里的核心诉求就是突破口 |

### 作者的盲点

- 灵枢的四步法假设"人之情莫不恶死而喜生"——所有人都趋利避害。但现实中有些人确实存在自毁倾向或非理性决策, 四步法对此类情况可能无效。
