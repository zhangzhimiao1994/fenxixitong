# Auspicious Risk Language

## R — 原文引用

### 核心判断词（卦爻辞中出现频率最高的判断用语）

**吉类**：
> 元吉 — 最大的吉（坤·六五"黄裳，元吉"；损·六五"或益之十朋之龟，弗克违，元吉"；鼎"元吉，亨"）
> 吉 — 条件匹配可行（同人·九五"先号咷而后笑，大师克相遇"）
> 终吉 — 过程有波折但结局好（需·九二"小有言，终吉"；讼·初六"不永所事，小有言，终吉"）
> 贞吉 — 守正得吉（比·六二"比之自内，贞吉"；颐"贞吉。观颐，自求口实"）

**凶类**：
> 凶 — 结构性危险（师·六三"师或舆尸，凶"；剥·初六"剥床以足，蔑贞凶"）
> 征凶 — 主动出击会带来危险（归妹"征凶，无攸利"；损·九二"征凶"）
> 终凶 — 持续下去结局危险（讼"终凶"；比"后夫凶"）

**中间状态**：
> 悔 — 已有偏差但可补救，后悔可消（复·初九"不远复，无祗悔，元吉"；革"悔亡"）
> 吝 — 局促、羞困、丢面子的小损失（蒙·六四"困蒙，吝"；噬嗑·六三"噬腊肉，遇毒，小吝"）
> 无咎 — 责任风险可控，没有过错但也未必有收获（乾·九三"厉无咎"；坤·六四"括囊，无咎无誉"）
> 厉 — 危险存在，需要警戒（乾·九三"夕惕若，厉无咎"；夬"孚号，有厉"）

**条件词**：
> 亨 — 通达，路径是通的（乾"元亨利贞"；困"亨" — 困境中仍有通道）
> 贞 — 守正、持续、不偏（各卦常见，是持续行动的质量要求）
> 孚 — 可信承诺、信任基础（需"有孚，光亨"；损"有孚，元吉"）
> 利 — 有利条件（"利见大人""利涉大川""利建侯""利艰贞"）

## I — 方法论骨架

《周易》的吉凶词是一个**风险+条件**体系，不是简单的"好/坏"二元判断。

**风险等级对照表**：

| 原文 | 现代含义 | 风险等级 | 核心动作 |
|------|---------|---------|---------|
| 元吉 | 根本性的有利结果 | 🟢 最有利 | 条件全满足时行动 |
| 吉 | 条件匹配下可行 | 🟢 有利 | 确认条件后推进 |
| 终吉 | 过程有波折但结局好 | 🟡 短期有阻 | 坚持，熬过波折 |
| 亨 | 路径通达 | 🟢 通畅 | 顺势而行 |
| 贞吉 | 守正得吉 | 🟡 需持续守正 | 不偏离正道 |
| 无咎 | 风险可控，无过错 | 🟡 中性偏安 | 保持警惕 |
| 悔 | 可补救的偏差 | 🟠 需修正 | 回头改过 |
| 吝 | 局促、丢面子 | 🟠 小损失 | 忍辱、避免扩大 |
| 厉 | 危险存在，需警戒 | 🟠 需警戒 | 提高警惕，准备应对 |
| 凶 | 结构性危险 | 🔴 危险 | 停止当前动作，调整方向 |
| 征凶 | 主动出击危险 | 🔴 不可主动 | 放弃进攻姿态 |

**关键原则：单个判断词不独立存在**

每一个吉/凶/悔/吝都绑定在具体条件上——"有孚"才有吉、"居贞"才能吉、"中"才吉、"终"才凶。脱离条件的判断词是断章取义。

## A1 — 源文件应用案例

### 案例 1：无咎 ≠ 大吉
- **乾·九三**："君子终日乾乾，夕惕若，厉无咎。"
- **解读**：无咎需要"终日乾乾"的努力和"夕惕若"的警惕。不是自然的、免费的。
- **应用**：听到"无咎"时，应翻译为"只要你保持警惕和努力，可以不犯错"，而不是"一切安全"。

### 案例 2：悔可亡
- **复·初九**："不远复，无祗悔，元吉。"
- **解读**：走偏了但没走太远就回头，连悔都不会留下。
- **应用**：偏差发生后，补救窗口越小，损失越小。别等到形成"悔"和"吝"再回头。

### 案例 3：凶 ≠ 命运诅咒
- **小过·九三**："弗过防之，从或戕之，凶。" / **归妹**："征凶，无攸利。"
- **解读**：小过的凶是因为没防备（该防不防），归妹的凶是因为方向错配（征伐不是嫁娶的业务）。
- **应用**：凶通常是动作方向、尺度或条件的错配，调整即可化解，不是天罚。

### 案例 4：孚是吉的前提
- **需**："有孚，光亨，贞吉。"
- **解读**：等待期只要有信任（有孚），路径就是光明的。
- **应用**：在不确定的等待期，维持信任是第一要务——信任在，通路的灯就亮着。

### 案例 5：困中也有亨
- **困**："亨，贞，大人吉，无咎。"
- **解读**：即使在困境中，路径也是通的（亨），但对的条件是"贞"（守正）和"大人"（有君子之德）。
- **应用**：困境不是死路，是对执行者的要求更高。不是谁都能从困中走通。

## A2 — 触发场景

### 适合触发
1. 用户读到周易判断词，不知道怎么转成现实含义。
2. 用户把"吉"误读成保证成功，把"凶"误读成必然失败。
3. 用户需要判断当前风险是可控（无咎）、可补救（悔）、局促（吝）、危险（厉）还是结构性危险（凶）。
4. 其他周易 skill 分析时需要统一术语解释。

### 不适合触发
1. 用户只求字频统计。
2. 用户要求把吉凶当确定预言。
3. 用户需要完整训诂考证、版本校勘。

**风险等级对照（参考）**：
| 原文 | 现代含义 | 等级 |
|------|---------|:--:|
| 元吉/吉/亨 | 条件满足下可行动 | 🟢 |
| 终吉/贞吉/无咎 | 过程有阻但结局可控 / 不出错但未必有收获 | 🟡 |
| 悔/吝/厉 | 可补救偏差 / 局促小损失 / 危险需警戒 | 🟠 |
| 凶/征凶 | 结构性危险 / 主动出击危险 | 🔴 |

### 步骤

1. **逐词填表**：每个判断词一行，绑定条件不能空（如「吉→因为有孚」「凶→因为征」）。
2. **展示核对**：输出填完的表。
   🔴 **CHECKPOINT**：展示结果，等待确认。
3. **输出行动**：悔/吝 → 给可补救动作；厉 → 给警戒清单；凶 → 给必须停止的动作 + 可重试条件。

## B — 边界与 Fallback

### 失败模式
- 把"无咎"翻成"大吉"。
- 把"悔"翻成不可挽回。
- 不看条件，只按单个字下结论。

### Fallback（if-then 三段式）

| 触发条件 | 一线修复 | 仍失败 → 兜底 |
|---------|---------|-------------|
| 用户把"无咎"当"大吉" | 纠正：无咎 = 没犯错，不等于有收获。期待大收获的话，无咎不够，需要调整策略 | 用户坚持这是好结果 → 问："你是想平平安安不出错，还是想获得实质成果？"前者 → 无咎够了；后者 → 需要更大动作 |
| "悔/吝"让用户过度恐慌 | 分寸：悔 = 可补救的小过（后悔了改了就好）；吝 = 丢面子的小损失（不大但让人不痛快）。两者都非致命 | 用户仍恐慌 → 给出具体的修复路径和时间线：悔 → "现在改，X 天后影响消退"；吝 → "损失是小范围的，影响不超过 X" |
| 只看一个字做决策，不看上下文 | 吉凶必须结合上下文才有意义，单字解读是断章取义。追回完整判断链 | 上下文不完整无法还原 → 标注"信息不足，此判断置信度低"。拒绝给出任何指向性建议 |
| "厉"被当成"凶"，过度反应 | 厉 = 风险存在但不是必然发生。核心是"你有没有防备？"有防备 → 厉可化解，无防备 → 厉变凶 | 用户不知道该怎么防备 → 给出具体的警戒动作："注意 X 信号，一旦出现就 A / 不出现就 B" |
| "亨"被当成"一定顺利" | 亨 = 通畅的可能性，不是保证。需要你去做才能亨，不做就不亨 | 用户问"那我什么都不做也能亨吗" → 明确告诉：不能。亨的前提是有孚（诚信）、有行动 |
| "贞"被误解为"什么都不动" | 贞 = 坚守正道，不是原地不动。走正路需要行动，不是呆坐 | 用户把坚守变成停滞 → 问："正道还在走吗？还是你已经停下但告诉自己'我在坚守'？" |

### 来源边界
使用六十四卦经文的判断词，不处理后世复杂占断规则。
