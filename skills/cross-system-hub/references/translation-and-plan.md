## 二、L4 的 21 天计划（持久战三阶段，`chijiuzhan-san-jieduan`；模板内不写问号）

```
第 1 周 防御·稳基础（身心 + 心理）
  Day 1-3 身体日志（睡眠/食欲/精力 1-10 分）
  Day 4-5 情绪命名：写下这句话像谁的口气
  Day 6-7 回顾 + 一张塔罗（只问镜子问题，不问结果）
第 2 周 相持·看结构（心理 + 行动 + 运势 + 判断 + 引擎）
  Day 8-10 面具审计：列出 3 个角色和各自的消耗
  Day 11-12 对照运势周期，写"这个阶段我要守住的 / 要试探的"；把其中一条写成带截止日和几成把握的判断
  Day 13-14 消耗 vs 修复表，找 1 个可减少的消耗源；用习惯四环查它卡在哪一环
第 3 周 反攻·小步推进（周易 + 心理 + 行动 + 判断 + 引擎）
  Day 15-17 就一个具体决定起一卦（只起一次），记下第一反应
  Day 18-19 做一个可逆的小试探（两分钟起步版）
  Day 20-21 写"我是谁、接下来要守住什么"；复盘 Day 11-12 写下的判断，看准不准
每日：身体接地 5 分钟 + 情绪命名 1 次 + 主要矛盾上的 1 个最小行动
```

把每一天的内容换成用户原话里的具体事（如"面具审计"→"列出你在公司、家里、父母面前各是什么样"）；用户没激活的维度对应的天数改成观察维度的练习。

## 四、⚖️ 事实风险清单（STEP 0 用；只列事实，不替用户决定；每个版本 ≤6 行；清单里不出现问号，要用户确认的写成"先弄清"或"□ 自查项"）

- 投资/借贷：
  - 原则："应急金（3-6 个月生活费）一般不动用；单一项目投入超过能承受的亏损额即属高风险。" 用户说"全部积蓄"时开头直说"按这条原则已经属于高风险"
  - 自己填："这笔钱 = 我 __ 个月的生活费"，附 1 个算例（"积蓄 8 个月生活费，留 3-6 个月应急，能承受亏光的最多 2-5 个月的量"）；"大概多少钱、占积蓄几成"是唯一问题的候选（hub 优先规则第 2 条 ②）
  - 先弄清 3 件事：靠什么赚钱、现在有没有收入、你的钱是股份还是借款（条款、退出条件）；投给熟人加 1 条自查："□ 这笔钱回不来时，你们还能像现在这样相处"
  - 3 个信号：催你尽快决定、承诺保本或高回报、说不清入股还是借款
  - 只提"只拿能承受亏光的部分、分阶段投入"，不说投或不投；仅借钱/投钱给熟人时，给 2-3 行可直接发给对方的话（"我想先看一下书面协议和最近几个月的流水，把我的份额和退出方式写清楚"）
- 替伴侣还债 / 取公积金：
  - 原则：替别人还债 = 把对方的债变成你的风险；应急金（3-6 个月生活费）一般不动用
  - 先弄清：债务总额与笔数、每笔的利率和到期日、有没有书面借条或还款约定
  - 公积金只能按规定用途提取（购房、租房、还房贷等），替他人还网贷一般不在其中，以当地公积金中心（12329）的答复为准
  - 自己填：这笔钱 = 我 __ 个月的生活费；□ 自查：有没有书面借条和还款时间
  - 3 个信号：反复催你尽快拿钱；只给"以后一起还"的口头承诺；不肯给账单或说不清欠款
- 辞职/创业/转行：
  - 原则：应急金（3-6 个月生活费）不动；辞职前先有一条验证过的收入来源
  - 自己填：不拿工资我能撑 __ 个月；启动资金 = 我 __ 个月的生活费
  - 先弄清 3 件事：靠什么赚钱、现在有没有人付过钱、做不成时退路是什么
  - 可逆的试法：先业余做 3 个月，或请假、停薪留职试水
  - 单纯换工作：删去"启动资金"行，"自己填"改为"没有新 offer 时我能撑 __ 个月"，可逆试法改为"在职面试，拿到书面 offer 再提离职"
  - 3 个信号：还没有人付过钱；要动应急金或借钱；有人催"窗口就这几个月"
- 三个版本的最后一行都是："重大财务决定，请咨询持证财务顾问或律师。"

## 五、出生时辰处理（hub C11 用）

**第 0 步：先校正，再判时辰。** 给了出生城市 → 带 `--lon 经度` 跑一次，读工具"真太阳时校正"行的分钟偏移；之后所有判断都用"校正后时间 = 钟表时间 + 偏移"。没给城市 → 按北京时间，不校正，收尾行请用户告知城市。交界 = 单数整点（如 15:00 是申时起点）。

按序取第一条成立的：
- ① 只说"X 点多"：可能时段 = 校正后的 [X:00, X:59]。整段落在同一时辰且两端离交界都 ≥30 分钟 → 按该时辰排，说"时柱稳定"。时段起点恰好贴着交界、整段在交界之后（没校正时的"3 点多"）→ 不算跨交界，只按交界之后的时辰中点排，提醒句写"如果实际早于 X 点，时柱是前一个时辰"。其余 → 按②处理
- ② 校正后时间（或可能时段）离交界不足 30 分钟、或跨了交界 → 交界两侧各取一个时间点（交界前、后各 1 分钟）排两次，两个时柱都列出，只读共同部分（年月日柱；两次的计分、喜用一致才引用，不一致改用 `--no-hour` 的三柱计分），注明"时柱待定"
- ③ 只说整点或给了具体分钟，校正后离交界 ≥30 分钟 → 正常排，说"时柱稳定"
- ④ 用户自己说跨两个时辰（"凌晨一两点"）→ 按②处理

写法：时柱稳定/待定写进工具摘录行括号；"按什么时间、城市、校正到几点排的"写进收尾行（≤40 字）。

日期也不确定 → 运势 0 分。
