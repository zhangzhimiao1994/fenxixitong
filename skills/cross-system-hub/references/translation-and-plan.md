## 四、⚖️ 事实风险清单（STEP 0 用；只列事实，不替用户决定；每个版本 ≤6 行；不出现问号；回复里不写 ⚖️ 符号）

照抄口径：原则行、"自己填"行、最后一行照抄；其余行保留事实，措辞贴合原话但用白话、不加引号（"窗口就这几个月" → 用户说的明年窗口期；引号留给其他段，见 hub 4.4）。位置：最后一个象征段之后、总括之前；分两部分时整块在第一部分。这里已有的事实（包括"先弄清"和"3 个信号"）只在清单出现，主要矛盾段和其他段落不再列；第 1 个步骤可以是把"先弄清"里的一件落到谁、何时去问，这不算重复。

- 投资/借贷：
  - 原则："应急金（3-6 个月生活费）一般不动用；单一项目投入超过能承受的亏损额即属高风险。"用户说"全部积蓄"时开头直说"按这条原则已经属于高风险"
  - 自己填："这笔钱 = 我 __ 个月的生活费"，附 1 个算例（"积蓄 8 个月生活费，留 3-6 个月应急，能承受亏光的最多 2-5 个月的量"）。候选②的措辞：原话说了"全部积蓄" → "大概多少钱、相当于几个月的生活费"；否则 → "大概多少钱、占积蓄几成"
  - 先弄清 3 件事：靠什么赚钱、现在有没有收入、你的钱是股份还是借款（条款、退出条件）；投给熟人加 1 条"□ 这笔钱回不来时，你们还能像现在这样相处"
  - 3 个信号：催你尽快决定、承诺保本或高回报、说不清入股还是借款
  - 只提"只拿能承受亏光的部分、分阶段投入"，不说投或不投；借钱、投钱给熟人时，可直接发给对方的那句话放进第 1 个步骤（"我想先看一下书面协议和最近几个月的流水，把我的份额和退出方式写清楚"）
- 替伴侣还债 / 取公积金：
  - 原则：替别人还债 = 把对方的债变成你的风险；应急金（3-6 个月生活费）一般不动用
  - 自己填：这笔钱 = 我 __ 个月的生活费；□ 自查：有没有书面借条和还款时间。候选②的措辞："他要你拿出的大概多少钱、相当于你几个月的生活费"
  - 先弄清：债务总额与笔数、每笔的利率和到期日、有没有书面借条或还款约定
  - 公积金只能按规定用途提取（购房、租房、还房贷等），替他人还网贷一般不在其中，以当地公积金中心（12329）的答复为准
  - 3 个信号：反复催你尽快拿钱（这句定性全仓只在这里）；只给"以后一起还"的口头承诺；不肯给账单或说不清欠款。"要你动公积金"由上面的公积金行处理，不再算作另一个信号
- 辞职/创业/转行：
  - 原则：应急金（3-6 个月生活费）不动；辞职前先有一条验证过的收入来源
  - 自己填：不拿工资我能撑 __ 个月；启动资金 = 我 __ 个月的生活费。候选②的措辞："不拿工资能撑几个月"
  - 先弄清 3 件事：靠什么赚钱、现在有没有人付过钱、做不成时退路是什么
  - 可逆的试法：先业余做 3 个月，或请假、停薪留职试水
  - 3 个信号：收入来源还只停在计划里；要动应急金或借钱；有人催"窗口就这几个月"
- 换工作（没有创业打算，只是换一份工）：
  - 原则：应急金（3-6 个月生活费）不动
  - 自己填：没有新工作时我能撑 __ 个月。候选②的措辞："没有新工作时大概能撑几个月"
  - 先弄清 3 件事：想换去做什么、有没有书面 offer、换不成时的退路
  - 可逆的试法：在职面试，拿到书面 offer 再提离职
  - 3 个信号：没拿到 offer 就想先辞；只因一时的情绪想走；有人催你马上决定
- 每个版本的最后一行都是："重大财务决定，请咨询持证财务顾问或律师。"

## 五、出生时辰处理（全仓唯一一份；`fortune`、`bazi-liunian` 和 hub C11 都指向这里）

**第 0 步：先校正，再判时辰。** 给了出生城市且在第七节表里 → 带 `--lon 经度` 跑一次，读工具"真太阳时校正"行的分钟偏移，之后所有时辰判定都用"校正后时间 = 钟表时间 + 偏移"。没给城市、或城市不在表里 → 不加 `--lon`，按北京时间，收尾行写明按北京时间排、请用户告知出生城市。交界 = 单数整点（如 15:00 是申时起点）。

按序取第一条成立的：
- ① 只说"X 点多"：可能时段 = [X:00 + 偏移, X:59 + 偏移]，按这一条排时给工具传时段中点 X:30。整段落在同一时辰且两端离交界都 ≥30 分钟 → 按该时辰排，"时柱稳定"；只有起点贴着交界、整段在交界之后 → 只按交界后那个时辰排，"时柱稳定"；其余 → ②
- ② 校正后时间（或时段）离交界不足 30 分钟、或跨了交界 → 交界前后各约 1 分钟各排一次、共两次，不另排原时间（钟表时间 = 取样点 − 偏移；工具按秒取整后取样点正好落在交界上 → 那一次算交界之后的时辰，把另一侧的取样点再往外挪 1 分钟），两个时柱都列出，只读共同部分（年月日柱；两次的计分档位（偏强/偏弱/中和）和喜用都一致才引用，不一致改用 `--no-hour` 的三柱计分），注明"时柱待定"；档位、喜用一致但分数不同 → 最终采用校正后时段覆盖更长那一侧的那组，摘录行只写这组分数
- ③ 只说整点或给了具体分钟，校正后离交界 ≥30 分钟 → 正常排，"时柱稳定"
- ④ 用户说跨两个时辰（"凌晨一两点"）→ 按②
- ⑤ 不知道时辰 → 按 `fortune` 的"运行抽牌/排盘工具"块运行子命令 `bazi YYYY-MM-DD --no-hour --gender m|f`，只排三柱

写法：时柱稳定/待定写进工具摘录行括号；"按什么时间、城市、校正到几点排的"写进收尾行的核对半句。日期也不确定 → 这个象征维度不激活。
