## 改进方案（第二轮优化方向）

### P1: dim8 实测表现提升
**问题**: 100% dry_run，无法验证真实输出质量
**方案**: 
1. 增加"模拟执行自检清单"（已在上文模拟执行检查中验证）
2. 在SKILL.md中增加"执行者自检表"，让使用者可以自我验证
3. 标注: "本skill建议搭配子agent实测验证， dry_run比例应<30%"

### P2: dim2 工作流清晰度提升
**问题**: STEP间流转不够显性
**方案**:
1. 在A章节开头增加流程图：
   ```
   STEP 1 → [激活<2体系?] → 是 → 路由到单一skill / 否 → STEP 2
   STEP 2 → [危机信号?] → 是 → C5 / 否 → STEP 3
   ...
   ```
2. 每个STEP增加"前置条件"和"不满足时的跳转"

### P3: dim4 检查点增加
**问题**: 仅3个CHECKPOINT
**方案**:
1. STEP 3后增加CHECKPOINT: "确认分析深度符合权重规则（≥4完整/3精简/≤2一句）"
2. STEP 6前增加CHECKPOINT: "确认已标注所有🔥共振点"
3. STEP 7前增加CHECKPOINT: "确认第一个行动是MVF（最小可行）"

### P4: dim5 可执行具体性提升
**问题**: 部分步骤仍偏描述
**方案**:
1. STEP 1增加"权重计算伪代码"：
   ```
   weight = keyword_hits + semantic_strength(1-3) + optional_bonus
   if physical_symptoms: 内经 += 2
   if dreams: 荣格/弗洛伊德 += 2
   ```
2. 增加"输出质量自检表"（使用者执行后自检）
