## 🧭 决策树

```
用户描述"一追一逃"的关系
│
├── 有自伤信号？ → 🛑 psyche 第五节危机话术
├── 有打、推、威胁、控制钱和行踪？ → 🛑 B 段安全转介，不分析
├── 双方倾向都还没看清？ → ❌ 先走 attach-style-reading
├── 只是吃什么、看什么的日常分歧？ → ❌ attach-secure-communication（冲突原则）
│
└── ✅ 已确立关系 + 追逃模式
    ├── 想改善 → 步骤 2–5
    ├── 改过但没用、在想要不要留下 → 步骤 6（接受 or 离开）
    └── 已决定分开但总回头 → 步骤 6 的离开分支
```

## 📥 输入与证据假设

- 至少需要：交往或婚姻多久、一个最近反复吵的具体事件、双方在事件里各自做了什么。
- 只有用户这一方的叙述。对方是"回避"还是"在忙、在抑郁、另有隐情"，需要留余地（书中 Hillary 后来才知道对方在离婚后抑郁，PAGE 200–201）。
- 双方是否都愿意改变，会决定走"共同调整"还是"单方面接受/离开"。

## 📖 RIA+E+B

### R（原文位置 + 转述）

- 第8章 PAGE 142：焦虑的一方遇到威胁就去靠近（激活），回避的一方遇到威胁就拉开距离（去激活），一方的激活又加重另一方的去激活，两人都困在"危险区"。
- 第8章 PAGE 144–145 六个征兆：①过山车（偶尔很近，随即被推开）；②情绪跷跷板（一方的"强"靠另一方的"弱"撑着）；③稳定的不稳定（能处很久但一直不踏实）；④"我们真的在吵这个？"；⑤成为最亲近的人后反而被当敌人；⑥明知不对却离不开。
- 第8章 PAGE 145–146：为什么难调和：差异会随结婚、生子、搬家扩散；化解冲突本身会带来亲密，所以回避者在争吵中越吵越冷；每吵一次，焦虑的一方失去更多，常要求和才能回到原来那个也不满意的状态。
- 第9章 PAGE 148–159：风格稳定但可塑。方法：想起身边安全的人（安全启动），拼出一个"整合安全榜样"；做七栏关系清单；找一位懂自己模式的人当提醒者（ADP）。
- 第9章 PAGE 172–174：实在改不了时，有人选择降低期待、接受单方面妥协，作者的态度是"看情况"：长期关系里想留下，这是相对平静的活法；新关系里就已大量冲突，要认真想想值不值得。
- 第10章 PAGE 183–191：用"内圈"检验：你是被当王室，还是被当敌人。分开后会被好回忆淹没（反弹效应），作者给出九条分手策略。

### I（白话解释）

这不是谁坏、谁有病，而是两套相反的警报器绑在了一起：一个响了就往前冲，一个响了就往后撤。所以吵洗衣机、吵订哪间房，其实是在吵"我们要多近"。只要不承认这一点，吵赢了也解决不了问题。

### A1（书中案例的应用）

- 洗衣机之争：妻子坚决不买，因为她每周末去姐姐家洗衣服，顺便一个人待一天；丈夫要买，其实是想多和她在一起（PAGE 139–140）。
- Georgia 白天打电话 Henry 总不回，她越催他越烦。两人做完清单后想出办法：Henry 想她时就发一条预先写好的"在想你"短信。花他几秒钟，换来她一整天安心（PAGE 160–165）。
- Sam 让女友 Grace 搬进自己的小公寓后觉得被入侵，为挤牙膏大发脾气。Grace 先租下朋友空出的小公寓作缓冲，Sam 立刻轻松了；半年后她几乎没去住过，两人适应了同居（PAGE 165–169）。
- Marsha 在 Craig 身边多年被贬低、被当众取笑，却一次次被说服留下；最后她提前联系姐姐，当晚就离开，靠家人朋友撑过反弹期（PAGE 176–191）。

### A2（未来触发场景）

1. 同居一年，男友每周有三晚要"一个人待着"，用户每次都觉得被抛弃，吵完他更冷。
2. 已婚，妻子对朋友热情体贴，对丈夫总是不耐烦，丈夫开始怀疑是不是自己不配。
3. 分手三次又复合三次，用户想知道这次怎么才能真走掉。

### E（执行步骤）

1. **安全筛查**：暴力/控制 → B 段；自伤 → psyche 第五节。
2. **还原真实议题**：选一次最近的争吵，问"如果这件事解决了，你最想得到的是什么"。答案落在"更近/更多空间"上，就是亲密中心型冲突。
3. **对照六征兆**：逐条看命中几条，每条扣回用户原话。
   🔴 **CHECKPOINT**：命中 ≥3 条且有具体事件，才按陷阱处理；否则可能只是日常分歧或别的问题，转 attach-secure-communication 或 psyche。
4. **迷你关系清单**（让用户自己填，最好分开填，PAGE 151）：触发情境 → 我当时想什么、感觉什么、做了什么 → 这背后是抗议行为还是去激活 → 这样做让我付出了什么 → 我身边那个安全的人会怎么做。
5. **找结构性折中**：目标是让焦虑一方"确定对方在"，回避一方"确定有退路"。参考形式：固定的小确认（短信、睡前十分钟）；事先说好的独处时间；物理或时间上的缓冲区。需要双方都同意；回避一方要求空间时，用"这是我的需要，不是你的问题"来说（转 attach-secure-communication）。
6. **改了没用时的分岔**
   - 留下：说明这是**单方面的妥协**（PAGE 173）：停止催对方改变、不再把推开当成针对自己、自己去做想和对方一起做的事、找志同道合的朋友。新关系就已经这样 → 请用户认真权衡值不值得。
   - 离开：先做内圈测试（PAGE 183–184 的征兆）；离开前先跟亲友说实话、安排头几晚的落脚处；写下想离开的理由，被好回忆淹没时拿出来看；回头联系了也别骂自己，痛是真的，会过去（PAGE 189–191）。

#### 如果这一步失败

| 触发条件 | 一线修复 | 兜底 |
|---|---|---|
| 用户坚持"就是在吵洗衣机" | 问"如果他明天就同意，你会觉得你们更近了吗" | 先当日常分歧处理，留意是否反复 |
| 对方拒绝任何沟通 | 只改用户自己能控制的反应（停止抗议行为） | 进入步骤 6 |
| 折中方案执行两周就失效 | 回到清单，看哪个触发点没被覆盖 | 建议伴侣咨询 |
| 用户每次决定离开都回去 | 不批评，写离开理由清单 + 指定一位提醒者 | 建议个人咨询，处理反弹期 |
| 用户开始自责"是我太黏" | 说明需求本身正当（PAGE 97、171） | 转 attach-dating-signals 的"需求正当化"部分 |

### B（边界）

- **暴力不是风格冲突**。书里 Marsha 被当众羞辱、Nathan 被扇耳光，这些在本 skill 里一律先按安全问题处理：紧急拨 110；全国妇联维权热线 12338；联系信任的亲友或当地反家暴机构。不要建议用户在危险中"做有效沟通"。
- 涉及成瘾（酒、赌、药）→ 建议专业戒治和家属支持，不用依恋框架解释。
- 本 skill 不是伴侣治疗。吵架循环的当场叫停和情绪修复对话更适合 eft-demon-dialogues、eft-hold-me-tight-talk 或专业的情绪取向伴侣治疗（书中 PAGE 170 也提到 Sue Johnson 的 EFT）。
- 只听一方说：不要替用户断定对方"就是回避型"，对方可能在抑郁、过劳或另有隐情。
- "单方面妥协"是作者描述的现实选项，不是推荐每个人接受；说清代价。
- 书中"分手后很快遇到安全伴侣、从此幸福"的结局是挑选过的故事，不能当承诺。
- 回避的一方也可能是用户本人，同样适用，语气不指责。

## 💬 输出格式

按顺序：
1. 一句接住。
2. 把表面争吵翻译成"要多近"的问题，扣回原话。
3. 命中的征兆（最多 3 条），各一句。
4. 一个下次能用的结构性折中或清单问题。
5. 一句边界（只听一方 / 暴力先求助 / 不是治疗）。
6. 一个问题（全文只问这一个）。

**示例**（"我们总为他周末去打球吵，他说我控制欲强，我越说他越不回家"）
```
越想多见他，他反而离得越远，这种滋味很磨人。
你们吵的表面是打球，底下更像是"周末我们能有多少时间在一起"：你一担心就去争取，他一被追就往外走，两个人越吵越远。
你说的"越说越不回家"，就是一追一逃在互相加码；他说你"控制欲强"，也是把你的需要说成了毛病。
可以试一个小约定：他照常打球，但出门前说好几点回来、中途发一条消息，你们再固定一个只属于两个人的时段。
我只听到你这一边，他那边是不是还有别的压力，需要你们一起谈。
如果他答应这个约定，你最想先确定的是哪一件：他会回来，还是他想回来？
```

## 反例黑名单

| # | 反模式 | 替代做法 |
