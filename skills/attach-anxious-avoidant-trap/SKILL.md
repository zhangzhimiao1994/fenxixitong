## 🧭 决策树

```
用户描述"一追一逃"的关系
│
├── 自伤信号 / 打、推、掐、威胁、控制钱和行踪 → 🛑 步骤 1（STOP）
├── 双方倾向都没看清 → attach-style-reading
├── 只是吃什么、看什么的日常分歧 → attach-secure-communication 步骤 3–4（找出需要、写一句话）
├── 想认出吵架循环 → eft-demon-dialogues；吵的当下降温 → eft-raw-spot-deescalation；想说出深层害怕 → eft-hold-me-tight-talk
│
└── ✅ 已确立关系 + 追逃模式
    ├── 想改善 → 步骤 2 → 3 → 4 → 5
    ├── 改过但没用、在想去留 → 步骤 2 → 3 → 6
    └── 已决定分开但总回头 → 步骤 6 离开分支
```

## 📥 输入与证据假设

- 至少需要：交往或婚姻多久、一个最近反复吵的具体事件、双方在事件里各做了什么。
- 只有用户一方的叙述。对方是"回避"还是在忙、在抑郁、另有隐情，要留余地（书中 Hillary 后来才知道对方在离婚后抑郁，PAGE 200–201）。

## 📖 RIA+E+B

### R（原文位置 + 转述）

- 第8章 PAGE 142：焦虑的一方遇到威胁就靠近（激活），回避的一方遇到威胁就拉开（去激活），一方的激活加重另一方的去激活，两人困在"危险区"。
- 第8章 PAGE 144–145 六征兆：①过山车（偶尔很近，随即被推开）；②情绪跷跷板（一方的"强"靠另一方的"弱"撑着）；③稳定的不稳定；④"我们真的在吵这个？"；⑤成为最亲近的人后反而被当敌人；⑥明知不对却离不开。
- 第8章 PAGE 145–147：差异会随结婚、生子、搬家扩散；化解冲突本身带来亲密，所以回避者越吵越冷；焦虑的一方每吵一次失去更多。
- 第9章 PAGE 148–159：风格稳定但可塑。方法：想起身边安全的人（安全启动），拼出"整合安全榜样"；做七栏关系清单；找一位 ADP（书中指懂你依恋模式、能在你冲动时提醒你的朋友）。
- 第9章 PAGE 170–174：实在改不了时，有人降低期待、接受单方面妥协。作者不给统一答案：长期关系里想留下，这是相对平静的活法；新关系里就已大量冲突，要认真掂量值不值得。
- 第10章 PAGE 183–191：用"内圈"检验你是被当王室还是被当敌人；分开后会被好回忆淹没（反弹效应），作者给出九条分手策略。

### I（白话解释）

这不是谁坏、谁有病，而是两套相反的警报器绑在一起：一个响了就往前冲，一个响了就往后撤。吵洗衣机、吵订哪间房，其实是在吵"我们要多近"。

### A1（书中案例的应用）

- 洗衣机之争：妻子不买，因为周末去姐姐家洗衣服能一个人待一天；丈夫要买，其实是想多和她在一起（PAGE 139–140）。
- Georgia 白天打电话 Henry 总不回，做完清单后约定：Henry 想她时发一条预先写好的"在想你"短信，几秒钟换她一整天安心（PAGE 160–165）。
- Sam 让女友 Grace 搬进小公寓后觉得被入侵；Grace 先租下朋友空出的公寓作缓冲，Sam 立刻轻松，半年后两人适应了同居（PAGE 165–169）。
- Marsha 多年被 Craig 贬低，最后提前联系姐姐、当晚离开，靠家人朋友撑过反弹期（PAGE 176–191）。

### E（执行步骤）

**1. 🛑 STOP 安全筛查**
- 输入：用户原话。输出：安全 / 不安全的结论。
- 有打、推、掐、威胁、控制钱和行踪（Marsha 被当众羞辱、Nathan 被扇耳光也算）→ 停止关系分析，不让用户在危险中"做有效沟通"；给渠道：紧急拨 110，全国妇联维权热线 12338，信任的亲友或当地反家暴机构；问"你现在安全吗？"，等用户回答再继续。
- 有自伤或"不想活"信号 → 停止，执行 cross-system-hub C5。
- 涉及酒、赌、药成瘾 → 去专业戒治机构，家属去家属支持小组；不用依恋框架解释。

| 触发条件 | 一线修复 | 仍失败兜底 |
|---|---|---|
| 用户说"他就推了一下，不算暴力" | 说明推、掐、摔东西都是安全问题 | 只给求助渠道，不进入步骤 2 |
| 用户坚持"你就告诉我怎么沟通让他别动手" | 说明当面沟通可能招来报复，先联系 12338 或反家暴机构 | 不给摊牌脚本 |

**2. 还原真实议题**
- 输入：一次最近的具体争吵。输出：一句"表面在吵 X，底下在争多近/多少空间"。
- 问法："如果这件事明天就按你的意思解决，你最想得到的是什么？"答案落在"更近/更多空间"上，就是亲密中心型冲突。

| 触发条件 | 一线修复 | 仍失败兜底 |
|---|---|---|
| 用户没给具体事件，只说"我们总吵" | 先按已知征兆给"记一行"的动作，结尾问题问最近一次吵的事 | 本轮不给折中 |
| 用户坚持"就是在吵洗衣机" | 问"如果他明天就同意，你会觉得你们更近了吗" | 先按日常分歧转 attach-secure-communication 步骤 3–4，请用户留意同类事是否反复 |

**3. 对照六征兆**
- 输入：步骤 2 的结论 + 用户原话。输出：命中的征兆清单（每条扣回原话）+ 分级结果。

🔴 **CHECKPOINT（定性前核对）**：每条命中都要能指出用户的哪句原话，指不出的不算。再分级：

| 情况 | 处理 |
|---|---|
| 已还原为"要多近" + 命中 ≥3 条 | 走步骤 4–6，输出里写"这像一个反复的追逃模式" |
| 已还原为"要多近" + 命中 1–2 条 | **降级**：照样走步骤 4–5 给折中，只描述"一个追、一个退" |
| 没落在"要多近"上（纯家务、钱、日程），且 0 条命中 | 转 attach-secure-communication 步骤 3–4 |

| 触发条件 | 一线修复 | 仍失败兜底 |
|---|---|---|
| 用户不认同"这是在争多近" | 不争论，改说"先不管叫什么，我们看看能不能让你们俩都好受一点" | 照降级处理给折中 |
| 用户要求"你直接判定他是回避型，我拿给他看" | 说明只听一方无法判定，贴标签会让对方更想退 | 转 attach-style-reading 看行为证据，本 skill 只给折中 |

**4. 迷你关系清单**
- 输入：一次触发事件。输出：用户自己填的一行清单 + 它指向的折中形式。
- 五栏（书中七栏表原图缺失，本 skill 用简版，PAGE 151）：触发情境 → 我当时想什么、感觉什么、做了什么 → 这是抗议还是退开 → 这样做让我付出了什么 → 我身边那个最让人安心的人会怎么做。用户先自己填；对方愿意时再各填一份对照。
- 映射到步骤 5：触发点是"联系不上、不回消息" → 固定小确认；"他要独处、出门" → 事先约好的独处；"同住、空间被挤占" → 缓冲区。

| 触发条件 | 一线修复 | 仍失败兜底 |
|---|---|---|
| 用户只填"他冷我就难受" | 只问一栏："上次他冷下来，你接下来一小时做了什么？" | 跳过清单，直接进步骤 5 |

**5. 找结构性折中**
- 输入：步骤 2 的"多近"议题 + 清单指向的形式。输出：1 个写清两半的折中 + 一句约定原话。
- 一个折中必须同时写清：焦虑一方"确定对方在"的部分 + 回避一方"确定有退路"的部分，缺一半不算。从下表选 1 种，贴用户的事件改写：

| 形式 | 给"要近"一方的确定 | 给"要空间"一方的退路 | 约定原话 |
|---|---|---|---|
| 固定小确认 | 每天一个固定时点的联系 | 其余时间不追问、不查岗 | "每天下班前发一句'在路上了'，其他时间我不催你。" |
| 事先约好的独处 | 知道对方几点回来、会回来 | 独处时间不用解释、不被打断 | "周三晚上归你，十点前回来就行，我不打电话。" |
| 缓冲区 | 有一个固定的"在一起"时段 | 物理或时间上有自己的地方 | "书房留给你一个人用，晚饭后那一小时我们一起过。" |

🔴 **CHECKPOINT（给折中前核对）**：①两半都写了吗？②步骤 1 有没有漏掉的暴力信号？③折中需要对方同意 → 写成"拿去和他商量的提议"，不写成已定的安排。向对方提出时用"这是我的需要，不是你的问题"的说法（attach-secure-communication 步骤 4）。

| 触发条件 | 一线修复 | 仍失败兜底 |
|---|---|---|
| 对方拒绝任何沟通 | 只改用户自己能控制的反应（停止追问、查岗等抗议行为） | 进入步骤 6 |
| 折中执行两周就失效 | 回到清单，找没被覆盖的触发点，换表中另一种形式 | 换形式后再失效 → 两人一起去找做情绪取向伴侣治疗（EFT）的咨询师 |

**6. 改了没用时的分岔**
- 输入：至少一次折中尝试的结果，或用户"已决定分开"的表态。输出：留下或离开分支的具体做法。

🔴 **CHECKPOINT（去留前问用户，每轮只问一个）**：用户已明确决定离开（如"这次真的想走干净"）→ 直接走离开分支，不劝留，不问。否则先只问"你们一起试过至少一次具体的约定吗？"，等用户回答再继续：没试过 → 回步骤 5，本轮不谈离开；试过 → 下一轮再问"他是明确拒绝，还是答应了做不到？"。

- 留下：说清这是**单方面的妥协**（PAGE 173）：停止催对方改变、不再把推开当成针对自己、自己去做想和对方一起做的事、找志同道合的朋友。新关系就已经这样 → 请用户写下"留下我得到什么、付出什么"各三条再决定。
- 离开：先问自己"他对外人、同事的礼貌和耐心，有没有同样给我？"——对我比对陌生人还差，就是被当成了敌人（内圈测试，PAGE 183–184）；离开前先跟亲友说实话、安排头几晚的落脚处；写下想离开的理由，被好回忆淹没时拿出来看；指定一位能在想回头时拦一下的朋友，想联系对方前先给他打电话；回头联系了也别骂自己，痛是真的，会过去（PAGE 189–191）。

| 触发条件 | 一线修复 | 仍失败兜底 |
|---|---|---|
| 选择留下后越来越委屈 | 对照那张"得到/付出"清单，看付出是否已超过得到 | 超过 → 回到本步骤重新选；影响睡眠、工作 → 去心理咨询机构 |
| 用户每次决定离开都回去 | 不批评，写离开理由清单 + 指定那位朋友 | 反弹期超过一个月或影响睡眠、工作 → 去医院心理门诊或心理咨询机构做个人咨询 |
| 用户开始自责"是我太黏" | 说明需要本身正当（PAGE 97、171） | 转 attach-dating-signals 步骤 2 的"心动 vs 警报"对照 |
| 书中工具（九条策略原文、七栏表）手头没有 | 直接用本步骤列出的做法，不让用户去找原书 | 只保留"理由清单 + 拦一下的朋友"两条 |

### B（边界）

1. 暴力、自伤、成瘾：见步骤 1。
2. 本 skill 不是伴侣治疗。当场叫停吵架和情绪修复对话 → eft-demon-dialogues、eft-raw-spot-deescalation、eft-hold-me-tight-talk，或专业的情绪取向伴侣治疗（书中 PAGE 170 提到 Sue Johnson 的 EFT）。
3. 只听一方说：不替用户断定对方"就是回避型"，对方可能在抑郁、过劳或另有隐情。
4. "单方面妥协"是作者描述的现实选项，不是推荐每个人接受；说清代价。
5. 书中"分手后很快遇到安全伴侣"的结局是挑选过的故事，不当承诺。
6. 回避的一方也可能是用户本人，同样适用，语气不指责。

## 💬 输出格式

按顺序，全文 ≤350 字。回复里不出现这些词：焦虑型、回避型、去激活、ADP、关系清单、内圈测试、skill 名；命中 <3 条时也不出现"陷阱"。ADP 一律说成"一位懂你、能在你想回头时拦一下的朋友"。
1. 一句接住（≤30 字）。
2. 把表面争吵翻译成"要多近"的问题，扣回原话（≤80 字）。
3. 命中的征兆（最多 3 条），各一句；命中 1–2 条时只描述"一个追、一个退"。
4. **只给 1 个动作**，按场景三选一（≤100 字）：
   - 有具体争吵事件 → 1 个结构性折中（写清两半 + 一句约定原话）；
   - 没有具体事件 → 1 个记一行的问题（下次他冷下来时记什么）；
   - 命中 ≥3 条且用户说"一直这样/好不了/分不掉" → 上面任一动作 + 一句分岔提示："先拿这个小约定试两周；试过仍没变，我们再谈留下要付出什么、离开要准备什么。"
5. 一句边界（只听一方 / 暴力先求助 / 不是治疗）；用户说已经试过办法没用时，加一句"两个人一起去找做情绪取向伴侣治疗（EFT）的咨询师"。
6. 一个问题（全文只问这一个，问号只出现一次）。先按已知信息给完 1–5 条，缺的那一项用这个问题补；CHECKPOINT 需要用户回答时就用那个问题。"平时有没有固定在一起的时间"这类现实信息也放进这个问题里。

**示例**（只示范方法，不是答案模板，遇到新情境按用户原话重写。"我们总为他周末去打球吵，他说我控制欲强，我越说他越不回家"）
```
越想多见他，他反而离得越远，这种滋味很磨人。
你们吵的表面是打球，底下更像是"周末我们能有多少时间在一起"：你一担心就去争取，他一被追就往外走。
你说的"越说越不回家"，就是一追一退在互相加码；他说你"控制欲强"，是把你的需要说成了毛病。
拿一个小约定去和他商量：他照常打球，出门前说好几点回来、中途发一条消息；你们再固定周日晚上只属于两个人。
我只听到你这一边，他那边是不是还有别的压力，需要你们一起谈。
如果他答应这个约定，你最想先确定的是哪一件：他会回来，还是他想回来？
```

## 反例黑名单

| # | 反模式 | 为什么 | 替代做法 |
|---|---|---|---|
| 1 | 对暴力关系说"多沟通、多理解" | 当面摊牌会招来报复，风险是人身安全 | 见步骤 1 |
| 2 | 替用户判定"他就是回避型"，并让她转述给对方 | 只听一方，标签会被对方当成指控，更想退开 | 只描述行为，看类型去 attach-style-reading |
| 3 | 只解决表面议题（买不买洗衣机） | 底下"要多近"没处理，换个话题照样吵 | 先还原成"要多近"（步骤 2） |
| 4 | 鼓励更强的抗议行为或用"分手"威胁"让他重视" | 追得越紧，对方退得越远，循环加码 | 用步骤 5 的两半折中 |
| 5 | 断言"焦虑配回避注定分手" | 第9章给了改善路径，断言会让用户放弃尝试 | 说清改善的可能和代价 |
| 6 | 把单方面妥协包装成"成熟的爱" | 隐藏代价，用户会长期委屈自己 | 写明这是单方面的，列出代价 |
| 7 | 指责用户"离不开是你软弱" | 反弹是正常的依恋反应，羞辱会让人更想回头 | 说明反弹效应（PAGE 186–188），给理由清单 + 拦一下的朋友 |
| 8 | 回复里并列多条办法、问两个问题，或写出"ADP""去激活" | 用户不知道先做哪个，术语让人像被分析 | 按输出格式第 4、6 条各只给 1 个，用白话 |
