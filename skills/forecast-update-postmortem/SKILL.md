## 🧭 决策树

```
用户手里有一条已登记（或能补登记）的预测
│
├── 没有当初的数字、只有记忆？ → ⚠️ 先补一条"现在的数"重新登记；旧的不复盘（记忆会被结果改写）
│
├── 问题未到期，来了新信息 → 【更新模式】第 1-4 步
│   ├── 新信息是人人都看到的大事件 → 直接大幅调整
│   ├── 新信息细微、可能是噪音 → 小步调整
│   └── 当初数字所依赖的关键证据失效 → 重置到原基率再走
│
├── 问题已到期 → 【复盘模式】第 5-7 步
│
└── 多人要合成一个数 → 【小组模式】第 8 步
```

## 📥 输入与证据假设

- 必需：预测日志一行（命题、当初概率、日期、事先写的更新信号）；新信息原文或到期结果。
- 假设：新信念 = 旧信念 × 新证据的诊断力。诊断力 = "若命题为真，看到这条证据的可能" 比 "若命题为假，看到这条证据的可能"。两者差不多的证据，再吓人也只值小幅调整。
- 对已到期的单条预测，结果只能说明"这次"，不能单独证明判断好坏。

## 📖 RIA+E+B

### R（原文位置，转述）
- 第 7 章（PDF 170-171 / p.156-157）：瑞士团队宣布推迟发布结果，弗拉克推断可能是在排除铅衰变来源，只谨慎地从 60% 调到 65%——细微而有诊断力的信号，先于众人朝正确方向移动。
- 第 7 章（PDF 171-173 / p.157-159）：反应不足——安倍身边人透露会参拜靖国神社，弗拉克没改；事后他发现自己回答的是"如果我是首相会不会去"。
- 第 7 章（PDF 172 / p.158）：反应过度——洛奇看到一份已过时一个月的海冰报告，从 55% 一把拉到 95%，结果失分。
- 第 7 章（PDF 174-177 / p.160-163）：信念越接近自我认同（像叠叠乐底层的积木），越难改；公开承诺会冻结信念。业余预测者自我投入少，反而容易认错。
- 第 7 章（PDF 177-178 / p.163-164）：稀释效应——无关细节也会让人改判，这同样是偏差，是被噪音吹动。
- 第 7 章（PDF 181-183 / p.167-169）：明托在叙利亚难民题上改了 34 次，平均每次只动 3.5 个百分点，最终 Brier 0.07；参议院选举例：一条新民调值多少，先定上限 10 个点，再逐步收窄到 4 个点，60%→64%。
- 第 7 章（PDF 184-186 / p.170-172）：乌尔费尔德用基率 96%（24 位国防部长提名仅 1 人被否）加贝叶斯，算出听证表现差后仍有约 83%；洛奇发现报告预测与实测越差越远后，先退回 55%、再降到 15%，才恢复小步更新——规则可破。
- 第 8 章（PDF 194-199 / p.180-185）：经验不等于进步，需要清晰及时的反馈；气象员和桥牌手校准好，警察测谎越老越过度自信。后见之明：专家回忆当年对苏联解体的估计，平均比实际高 31 个百分点。在一类问题上练出的校准很难迁移到另一类。
- 第 8 章（PDF 199-201 / p.185-187）：杜菲复盘自己团队"钋半衰期太短不可测"的错误假设；对答对的几内亚选举题也承认"我们运气好"；专家欢迎"我差点说对"的反事实，排斥"我差点说错"。
- 第 4 章（PDF 110-118 / p.96-104）：大量预测者里总有人靠运气连中；用回归均值区分运气与技能——超级预测者逐年相关约 0.65，每年约 30% 跌出前 2%。
- 第 9 章（PDF 212-222 / p.198-208）：团队讨论会破坏判断独立性；团队平均比个人准 23%；精确提问、建设性对抗、事前验尸（假设方案已失败，解释为什么）；团队的开放性是沟通方式涌现出来的。
- 附录 (4)(7)(8)：在反应不足与过度之间找平衡；兼顾校准与区分度；不为失败找借口，也别从失败里学过头，成功也要复盘。

### I（白话）
改数像刷牙：天天做、每次小、长期见效。但有两种情况要大动：证据明显只会出现在一种世界里（诊断力强），或者当初撑起这个数的那条证据塌了。复盘时只认日志，不认记忆；分数和"只用基率""一直说五五开"比；说中的也要问"是判断对，还是运气好、两个错误抵消了"。

### A1（书中应用，转述）
- 弗拉克 60%→65% 的谨慎上调，与预测市场收盘时的 4.27% 相比，最终 Brier 分好了约五倍（PDF 171 / p.157）。
- 明托的同一个人：叙利亚难民题 0.07，靖国神社题 1.46，他清楚知道哪次是"空心入网"、哪次"扔进了垃圾桶"（PDF 199 / p.185）。

### A2（未来触发场景）
1. 用户预测"三个月内拿到 offer 40%"，今天收到一家终面邀请 → 问"拿到 offer 的人里有多少走过终面 vs 没拿到的人里有多少"，据此只调几个到十几个点。
2. 星盘说"窗口期"，到期没发生 → 复盘时分开记：用户自己的概率分、"系统倾向"栏的分、只用基率的分，看哪一栏更好。
3. 三个合伙人对"新店第三个月营收破十万"意见不一 → 各自先写下数字和一句理由，再讨论，最后取平均并记录分歧。

### E（执行步骤）
**更新模式**
1. **读信息定诊断力**：写出"若为真，看到它的可能 ≈ __；若为假 ≈ __"。两者接近 → 噪音或小信号；悬殊 → 强信号。检查是否只是同一来源的重复、是否已过时。
2. **定幅度**：先给"最多改几个点"的上限，再用其他相关事实收窄；弱信号一般不超过 5-10 个点（经验值）。强信号、人人可见的大事件 → 直接大调。
   🔴 CHECKPOINT 1：这条信息是否命中了当初登记的"更新信号"？命中却不改 → 反应不足；没命中却大改 → 反应过度。
3. **两种偏差自检**：反应不足——这个判断是否牵连我的身份、立场或公开说过的话？我是不是在回答替代题？反应过度——这是不是无关细节，或一份过时的报告？
4. **锚证据失效则重置**：当初数字主要靠某条证据，而它已被推翻 → 先退回基率，再重新走 forecast-fermi-baserate 的调整，之后恢复小步。

**复盘模式**
5. **按日志记分**：二元事件 Brier = 2×(概率−结果)²（发生=1，未发生=0）。对照：只用基率的分、0.5（一直说五五开）、象征倾向栏的分。一条只看方向，几十条以后看校准表（说 70% 的那些，实际发生了多少）。
6. **找错误在哪一层**：命题定义（替代题？）→ 基率（参照类选错？）→ 内部假设（哪条假设错？）→ 更新（不足/过度？）→ 纯运气（结果由事先无人能知的偶发事件决定？）。写下"下次具体改什么"一条。
   🔴 CHECKPOINT 2：成功的题也做一遍——有没有"差点就错"的反事实？有就别把这次当成判断正确的证据。
7. **防后见之明与学过头**：不重写当初的理由；只有当错误出在基本假设上才改方法，技术性小失误别推翻整套思路。

**小组模式**
8. 每人先独立写数和一句理由（不先听领导或最自信的人）；再用精确提问（"你说的'很快'是几周？证据是什么？"）讨论；做一次事前验尸（"假设一年后这件事没成，最可能的原因是？"）；最后取平均作为小组数，分歧大本身记进日志。
   🔴 CHECKPOINT 3：大家一致同意时，问一句"有没有人还没说出疑虑"——一致本身不是正确的证据。

#### 如果这一步失败
| 触发条件 | 一线修复 | 兜底 |
|---|---|---|
| 用户说不出诊断力（"我也不知道这消息算多大"） | 问两个频率："成了的人里多常见到这种事？没成的人里呢？" | 只调 2-3 个点，标"弱信号"，等下一条 |
| 用户情绪上不肯改（"我就知道他会回来"） | 指出这条判断离"自我认同"很近，问"什么证据会让你改口" | 不强改，登记"拒绝更新"，到期一并复盘 |
| 没有原始日志，只有记忆 | 说明记忆会被结果拉偏，本次不记分 | 现在补登记，从下一条开始记 |
| 复盘变成自责（"我太蠢了"） | 区分"判断过程"与"结果"，指出一条能改的具体步骤 | 持续自我否定、影响睡眠工作 → 建议找心理咨询师 |
| 小组被一个人主导 | 改为匿名写数后再公开 | 只取独立数字的平均，不取讨论后的数 |

### B（边界）
- 书中更新与复盘的证据来自数月到一年半的问题、且能频繁获得新闻的情境；对很少有新信息、或几年才见分晓的个人大事，小步更新的价值有限，复盘周期要拉长。
- 一条预测的输赢不能证明能力；超级预测者也会掉出排名（每年约三成）。别用一次说中给自己或任何系统封神。
- "小步更新"不是铁律：强证据要大调，锚证据失效要重置。
- 不复盘他人的隐私细节；涉及亲密暴力、成瘾的预测（"他会不会再动手"）→ 不估概率，转介专业帮助与安全资源。自伤自杀信号 → psyche 第五节危机话术。
- 复盘目标是改进判断，不是追责；团队里若复盘被用来甩锅，结论会变成"下次说含糊点"，这正是书中批评的"责任乒乓"（PDF 272-273 / p.258-259）。

## 💬 输出格式

回复按顺序：
1. 一句话：这条新信息（或结果）对原命题意味着什么。
2. 诊断力判断：强/弱/噪音，一句理由。
3. 新数字（更新模式）或分数与对照（复盘模式），一行给出变化：60%→64%。
4. 一条具体教训或下一条要盯的信号。
5. 更新后的日志行。
6. 只问 1 个问题。

**示例**（"我上个月估'年底前搬进新房'70%，今天开发商说交房推迟两周，要改吗？"）
```
推迟两周本身不改变"年底前能不能搬"，除非原定交房日离年底已不到一个月。
这条信号偏弱：准时交付和最终延期很久的楼盘，都常出现"小推迟两周"的通知。
建议小调：70%→63%。真正该盯的是验收和办证节点有没有一起推迟。
日志：2026-10-03｜年底前入住｜63%（原70%）｜理由：交房推迟2周，弱信号｜下次看：验收日期
原定的交房日是哪天？
```

## 反例黑名单

| # | 反模式 | 替代做法 |

| 2 | 新证据与身份相关就视而不见 | 问"什么证据会让我改口" |
