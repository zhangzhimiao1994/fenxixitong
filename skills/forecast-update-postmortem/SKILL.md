## 🧭 决策树

```
用户手里有一条已登记（或能补登记）的预测
│
├── 第 1 步 🛑 预测对象是亲密暴力 / 成瘾复发 / 自伤？ → 只走第 1 步
│
├── 问题未到期，来了新信息 → 【更新模式】第 2-5 步
│   ├── 强信号 → 第 3 步大调（≤30 点）
│   ├── 弱信号 / 噪音 → 第 3 步小调（≤10 点 / ≤2 点）
│   └── 当初所依赖的关键证据失效 → 第 5 步重置
│
├── 问题已到期 → 【复盘模式】第 6-7 步（有日志已贴 / 有日志未贴 / 根本没记）
│
└── 多人要合成一个数 → 【小组模式】第 8 步
```

## 📥 输入与证据假设

- 必需：预测日志一行（命题、当初概率、日期、事先写的更新信号）；新信息原文或到期结果。
- 假设：新信念 = 旧信念 × 新证据的诊断力。诊断力 = "若命题为真，看到这条证据的可能" 比 "若命题为假，看到这条证据的可能"。两者差不多的证据，再吓人也只值小幅调整。
- 对已到期的单条预测，结果只能说明"这次"，不能单独证明判断好坏。

### E（执行步骤）
总规则：只有第 1 步 🛑 能让本轮停下；其余检查点先按已知信息出完整回复（假设写明），缺的那一项作为全文唯一的问题。

1. **🛑 STOP 安全筛查**
   输入：命题原文。输出：放行，或只输出安全话术。
   命题是"他会不会再动手""会不会复吸/复饮""我会不会伤害自己" → 停止本流程，不估也不更新概率。先问"你现在安全吗？"，给"紧急打 110，咨询打 12338 妇女维权热线；成瘾问题去当地精神卫生中心；心理援助打 12356"；自伤信号按 cross-system-hub C5。等用户回答再继续：答"安全" → 只帮用户安排今天能做的安全措施；答"不安全"或不答 → 只重复 110 与上述热线。

| 触发条件 | 一线修复 | 仍失败兜底 |
|---|---|---|
| 用户坚持要概率"好决定要不要留下" | 说明数字会被当成安全保证，转到今天能做的安全安排 | 只给 110 / 12338 与 cross-system-hub C5，结束该部分 |
| 用户否认危险但描述里有动手、威胁 | 复述那句描述，再问一次安全 | 按有风险处理，不进第 2 步 |

**更新模式**

2. **读信息定诊断力**
   输入：新信息原文 + 日志行。输出：两侧频率、强/弱/噪音、是否过时或重复来源。
   写"若为真看到它 ≈ __；若为假 ≈ __"。两频率之比 ≥3（或 ≤1/3）→ 强；1.5-3 → 弱；<1.5 → 噪音。同一来源的多次转载只算 1 条。

| 触发条件 | 一线修复 | 仍失败兜底 |
|---|---|---|
| 用户说不出诊断力（"我也不知道这消息算多大"） | 问两个频率："成了的人里多常见到这种事？没成的人里呢？" | 按弱信号处理，只调 2-3 个点 |
| 新信息真伪不明（传言、单一匿名来源） | 先找第二个独立来源 | 按噪音处理，最多调 2 个点，标"待证实" |

3. **定幅度**
   输入：诊断力判断。输出：上限 → 收窄理由 → 新数字（60%→64%）。
   噪音上限 2 个点；弱信号上限 10 个点；强信号单次上限 30 个点，超过 30 必须写出"若为假几乎不会看到它"的理由。

| 触发条件 | 一线修复 | 仍失败兜底 |
|---|---|---|
| 同时来了方向相反的两条信息 | 分别写诊断力，按差值定净幅度 | 各登记一行，不改数，标"信号冲突" |

4. **两种偏差自检**
   输入：新旧数字 + 当初登记的更新信号。输出：一句"更可能是反应不足/过度，因为__"。
   🔴 CHECKPOINT 1：这条信息是否命中当初登记的"更新信号"？命中却不改 → 反应不足；没命中却大改 → 反应过度，回到第 3 步重定幅度。另查：判断是否牵连身份、立场或公开说过的话（反应不足）；是不是无关细节或过时报告（反应过度）。

| 触发条件 | 一线修复 | 仍失败兜底 |
|---|---|---|
| 用户情绪上不肯改（"我就知道他会回来"） | 指出这条判断离"自我认同"很近，问"什么证据会让你改口" | 不强改，登记"拒绝更新"，到期一并复盘 |
| 用户一次大跳且不认同回调（"文章说行业要崩"） | 用第 2 步查来源是否单一、过时 | 两个数都登记，到期比较哪个分更好 |

5. **锚证据失效则重置**
   输入：被推翻的证据。输出：≤2 行：被推翻的锚证据（来源/日期）+ 退回的基率数。
   🔴 CHECKPOINT 2：用户确认"这条就是当初撑起数字的主要依据"之前，本轮只给退回基率的数，不做后续调整；把这句确认作为唯一问题。确认后下一轮按 forecast-fermi-baserate 第 4-7 步重新调整，之后恢复小步。

| 触发条件 | 一线修复 | 仍失败兜底 |
|---|---|---|
| forecast-fermi-baserate 不可用或查不到基率 | 用上下界中点作基率，标"暂估" | 退到 35%-65% 区间，标"重置待补" |

**复盘模式**

6. **按日志记分**
   输入：日志。输出：每条 Brier、总平均、对照线、校准表。
   二元事件 Brier = 2×(概率−结果)²（发生=1，未发生=0）。对照：0.5（一直说五五开）、只用基率的分、原说法的分。校准表按 0-10%、10-20%……90-100% 分档；单档 <5 条只列不解读；总条数 <20 只报总分，不下"准不准"的结论。

| 触发条件 | 一线修复 | 仍失败兜底 |
|---|---|---|
| 用户说有日志但没贴 | 走"有日志未贴"模板 | 下一轮按"有日志已贴"记分 |
| 用户根本没记，只有记忆 | 走"根本没记"模板，本次不记分 | 从今天起按模板登记 |
| 日志缺"当时概率" | 只算字段完整的那几条，列出缺什么 | 只做第 7 步的定性复盘，不出分数 |

7. **区分运气与判断，找错误层级**
   输入：分数 + 每条当时的理由。输出：说中题的判定 + 最主要的错误层 + 下次改的一件事 + 要不要改方法 + 写回日志的一行。
   说中的题过三个检验：①当时写下的理由后来成立了吗？②结果是不是由事先无人能知的偶发事件决定？③有没有差一点就反过来？①是、②③否 → 算判断；否则算运气，不计入"判断对"。说错的题也查"差点就对"。
   错误层级：命题定义（替代题？）→ 基率（参照类选错？）→ 内部假设 → 更新（不足/过度？）→ 纯运气。只有错在基本假设上才改方法，技术性小失误不推翻整套思路；不重写当初的理由。
   🔴 CHECKPOINT 3：说中题里当时概率最高的 1 条，把"当时写下的理由后来成立了吗？"作为唯一问题；其余列成待核清单，下一轮逐条处理。

| 触发条件 | 一线修复 | 仍失败兜底 |
|---|---|---|
| 复盘变成自责（"我太蠢了"） | 区分"判断过程"与"结果"，指出一条能改的具体步骤 | 持续自我否定、影响睡眠工作 → 去 12356 心理援助热线，或找心理咨询师 |

**小组模式**

8. **独立 → 讨论 → 平均**
   输入：各人的数。输出：独立数列表、平均数、分歧幅度、事前验尸一条、日志行。
   每人先独立写数和一句理由（不先听领导或最自信的人）；再精确提问（"你说的'很快'是几周？证据是什么？"）；做一次事前验尸（"假设一年后这件事没成，最可能的原因是？"）；取平均作小组数，没理由的数权重减半，分歧大本身记进日志。
   🔴 CHECKPOINT 4：大家一致时，一致本身不是正确的证据；用户单人转述时，把"谁还没说出疑虑？"作为唯一问题。

| 触发条件 | 一线修复 | 仍失败兜底 |
|---|---|---|
| 小组被一个人主导 | 改为匿名写数后再公开 | 只取独立数字的平均，不取讨论后的数 |

### B（边界）
- 书中更新与复盘的证据来自数月到一年半的问题、且能频繁获得新闻的情境；对很少有新信息、或几年才见分晓的个人大事，小步更新的价值有限，复盘周期要拉长。
- 一条预测的输赢不能证明能力；超级预测者也会掉出排名（每年约三成）。别用一次说中给自己或任何系统封神。
- 不复盘他人的隐私细节。
- 复盘目标是改进判断，不是追责；团队里若复盘被用来甩锅，结论会变成"下次说含糊点"，这正是书中批评的"责任乒乓"（PDF 272-273 / p.258-259）。

## 💬 输出格式

第 1 步命中 🛑 → 只输出安全话术与热线。其余按决策树选一套模板，全文唯一的问题放最后。用户可见处不写"CHECKPOINT/占位/诊断力比值"等内部标签。

**保留常识**（三套通用，只在此处定义）：与结果直接相关的行动常识（如"其他投递别停""认真准备终面"）在倒数第二段用 1 句写出，≤30 字。

### 【更新模式】（第 2-5 步，≤300 字）
1. 这条新信息对原命题意味着什么，一句。
2. 【第 2 步】"若为真看到它 ≈ __，若为假 ≈ __" → 强/弱/噪音；是否过时、重复来源。
3. 【第 3 步】上限 → 收窄理由 → 60%→64%。
4. 【第 4 步】偏差自检一句。
5. 【第 5 步】仅锚证据被推翻时出现，≤2 行。
6. 下一条要盯的信号 + 更新后的日志行。

**示例**（"我上个月估'年底前搬进新房'70%，今天开发商说交房推迟两周，要改吗？"）
```
推迟两周本身不改变"年底前能不能搬"，除非原定交房日离年底已不到一个月。
分量：弱。最终能年底入住和不能的楼盘，都常发这种通知；是开发商当天的通知，不是旧闻。
幅度：上限 −10 点，原定交房日离年底还有两个月，收窄到 −7：70%→63%。
自检：小调而非大改，避免被"推迟"两个字吓到。
下次看：验收和办证节点有没有一起推迟。日志：2026-10-03｜年底前入住｜63%（原70%）｜理由：交房推迟2周，弱信号｜下次看：验收日期
原定的交房日是哪天？
```

### 【复盘模式】（第 6-7 步）三选一
**有日志已贴**（≤350 字）：
1. 这批结果能说明什么、不能说明什么（<20 条只报总分）。
2. 【第 6 步】至少一条算式 + 总平均 + 对照线。算式格式："说 70% 且发生 → 2×(0.7−1)² = 0.18；没发生 → 2×(0.7−0)² = 0.98"。
3. 【第 6 步】校准表（10% 一档：条数 / 实际发生率）。
4. 【第 7 步】说中题按三个检验判"判断/运气"，其余列待核清单。
5. 【第 7 步】最主要的错误层 + 下次改的一件事 + 要不要改方法 + 写回日志的一行。

**有日志未贴**（≤250 字）：先回答用户问的那一点（如"说中的是不是判断对了"），再要数据——
1. 一句：这么多条能看出什么（总分、按 10% 一档粗看校准）、还不能说明什么。
2. 第 7 步的三个检验，用白话写给用户自查；说错的题也看有没有"差点就对"。
3. 一条算式示范 + "一直说五五开是 0.5，总分比它低才算有本事"。
4. 格式模板"日期｜命题｜当时概率｜当时理由｜结果" + 唯一问题"能按这个格式贴给我吗？"。

**根本没记**（≤150 字）：一句"没有当时的数字没法记分，记忆会被结果改写" + 一条算式示范 + 上面的模板 + 唯一问题"第一条想记什么？"。

**示例**（"我年初说'6 月底前减重 5 公斤'80%，结果做到了，是我判断准吗？"）
```
一条说中只说明"这次"，不能单独证明判断准。
记分：说 80% 且发生 → 2×(0.8−1)² = 0.08；一直说五五开是 0.5，这条很好，但只有 1 条，不分档。
运气还是判断：你当时的理由是"每周跑 3 次 + 戒夜宵"。这两条做到了，算判断；主要靠一场病或别的意外瘦下来，算运气，不计入"判断对"。
错误层级：暂无；下次把"做到了哪些行为"也写进日志。不用改方法。
日志：2026-10-03｜6月底前减重5kg｜80%｜结果：发生｜Brier 0.08｜原因待确认
这 5 公斤里，跑步和戒夜宵大概各做到了几成？
```
