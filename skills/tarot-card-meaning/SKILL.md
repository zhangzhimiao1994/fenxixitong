# Tarot Card Meaning — 单牌释义（结构推导法）

## R — 来源（已对照原文，2026-10-02）
- 大阿卡纳顺序依 Waite：力量 VIII、正义 XI（Waite 对调且不说明理由，Part II §2）✅
- 正逆位释义：Part III §2（小阿卡纳）、§3（大阿卡纳）✅
- **四花色-元素对应、宫廷牌"成熟度"梯度均非 Waite 原书内容**：前者属金色黎明及后世通行体系，后者为现代读法（evidence: reliable-secondary）
- 本表"正位邀请你看""转化面"两列是本体系的心理转译；Waite 原释义多为事件性词语（见各牌条目）

### 2. 小阿卡纳：元素 × 数字 推导公式

**花色 = 生活领域**（元素对应为后世通行体系，非 Waite 原书）
| 花色 | 元素 | 领域 |
|------|-----|------|
| 权杖 | 火 | 行动、热情、事业冲劲 |
| 圣杯 | 水 | 情感、关系、直觉 |
| 宝剑 | 风 | 思维、冲突、决断、言语 |
| 星币 | 土 | 金钱、身体、工作、物质 |

**数字 = 阶段**
| 数字 | 阶段含义 |
|:---:|---------|
| 王牌 | 种子、新机会 |
| 2 | 二元、选择、平衡 |
| 3 | 初步成形、协作 |
| 4 | 稳定或停滞 |
| 5 | 冲突、失去、考验 |
| 6 | 恢复和谐、给予与接受 |
| 7 | 评估、坚持、考验信念 |
| 8 | 推进、精进或受困 |
| 9 | 接近完成、独自承担 |
| 10 | 完成、过载、周期终点 |

**宫廷牌 = 成熟度/角色**：侍从（学习、讯息）→ 骑士（行动、冲动）→ 王后（内化、滋养）→ 国王（掌控、外化）。宫廷牌逆位 = 该角色的不成熟或过度版本（如国王逆 = 控制欲、侍从逆 = 拖延或轻率）；宫廷牌可指用户自己，也可指生活中的某个人，问用户"像你，还是像你身边的谁？"

**推导示例**：
- 宝剑五 = 风（思维/言语冲突）× 5（失去/考验）→ "赢了争论、输了关系"
- 星币四 = 土（物质）× 4（稳定/停滞）→ "守得太紧"
- 圣杯骑士 = 水（情感）× 骑士（行动）→ "带着情感去追求，理想化、浪漫"

推导结果是现代读法。Waite 原书小牌释义多为事件性词语，可作对照（已核对原文）：宝剑五 "Degradation, destruction… loss"；星币四 "surety of possessions, cleaving to that which one has"；宝剑四 "Vigilance, retreat, solitude"；宝剑十 "pain, affliction, tears"。

### 3. 逆位的三种读法（内部选一种，回复只说意思）
1. **能量受阻**：正位能量没有流动出来（默认）
2. **能量内化**：该主题在内心而非外部发生
3. **阴影/过度**：正位品质走向极端

**选择规则**（按顺序判断，命中即停）：
① 牌在内在类位置 → 读法 2（内化）。内在类位置 = 三张的"过去/根源"、关系五张的"我的状态"、凯尔特十字的"其下·已成的根基""自我态度""希望与恐惧"、stakes 全部三个位置
② 用户叙述里，正位品质已经用得太多（如皇帝逆、用户本身在过度控制）→ 读法 3（过度）
③ 其余情况 → 读法 1（受阻，默认）
**写法规则**：回复里只用白话说出读法的意思（如"这股劲还没放出来"），不出现"按『X』读逆位"这类方法说法

## A1 — 应用案例
- **死神正位，问工作**："不是会出事，是某种工作方式/角色到期了。哪部分你其实早就不想继续？"
- **圣杯三逆位，问友谊**：水×3（情感协作）受阻 → "社交在消耗而非滋养你"
- **宝剑十正位**：风×10 → 思维冲突走到终点、"最糟已经发生"；转化面：黎明在背景里，不会更糟了

## E — 执行步骤
1. 识别牌：大/小阿卡纳、花色、数字/宫廷、正逆
   🛑 **CHECKPOINT**：牌名认不出 → 先追问，不猜；没说正逆 → 不停，正位为主、逆位补 1 句
2. 大阿卡纳 → 查原型表；小阿卡纳 → 元素 × 数字推导
3. 结合**牌阵位置**（如"阻碍"位置的太阳 = "过度乐观可能是阻碍"）；没说位置 → 按所问领域读，不猜位置
4. 结合**用户问题领域**落地成一句具体的话
5. 凶牌 → 必须输出"转化面"
6. **输出每张牌**（1-2 句自然的话，不用竖线模板，不照抄表格关键词）：牌名·正逆 → 原型 +（`tarot-projective-dialogue` 的 references/image-details.md 里有这张牌时）画面里 1 个具体细节，没有就不写画面、不凭记忆补 → 在此位置意味着什么（不列"岗位调整""离职"这类具体事件）；不逐张提问
7. **单张收尾**：用户带着害怕问（"是不是很糟"）→ 第一句先答"不是坏事的预告"，没表现出害怕就不写这句；再讲这张牌落在所问领域里的具体样子（写成心态或感受，如"对这份工作的热情已经到期"，不写事件）；没给领域 → 逆位从第 3 节三种读法里给两种：读法 1"受阻"（默认）+ 该牌最贴近的另一种（多数牌是读法 2"内化"；正位品质本身容易过头的牌用读法 3"过度"：皇帝、教皇、战车、恋人、权杖国王、宝剑国王、星币四、圣杯七；其余按读法 2），各落到一种常见心态；这张牌在表里有"转化面"时，再补一句转化面（如宝剑三：痛被说出来，才开始愈合），把"正在疗愈"这一面也给到；表里"逆位/阴影面"一列写成"正在挣脱"一类的牌（如恶魔），"受阻"那一读按这一列写；候选问题交给 `tarot` 契约（没说正逆时候选是"抽到的是正位还是逆位"）
8. **多张**：不停，直接进 `tarot-spread-synthesis`；候选问题见 `tarot` 契约

## B — 边界与 Fallback

| 触发条件 | 一线处理 | 仍失败 → 兜底 |
|---------|---------|-------------|
| 用户问托特、马赛等其他牌组 | 先查 `references/decks.md`（编号、改名、谁调换了），**不凭记忆讲牌史**；再三步：① 该牌组自己的名称与画面简述 ② 与 RWS 的编号/占星对照 ③ 一句对比（如"驯服 vs 拥抱"）+ 落回用户的问题。只讲问到的牌 | 用户要深读 → 说明"细节以该牌组的书为准" |
| 问"高塔是不是说明家里会出事" | 原样回答："牌不预告具体事件。" 再给转化面 | 追问不休 → 转 `tarot-projective-dialogue` 问"你最担心的是什么？" |
| 🔴 用户的直觉与书面释义冲突 | 停下，不坚持书面义；以用户直觉为准，转 `tarot-projective-dialogue` | — |
| 牌名无法识别 | 追问牌组名与图案 | 仍认不出 → 按用户描述的画面做投射式解读 |

- 释义是**起点**，用户的直觉联想优先
