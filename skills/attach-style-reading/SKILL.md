## 🧭 决策树

```
用户问"我/他是什么依恋类型"
│
├── 自伤/轻生信号，或被打、被威胁、被控制 → 🛑 步骤 1（STOP）
├── 要"诊断"（"我是不是人格障碍"）→ 步骤 1 诊断话术后继续
├── 刚认识几周，真正想问"值不值得继续" → attach-dating-signals
├── 已确认一追一逃，想改关系 → attach-anxious-avoidant-trap
│
└── ✅ 想了解自己或一个相处过一段时间的人
    ├── 看自己 → 步骤 2A → 3 → 4 → 5
    ├── 看对方 → 步骤 2B → 3 → 4 → 5
    └── 两个维度都高 / 说不清 → 步骤 4 情境过滤后再定
```

## 📥 输入与证据假设

- 用户讲的是**单方面叙述**。看对方时，只有用户转述的行为，没有对方的内心感受。
- 证据单位是**具体行为**和**情境**（争吵、分开时、谈未来时、难过时）。只有形容词（"他很冷漠"）不算证据。
- 先确认：交往多久；用户是不是正"上头"（兴奋时客观性会下降，PAGE 51）；近期有没有离婚、丧亲、重病、生孩子这类大事（会让人暂时变样，PAGE 109、136）。

## 📖 RIA+E+B

### R（原文位置 + 转述）

- 第3章 PAGE 46–48：风格由两个维度决定：对亲密有多不自在；对伴侣的爱和关注有多焦虑。两个都低偏安全；想亲近但很焦虑偏焦虑；不想太近也不太操心偏回避；两个都高是少数的混合型。
- 第3章 PAGE 39、第9章 PAGE 148：风格"stable but plastic"。第1章 PAGE 17：平均每四个人里有一个在四年左右发生变化。第7章 PAGE 129–130：童年照料与成年风格只有弱关联，基因和成年后的强烈恋爱经历也会改变它。
- 第4章 PAGE 64–67 判断对方的五条黄金法则：①他是否寻求亲密（最重要）；②他对关系有多操心、对拒绝有多敏感；③不靠单个"症状"，看整体模式；④看他对你直接表达需求的反应；⑤听他没说的、看他没做的。
- 第4章 PAGE 65 与第7章 PAGE 124–125：任何性格的人都可能是任何风格，外向、自信、笨拙都不能当线索。第5章 PAGE 103：别把回避等于男性、焦虑等于女性，多数男女都是安全型。

### I（白话解释）

依恋风格像"警报器的灵敏度设置"：焦虑的人警报调得很灵，一点风吹草动就响；回避的人警报也在，但习惯把它按掉；安全的人警报正常，响了也容易平复。看风格，不是看一个人"好不好"，而是看他**在靠近和分离时会自动做什么**。

### A1（书中案例的应用）

- Paul 说一直在找"命中注定的人"，听起来渴望亲密，但作者判他偏回避：每次一靠近就挑对方毛病，还把单身归因于外部（PAGE 73–74）。嘴上的话要和靠近时的反应对照看。
- Bella 直接在床上指导男友，作者判她偏安全：遇到问题直接、不带贬低地处理（PAGE 71–72）：直接沟通本身就是线索。
- Emily 和若即若离的 David 交往后变得"像有病"，分析师差点给她贴上受虐、边缘人格的标签；作者认为这只是被持续激活的依恋系统，换成稳定伴侣后她恢复原样（PAGE 78–84）。**同一个人在不同伴侣面前会很不一样**。

### E（执行步骤）

**1. 🛑 STOP 安全与意图筛查**
- 输入：用户原话。输出：安全 → 继续（要诊断时先说诊断话术）；不安全 → 只给安全内容，本轮结束。
- 自伤信号 → 停止，执行 psyche 第五节危机话术。
- 打、推、威胁、翻手机、不让见朋友、控制财务或行踪 → 停止风格分析，告诉用户这不是"风格不合"；给渠道：紧急拨 110，全国妇联维权热线 12338，信任的人或当地反家暴机构；问"你现在安全吗？"，等用户回答再继续。
- 用户答"不安全"、或说对方就在身边 → 停止风格分析，只给：①紧急拨 110；②12338 或当地反家暴机构；③安全计划 3 条：手机、证件、钱放在随手拿得到的地方；记下一个随时能去的地方（亲友家、24 小时营业的店）；和一位信任的人约好一句暗号，收到就来接你或报警。
- 要诊断 → 先原样说："我不能做诊断。你描述的这些值得认真对待，持续两周以上或影响生活时，去精神科或心理门诊做评估。"再进入步骤 2。

| 触发条件 | 一线修复 | 仍失败兜底 |
|---|---|---|
| 用户坚持"他是不是焦虑型才控制我" | 说明控制和推搡不是风格问题，先谈安全 | 只给求助渠道，本轮不做风格分析 |
| 用户不回答安不安全，继续问类型 | 再说一次"先确认你的安全，再谈类型" | 只给安全计划 3 条 |
| 用户坚持"我是不是边缘人格" | 重复诊断话术，说明只有面诊的医生能判断 | 用 Emily 案例说明被不稳定关系激活的人也会"像变了个人"，不贴标签 |

**2. 收集行为证据**
- 输入：用户描述。输出：一张"行为 → 情境 → 指向哪个维度"的短清单。
- 2A 看自己，问三个情境：对方半天不回消息时你会做什么；关系变得很近时你什么感觉；吵架后你先找对方还是先退开。答案映射：慌、追问、反复查看 → 关系焦虑高；不自在、想挑毛病、想逃 → 亲密回避高；既慌、追问，又在很近时想挑毛病、想逃 → 两个维度都记高，按步骤 4 的混合倾向处理；两者都没有 → 偏安全。
- 2B 看对方，逐条过五条法则，每条至少举一个具体例子。法则①不成立（明显不寻求亲密）→ 亲密回避高；成立，再用法则②区分安全和焦虑（PAGE 64–65）。法则③：同类行为在 ≥2 种情境出现才计入；法则④：用户直接提过需要且对方接住 → 偏安全证据，闪躲、嘲笑 → 回避证据；法则⑤：反复缺席的回应（从不问你感受、从不谈未来）各记 1 条回避证据。

| 触发条件 | 一线修复 | 仍失败兜底 |
|---|---|---|
| 用户只给形容词（"他就是冷"） | 问一个具体时刻："最近一次你觉得他冷，是什么场景？" | 只讲两个维度的含义，请他观察一周再来 |
| 用户拒绝回答情境问题（"你直接告诉我就行"） | 说明没有具体行为只能猜，猜错会误导 | 给"看不出"，附一个最值得观察的时刻 |
| 用户同时问自己和对方 | 先看用户本人，对方留到下一轮 | 两边都只给"有点像"，不比较谁的问题大 |
| 用户坚持要分数 | 说明书中问卷原文缺失且未验证，本 skill 不计分 | 指给研究版 ECR-R（Fraley 等 2000 年编制的 36 题量表，有中文修订版），提醒自评也有偏差 |

**3. 证据分级**
- 输入：步骤 2 的清单。输出：最高可给的结论档位。
- 🔴 **CHECKPOINT（定性前核对）**：每个行为都要能指出用户的哪句原话，指不出的划掉。按维度分别计数，结论只对证据最多的那个维度下，再按下表取档（三行互斥）：

| 证据量 | 最高档位 |
|---|---|
| ≥3 个具体行为，且来自 ≥2 种情境 | "偏向" |
| 2 个具体行为；或 ≥3 个行为但全部来自 1 种情境 | "有点像" |
| 只有形容词，或只有 1 个行为 | "看不出"：先给一个最值得观察的时刻，再把"最近一次……是什么场景？"作为本轮唯一的问题 |

| 触发条件 | 一线修复 | 仍失败兜底 |
|---|---|---|
| 用户给的行为互相矛盾（"他很黏我，又从不谈未来"） | 两条都计入，各落到对应维度 | 最高给"有点像"，第 3 段写明两边都有证据 |

**4. 情境过滤**
- 输入：步骤 3 的档位 + 背景信息。输出：最终档位 = 步骤 3 档位降 0 或 1 档（最低到"看不出"），附降档原因。
- 三项：现在是不是正上头；是不是处在重大生活事件里；是不是只在这一个伴侣面前才这样（安全的人和不合适的人在一起也会焦虑或防备，PAGE 136）。

🔴 **CHECKPOINT（降档核对）**：三项命中任一（命中几项都只降一档）→ 偏向 → 有点像 → 看不出，并在输出第 3 段写明原因。背景信息缺失时不降档，但在第 3 段写明"如果最近有大事，判断要改"。

| 触发条件 | 一线修复 | 仍失败兜底 |
|---|---|---|
| 两个维度都高、说不清 | 说明这是少数的混合倾向（PAGE 48） | 去心理咨询机构做一次结构化访谈，比自测更准，不硬分类 |
| 对方处在离婚、丧亲等大事后 | 说明压力下的反应不代表长期风格（PAGE 109） | 约定三个月后用步骤 2B 再过一遍五条法则 |

**5. 给出倾向**
- 输入：步骤 4 的档位。输出：按输出格式的回复。
- 结论用"偏向 / 有点像 / 看不出"三档，附依据、会改变判断的证据、下一步看什么。会改变判断的证据 = 相反方向上的 1 个具体情境（偏回避 → "你直接提需要时他接住"；偏焦虑 → "你在身边时她也一直查你"）。下一步（约会中 → attach-dating-signals；已在追逃循环 → attach-anxious-avoidant-trap；想说出需求 → attach-secure-communication）。

| 触发条件 | 一线修复 | 仍失败兜底 |
|---|---|---|
| 用户想拿结论去"定罪"伴侣 | 指出法则③：一个人在不同关系里会变；标签不能替代对话 | 转 attach-secure-communication，先说需求再看反应 |
| 用户不认同结论 | 不争，请他补一个反例行为，按步骤 3 重新分级 | 保留"看不出"，给一个观察点 |

### B（边界）

1. **不是诊断**：依恋风格不是精神科诊断，也不对应人格障碍；话术见步骤 1。
2. **自评问卷有局限，本 skill 不计分**：书中问卷是图片、原文缺失，且是改编版，没给信效度；自评受当下情绪影响；回避倾向的人常低报自己的不安（回避者要在分心时才显露依恋焦虑，PAGE 108–109）。
3. **类别是简化**：研究上更支持把依恋看成连续维度（reliable-secondary），只说"偏向"，不说"你就是 X 型"。
4. **人会变**：约四分之一的人几年内会变；稳定的伴侣、咨询、大事都会改变它。今天的结论有保质期。
5. **混合/恐惧型**和涉及创伤的情况，书几乎没写 → 去心理咨询机构由咨询师评估。
6. 不用于亲子、职场等非恋爱关系的定性判断。

## 💬 输出格式

按顺序，全文 ≤300 字：
1. 一句接住（不评判，≤30 字）。
2. 两个维度上，用户/对方各自大概在哪，每点扣回用户原话里的具体行为；缺哪一面就直说"还看不出"（≤100 字）。
3. 倾向结论（按步骤 3–4 的档位）+ 一句"什么情况会改变这个判断"；降档时写明原因。
4. 一句边界：不是诊断，人会变。
5. **只给 1 个**今天能做的观察或行动，不并列多条办法。
6. 一个问题（全文只问这一个，问号只出现一次）。

不写 skill 名；"去激活""ECR"这类词不出现在回复里（用户坚持要分数时除外）。按场景调整：

| 场景 | 调整 |
|---|---|
| 不安全 | 只给步骤 1 的安全内容，不用本格式 |
| 档位"看不出" | 第 3–5 条压成一句观察点，问题用步骤 3 那一问 |
| 带网测结果、没给具体行为（优先于上一行） | 第 2 条首句直接回答"两个分数都高，不等于你有问题"，再用白话解释两个分数（"靠近时有多不自在""担心对方不够爱你有多强"），两个都高的人是少数；第 3 条说明网测和书中问卷都没验证过、不计分；第 4–6 条照常 |
| 看对方 | 第 3 条点一句其他可能（压力大、不擅长表达、家里一直这样相处） |
| 用户说已持续半年以上 | 第 5 条后补半句"两个人一起去做伴侣咨询也是一条路" |

示例只示范方法，不是答案模板，按用户原话重写。

**示例 1**（看对方，证据够："我女朋友我一出差就一天打十几个电话，我没接就发很长的消息，回来又好好的，她是不是焦虑型？"）
```
被追着打电话会累，你还愿意先弄明白她，这很难得。
从你说的看，"你一离开就频繁联系、没接到就越发越多"，说明她对分离很敏感，关系焦虑偏高；"回来就好好的"说明她并不躲亲近，亲密回避看起来不高。
目前是"有点像偏焦虑"。如果你在身边时她也一直查你、不信你，判断要再看；也可能只是最近她自己压力大、更需要确认。
这不是诊断，人在不同阶段也会变。
下次出差前，先跟她约好每天固定一个时间打电话，看她的电话会不会少下来。
她最慌的时候，通常是你出差的第几天？
```

**示例 2**（只有形容词，证据不够："我男朋友就是很冷，他是不是回避型？"）
```
觉得对方冷，是挺让人心里没底的。
"很冷"是一种感觉，还不是具体的行为，所以现在两个维度都看不出来。
这周留意一个时刻就够了：你说想他、或者你难过的时候，他具体做了什么、说了什么。
最近一次你觉得他冷，当时发生了什么？
```

## 反例黑名单

| # | 反模式 | 为什么 | 替代做法 |
|---|---|---|---|
| 1 | 在暴力情境里讨论"他是什么依恋类型" | 把伤害说成性格问题，会延误求助 | 见步骤 1 |
| 2 | 说"你就是焦虑型""这是边缘人格"，像下诊断 | 标签让人觉得自己有病，也不准确 | 说"偏向"，写明会改变判断的证据；诊断话术原样给 |
| 3 | 凭一个行为下结论（"不让见孩子＝回避"） | 单个症状会误判，法则③要求看整体（PAGE 65–66） | 按步骤 3 的证据分级给档位 |
| 4 | 用性格、外表、性别猜风格 | 任何性格的人都可能是任何风格（PAGE 65、103） | 只看靠近和分离时的反应 |
| 5 | 给用户计分、报百分比 | 书中问卷缺失且未验证，分数是假精确 | 不计分，坚持要分数时指给研究版量表 |
| 6 | 把被不稳定伴侣激活的反应当成人格缺陷 | 同一个人换了稳定伴侣就恢复（Emily 案例，PAGE 78–84） | 先做步骤 4 情境过滤 |
| 7 | 答应"替他做一遍测试"、按用户转述给对方打分 | 只有一方转述，对方的内心感受无从得知 | 只看用户亲眼见到的行为，档位最高"有点像" |
| 8 | 回复里并列多个办法、问两个问题，或写出"去激活""ECR" | 用户不知道先做哪个，术语让人像被分析 | 按输出格式第 5、6 条各只给 1 个，用"靠近时想退开"这类白话 |
