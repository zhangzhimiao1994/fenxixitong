# 虚实补泻决策框架

## R — 原文 (Reading)

> 凡用针者, 虚则实之, 满则泄之, 宛陈则除之, 邪胜则虚之。
> 徐而疾则实, 疾而徐则虚。言实与虚, 若有若无。
> 形气不足病气有余, 急泻之; 形气有余病气不足, 急补之。
>
> — 黄帝/岐伯, 九针十二原第一、根结第五

---

## I — 方法论骨架 (Interpretation)

虚实补泻是一个用于判断失衡方向并选择纠正策略的二元决策框架。

其核心操作分为三层:

1. **判虚实**: 判断问题是"不足"(虚——缺乏、薄弱、不够)还是"有余"(实——过剩、过盛、淤积)。这是方向判断——虚则补(增益), 实则泻(削减)。方向错了比不干预更糟。

2. **补泻有别**: 补和泻不是简单的"加和减"。补是"徐而疾则实"——慢慢积累然后快速收效; 泻是"疾而徐则虚"——快速祛除然后慢慢恢复。操作节奏不同。



   🔴 **CHECKPOINT**: 在进入下一步之前，将分析结果展示给用户，等待确认后再继续。
3. **多信号综合判断**: 当外在表现(形气)和问题本身(病气)的虚实不一致时, "急泻之"或"急补之"——以问题本身的虚实为优先依据, 外在表现为参考。
   🛑 **STOP**：请确认上一步的分析结果后再继续。


4. **方向决定一切**: "虚而泻之则经脉空虚, 血气竭枯; 满而补之则阴阳四溢"——方向错误比力度不足更致命。

## A1 — 书中的应用 (Past Application)

### 案例 1: 形气与病气的虚实不一致
- **问题**: 如何处理外在体质(形气)和实际病况(病气)虚实不一致的情况?
- **方法论的使用**: "形气不足, 病气有余, 是邪胜也, 急泻之"——虽然体质弱但病邪盛, 此时反而要泻(祛邪)。"形气有余, 病气不足, 急补之"——虽然体质壮但正气不足, 此时反而要补(扶正)。
- **结论**: 不能简单看"体强则泻、体弱则补", 而要看"问题本身的虚实方向"。
- **结果**: 避免了"体弱就补"的教条错误, 实现精准的方向决策。

### 案例 2: 阴阳俱不足时的保守策略
- **问题**: 当系统全面虚弱("阴阳气俱不足"), 既不实也不盛, 怎么办?
- **方法论的使用**: "不可刺之, 刺之则重不足"——不能泻也不能强补, "可将以甘药"——用温和的调理代替强力的补泻。
- **结论**: 当系统全面虚弱时, 任何方向的强力干预都是危险的, 需要温和调理。
- **结果**: "重不足则阴阳俱竭"——避免了过度干预导致的全面崩溃。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. **方向迷茫**: 面对失衡不知"该加还是该减""该投入还是该撤出"。
2. **越处理越严重**: 干预后问题反而加重, 可能是补泻方向错了。
3. **两极失衡**: 系统明显出现一方过强一方过弱, 需要判断纠正方向。

### 语言信号

- "不知道该加强还是该削减"
- "越补越虚/越减越乱"
- "一边过剩一边不足"
- "系统在两个极端之间摇摆"

### 与相邻 skill 的区分

- 与 `qi-regulation` 的区别: 调气治本是"**为什么**要干预功能", 虚实补泻是"**怎么**干预(补还是泻)"。
- 与 `root-cause-priority` 的区别: 虚实补泻解决"**方向**"(补/泻), 标本根结解决"**顺序**"(先治哪个)。

## E — 可执行步骤 (Execution)

1. **列出失衡的两极**
   - 明确系统中的对立两方(如: 进攻vs防守、产出vs质量、速度vs安全)。
   - 完成标准: 两极定义清晰, 不混用不同维度。

2. **判虚实方向**
   - 评估每方是"过盛"还是"不足"。区分"绝对过盛"和"相对过盛"(一方正常但另一方不足导致失衡)。
   - 完成标准: 给出明确判断——"X虚Y实"或"X正常Y不足"。
   - 判停条件: 如果两方都虚(全面不足), 跳到步骤4的保守策略。

3. **确定补泻方向**
   - 实则泻(削减过盛方), 虚则补(增益不足方)。优先纠正不足方, 因为"虚者恢复"比"实者削减"更根本。
   - 完成标准: 给出明确的"补X/泻Y"方向和至少1个具体动作。

4. **注意边界情况**
   - 全面虚弱: 不可强力补泻, 改用温和调理。
   - 表面矛盾: 外在表现与实际虚实不一致时, 以实际问题为依据。
   - 完成标准: 识别并标注边界情况。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- **没有对立面**: 如果问题只有单一维度, 没有对立面可以对比, 虚实框架无法展开。
- **纯平衡评估**: 用户只是想知道"是否平衡", 不需要决定纠正方向。

### 反例黑名单（不做什么，什么情况下这个 skill 不灵）

| # | 反例模式 | 为什么危险 | 正确姿势 |
|---|---------|-----------|---------|
| 1 | **方向反了（虚当实泻/实当虚补）** | 方向错误 → 后果比不干预更严重 | 输出前做方向校验：如果反过来会怎样？补了更堵 = 实，泻了更虚 = 虚。两个方向都卡住 → 暂停，重新评估 |
| 2 | **阴阳俱虚时强攻** | 系统全面虚弱时强力干预 → 阴阳俱竭 | 阴阳俱虚 = 先小幅补正。扶正到系统恢复基本机能后再处理局部问题 |
| 3 | **同时有局部实和全身虚** | 直接攻局部实 → 虚人不可猛攻 | 先补全身虚 → 等系统有能量支撑 → 再攻局部实。顺序不可颠倒 |
| 4 | **信息不足时强行判断** | 用户无法提供足够信息 → 猜测方向 | 宁可信其虚不可信其实。补虚的代价远小于泻虚的代价。如果不确定 → 选补 |
| 5 | **只做定性不做定量** | 纯凭感觉判断虚实 → 缺乏验证 | 虚实框架是方向辅助，不排斥数据。有定量指标的地方应结合定量数据做精确判断 |

### 作者在书中警告的失败模式

- **方向反了**: 虚当实泻, 实当虚补——后果比不干预更严重。
- **阴阳俱虚时强攻**: 系统全面虚弱时强力泻或补都会导致"阴阳俱竭"。


### Fallback（if-then 三段式）

| 触发条件 | 一线修复 | 仍失败 → 兜底 |
|---------|---------|-------------|
| 虚实方向判断错误，系统恶化 | 立即停止。最典型信号：补了更堵（实上加实）→ 方向反了、泻了更虚（虚上加虚）→ 方向反了。出现任一信号立即反向 | 两个方向都试了仍不行 → 不是单纯虚实问题，可能涉及结构性障碍。调用 `root-cause-priority` |
| 同时存在「局部实」和「全身虚」 | 先补全身虚，再攻局部实。虚人不可猛攻——全身虚时没有能量支撑局部攻邪 | 补全身虚效果不明显 → 补的力度或方式不对。检查：补在了对的层面吗？（气血阴阳哪个层面虚？） |
| 用户无法提供足够判断信息 | 宁可信其虚。补虚的代价（效率慢）<< 泻虚的代价（系统崩溃） | 选了补之后发现是实证 → 比选泻后发现是虚证好一万倍。立即切换方向即可 |
| 阴阳俱虚时猛攻或猛补 | 全局虚弱 + 强力干预 → 阴阳俱竭。先小剂量扶正（休养/基本资源），等恢复基本机能再处理 | 连扶正都承受不住 → 说明系统处于极度脆弱状态。只做保护（减少消耗、避免刺激），不主动干预 |
| 只用一种策略——哪都补或哪都泻 | 缺乏虚实判断 = 一把锤子。每次输出必须标注「这是补还是泻」，并给出反向策略对比 | 用户偏好一种策略 → 提醒「虚虚实实」警告。问：「如果你判断反了，最坏的结果是什么？」 |
| 定量数据与定性判断矛盾 | 数据说「财务健康」但感觉「团队虚」 → 不忽略数据也不忽略感觉。分维度处理：「财务实→不补；团队虚→补」 | 矛盾无法调和 → 先信数据做决策，感觉作为风险提示持续监控 |

### 作者的盲点 / 时代局限

- 灵枢的虚实是定性判断, 现代决策中可能需要定量数据辅助。虚实框架应作为方向判断的辅助视角, 不排斥数据驱动的精确分析。
