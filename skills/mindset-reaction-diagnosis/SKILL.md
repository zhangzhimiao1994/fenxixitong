# 四时刻反应诊断

> 同一件事，固定型读成"对我的判决"，成长型读成"关于下一步的信息"。本 skill 只诊断"这一刻用的是哪种读法"，不给人贴类型。

## 🧭 决策树

```
用户描述了一个反应
│
├── 危机信号或持续低落 → 🛑 步骤 1（规则只写在步骤 1）
├── 外部结构问题为主（裁员、歧视、贫困） → ⚠️ 步骤 1 标记，步骤 6 只看可控的一小块
├── 要"给我测一下我是什么类型" → ⚠️ 不贴标签，步骤 2 改看一个具体时刻
├── 说不出任何具体时刻 → 🔴 步骤 4：先给通用小行动，用唯一问题问时刻
│
└── 有具体时刻（失败/努力/批评/他人成功） → ✅ 步骤 2–8
    └── 已经知道是哪个触发点、想改 → 交给 mindset-trigger-reframe
```

## 📥 输入

- 必需：一个具体时刻（发生了什么、当时脑中闪过的话、之后做了什么）。只有"我心态不好"这种概括不够。
- 可选：这个模式出现的领域（学业 / 工作 / 运动 / 艺术 / 人际）。
- 证据强度见 B 段第 1 条；诊断只当反思线索。

## 📖 RIA+E+B

### R（原文位置与转述）

- Ch2 PAGE 12：两种思维的三组翻转——成功是"证明"还是"伸展"；失败是"说明我不行"还是"没有成长"；努力是"没天赋才需要"还是"让人变强的东西"。
- Ch1 PAGE 8–9：同一组小挫折（期中 C+、罚单、朋友敷衍），固定型说自己是彻底的失败者、想放弃投入；成长型也难过，但会去查错题、交罚单、找朋友聊。
- Ch2 PAGE 27：努力对固定型有两重威胁——显得没天赋，以及失去"我没认真"这个借口。
- Ch2 PAGE 22–23：别人的成功被固定型当作自己的贬值。
- 引用 1 处："Becoming is better than being."（Ch2 PAGE 18）

### I（白话解释）

固定型不是"自卑"，而是把每件事都当成对"我本质如何"的打分。所以四个时刻会特别刺痛：失败 = 被打了低分；需要努力 = 承认自己不是天生的；被批评 = 有人在给我下定论；别人成功 = 我被比下去了。成长型的人同样会难受，区别在于难受之后，问题从"这说明我是谁"变成"我接下来做什么"。

诊断看**两层**：①解释（这件事说明了什么）；②行动（接下来是靠近还是躲开）。行动比口头说法更可靠。

### A1（书中案例）

- 香港大学英语不好的新生，固定型学生对补习课兴趣很低，宁可冒学业风险也不暴露短处（Ch2 PAGE 13）。诊断点：**努力时刻 + 回避**。
- 少年成名的小提琴手多年不改坏习惯、不带琴上课，因为全力以赴后失败就没借口了（Ch2 PAGE 27）。诊断点：**努力时刻 + 自我设障**。
- 作者钓到鱼，别人来问她丈夫"还撑得住吗"（Ch2 PAGE 22–23）。诊断点：**他人成功时刻**。
- 权威教授严厉点评学生作文，固定型学生骂他偏见；成长型学生虽觉得他傲慢，仍认为意见具体可用（Ch3 PAGE 45）。诊断点：**批评时刻**。

### E（执行步骤）

1. 🛑 **STOP 安全筛查**
   - 输入：用户原话。
   - 核对：出现"不想活/想消失/伤害自己/活着没意思" → 停止，只输出 psyche 第五节危机话术，不做任何思维诊断；持续两周以上低落、失眠、什么都不想做 → 转 psyche，最多附一句心态视角（书中 PAGE 24–25 的抑郁应对论述不适用于抑郁用户，不要求"硬撑"）；问"我是不是抑郁症" → 按 psyche 第五节第 2 条固定回答；外部结构因素为主 → 标记"外部"，进入步骤 2。这是本 skill 唯一的安全分流处，只有这里能整轮停下。
   - 输出：通过 / 停止 / 标记外部。
2. **选时刻**
   - 输入：用户描述。
   - 做法：由你选一个最近、最具体的时刻（失败 / 努力 / 批评 / 他人成功），多个并存选情绪最强的；同时内部判断领域（Ch2 PAGE 29），不单独输出。用户把一件事泛化成"我什么都不行"时，第 2 段加半句"这是在××这件事上的读法"。
   - 输出：一个时刻类型 + 领域。
3. **取原话与行动**
   - 输入：用户描述。
   - 做法：取当时脑中闪过的那句话，和之后实际做了什么，本步不提问。用户没给脑中原话时，用最能体现评判的那句行为或形容词代替（如"忍不住挑她的毛病""一看到他就烦"），第 5 条问题改问"当时脑子里闪过的第一句话"。
   - 输出：原话（或代替句）、行动，或标出缺哪一项。
4. 🔴 **CHECKPOINT 1（证据核对，下判定之前）**
   - 核对：是否至少有一个具体时刻？原话和行动是否齐备？
   - 没有任何具体时刻 → 不下判定，但仍给可用内容：第 1 段接住 + 一个通用小行动（"下次难受时，记下时间、发生了什么、脑中第一句话"）+ 唯一问题"最近一次让你特别难受或特别想放弃的，是哪件事？"；用户回答后从步骤 2 继续。
   - 有时刻但原话 / 行动缺一项 → 继续，判定写"倾向"，用第 5 条的唯一问题补缺项（优先问行动）。
   - 输出：继续 / 只给通用内容。
5. **读解释**
   - 输入：原话 + 行动。
   - 做法：对照下表，判断那句话是在"给自己定性"还是"找下一步"。

   | 时刻 | 固定型信号 | 成长型信号 |
   |---|---|---|
   | 失败 | "我就是…""证明我不行"；少做、作弊、找更差的人比 | "哪里出问题""下次换什么方法"；查错、求助 |
   | 努力 | "要这么费劲说明我没天赋"；拖、不准备、留借口 | "难说明在学"；加练、换策略 |
   | 批评 | "他针对我""他不懂"；全盘否定对方 | "哪句能用"；挑出可执行的部分 |
   | 他人成功 | "他赢 = 我输"；贬低、回避、嫉妒到失眠 | "他做对了什么"；去问、去学 |

   - 输出：一句判定——"这一刻在给自己定性"或"这一刻在找下一步"（证据缺一项时加"倾向"）。
6. 🔴 **CHECKPOINT 2（给可改点之前）**
   - 核对三项：①判定里没有"你是固定型"这类人格标签；②步骤 1 标了"外部"时，已先说清"这不是心态能解决的部分"；③描述的是他人时，用"可能"并只改用户自己的说法。任一项不过 → 回步骤 5 改写判定。
   - 输出：通过。
7. **给一个可改点**
   - 输入：判定 + 时刻。
   - 做法：只给一个今天能做、≤30 分钟的行为（如"把评价逐条抄下，标出有具体例子的那条"）。复杂改造交给 mindset-trigger-reframe。
   - 输出：一个行动。
8. 🔴 **CHECKPOINT 3（发送前）**
   - 核对：全文 ≤250 字；全文只有 1 个问号；第 2 条用了对应时刻的槽位；第 3 条复用了用户场景名词；没有"固定型/成长型"以外的术语。任一项不过 → 回到对应段改写。
   - 输出：可发送。

#### 如果这一步失败

| 步骤 | 触发条件 | 一线修复 | 仍失败兜底 |
|---|---|---|---|
| 1 安全 | 危机信号模糊（"好累，不想撑了"） | 先问一句"你说的不想撑，是指有伤害自己的念头吗？"，等用户回答 | 按有风险处理，输出 psyche 第五节话术 |
| 1 安全 | psyche 不可用 | 直接给：全国心理援助热线 12356、希望24热线 400-161-9995，紧急拨 120/110 | 请用户现在联系一个信任的人，不做分析 |
| 2 选时刻 | 用户坚持"给我测类型/告诉我是不是抑郁症" | 说明不做人格或疾病判定，只看一个时刻 | 疾病问题按 psyche 第五节第 2 条固定回答 |
| 3 取原话 | 原话和行动矛盾（嘴上"没事"，行动在躲） | 以行动为准，温和指出差异 | 判定写"可能"，请用户观察下一次 |
| 4 证据 | 只说"我心态不行"，给不出时刻 | 给通用小行动 + 唯一问题问时刻 | 第二轮仍给不出：用书中 C+ 坏日子情境（PAGE 8–9）请用户设想自己的反应，据此只下"倾向"判定 |
| 5 判定 | 用户否认（"我没定性，他就是针对我"） | 不争对错，只指出"推开整份评价"这一行动的代价 | 退到只给可改点，不再下判定 |
| 5 判定 | 用户被判"定性"后更自责 | 强调这是某一刻的读法，不是人格；作者本人也长期如此（PAGE 12） | 只给一个小行动，不再分析 |
| 6 他人 | 用户描述孩子 / 下属 / 伴侣 | 只能推测，用"可能" | 转 mindset-process-praise 调整用户自己的说法 |
| 7 行动 | 用户只要安慰、不想分析 | 只输出第 1 段接住 + 一个今天能做的照顾自己的小事 | 不做诊断，问一句"现在最需要的是什么？" |

### B（边界）

- **证据强度**：书中的对照来自作者实验室研究。大规模独立研究显示，思维与成绩的平均相关很弱，干预的平均效应很小（Sisk et al. 2018 元分析；Macnamara & Burgoyne 2023 元分析在控制偏倚后效应接近零）。诊断只当反思线索，不预测成败，不承诺"改了心态就会好"。
- **不是人格测试**：书中量表（PAGE 11）是自评倾向，人可以混合、分领域、随情境切换（PAGE 29）。不给人（尤其孩子）贴"固定型"标签。
- **作者自己的限定**：努力不是一切，资源和机会不平等（PAGE 30）；不是所有东西都需要改（PAGE 31 出租车司机学歌剧的例子）。
- **安全**：见步骤 1。
- **关系主题**：把伴侣问题归到对方性格上是一个固定型信号（Ch6 PAGE 84），但冲突循环的处理转 eft-demon-dialogues。
- 失效情形：用户的反应其实是合理的风险规避（如拒绝一个明显不公平的考核）；不要把"拒绝"误读成"回避挑战"。

## 💬 输出格式

分支输出：步骤 1 停止 → 只输出 psyche 第五节危机话术；步骤 4 无具体时刻 → 第 1 段 + 通用小行动 + 一个问题。

常规回复顺序固定，全文 ≤250 字，每段 ≤2 句（步骤 5 → 第 2 条，步骤 7 → 第 4 条）：
1. 一句接住（承认这件事确实难受；涉及嫉妒、愤怒时说明"有这种感受不代表你是坏人"）。
2. 引用用户原话（或步骤 3 的代替句），按时刻四选一：
   - 失败 / 努力："你说的'……'，是在给自己定性，而不只是在说这件事。"
   - 批评："你说的'……'，是在给对方和这份评价下定论，于是整份意见连同有用的部分都被推开了。"
   - 他人成功："你说的'……'，是在把对方赢读成你输，而不只是在说这次结果。"
   - 判定为"在找下一步"："你已经在问'……'，这正是把它当信息的读法。"
3. 对照句：把它当信息的人会先问什么。必须复用用户场景里的具体名词（如"执行力差""那个研究生项目""科目二"），禁止"下一步做什么"这类通用句。
4. 一个今天就能做、≤30 分钟的小行动。
5. 一个问题（全文只问这一个），引用用户原话；原话或行动缺一项时，用它补缺的那项。

**保留常识**：baseline 回答里常见的实用常识（如"先把情绪和事实分开""约对方问一句具体例子""暂时少刷对方动态"），只要不和第 4 条冲突，压成半句并进第 4 条，不另列清单。

不写 skill 名，不下人格结论。

**示例**（用户："驾照科目二挂了第二次，教练说我手太笨，我也觉得自己就是不适合开车，这周教练约我练车我都推了。"）

```
连挂两次又被说手笨，泄气很正常，换谁都不好受。
你说的"我就是不适合开车"，是在给自己定性，而不只是在说这次没过；推掉练车，就是这个判断在替你做决定。
把它当信息的人，会先问的是"科目二这两次具体是挂在倒库还是坡起"。
今天只做一件事：把两次扣分的项目写下来，挑扣得最多的那一项，回复教练约一节只练它的课。
这两次科目二，你记得分别是在哪一项被扣分的吗？
```

## 反例黑名单

| # | 反模式 | 为什么 | 替代做法 |
|---|---|---|---|
| 1 | "你就是固定型思维" | 把一刻的读法变成人格标签，正是固定型逻辑 | 说"这一刻的读法偏向给自己定性" |
| 2 | 把裁员、歧视、贫困归因到心态 | 作者本人说努力不是一切（PAGE 30），会加重自责 | 先承认外部因素，只看可控的一小块 |
| 3 | 承诺"换个心态成绩就上去了" | 大规模研究显示效应很小 | 说明效应小，只给一个具体行动 |
| 4 | 用名人故事（乔丹、伍兹）说教 | 离用户的原话太远，像训话 | 回到用户自己的原话和行动 |
| 5 | 对持续低落或有消极念头的用户说"越难受越要行动" | 安全风险：可能延误危机处理 | 步骤 1 停止，转 psyche 第五节 |
| 6 | 一次列四个时刻全面分析 | 信息过载，用户无法行动 | 只选一个时刻 |
| 7 | 用户描述孩子 / 下属时直接说"他是固定型" | 过度诊断，只凭转述无法判定 | 只说"可能"，转 mindset-process-praise 改用户自己的说法 |
