# 四时刻反应诊断

> 同一件事，固定型读成"对我的判决"，成长型读成"关于下一步的信息"。本 skill 只诊断"这一刻用的是哪种读法"，不给人贴类型。

## 🧭 决策树

```
用户描述了一个具体反应
│
├── 出现"不想活/想消失/伤害自己" → 🛑 停止，按 psyche 第五节危机话术
├── 主要是持续两周以上的低落、失眠、焦虑 → ❌ 转 psyche，可附一句心态视角
├── 主要是外部结构问题（裁员、歧视、贫困） → ⚠️ 先承认外部因素，再看是否还有可改的解释
├── 要"给我测一下我是什么类型" → ⚠️ 不贴标签，改问一个具体时刻
│
└── 有具体时刻（失败/努力/批评/他人成功） → ✅ 激活
    ├── 时刻 ≥2 个且说不清哪个最难受 → 步骤1 先选一个
    ├── 已经有一个具体时刻 → 步骤2 读解释
    └── 已经知道是固定型，想改 → 交给 mindset-trigger-reframe
```

## 📥 输入与证据假设

- 必需：一个具体时刻（发生了什么、当时脑中闪过的话、之后做了什么）。只有"我心态不好"这种概括不够。
- 可选：这个模式出现的领域（学业 / 工作 / 运动 / 艺术 / 人际）——作者明确说人可以在不同领域持不同思维（Ch2 PAGE 29）。
- 证据假设：书中的诊断特征来自实验和问卷研究，但思维与成绩的相关在大规模元分析中很弱（Sisk et al. 2018），所以诊断结果只当"反思线索"，不当预测。用户说的是他人时，只能推测，必须标"可能"。

## 📖 RIA+E+B

### R（原文位置与转述）

- Ch2 PAGE 12：作者把两种思维概括为三组翻转——成功是"证明"还是"伸展"；失败是"挫折说明我不行"还是"没有成长"；努力是"没天赋才需要"还是"让人变强的东西"。
- Ch1 PAGE 8–9：同一组小挫折（期中 C+、罚单、朋友敷衍），固定型的人说自己是彻底的失败者、想放弃投入；成长型的人也难过，但会去查错题、交罚单、找朋友聊。
- Ch2 PAGE 23–24：固定型在失败后倾向少学、考虑作弊、去看比自己更差的人、找借口。
- Ch2 PAGE 27：努力对固定型有两重威胁——显得没天赋，以及失去"我没认真"这个借口。
- Ch2 PAGE 17, 20；Ch3 PAGE 45：对批评，固定型把它当攻击，成长型就算不喜欢对方也会拿走有用的部分。
- Ch2 PAGE 22–23：别人的成功被固定型当作自己的贬值。
- Ch2 PAGE 31–32：固定型事前信心并不低，脆弱发生在挫折之后。
- 引用 1 处：书中借用一句六十年代的说法，"Becoming is better than being."（Ch2 PAGE 18）

### I（白话解释）

固定型不是"自卑"，而是把每件事都当成对"我本质如何"的打分。所以四个时刻会特别刺痛：失败 = 被打了低分；需要努力 = 承认自己不是天生的；被批评 = 有人在给我下定论；别人成功 = 我被比下去了。成长型的人同样会难受，区别在于难受之后，问题从"这说明我是谁"变成"我接下来做什么"。

诊断看的是**两层**：①解释（这件事说明了什么）；②行动（接下来是靠近还是躲开）。行动比口头说法更可靠。

### A1（书中案例）

- 香港大学：英语不好的新生被问是否愿意上补习课，固定型学生兴趣很低——宁可冒学业风险也不想暴露短处（Ch2 PAGE 13）。诊断点：**努力时刻 + 回避**。
- 一位少年成名的小提琴手多年不肯改坏习惯，甚至不带琴去上课，因为全力以赴后失败就没有借口了（Ch2 PAGE 27）。诊断点：**努力时刻 + 自我设障**。
- 作者钓到鱼，别人来问她丈夫"还撑得住吗"——他们默认别人的成功会让身边的人变小（Ch2 PAGE 22–23）。诊断点：**他人成功时刻**。
- 一位权威教授严厉点评学生作文，固定型学生骂他偏见、不懂；成长型学生虽觉得他傲慢，仍认为意见具体可用（Ch3 PAGE 45）。诊断点：**批评时刻**。

### A2（未来触发场景）

1. 职场：方案被领导当众否掉后，用户说"我就不是做这块的料"，接下来一周不再主动提方案。
2. 学业：孩子数学考差后说"反正我笨"，开始抄同学作业。
3. 社交比较：朋友创业拿到融资，用户刷到消息后失眠、开始挑对方毛病。

### E（执行步骤）

1. **选时刻**：让用户只选一个最近、最具体的时刻（失败 / 努力 / 批评 / 他人成功）。多个时刻并存时，选情绪最强的那个。
2. **取原话**：问出当时脑中闪过的那句话，和之后 24 小时内实际做了什么。
3. **读解释**：对照下表，判断那句话是在"给自己定性"还是"找下一步"。

   | 时刻 | 固定型信号 | 成长型信号 |
   |---|---|---|
   | 失败 | "我就是…""证明我不行"；少做、作弊、找更差的人比 | "哪里出问题""下次换什么方法"；查错、求助 |
   | 努力 | "要这么费劲说明我没天赋"；拖、不准备、留借口 | "难说明在学"；加练、换策略 |
   | 批评 | "他针对我""他不懂"；全盘否定对方 | "哪句能用"；挑出可执行的部分 |
   | 他人成功 | "他赢 = 我输"；贬低、回避、嫉妒到失眠 | "他做对了什么"；去问、去学 |

4. **定领域**：确认这是哪个领域的模式，提醒用户其他领域可能不同（Ch2 PAGE 29）。
5. 🔴 **CHECKPOINT**：诊断必须同时有"原话证据"和"行动证据"才下结论；只有一种时写"倾向"。若原话里出现"活着没意义 / 我是彻底的废物且什么都不想做"并持续，停止诊断，转 psyche。
6. **给一个可改点**：只指出一个行为（如"下次被否之后，先问一句'哪部分最需要改'"），复杂改造交给 mindset-trigger-reframe。

#### 如果这一步失败

| 触发条件 | 一线修复 | 兜底 |
|---|---|---|
| 用户只说"我心态不行"，给不出具体时刻 | 问："最近一次让你特别想放弃或特别难受的，是哪件事？" | 用书中 C+ 坏日子情境（PAGE 8–9）请用户设想自己的反应 |
| 原话和行动矛盾（嘴上说"没事"，行动在躲） | 以行动为准，温和指出差异 | 只写"可能"，请用户观察下一次 |
| 用户在描述他人（孩子 / 下属 / 伴侣） | 提醒只能推测，并问对方最近一次的具体反应 | 建议用户改用 mindset-process-praise 调整自己的说法 |
| 外部因素明显是主因（被裁、被歧视） | 先说清"这不是心态问题能解决的部分" | 只在用户自己能控制的那一小块上看解释方式 |
| 用户被诊断为"固定型"后更自责 | 强调这是某一刻的读法，不是人格；作者本人也长期如此（PAGE 12） | 退回只给一个小行动，不再分析 |

### B（边界）

- **证据强度**：书中的对照来自作者实验室的研究。大规模独立研究显示，思维与成绩的平均相关很弱，干预的平均效应很小（Sisk et al. 2018 元分析；Macnamara & Burgoyne 2023 元分析在控制偏倚后效应接近零）。所以：诊断只当反思线索，不预测成败，不承诺"改了心态就会好"。
- **不是人格测试**：书中的量表（PAGE 11）是自评倾向，人可以混合、分领域、随情境切换（PAGE 29）。不给人（尤其孩子）贴"固定型"标签。
- **作者自己的限定**：努力不是一切，资源和机会不平等（PAGE 30）；不是所有东西都需要改（PAGE 31 出租车司机学歌剧的例子）。
- **临床边界**：书中把抑郁应对和思维挂钩（PAGE 24–25），本 skill 不据此建议抑郁用户"硬撑"。持续低落 → psyche；自伤 / 自杀信号 → psyche 第五节危机话术；用户问"我是不是抑郁症" → 按 psyche 第五节第 2 条固定回答，不做诊断。
- **关系主题**：把伴侣问题归到对方性格上是一个固定型信号（Ch6 PAGE 84），但冲突循环的处理转 eft-。
- 失效情形：用户描述的反应其实是合理的风险规避（如拒绝一个明显不公平的考核）；这时不要把"拒绝"误读成"回避挑战"。

## 💬 输出格式

给用户看的回复，按顺序：
1. 一句接住（承认这件事确实难受）。
2. 点出时刻和那句原话："你说的'……'，是在给自己定性，而不只是在说这件事。"
3. 对照：成长型的人遇到同样的事，通常会问什么（一句）。
4. 一个今天就能做的小行动。
5. 一个问题（全文只这一个），引用用户原话。

不写 skill 名，不写"固定型/成长型"之外的术语堆砌，不下人格结论。

**示例**（用户："组会上导师说我的实验设计有大问题，我当场脸都烧了，回来两天没打开过那个文件。"）

```
被当众指出大问题，脸烧起来很正常，换谁都不好受。
值得留意的是后面那两天：文件没打开，像是"这说明我不行"在替你做决定，而不只是"这个设计有问题"。
把它当信息的人，通常会先问的是"他说的大问题具体是哪一环"。
今天可以只做一件事：打开文件，把导师的意见拆成三条，标出你最能改的那一条。
导师说的"大问题"，你记得他具体指的是哪一部分吗？
```
