# 托勒密主题取用五步法（Topic Ruler）

## 🧭 决策树

```
用户问某个生活主题，并愿意用古典本命方法
│
├── 主题是寿命/死亡/疾病/父母安危/子女/婚姻判决/合盘/地位/旅行凶险？
│     → ❌ 拒绝该部分（B 段固定说法），问用户是否换成职业或财富风格
├── 问投资、买卖时机？ → ❌ 不择时，转专业渠道
├── 没有出生日期？ → ❌ fortune 路由
├── 问今年怎么样？ → ❌ astrology-transit（可先用本 skill 读结构再交接）
│
└── 主题 ∈ {职业方向, 财富来源风格}
    ├── 有精确时间 + 城市 → ✅ 全流程（中天、福点都需要上升）
    ├── 只有日期 → ⚠️ 职业只能用"太阳前最近东出的行星"一条线；福点不可算 → 明说
    └── 用户已说明现职/现状 → 第 6 步以事实为准做对照
```

## 📥 输入与证据假设

- 数据：`python tools/divine.py astro YYYY-MM-DD HH:MM --tz 8 --lat 纬度 --lon 经度`（输出黄经 + 上升，整宫制），或用户软件粘贴。禁止心算行星位置。
- **中天**：工具不给精确中天，用第 10 宫星座近似并写明"整宫近似"；用户软件给了中天度数就用软件的。
- **福点**（卷三第 13 章，PAGE 117；卷四第 2 章，PAGE 145）：福点黄经 = 上升 + 月亮 − 太阳（取 0-360）。托勒密昼夜同一公式（后世多数流派夜间颠倒，若用户软件不同，并列说明）。这是对工具输出的加减，不是心算星位；写出算式。
- 需要的底层判断（尊贵、派别、东西方、显眼度）全部调用 `ptolemy-planet-condition` 第 3-6 步。
- 证据假设：古典象征规则，无经验预测效力（Carlson 1985；Dean & Kelly 2003）。用户的真实经历、能力与市场信息优先于盘。

## 📖 RIA+E+B

### R — 原文位置与转述

- 卷三第 4 章（PAGE 104-105）给出全书的通用方法：先找主题对应的位置（例：中天对应职业，太阳对应父亲）；再找在该处拥有"五种权利"的行星，权利最多者为主宰；主宰星与相关星座的性质决定事情的**性质**；主宰星的宇宙强弱与盘中位置决定**程度**；主宰星晨出或在角宫 → 作用"更早更快"，昏入或在续宫 → "更晚更慢"。
- 卷三第 5 章末（PAGE 109）：星必须在出生时就与主题位置有联系，否则"不会有重要作用"。
- 卷四第 4 章（PAGE 148-151）：职业由两处争夺主导——太阳（看最靠近太阳东出的行星）与中天（看在中天的行星，尤其月亮入相者）；二者兼具者独占；职业的**种类**主要由水星、金星、火星三颗"行动星"及其星座决定，木星、土星作证会改变档次与风格；主宰星东出/在角宫 → 有主导权，西入/在果宫 → 偏从属。
- 卷四第 2 章（PAGE 145-146）：财富只看福点及其主宰星：土星主建筑、农地、航运；木星主职位、受托与宗教职务；火星主军职；金星主友人与馈赠；水星主学问与贸易。
- 卷四第 10 章（PAGE 165-168）：判断必须先服从"更大的先在原因"（地域、族群、年龄阶段），否则会说出荒谬结论；又说人生多为"适度的交替"，同一时期常有得有失。

### I — 白话解释

托勒密把每个生活主题当成一个"靶子"（他自己用射箭比喻，卷三第 2 章，PAGE 101），先找靶子在盘上的位置，再看谁对那里"有发言权"，最后用发言人的性格、实力和出场时间来说事。它不回答"会不会成功"，而回答"**这个领域的象征发言人是谁、什么风格、早显还是晚成**"。

### A1 — 书中应用（转述）

- **职业**：水星为主 → 书写、管理事务、会计、教学、商贸、解释与翻译；金星为主 → 香料、染色、衣饰、颜料；火星与太阳相连 → 用火与金属的行业，与太阳分离 → 造船、木石、农作；水金合 → 音乐、诗歌、表演；水火合 → 雕塑、造器、外科；金火合 → 染色、金属、以药行医。木星作证 → 更体面、偏管理与公共事务（PAGE 149-151）。
- **财富**：同一套"主宰星性质 → 来源类别"的写法，见上 R。
- **友谊**（卷四第 7 章，PAGE 158-159）：作者用同一逻辑区分三种友谊——日月相合 = 出于本心，福点相合 = 出于利益，上升相合 = 出于彼此带来的苦乐。这说明五步法的核心是"位置 ↔ 意义"的对应表。（本 skill 不做两人盘判断，见 B。）

### A2 — 未来触发场景

1. "我在做会计但总想转设计，盘上怎么看？" → 职业主宰星若是水星且金星作证 → "这套规则会把你放在'数字 + 审美'的交界"，再对照用户事实给 1 个低成本试验。
2. "我是不是大器晚成？" → 第 5 步：主宰星昏入、在续宫 → 古典规则称"更晚更慢显现"；同时强调这只是象征节奏。
3. "福点在哪？说明我靠什么赚钱？" → 算福点 → 找主宰星 → 给"来源风格"（关系网络 / 专业知识 / 实物与长期资产 / 组织与职位 / 竞争与执行），不谈多少、不谈时机。

### E — 执行步骤

1. **主题过滤**：主题不在白名单 → 用 B 段固定说法拒绝该部分，问"要不要改看职业方向或财富来源风格？"（这是全回复唯一的问题时，后面不再提问）。
2. **取数据**并展示一行盘面；🔴 **CHECKPOINT 1**：日期不确定或用户说盘不对 → 停下核对。无出生时间 → 中天、福点、宫位都不读，只走"太阳前最近东出行星"一条线，并说明精度不足。
3. **找位置**：职业 = 中天（整宫第 10 宫近似）+ 太阳；财富 = 福点（写出算式与结果）。
4. **选主宰星**：
   - 职业：候选 A = 黄经落后太阳 15-180° 中**最小者**（最近东出的行星，限水金火木土）；候选 B = 位于第 10 宫的行星。A=B → 唯一主宰；只有其一 → 用它；两者都有 → 用 `ptolemy-planet-condition` 第 3-5 步比强弱取强者，另一个作"副声部"；都没有 → 用中天星座的庙主，并注明"信号较弱，这套规则对此的结论最不确定"。
   - 财富：福点所在星座中拥有庙/三分性/旺最多的行星（并列 → 显眼度高者）。
5. **定性质、程度、早晚**：
   - 性质：主宰星本性 + 所在星座类型（人形星座 → 知识、服务于人；四足星座 → 实物、贸易、建造；回归/二分星座 → 交换、翻译、测量；水象/土象 → 与水、植物、保存相关）。职业类别再看水、金、火三星谁最强或与主宰星相连。
   - 程度：调用 condition 第 5 步——东出/角宫 → "主导型、容易站到前台"；西入/果宫 → "协作型、在别人的结构里发挥"；张力型行星压在主宰星之上 → "需要更多耐心与防守"（不说"卑贱、不稳"）。
   - 早晚：晨出或角宫 → 早显；昏入或续宫 → 晚成。
6. 🔴 **CHECKPOINT 2（先在原因 / 事实对照）**：把古代类别翻成今天的职业时注明是"现代对应"；对照用户年龄阶段与已知事实（卷四第 10 章）——与事实冲突时以事实为准，并把冲突本身说出来（"盘的发言人是金星，但你一直在做工程——可以看作审美在工程里的位置"）。
7. **语言转换**：执行 `fortune` 第三节；删掉所有"会成功/会失败/发财年"。
8. **落地**：1 个两周内可做、成本低的验证行动（如：做一个小作品、约一次行业访谈、记录一周最投入的 3 件事）。

#### 如果这一步失败

| 触发条件 | 一线修复 | 兜底 |
|---|---|---|
| 工具不可用 | `pip install -r requirements.txt` 后重跑 | 请用户粘贴行星星座 + 上升 + 中天；仍无 → 只用太阳星座说"太阳主题"，注明未做五步法 |
| 职业候选都没有、中天庙主又很弱 | 如实说"这张盘在古典规则里没有清晰的职业发言人" | 改用 ptolemy-mind-temperament 的心性优势谈方向 |
| 福点落在星座边界 | 并列两个星座的主宰星 | 请用户核对出生时间 |
| 用户软件的福点（夜间颠倒公式）与本 skill 不同 | 并列两种结果，说明托勒密原书为昼夜同一公式 | 以用户选择为准 |
| 结论与用户现职完全相反，用户不悦 | 回到第 6 步：事实优先，盘只是"另一种描述" | 不再坚持，转问用户真正的困惑 |
| 用户把结论当成转行依据 | 明确"不能作为决定依据"，给信息收集行动 | 必要时建议职业咨询 |

### B — 边界

- **白名单之外的主题一律不落地**。固定说法："托勒密的书里确实写了这部分，但它没有任何证据，而且这类判断容易伤人，我不按它来推。可以看看职业方向或财富来源风格。"
  - 寿命、死亡方式、父母寿命 → 另按 `fortune` 第五节第 6 条处理。
  - 婚姻（早晚、次数、配偶好坏）、合盘"能否长久"、友谊/敌意判决 → 不做；关系困扰转 `astrology-transit` 的固定回答或 `psyche`。
  - 子女有无与多少、生育 → 转医生。地位高低（"王侯/卑贱"）、旅行凶险 → 不做。
- **作者自己的限度**：托勒密说兄弟姐妹只能"一般、粗略"地看，追求细节是徒劳（卷三第 6 章，PAGE 109）；本 skill 把这条推广到所有主题——只给类别与风格，不给事件。
- 托勒密的职业清单反映 2 世纪的社会分工；现代对应是解释层（inference），不可当作"你该做 X"。
- 原书说"职业主宰不明者常闲居无业"（PAGE 149）——**禁止输出**，属于恐吓。
- 不预测财富多少、能否守住、何时发财；不给投资、买卖时机。

## 💬 输出格式

自然段落，≤450 字，按序：
1. 一行盘面（来源、精度、中天/福点是否近似）
2. 主题的"发言人"是谁、为什么（1-2 句，术语 ≤2 个并括注）
3. 性质 → 现代对应的 2-3 个方向（标"现代对应"）
4. 程度与早晚（倾向语言）
5. 与用户事实的对照（有则写）
6. 1 个两周内的验证行动
7. 结尾："这是古典规则的象征读法，没有科学预测效力，最终看你的兴趣、能力和机会。" + 唯一 1 个问题

**示例**（问职业，工具盘面：太阳摩羯 17°、水星摩羯 20°、金星水瓶 4°、火星射手 14°、上升摩羯，第 10 宫天秤无行星）：
> 盘面：工具排盘，整宫制，中天按第 10 宫天秤近似。第 10 宫没有行星；在太阳前、离太阳最近又已东出的是火星（射手 14°），按托勒密的取法，它是职业的"发言人"。火星在射手不在自己的地盘，又落在第 12 宫，属于偏幕后的位置，但它东出，发力较早。古代把火星归到与火、金属、工具有关的行业；现代对应可以是工程、制造、户外或需要快速决断的执行岗位。这套规则更倾向于说：你适合在别人搭好的结构里当"攻坚手"，而不是一开始就站到前台。两周内可以试一件事：找一个需要动手解决的实际项目，记录哪一步最让你投入。这是古典规则的象征读法，没有科学预测效力，最终看你的兴趣和机会。你现在做的是什么工作？
