## 🧭 决策树（快速路由）

```
用户描述竞争困境
│
├── 对手明显强于自己（资源≥3倍差距）？ → ✅ 继续
│   └── 自身明显强于对手或势均力敌？ → ❌ 不触发，用更直接的竞争策略
├── 短期（3-6月内）可解决？ → ❌ 不触发
├── 非竞争场景（内部管理/产品开发）？ → ❌ 不触发
│
└── 以弱对强 + 长期竞争 → ✅ 激活本skill
    │
    ├── 不确定当前处于哪个阶段？→ 步骤1
    ├── 知道阶段但不知道具体策略？→ 步骤2
    └── 需要判断是否该切换阶段？→ 步骤3
```

## 🔄 三步流程

```
步骤1: 判断当前所处阶段          步骤2: 制定阶段性策略             步骤3: 设定阶段转化条件
┌──────────────────┐      ┌─────────────────────┐      ┌──────────────────────┐
│ 输入: 竞争态势描述   │       │ 输入: 当前阶段判断结果   │       │ 输入: 阶段性策略卡        │
│ 动作: 四对矛盾评估   │  ──→  │ 动作: 按阶段制定策略    │  ──→  │ 动作: 设转化信号+复盘节点 │
│ 输出: 阶段判断+依据  │       │ 输出: 阶段性策略卡       │       │ 输出: 转化条件清单        │
│ 🔴 CHECKPOINT 1   │      │ 🔴 CHECKPOINT 2        │      │ 🔴 CHECKPOINT 3        │
└──────────────────┘      └─────────────────────┘      └──────────────────────┘
```

## 📋 步骤1：判断当前所处阶段

**输入**：竞争态势完整描述（对手是谁、差距多大、当前战况）。

**动作**：用四对矛盾评估力量对比——

| 矛盾维度 | 你方 | 对手 | 趋势 |
|---------|------|------|------|
| 资源对比（资金/人才/渠道） | | | 差距在扩大/缩小？ |
| 规模对比（市占率/用户量/营收） | | | |
| 增长势能/创新力 | | | 谁在加速？ |
| 外部支持/生态优势 | | | 谁的朋友更多？ |

根据评估结果判断当前阶段：

- **防御期**：对手全面进攻，我方在收缩。力量对比严重失衡（差距>5倍），核心任务是活下去。
- **相持期**：双方在拉锯，力量趋于平衡。四对矛盾中至少2对在向我方倾斜，差距缩小到2-5倍。
- **反攻期**：我方在某些领域开始主动出击，对手在细分领域显露弱点。至少2对矛盾我方占优。

**输出**："我们当前处于___期。判断依据：①___ ②___ ③___。力量对比关键数据：___。"

🔴 **CHECKPOINT 1**：阶段判断是否基于四对矛盾的量化评估？是否有具体数据支撑而非主观感觉？

### 如果步骤1失败

| 触发条件 | 一线修复 | 仍失败则兜底 |
|---------|---------|------------|
| 四对矛盾数据不全，无法评估 | 先评估能拿到数据的矛盾维度，其余标注"未知" | 至少完成2对矛盾的评估方可进入步骤2；如果连2对都做不到，先补数据 |
| 力量对比处于两个阶段边界（模糊地带） | 偏向保守判断：宁可低估优势（防御→相持的边界按防御处理） | 如无法判断，暂判为防御期——低估自己比高估自己安全 |
| 用户高估或低估自身实力 | 要求提供定量数据（竞品市占率、用户数对比、收入对比），不用"感觉"判断 | 如果拿不到定量数据，用第三方数据交叉验证 |

## 📋 步骤2：制定阶段性策略

**输入**：步骤1产出的阶段判断结果。

**动作**：根据所处阶段执行对应策略——

**防御期策略**：
- 核心目标：活下来
- 关键动作：守住核心客户群和差异化壁垒，砍掉非核心支出，不全面对攻
- 关键指标：现金流可维持月数、核心客户留存率
- 绝对不做的事：正面硬刚、烧钱获客、扩团队

**相持期策略**：
- 核心目标：建立不对称优势
- 关键动作：深耕细分领域，积累对手无法复制的数据/信任/行业know-how
- 关键指标：垂直市场占有率、用户粘性（留存/复购/时长）
- 绝对不做的事：全面进攻、放弃差异化和对手拼规模

**反攻期策略**：
- 核心目标：扩大战果
- 关键动作：在对手力所不及的领域全面扩张，利用积累的信任和数据优势快速推进
- 关键指标：市场份额增速、收入增长
- 绝对不做的事：缩手缩脚不敢扩张、分散兵力多头出击

**输出**（阶段性策略卡）：
> "当前阶段：___。核心目标：___。关键动作（≤3项）：___。关键指标：___。绝对不做：___。"

🔴 **CHECKPOINT 2**：策略卡是否包含"绝对不做"清单？防御期有没有出现速胜冲动？反攻期有没有出现怯懦？

### 如果步骤2失败

| 触发条件 | 一线修复 | 仍失败则兜底 |
|---------|---------|------------|
| 防御期出现"全面反击"冲动（速胜论） | 立即叫停——引用论持久战原文："急性病的速胜论者熬不过持久战的艰难路程"。退回防御。 | 重新评估是否真的还在防御期——如果力量对比确实已变，说明阶段判断有误 |
| 相持期痛苦不堪想放弃 | 相持期是"转变的枢纽"——最痛苦但最关键。列出已经积累的不对称优势（即使很小）。 | 如果确实没有任何优势在积累，说明商业模式本身有问题——这不是持久战能解决的 |
| 反攻期还在保守退缩 | "机会窗口有限，反攻期的窗口是弱者用长期忍耐换来的"——加码 | 如果窗口确实已经关闭了，重新判断是否回到了相持期 |

---

## 📋 步骤3：设定阶段转化条件和复盘节点

**输入**：步骤2产出的阶段性策略卡。

**动作**：为每个阶段设定明确的"转化信号"和复盘节点。

| 转化 | 触发条件（量化指标 + 观测信号） |
|------|-------------------------------|
| 防御→相持 | 对手放缓进攻节奏（新功能/降价/补贴频率下降）+ 我方核心客户流失率连续2个月<5% |
| 相持→反攻 | 我在细分领域市占率≥30% 且连续3个月增长 + 对手在细分领域投入减少或公开表态退出 |
| 反攻→巩固 | 我方市场份额增速放缓 + 新进入者出现——需要巩固而非继续扩张 |

**设定季度复盘节点**：每个季度末，重新运行步骤1的四对矛盾评估。

**输出**（转化条件清单）：
> "防御→相持：当___指标达到___且持续___周期时触发。相持→反攻：当___指标达到___且持续___周期时触发。下次复盘节点：___。"

🔴 **CHECKPOINT 3**：转化条件是否含具体数字和时间周期？是否有定期复盘节点？

### 如果步骤3失败

| 触发条件 | 一线修复 | 仍失败则兜底 |
|---------|---------|------------|
| 转化条件过于模糊（"市场变好了就行"） | 量化每个条件——"当___指标达到___数值" | 至少给出3个可观测信号 |
| 复盘周期太长或太短 | 季度为理想周期（太短没变化，太长会错过信号） | 如果行业变化极快（如AI），改为月度 |
| 转化条件设定后从未触发 | 检查是条件太苛刻还是判断错误——如果12个月未触发防御→相持，重新评估 | 考虑是否该承认失败退出而非继续持久战 |

## 🔴 红灯场景（立即停止使用本skill）

1. **对手不是真正的"强者"**：如果资源差距≤2倍且可能逆转，应使用集中优势兵力模型而非持久战。
2. **持久战变成"等死"**：如果在防御期或相持期超过18个月没有任何正向变化——必须认真考虑退出而非继续耗下去。
3. **赢者通吃的市场**：某些互联网市场强者愈强（网络效应），弱者可能永远没有反攻期——三阶段模型需要慎重判断是否适用。

## ⚠️ 作者盲点

- 毛泽东的三阶段模型基于抗战时期特殊条件（正义/非正义、大国/小国），商业竞争中的"强者"可能通过赢者通吃效应变得更强。必须在分析矛盾转化的实际条件后才能应用。
- 预期的时间跨度可能严重低估——毛的八年抗战预测最终验证，但商业竞争中技术变革可能在更短时间内颠覆格局。设定18个月检查是否要继续。

## 🧪 测试用例

### Test 1：巨头入场
> "字节跳动宣布进入我们的AI客服赛道，他们有流量有资金，我们团队只有20人。"

激活本skill → 步骤1评估四对矛盾 → 防御期（差距>5倍）→ 步骤2制定防御策略：守住已有客户+深耕垂直行业know-how → 步骤3转化条件：当字节在该赛道投入放缓+我方客户净推荐值>40时进入相持。

### Test 2：拉锯战
> "和竞品打了18个月了，他们有品牌但我们产品更好，市占率我们15%他们22%，最近3个月差距在缩小。"

激活 → 评估：资源差距2倍以内，2对矛盾向我方倾斜 → 相持期 → 策略：深耕产品优势，积累用户口碑和案例 → 条件：市占率达30%进入反攻。

### Test 3：速胜冲动
> "最近竞品出了个重大事故，用户大量流失到我们这边，是不是该趁势全面进攻？"

激活 → 评估：是否真的进入反攻期？检查四对矛盾——如果只是竞品暂时失误而非我方优势积累，仍是防御/相持 → 警惕速胜论 → 可以抓住窗口但不意味着全面换阶段打法。
