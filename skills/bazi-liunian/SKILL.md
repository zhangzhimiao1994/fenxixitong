## R — 来源
子平法（《渊海子平》《子平真诠》《滴天髓》，转述）；出处、计分规则与排盘约定见 `references/sources.md`

## I — 方法论骨架

### 1. 读盘四步（只读结构，不下断语）
| 步 | 看什么 | 翻译成 |
|---|-------|-------|
| ① 日主 | 日干五行（甲乙木/丙丁火/戊己土/庚辛金/壬癸水） | 你的"底色"气质 |
| ② 旺衰 | 取 `divine.py` 的"旺衰计分"行 | 能量是"满"还是"需要补给"；中和（计分 -1 到 +1）→ 底色"底子不偏不倚"，不写流年一步推断（写法见 `fortune` 契约） |
| ③ 十神分布 | 哪类十神最多/缺失 | 生活重心与盲区（见下表） |
| ④ 喜忌 | 取 `divine.py` 的"喜用（扶抑法）"行；中和时不定喜用 | 适合的环境、节奏、补给方式 |

### 2. 十神 → 心理/生活主题（本体系翻译，非传统断语；被调用时只用"白话"列，"过旺/缺失"两列不写给用户）
| 十神（与日主） | 白话 | 过旺时 | 缺失时 |
|-----|---------|-------|-------|
| 比劫（同我） | 自我、同伴、竞争 | 固执、与人争 | 缺少支持感 |
| 食伤（我生） | 表达、创造 | 叛逆、口舌 | 表达受阻 |
| 财（我克） | 掌控资源、务实 | 逐利、操心 | 对物质无感 |
| 官杀（克我） | 规则、压力、责任 | 压力过大 | 缺少方向 |
| 印（生我） | 学习、庇护 | 依赖、想多不做 | 缺少后盾 |

### 3. 大运流年 → "季节"类比
大运（10 年）= 气候，流年 = 天气。带来喜用五行 / 忌神五行只作内部判断；写给用户时按 `fortune` 契约的顺逆禁令（不给年份定性，只用一步推断事实句）；流年地支冲日支/月支 → 变动年（只说变动，不说吉凶）；交运前后 1-2 年 → 转换期

## A1 — 应用案例
- 工具输出：丁火日主，旺衰 -3 偏弱，喜用木、火；2026 丙午 → "能量需要补给；这套系统的读法是，今年丙午的火在喜用里，这套说法把它当作提醒：多给自己找支持"
- 行动：本周约一位能给你建议的前辈聊 30 分钟

## A2 — 触发场景
- ✅ "1994-05-01 早上 8 点出生，女，看今年"；"四柱是甲戌 戊辰 丁亥 甲辰，看大运"（→ 先反查）
- ❌ "什么时候结婚"（→ 改写为感情领域的节奏）；"会不会出大病"（→ 拒绝，转就医）

## E — 执行步骤
1. **取盘**：用户粘贴四柱+大运，或运行 `scripts/divine.py bazi YYYY-MM-DD HH:MM --gender m|f`（有出生城市加 `--lon 经度`）；**禁止心算**。只有四柱 → 先用 `pillars` 子命令反查是否真实存在（见 B 表）
2. 出生日期不确定、公历/农历不明，或用户说盘不对 → 按 `fortune` 契约失败分支，不停
3. **读盘四步**（内部分析）。时辰模糊、整点、交界 → 只按 `cross-system-hub` 参考文件第五节（全仓唯一的时辰规则）
4. **定位周期**：当前大运 + 今年流年（取 `divine.py` 的"流年"行，括号里是流年天干十神，只在 `fortune` 契约 ⚖️ 场景那一句里用；问本命年/犯太岁时另跑 `divine.py taisui 出生年`），用"季节"类比，只标"变动/转换期"，不标顺逆（`fortune` 契约顺逆禁令）
5. **语言转换**：执行 `fortune` 的运势语言转换表
6. **落地**：1 个顺应周期的最小行动；内部检查"不信命理时这个行动是否仍有道理"，这句检查不写给用户（步骤后不加劝告）
7. **素材顺序**：一眼看盘 → 四柱 → 底色 → 能量 → 重心与盲区 → 补给 → 大运 → 流年 → 行动；格式、收尾按总入口全局契约
8. **写法规则**：
   - 🔴 软核对（不停下）："按什么时间、城市排的"写进总入口收尾行；没给城市 → 收尾行写明按北京时间排
   - 大运写出干支和起止年份（如"甲寅运，2024-2033"）
   - 流年落到用户关心的 1-2 个领域，各 1 个具体情境；用户没说就选与十神重心最相关的
   - 数字和术语不裸露：正文写"能量偏弱（需要补给）"不写"计分 -3"（工具摘录行照原样保留计分，见 `fortune` 契约）；十神首次出现括注白话
9. **与身心维度接口**：五行偏枯可提示 `five-elements-network`/`seasonal-regimen` 做调养参照（非医疗）

## B — 边界与 Fallback
| 触发条件 | 一线处理 | 仍失败 → 兜底 |
|---------|---------|-------------|
| 没给出生信息 | 一次问齐公历生日、出生时间、性别 | 不给 → 改走 `zhouyi-divination` 或 `tarot` |
| `divine.py` 输出 `[DEPENDENCY_MISSING]` | agent 执行 `pip install -r scripts/requirements.txt`，成功后重跑 | 环境禁止安装 → 请用户从排盘软件粘贴四柱+大运；仍无 → 不读盘，按 `fortune` 契约失败分支 |
| 无时辰 | 运行 `divine.py bazi YYYY-MM-DD --no-hour --gender m|f`（只排三柱，旺衰与喜用不含时柱）；标注"缺时柱，子女/晚年层面不解读" | 出生日期也不确定 → 不读盘（`fortune` 契约失败分支） |
| 只有四柱、没有性别或生日 | 先跑 `scripts/divine.py pillars 年柱 月柱 日柱 [时柱]` 反查：查不到 → 直说"这组四柱在 1900-2050 年里对不上"，不读盘；同轮转述工具"诊断"行（哪柱最可能记错 + 候选日期）+ 1 句"大运从月柱起排，阳年男、阴年女顺排"，再请用户给公历生日；查到 → 列出对应日期请用户确认，并补问性别 | 不给 → 只读原局（已确认存在的盘），不排大运 |
| 无时辰且无性别 | 用 `--no-hour` 分别以 `--gender m` 和 `--gender f` 各跑一次：原局与今年流年两盘相同，照常读；大运两盘不同 → 各用 1 句写"如果你是男/女，现在走的是 X 运（…）"；末尾 1 行一起问性别，并提示找回时辰的办法（出生证明、问长辈） | — |
| 时辰模糊 | 按 `cross-system-hub` 参考文件第五节（全仓唯一的时辰规则） | — |
| 用户说盘排错了 | 核对公历/农历、时区、真太阳时、早晚子时后重排 | 仍有分歧 → 以用户软件为准 |
| 要"旺衰"的确定答案 | 说明扶抑/格局/调候各派分歧，只给工具计分倾向 | — |
| 结果令用户焦虑 | 转 `psyche`；重申"倾向不是命定" | 危机 → `cross-system-hub` C5 |
| 用户问化解/改运 | 用 `fortune` 边界第 4 条固定回答 | — |
- 不纳入神煞（"命带孤辰"）、六亲吉凶断语、寿元；科学性见 `fortune` 边界第 1 条

## 不要做什么

| # | 反模式 | 为什么 | 替代做法 |
|---|-------|-------|---------|
| 1 | 心算四柱或大运 | 节气换月、立春换年极易算错 | 运行 `divine.py` 或请用户粘贴 |
| 2 | 补全工具没有输出的柱 | 等于编造命盘 | 标注"缺 X 柱"，只读已有部分 |
| 3 | 预测生病之年、结婚日期、寿命 | 无证据且伤害大 | 拒绝，转为"这一阶段的关注领域" |
| 4 | 给流年下"吉/凶"或顺逆判词 | 宿命化 | 按 `fortune` 契约顺逆禁令；只说变动 + 季节类比 |
| 5 | 投资择时（"哪年买房"） | 高风险 | 不作依据，请咨询持证财务顾问 |
| 6 | 推荐付费化解、改名、开光 | 利益冲突 | 只给作息、环境、学习建议 |
