# Astrology & Transit — 星盘与行运

## R — 来源
托勒密《四书》+ Rudhyar 1936 心理占星取向（转述）；周期时长是天文事实，心理意义属解释层。详见 `references/houses-and-sources.md`（含十二宫领域表、通用周期）

## I — 方法论骨架

### 1. 三要素（最常用、最稳的部分）
| 要素 | 象征 | 需要的数据 |
|------|------|----------|
| ☉ 太阳星座 | 核心意志、想成为的样子 | 出生日期 |
| ☽ 月亮星座 | 情绪需求、安全感来源 | 日期 + 大致时间（月亮约 2.5 天换座） |
| ↑ 上升星座 | 面对世界的方式（≈ 荣格"面具"） | 精确时间 + 地点 |

### 2. 行星与相位
- 行星：水星 思维沟通｜金星 价值与爱｜火星 行动与愤怒｜木星 扩张与机会｜土星 结构与责任｜天王/海王/冥王 突变/理想与幻灭/深层转化（世代性）
- 相位：合 0° 融合｜六分 60° 机会｜四分 90° 张力→动力｜三分 120° 顺畅→可能惰性｜对分 180° 拉扯→需要整合

### 3. 人生周期（行运）
| 周期 | 大致年龄 | 主题 |
|------|---------|------|
| 第一次土星回归 | ~28-30 岁 | 告别"应该"，建立自己的结构（≈ 荣格：面具松动） |
| 天王星对分 | ~40-42 岁 | 中年觉醒、想打破 |
| 第二次土星回归 | ~58-60 岁 | 收获与传承、重新定义角色 |
| 木星回归 | 每 ~12 年 | 新一轮扩张/信念更新 |
| 水星逆行 | 每年 3-4 次 | 仅作"复盘细节"的提醒，不作推迟任何事务的理由 |

## A1 — 应用案例
- 用户 29 岁，"工作做得很好但突然觉得全错了"→ 土星回归期："这一周期常被描述为把父母/社会给的结构换成自己的。你现在感到的'错'，可能是旧结构到期。"→ 联动心理维度 `jung-persona-self`
- 行动：写下三条"我一直在遵守但从没认同过的规则"
- "水逆期间能签购房合同吗？"→ "可以签。"再给 3-4 条核对项（清单见 references 第四节）

## A2 — 触发场景
- ✅ "帮我看星盘，1996-08-12 15:20 成都"；"快 30 了，是不是土星回归"；"水逆能签合同吗"
- ❌ "我和他星座合不合"（→ 不做配对判决）；"哪天动手术好"（→ 不择日、转医生）

## E — 执行步骤
1. **取盘**：运行 `python tools/divine.py astro YYYY-MM-DD HH:MM --tz 8 --lat 纬度 --lon 经度`（出生城市中心坐标，如成都 30.67/104.07，第 2 步一并展示供核对）。输出含落座、上升、相位、**当前木星/土星行运**。**禁止心算行星位置**。
   工具不可用时，请用户从 astro.com 粘贴：`太阳/月亮/上升/水金火木土 各 __座 __°；主要相位；宫制`
2. 🛑 **硬关卡**：出生日期不确定，或用户说盘不对 → 停下核对，不解读
   🔴 **CHECKPOINT（软核对，不空停）**：同一轮完成第 3-8 步（给了精确时间 + 城市 → 上升也读）；末尾 1 行请用户核对时间与坐标，并说明上升的敏感度（"时间差 1 小时，上升可能变成相邻星座"）
3. **三要素速写**：每项 1 句，用"倾向"语言
4. **一个关键相位**：从工具相位列表的四分/对分中，选偏差最小的一组（偏差 = |度数−90| 或 |度数−180|；并列时优先含太阳或月亮的那组），作为"内在张力"；无硬相位 → 跳过本步
5. **当前行运**（取工具"当前行运"两行）：
   - 主题：土星 = 功课，木星 = 窗口；落回用户这次最关心的事（没说就默认工作与关系各 1 句），各给 1 个生活里的具体情境
   - 领域：查 references 第一节，注明"以上升 X 座为准"
   - 强度与时长：只用工具的"差 X°"和 references 第二节的通用周期，不报结束日期
   - 外行星：年龄落入 I.3 周期表时才提 1 句
   - 工具不可用 → 只按年龄给周期主题，注明"未核对当前行运位置"
6. **语言转换** → 执行 `fortune` 转换表
7. **落地**：**恰好 1 个**最小行动
8. **输出顺序**（自然段落）：白话总括 1 句 → 1 行压缩盘面（☉☽↑ + 本命土星星座 + 关键行运）→ ☉☽↑ 速写 → 内在张力 → 当前周期 → 行动 → "占星传统认为，非预测"；只写已有项，不写"整宫制"等术语

## B — 边界与 Fallback

| 触发条件 | 一线处理 | 仍失败 → 兜底 |
|---------|---------|-------------|
| `[DEPENDENCY_MISSING]` | agent 执行 `pip install -r requirements.txt` 后重跑 | 禁止安装 → 请用户从 astro.com 粘贴；不愿排盘 → 只做太阳星座 + 年龄周期 |
| 工具输出缺行星或上升为空 | 检查参数后重跑 1 次 | 仍缺 → 只读已有项，注明缺什么 |
| 没说出生城市 | 补问 1 次 | 不说 → 用 `--lat 30 --lon 114` 运行，**不读上升与宫位** |
| 问水逆能不能签合同 | 直说"可以签，水逆没有证据会影响结果"，再给 3-4 条按合同类型的核对项（references 第四节） | — |
| 缺精确出生时间 | 不读上升与宫位；月亮当天换座 → 两个都列 | 日期也不确定 → 转 `zhouyi-divination` 或 `tarot` |
| 问星座配对 | 原样回答："星座不决定合不合。聊聊你们在哪些事上容易卡住？" | — |
| 只问周期、没给数据 | 按年龄给周期主题 + 1 句现实视角（"快 30 本就常是重估期"）+ "别同时换工作、分手、搬家"；补问日期 | 不给 → 注明未核对 |
| 引发焦虑 | 转 `psyche` | 危机 → `cross-system-hub` C5 |
| 要求择日 | "星盘只看人生阶段，不择日" | — |

- 证据见 `fortune` 边界第 1 条；用户的盘用别的宫制时以用户为准

## 不要做什么

| # | 反模式 | 为什么 | 替代做法 |
|---|-------|-------|---------|
| 1 | 心算月亮、上升或行星位置 | 月亮 2.5 天、上升 2 小时换座 | 用工具，或只按日期给太阳星座 |
| 2 | 预测事件日期、择日、报行运结束日期 | 无证据 | 只描述周期主题 |
| 3 | 星座配对判决 | 巴纳姆效应 | 见 B 表 |
| 4 | 劝人因水逆推迟签约、就医、出行 | 可能造成实际损失 | 提醒"复盘细节"即可 |
| 5 | 疾病判断 | 高风险 | 拒绝，建议就医 |
| 6 | 相位说成命定（"土星刑太阳注定受挫"） | 宿命化 | "一种内在张力，也是动力" |
