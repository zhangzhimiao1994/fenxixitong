## 🧭 决策树

```
用户：被浅层事务淹没 / 下班停不下来
│
├── 🛑 自伤或自杀信号 → 立即停止，按 psyche 第五节危机话术回应
├── 🛑 违法超时、欺凌 → 拨 12333 或找当地劳动监察；长期失眠、崩溃感 → 医院精神心理科，情绪为主 → psyche
├── 需要的是"整块深度时间用哪种方式排" → ❌ deepwork-depth-philosophy
├── 时间有了但专注不住 → ❌ deepwork-embrace-boredom
│
└── 浅层事务挤压正事 / 下班停不下 → ✅ 先过步骤 1，再按类型（与输出格式 A–D 一一对应）：
       ├── A 白天被会议消息塞满、说不清时间去哪 → 步骤 2–4（盘点 → 预算与下班点 → 时间块）
       ├── B 下班后脑子停不下来 → 直接步骤 5（收工清点），跳过步骤 2–4
       ├── C 时间块总被打乱 → 直接步骤 4（时间块），跳过步骤 2–3
       └── D 入门级、完全由他人派活 → 步骤 4 轻量版 + 步骤 5，不做步骤 3 的预算谈话
```

## 📥 输入与证据假设

**需要的输入**：
1. 上周（或典型一天）的事项清单与大致时长；
2. 岗位层级与自主度：能否拒绝会议、能否和上级谈工作配比；
3. 固定占用（会议、课、通勤、照护）；
4. 希望的下班时间与当前实际下班时间；
5. 下班后被工作侵入的主要入口（邮件、群消息、脑内反复）。

**证据假设**：
- 量化深度的"应届生月数"是作者设计的思想实验，用于排序，不是精确度量。
- 30%–50% 浅层比例是作者对多数非入门知识岗位的经验估计。
- 固定日程生产力来自作者与另一位教授（Nagpal）的自述，学术岗位自主度偏高。
- 停工仪式的研究依据：作者引用的无意识思考研究复现失败；注意力恢复研究效应温和；蔡格尼克效应与"做计划可释放注意"的稳健性近年存疑。可靠的部分是"每日深度上限有限、晚上补的多是低价值浅层工作"这一推理和作者的长期实践。要说"值得试"，不说"科学证明"。
- 人们普遍高估或低估自己的时间用途（书中引用的看电视、睡眠、工时自估偏差数据），这是做时间块的出发点。

## 📖 RIA+E+B

### R（Reading，转述）
- 浅层要封顶不是清零（PAGE 129–130）：每日深度上限约 4 小时，而会议、课程、电话很容易把一天切到连这 4 小时都凑不出（作者一个普通教学日就去掉 4 小时）。
- 每分钟排程（PAGE 130–134）：每天开工时在本子上把工作时间全部划块，被打断就为剩余时间重排，加溢出条件块和任务块，重要灵感可推翻计划；"It's the habit of asking that returns results"（有价值的是不断追问时间怎么用，而不是死守答案）。
- 量化深度（PAGE 134–136）：问"培训一个没有专业背景的聪明应届生多少个月能接手？"——编辑学术论文约 50–75 个月（深），季度销售 PPT 约 2 个月，项目状态会议约 3 个月（浅）。
- 浅层预算（PAGE 136–138）：和老板谈浅层应占多少（多数非入门岗位 30%–50%）并守住，下次拒绝有组织认可；老板答"需要多少做多少"说明这份工作不支持深度，作者主张开始规划转岗；入门级应推迟这一步，自雇者自己定比例。
- 五点半前收工（PAGE 138–142）：先定死不工作的时间再倒推规则（Nagpal 每周 50 小时、每年只出差 5 次、限审稿量）；拒绝时态度明确、理由模糊，不给安慰奖；固定下班点会测出老板深夜邮件其实不要求即时回复。
- 邮件（PAGE 145–148）：回复前先想清"这封邮件代表什么项目、用最少来回怎样走完"，一次写清流程、当前步骤和下一步（如约咖啡直接给两天各三个时段）。
- 停工仪式（PAGE 84–91）：收工后不允许任何工作侵入；作者每天花 10–15 分钟清点收件箱、任务、日历、排明天，再说固定口令，约 1–2 周后大脑才信任它；"When you work, work hard. When you're done, be done."（工作时全力，收工就彻底收工）。

### I（Interpretation，白话）
浅层工作的危害常被低估，因为每件小事单看都"挺合理"。只有把一周加总、算出比例，才看得见代价。先用"应届生月数"分出深浅，再给浅层定上限、给一天定终点，你就被迫做取舍。时间块不是为了把自己捆死，而是逼自己隔一会儿就问一次"剩下的时间怎么用最好"。收工清点让清单替你记住未完成的事，下班后才能真的停下来。

### A1（书中应用，转述）
- 作者 2011–2014 年几乎不在晚上和周末工作，发表约 20 篇论文、拿到两项基金、写了一本书；同行"Tom"一天 12 小时只有 1.5 小时做真正的研究（PAGE 139）。Nagpal 定每周 50 小时上限后提前拿到正教授（PAGE 139–140）。37signals 夏季四天工作周后产出不减，砍掉的主要是浅层工作（PAGE 127–128）。

### E（Execution，执行步骤）
1. **🛑 STOP 安全筛查**
   输入：用户原话。核对：自伤或自杀信号；违法超时、欺凌；长期失眠、崩溃感、躯体症状。
   输出：通过，或转介去向（见决策树）。任一命中 → 停止后续步骤；全部不命中才按类型进入步骤 2/4/5。
2. **盘点与打分**（类型 A）
   输入：上周事项与时长。输出：浅层占比数字（对应输出格式 A①）。
   每项问"聪明应届生要培训几个月才能接手"，≤3 个月记为浅层，算出浅层占比。
   🔴 CHECKPOINT 1（仅类型 A）：核对用户是否得到一个具体数字（如"上周浅层 68%"）。用户给不出时长 → 用他原话里的事项粗估一个比例，并把"上周哪三件事最占时间"作为唯一问题，等用户回答再修正；没有数字不进入步骤 3 的谈话话术。
3. **定预算与终点**（类型 A）
   🔴 CHECKPOINT 2a（仅类型 A，谈话前）：核对用户是否入职不足 1 年或工作完全由他人派发。是 → 跳过预算谈话，只定固定下班点，改按类型 D 输出；用户没提 → 按非入门级处理。
   输入：浅层占比、岗位层级。输出：固定下班点 + 至少一条配额 + 一句话术（对应输出格式 A②）。
   - 有上级：开场话术——"我统计了上周，浅层工作约占 X%，你觉得我这个岗位多少比例合适？"拿到一个数字（通常 30%–50%）。
   - 自雇或无法谈：自己定一个比例。
   - 定一个固定下班时间，倒推 2–3 条配额（例：每周会议不超过 N 小时、周例会改为"有进展再同步"、早上前两小时不开通信工具），准备一句干脆的拒绝话术，不附带安慰奖。层级文化或客户服务岗 → 拒绝改为明确延后（"下周四之后可以"）。
   🔴 CHECKPOINT 2（仅类型 A）：预算与下班点是否写下来了，且至少有一条配额？
4. **每天时间块**（类型 A、C、D 轻量版）
   输入：明天的固定占用与待办。输出：3–5 行时间块草图（对应输出格式 A③、C③、D②）。
   开工时在纸上把工作时间全部划块（≥30 分钟），深度块先放，杂事合并进任务块；不确定的任务加溢出条件块；估时放宽 1.5 倍；被打断就在下一个空隙重排剩余时间；有重要灵感可推翻计划。回邮件用流程式写法：一次写清流程、当前步骤和下一步。D 轻量版只排上午。
5. **收工清点**（类型 B、D，A 有晚间侵入时压缩版）
   输入：今天的未完成事项与未来几天日历。输出：一个清单 + 明天粗排 + 一句收工口令（对应输出格式 B②、D③）。
   每天收工前 10–15 分钟，固定顺序：看一眼收件箱有无今天必须回的 → 把散落的新任务收进一个清单 → 扫一遍所有清单和未来几天日历 → 粗排明天（可作为明天时间块的草稿）→ 说一句固定收工口令。之后不看工作消息；脑中又冒出工作念头，提醒自己"已经在清单里了"。
6. **两周回看**
   输入：两周记录。输出：维持 / 缩小规则。看浅层占比是否下降、下班后被侵入次数是否减少。
   🔴 CHECKPOINT 3：调整依据是记录数据（占比、侵入次数），而不是"好像还是很忙"；用户没有记录 → 先补记一周再调整。

**如果这一步失败**

| 步骤 | 触发条件 | 一线修复 | 仍失败兜底 |
|---|---|---|---|
| 1 | 用户否认问题严重，但描述里有连续失眠、崩溃感 | 复述他说的具体事实，说明先处理身心状况 | 仍只要方法 → 只给步骤 5，同时写明精神心理科就诊渠道 |
| 1 | psyche 无法调用 | 直接给当地心理援助热线（如 12356），紧急情况拨 120 或 110 | 停止本 skill 其余内容 |
| 2 | 记不起上周做了什么 | 从本周起每天收工时记一行 | 只盘点"会议 + 消息"两类 |
| 3 | 老板回避或答"需要多少做多少" | 用数据换一种问法："如果砍掉一个会，你最先砍哪个？" | 说明这是岗位不支持深度的信号，长期考虑调整岗位；入门级先积累技能 |
| 3 | 担心拒绝影响关系 | 只先拒绝"应届生月数最低"的那一类 | 把拒绝改为延后（"下周四之后可以"） |
| 3 | 用户想冷处理同事、直接不回消息（越界） | 说明封顶不是清零，冷处理会违反岗位职责 | 只给固定回复时段（如每天 11:00、16:00） |
| 4 | 一天重排太多次而放弃 | 加长任务块、加溢出条件块，估时放宽 1.5 倍 | 只排上午，下午自由 |
| 5 | 下班后还是忍不住看消息 | 收工口令后把工作 App 退出登录 / 手机工作模式 | 留一个固定的晚间 10 分钟检查窗口，其余时间不看 |
| 5 | 仪式坚持不到一周 | 压缩为三步：收清单 → 排明天 → 口令 | 和用户约定只试 10 个工作日 |
| 5 | 做了收工清点仍躺床想工作 | 清单放床头，冒出新念头写一行即停 | 10 个工作日仍无改善或失眠影响白天 → 去医院睡眠科或精神心理科 |
| 6 | 两周数据未改善 | 检查是否跳过了收工口令，或在检查窗口外看消息 | 缩小为只守固定下班点一条规则再试两周 |

### B（Boundaries，边界）
- **封顶不是清零**：浅层工作是工作的一部分，目标是控制占比，不是不回邮件、不开会。
- **自主度门槛**：入门级岗位、轮班、日程完全由他人决定的岗位，预算谈话不适用（作者明说入门级应推迟）；只保留收工清点和轻量时间块，并承认结构性限制。
- **文化差异**：书中"理由模糊的拒绝""不回复"等做法在层级文化或客户服务型工作中代价不对称；这类用户一律用"明确延后"代替拒绝，不冷处理同事、不违反岗位职责。
- **学术偏差**：固定下班点的成功案例都来自教授，自主度高于多数岗位；先在小范围测试"老板深夜消息是否真要求即时回复"。
- **证据强度**：停工仪式的心理学依据多条存疑（见上）；时间块、预算、固定下班点是作者经验。对用户说"可以试两周看数据"。
- **不是组织改造**：本 skill 只给个人做法；团队会议文化、全员即时通讯规则需要组织层面讨论（多问题交织时先用 maodun-fenxi 找主要矛盾）。
- **安全**：见决策树前两行与步骤 1。

## 💬 输出格式

**固定首尾**（每次都有，不计入项数）：开头一句复述用户处境（用原话里的数字或场景）；结尾一句证据提醒 + 全文唯一的 1 个问题。

**中间按问题类型（与决策树 A–D 对应）只选下列对应的 3–4 项**，按表中顺序输出，其余项不写：

| 用户问题类型 | 输出的项（按序） |
|---|---|
| A 白天被会议/消息/杂事塞满 | ① 用"应届生月数"给他提到的 2–3 件事打分，点出浅层；② 一个底线（有上级 → 固定下班点 + 一句对上级的话术；自雇 → 自定浅层比例）；③ 明天的时间块草图（3–5 行） |
| A + 还提到晚上/周末在回消息 | ① 打分只点 2 件事、合并为一句；② 底线 + 话术，配额只写 1 条；③ 时间块草图限 3 行；④ 收工一句（收清单 → 排明天 → 口令）。全文约 320 字 |
| B 下班停不下来 / 躺床还在想工作 | ① 一个固定下班点（一句）；② 收工清点 3–5 步 + 收工口令，并说明头 1–2 周大脑还不太信任它；③ 零侵入规则（口令后退出工作 App；冒出念头写一行进清单）。不打分、不排时间块 |
| C 时间块总被打乱 | ① 重排规则（被打断就在下一个空隙重排剩余时间）；② 溢出条件块 + 任务块 + 估时放宽 1.5 倍；③ 明天的时间块草图 |
| D 入门级 / 完全由他人派活 | ① 说明作者主张入门级推迟预算谈话；② 轻量时间块（只排上午）；③ 收工清点 3 步 |

**保留常识**（baseline 常见、本 skill 容易漏的，命中类型时各加半句，不另起一项）：
- A 类：点名一个可以"改看纪要"的会；消息批量处理定次数（如每天 3 次）。
- B 类：收工口令配一个物理动作（合上电脑、清空桌面）；睡前 1 小时不看工作消息；入睡困难超过 2 周或已影响白天 → 证据提醒里加一句"去医院睡眠科看看"。

**写法限制**：全文 ≤400 字；不写 skill 名和"浅层预算""停工仪式"之类术语标签，直接说做法。

**示例**（类型 A，用户："我在高校做行政，每天被表格、通知和临时会议占满，自己负责的项目报告一周一个字都没动。"）
```
表格、通知、临时会把一周吃光，报告一个字没动——你的白天全被零碎事切碎了。
先打个分：找一个聪明的应届生，填表和转通知培训一两周就能接手，临时会大概一个月，项目报告恐怕要一年以上。前两类是浅层，但现在占了你几乎全部时间；其中例行通报会可以改看纪要。
先定一个下班点，比如 17:30，倒推一条配额：通知类消息每天只在 11:00、16:00 两次集中处理。跟领导可以说："我统计了上周，表格和会议占了八成时间，报告这周想每天上午留两小时，哪些会您觉得我可以看纪要？"
明天的格子：8:30–10:30 写报告（不开消息），10:30–11:00 填表，11:00–11:30 处理通知，14:00–16:00 留给会议，16:00–16:30 再处理一次消息，16:30–17:30 填表和机动。
这些是作者和几位教授的经验，研究依据有限，先试两周，看报告每周写了几小时。
这些临时会里，哪一类最常是"其实不需要你在场"的？
```

## 反例黑名单

| # | 反模式 | 为什么 | 替代做法 |
|---|---|---|---|
| 1 | 劝用户"别回邮件、别开会" | 浅层是工作的一部分，清零会损害岗位职责 | 给浅层定比例上限 |
| 2 | 时间块一被打乱就整天放弃 | 作者一天重排六次也正常，价值在持续追问 | 在下一个空隙重排剩余时间 |
