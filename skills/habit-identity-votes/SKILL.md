## 🧭 决策树

```
用户在谈一个想养成/想戒掉的重复行为
│
├── 步骤 1 安全与分流（🛑 安全信号；❌ 近邻诉求按步骤 1 路由表转出）
│
└── 通过 → ✅ 激活
    ├── 首轮：步骤 2 补齐事实 → 步骤 3 身份 → 步骤 4 一票 → 输出
    ├── 身份绑在单一角色上（退役、转岗）→ 步骤 2 → 步骤 6 → 步骤 4 → 输出
    └── 第二轮：用户认同身份 → 步骤 5 计票；用户否认 → 回步骤 3
```

## 📥 输入与证据假设

- **需要**：用户想要的结果；目前的行为（一周几次）；用户描述自己时用的原话（"我就是…"）。
- **可选**：以前失败或反弹的经过；即将到来的角色变化（退役、离职、生育）。
- **证据假设**：身份"由重复证据累积"是作者的整合性主张；书中引用的"认同为投票者更会去投票"研究，后续大样本复制结果不一致（reliable-secondary）。因此本 skill 把身份当作**可检验的自我叙事工具**，不承诺"改了说法就会改行为"。

## 📖 RIA+E+B

### R（原文转述）
- 第2章（PAGE 32–33）：改变有三层——结果（得到什么）、过程（做什么）、身份（相信自己是谁）。问题不在哪层更好，而在**方向**：多数人从结果出发，作者主张从身份出发。
- PAGE 36：很多"我就不是…的人"的说法，是多年重复出来的叙事，不是天性。
- PAGE 37–39：身份来自习惯。你相信自己是某种人，是因为你有证据；每重复一次，就是给那种身份添一份证据。作者原话："Every action you take is a vote"（PAGE 38）。不需要全票，过半即可。
- PAGE 39–40：两步法——①决定想成为哪种人；②用小胜利向自己证明。不知道从哪开始，就从想要的结果倒推："什么样的人会得到这个结果？"
- PAGE 159–160：短期奖励要与目标身份一致，否则是给冲突的身份投票；最终"身份本身成为强化物"。
- PAGE 204–205：反面——身份抓得越紧越难成长；把角色改写成可迁移的特质。

### I（白话解释）
结果层的改变（瘦了 10 斤）达成后就失去动力；身份层的改变（"我是照顾身体的人"）没有终点，每天都有事可做。身份靠**攒证据**：每次小行动都是一张选票，票多了，"我是这种人"才从愿望变成事实。

### A1（书中案例应用）
- **拒烟两种说法**（PAGE 33–34）："我在戒烟"仍把自己当烟民；"我不抽烟"把抽烟放进过去。
- **咬指甲的人去做美甲**（PAGE 34–35）：美甲后第一次为指甲感到自豪，从此不再咬——起作用的是自豪感（身份），不是花了钱。
- **"健康的人会怎么做？"**（PAGE 40）：作者一位朋友每天用这个问题指导走路还是打车、吃什么，最终减掉百磅以上。
- **作者成为写作者**（PAGE 38）：坚持每周一、四发文，证据多了，写作者身份才成立。

### E（执行步骤）

**步骤 1：安全与分流筛查**
- 输入：用户原话。
- 输出：继续 / 转出 / 停止 三选一。
1. 自伤、自杀信号 → 🛑 **STOP**：按 cross-system-hub C5回应，本轮不做任何习惯工作。
2. 物质成瘾、赌博、进食障碍信号（每周暴食、催吐、"吃到吐"）→ 🛑 **STOP**：输出"这种情况去医院精神心理科（进食障碍门诊）当面评估更合适"，最多补一句身份视角，不设计一票。
3. 要求诊断（"我是不是 ADHD"）→ 说明"我不做诊断"，继续步骤 2。
4. 近邻诉求按下表转出，不进入步骤 2：

| 用户的核心诉求 | 转到 |
|---|---|
| 能力能不能提高、失败后自我否定 | mindset-reaction-diagnosis |
| 某一环的执行细节（想不起、太麻烦） | habit-four-laws-audit |
| 只要一个起步动作 | habit-starter-design |
| 存在性困惑、低落持续两周以上 | psyche |
| 专注工作安排 | deepwork-depth-philosophy |
| 想改写伴侣/孩子的身份（"他就是懒"） | 不做；亲密关系冲突 → eft-demon-dialogues（争吵循环）或 eft-hold-me-tight-talk |

| 触发条件 | 一线修复 | 仍失败兜底 |
|---|---|---|
| 信号模糊（"有时吃多了很难受"） | 本轮只问一句："每周大概几次？吃完会不会想吐掉？" | 用户回答确认暴食或催吐 → 按第 2 条；回答否认 → 继续步骤 2 |
| 用户坚持"就用身份法帮我停止暴食" | 说明身份改写替代不了治疗，复述转介渠道 | 只给求助动作（今天把情况告诉一个信任的人），不给习惯方案 |
| psyche 不可用 | 直接给危机话术要点：表达关心、确认安全、去最近医院急诊或拨 12356 心理援助热线 | 停止本 skill，不继续习惯话题 |

**步骤 2：补齐行为事实**
- 输入：用户原话。
- 输出：结果目标、目前频率、自述原话三项（缺项按下列默认值）。
1. 只缺频率 → 不追问，按"目前 0 次"设计一票。
2. 既没说结果也没说经过 → 用该行为最常见的结果写进步骤 3（减重 → 不反弹；早起 → 每天按时起）。
3. 用了第 2 条默认值 → 输出第 5 条的唯一问题改问"你最想因此得到什么"。

| 触发条件 | 一线修复 | 仍失败兜底 |
|---|---|---|
| 用户说不清频率 | 按 0 次处理 | 一票取最小一档 |
| 用户只说"想变自律"，没有具体行为 | 唯一问题改问"最想先改的是哪一件具体的事" | 下一轮仍说不出 → 转 habit-starter-design |

**步骤 3：把结果改写成身份**
- 输入：步骤 2 的结果目标与原话。
- 输出：1 句"我是那种……的人"。
1. 问"什么样的人会自然得到这个结果？"，列 2–3 个候选身份，**写特质不写头衔**（"会按时出现的人"优于"作家"）。
2. 选不依赖单一结果、且与用户原话最贴的一个写进输出。

🔴 **CHECKPOINT 1（定身份前）**：核对三项——①不是结果换皮（"我是瘦子"=结果）；②写的是特质不是头衔；③当天能找到对应行动。任一不过 → 回 3.1 重写。首轮的身份标"先按这个试"，用输出第 5 条问用户是否认同；用户下一轮否认 → 回步骤 3 重写，并同步换掉步骤 4 的一票。

| 触发条件 | 一线修复 | 仍失败兜底 |
|---|---|---|
| 用户说"这都是自我催眠" | 承认身份是攒出来的；只做步骤 4，不要求相信 | 只保留一票行动，不再提身份 |
| 用户想不出任何身份 | 用"你欣赏的某个人，他每天会做什么"倒推 | 直接用结果目标，转 habit-starter-design |
| 身份陈述自带苛责（"自律到变态的人"） | 换成中性、可持续的特质 | 暂不谈身份，只谈一个小行动 |
| 用户一次想换 5 个身份 | 只选与当前最痛的结果最相关的一个 | 其他写进"以后"，本轮不展开 |
| 用户陷入强烈自我否定（"我就是废物"） | 停止身份工作，先接住情绪 | 转 psyche；出现自伤信号按步骤 1 第 1 条 |

**步骤 4：设计今天能投的一票**
- 输入：步骤 3 的身份陈述。
- 输出：1 个当天可做的动作 +（如有）1 个冲突奖励 +（如有）1 条操作提示。
1. 一票 = **反证旧叙事**的最小动作：取用户自认"做不到"的那件事里今天就能做到的一截（"起不来" → 闹钟响后 1 分钟内坐起并拉开窗帘；"达标就松" → 达标后每天仍做的那件事）。
2. 自检句式"每次我做 X，我就是 Y 的人"（不写进输出）。
3. 检查现有奖励是否在给**冲突身份**投票（运动后吃冰淇淋，PAGE 159）。
4. 用户原问题含具体操作诉求（怎么不反弹、怎么起得来）→ 一票直接作用于该环节，另附 1 条操作提示（减重 → 比目标高 2 斤就恢复记录饮食；早起 → 每天同一时间起床，周末偏差 ≤1 小时）。

🔴 **CHECKPOINT 2（给行动方案前）**：核对一票 ≤2 分钟或只有 1 个动作，且不依赖天气、心情、他人。不过 → 回 4.1 再缩一截。

| 触发条件 | 一线修复 | 仍失败兜底 |
|---|---|---|
| 用户嫌一票"太小没意义" | 说明现在练的是每天出现，不是练量 | 允许 5 分钟版，前提是坏日子也能做到 |
| 轮班/照护导致没有每天固定时刻 | 挂在随班次必然发生的动作后（下班换鞋后） | 承认约束，改成每周 3 次 |
| 一票当天就没做到 | 不追究，明天同一时刻再做 | 再缩一截（只做第一个动作） |
| 用户不愿放弃冲突奖励（"不吃大餐还有什么意思"） | 换成与身份一致、同样愉快的奖励（一次按摩、一件运动装备） | 保留原奖励，但推迟到一票连续做满 7 天后 |

**步骤 5：约定计票（第二轮，用户认同身份后）**
- 输入：用户对身份陈述的认同。
- 输出：1 种计票载体 + 1 个回看时间。
1. 偶尔投给旧身份不等于失败，目标是多数票（PAGE 39）。
2. 载体三选一：手机日历当天打 ✔ / 门上便签画正字 / 已在用的打卡 App。
3. 每周日回看一次，本周 ≥4 票即算多数；中断后怎么回归 → habit-streak-plateau。

🔴 **CHECKPOINT 3**：问用户"三种记法你选哪一种？"，等用户选定再结束本流程；用户不选 → 默认手机日历打 ✔。

| 触发条件 | 一线修复 | 仍失败兜底 |
|---|---|---|
| 记录本身成了负担 | 只在周日回看一次 | 停止记录，只保留行为 |
| 用户没有手机日历、不愿用 App | 改用门上便签 | 每周日口头回想本周做了几次 |

**步骤 6：拆开过紧的身份（角色转型时）**
- 输入：用户押上全部自我的那个角色。
- 输出：2–3 个可迁移特质，选 1 个交给步骤 4。
1. 用"我是那种……的人"把角色拆成可迁移特质（PAGE 205："我是运动员" → "我是喜欢身体挑战、心理韧性强的人"）。

🔴 **CHECKPOINT 4**：输出第 5 条改问"如果这个角色明天没了，这句话还成立吗？"；用户下一轮说不成立 → 回 6.1 换特质。

| 触发条件 | 一线修复 | 仍失败兜底 |
|---|---|---|
| 出现持续低落、"活着没意义" | 停止身份工作，转 psyche | 低落超过两周或影响睡眠 → 去医院精神心理科，或拨 12356 心理援助热线 |
| 用户拒绝拆分（"我只能是运动员"） | 只保留一条与运动相关的特质 | 不强推改写，只设计退役后第一周的一票 |

### B（边界与失效情形）
- **不是性格测验**：身份陈述是行动导向的自我叙事，不给人贴类型标签；当作可试验的工具，看两周行为是否改变。
- **身份可以变成枷锁**（PAGE 204）：用户若因身份拒绝调整（"我是素食者，所以医生的话不听"），提醒身份要保持小。
- **不替代治疗**：不用"你还不够认同自己"解释成瘾、抑郁导致的行为退缩。

## 💬 输出格式

步骤 1 触发 🛑 时只输出 2–3 句（共情 + 转介渠道），不设计一票。其余按顺序，全文 ≤250 字：
1. 引用用户原话，点出卡在"结果"还是"自我认定"。原话含"天生/就是"时，先用半句承认真实差异（作息、体质），再指出这个结论是一次次重复出来的。
2. 1 个身份改写（标"先按这个试"的语气），说明它为什么不依赖单一结果。
3. 今天就能做的一小步（步骤 4）+ 冲突奖励（如有）+ 操作提示（如有）。
4. 一句收尾："多数天做到就算赢"。行为涉及身体（饮食、运动、睡眠）时，紧跟 1 句与该行为直接相关、普通人都该知道的生理或安全常识，写成可照做的一句。
5. 只问 1 个问题：默认问身份说法是否认同；步骤 2 或 CHECKPOINT 4 指定了问法时，改用指定的那一问。

不写 skill 名，不写"投票/身份层/一票"等术语，不写"根据本书框架"之类的套话。示例只示范结构，回答必须用用户自己的场景重写，不得套用示例句子。

**示例**（"想少点外卖，但总觉得自己就是懒，做饭坚持不了三天"）
```
"我就是懒"——这个结论是一次次点完外卖后攒出来的，不是天生的。
换个说法试试："我是那种每天给自己弄点真东西吃的人"。它不要求顿顿做饭，煮个蛋也算。
今天就能做的一小步：晚饭前花 2 分钟煮一个蛋，配着外卖吃也行。顺手把外卖 App 从手机首屏挪走。
多数天做到就算赢。外卖的问题多半在油、盐和分量，先把最油的那一单换掉，比完全不点更容易坚持。
"给自己弄点真东西吃的人"，你读起来认同吗？
```

## 反例黑名单

| # | 反模式 | 为什么 | 替代做法 |
|---|---|---|---|
| 1 | 让用户对镜子喊"我是自律的人"就算完成 | 没有行为证据，身份不会成立 | 身份必须配一个当天可做的行动 |
| 2 | 身份写成结果的换皮（"我是 60kg 的人"） | 达标即终点，反弹照旧 | 写特质、写行为方式 |
| 3 | 身份写成否定式（"我不再是懒人"） | 句子里仍在重复旧标签 | 写成想成为的样子（"我是给自己做饭的人"） |
| 4 | 用奖励给冲突身份投票（运动后吃冰淇淋） | 奖励在强化旧身份（PAGE 159） | 选与身份一致的奖励 |
| 5 | 对暴食催吐、成瘾用身份改写硬扛（安全） | 临床问题需要治疗，延误有风险 | 🛑 STOP，去医院精神心理科 |
| 6 | 给用户贴"你就是夜猫子/拖延型人格"或判断"你是 ADHD"（过度诊断） | 标签固化叙事，诊断超出能力 | 只描述行为，不下诊断 |
| 7 | 要求全票、断一次就说"身份失败" | 全或无会导致放弃 | 过半即赢；回归 → habit-streak-plateau |
| 8 | 把用户绑进单一宏大身份 | 角色消失时自我跟着塌 | 拆成可迁移的小特质（PAGE 205） |
