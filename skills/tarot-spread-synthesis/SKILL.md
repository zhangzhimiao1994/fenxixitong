## R — 来源
- Waite 凯尔特法按位置逐张读、以第 10 张为汇总点（Part III §7）；先浏览整体再细读（§8）✅
- 元素分布、大牌比例等统计法为后世通行实践（inference）；各牌阵位置名与"先看哪里"见 `references/spreads.md`

## I — 方法论骨架：四层扫描

| 层 | 看什么 | 意味着 |
|---|-------|-------|
| 1. 大牌比例 | 大阿卡纳占比 | >50%：人生层面的议题；1-50%：日常事务中夹着一个深层主题（找出那张大牌）；0 张：日常可控层面 |
| 2. 元素分布 | 四花色数量（圣杯 = 情感关系，宝剑 = 思维冲突，权杖 = 行动热情，星币 = 物质身体） | 某元素缺席 = 该领域被忽视；某元素过半 = 主战场 |
| 3. 重复信号 | 同数字/同宫廷出现 ≥2 | 该阶段（如多个 5 = 冲突期）被强调 |
| 4. 正逆比例 | 逆位占比 | >50%：能量普遍受阻/内化，先处理内在再谈行动；≤50%：照常读 |

牌数 ≤3 时只做第 2、4 层；第 2 层只看"问题领域对应的元素是否缺席"（如问感情却 0 张圣杯），其他元素缺席是样本太少，不提。

然后做**叙事线**：按位置顺序讲一个"起-承-转-落"的故事，并找出**关键张**（最能改变走向的那张）：

| 牌阵 | 候选位置 |
|------|---------|
| 三张 | 第 2"现在"、第 3"趋势"（过去已发生，不作关键张） |
| 关系五张 | 第 4"阻碍"、第 5"建议" |
| 凯尔特十字 | 第 2"交叉"、第 7"自我态度"、第 10"将来" |
| 态度三张（stakes） | 三个位置都可以；按下面 ①② 挑，仍并列 → 第 3"我忽略了什么"（它最靠近用户能着手的事）；暴力、经济施压时，原因只写此刻的感受和需要 |

在候选中按顺序挑：① 逆位优先 ② 元素与问题领域一致（问"整体状态"、"我该怎么办"时跳过；大牌没有花色，这一步不算一致；问题同时涉及两个领域 → 取用户最后落在的那个问句的领域；领域对应：感情、关系 → 圣杯，钱、工作稳定、身体 → 星币，事业开创、行动冲劲 → 权杖，想法、决定、冲突 → 宝剑）③ 仍并列 → 用户现在最能着手改变的那张。给用户只讲这张牌为什么关键，不讲挑选规则。

## A1 — 应用案例

**三张牌：问"要不要换城市"**
- 圣杯六正｜宝剑二逆｜战车正；元素 水→风→大牌（怀旧 → 犹豫 → 意志驱动）
- 叙事线："对熟悉环境的眷恋 → 僵持开始松动、不得不选 → 一旦选定，有往前冲的势头"
- 关键张：宝剑二逆 —— 拖延已经撑不住了，选择本身比选哪个更重要
- 镜子问题："如果明天必须给出答案，你嘴里先说出的是哪个？"
- 最小行动：把留下和离开各写 3 条理由，圈出你最不愿承认的那一条

## E — 执行步骤

1. 列出所有牌面（位置 · 牌名 · 正逆），确认来自 `tarot-draw-protocol`
   🔴 **CHECKPOINT**：牌面缺位置或正逆 → 先追问一次再做统计；仍缺 → 按 B 表默认并标注
2. 四层扫描（内部用）：给用户只说统计结论对他意味着什么（"三张都在讲行动和压力，感情这块没出现"），不说扫描过程
3. 逐位置简读（每张 ≤1 句，引用 `tarot-card-meaning`）——作为第 4 步的素材，不单独成段
4. 叙事线：起-承-转-落，≤4 句，把第 3 步的逐张简读织进去
5. 确定关键张，理由落到用户的问题上（"它关系到你问的 X"）
6. 输出（自然段落；前提假设最多 1 行）：
   - 象征主线 1-2 句（逐张简读织在里面）→ 关键张及原因 → 元素提示
   - 结尾只有 1 个提问：镜子问题（元素缺席时优先问这个领域）
   - 5 分钟可开始的最小行动（交给总入口的行动）；免责只在总入口收尾行
7. 🔴 **CHECKPOINT**：本轮结尾的唯一提问就是镜子问题；用户回应后的下一轮再问"哪张牌让你最有感觉？"→ 进入 `tarot-projective-dialogue`

## B — 边界与 Fallback

| 触发条件 | 一线处理 | 仍失败 → 兜底 |
|---------|---------|-------------|
| 说"抽好了"但没列牌面 | 先回应话里已有的信息（如"全是好牌"→ 见全吉行），再按 references 第二节挑 2-3 个关键位置，各 1 句"这个位置回答什么"，然后请用户按 `位置 · 牌名 · 正逆` 列出 | 还没抽 → 转 `tarot-draw-protocol` |
| 牌面不全 | 追问一次 | 仍缺 → 按正位、默认顺序读并标注 |
| 没有明确问题 | 扫描前用 1 句问"这次想看的是哪件事？"，同轮先按"当下整体状态"读完 | "随便看看" → 维持整体读法 |
| 牌面信号互相矛盾 | 不强行统一，说"牌阵呈现了两种力量的拉扯" | 镜子问题问"这两股力量，你现在更站在哪一边？" |
| 全是凶牌 | 先问"看到这组牌你现在心里怎么样？"，再找转化面最贴近用户问题的一张作出口 | 恐慌 → `tarot-projective-dialogue`；危机 → `cross-system-hub` C5 |
| 全吉牌、要"确认会成功"（牌已列） | 先说"牌面顺利≠结果保证，说的是你的状态有利"；关键张选最需要付出努力的那张；1 句 B 计划提醒；镜子问题"成功需要你做到哪一件事？"+ 最小行动 | — |
| 同上，但牌没列出 | 按 references 第三节：顺的牌意味着什么 + 好牌落在"阻碍"位也是提醒 + 1 句 B 计划；给最小行动；结尾只有 1 个请求："把这次想成的事和牌面（位置 · 牌名 · 正逆）一起发我" | — |
| 用户认为"不准" | 不辩护。问"哪里不像？"——不像的部分同样有信息 | 用户说明后：以用户描述的现实为准，只重写叙事线和镜子问题，不重抽、不改牌义 |

## 反例黑名单

| # | 反模式 | 为什么 | 替代做法 |
