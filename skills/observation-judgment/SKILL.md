# Observation Judgment

## R - 原文

> 观：盥而不荐，有孚颙若。（P8，第二十卦）
> 初六：童观，小人无咎，君子吝。
> 六二：窥观，利女贞。
> 六三：观我生，进退。
> 六四：观国之光，利用宾于王。
> 九五：观我生，君子无咎。
> 上九：观其生，君子无咎。

> 贲：亨。小利有攸往。（P9，第二十二卦）
> 初九：贲其趾，舍车而徒。
> 上九：白贲，无咎。

> 明夷：利艰贞。（P13，第三十六卦）
> 初九：明夷于飞，垂其翼。君子于行，三日不食。有攸往，主人有言。
> 六四：入于左腹，获明夷之心，于出门庭。
> 六五：箕子之明夷，利贞。
> 上六：不明晦，初登于天，后入于地。

> 履：履虎尾，不咥人，亨。（P5，第十卦）
> 上九：视履考祥，其旋元吉。

## I - 方法论骨架

《周易》里有几条关键的感知线：

**观卦**区分了观察的层级：童观（肤浅）、窥观（片面但有实用性）、观我生（用反馈校准自我感知）、观国之光（向外看全局）、观其生（审视外部生态）。这不是"看多看透"的宏大叙事，而是渐进式的视角升级。

**贲卦**讨论装饰与本质：贲是修饰，白贲是返璞归真。外表修饰到极致反而不如简洁（"白贲，无咎"），过度包装会遮蔽真相。

**明夷卦**讨论黑暗中的智慧：光明受伤沉入地下（太阳入地），这是被迫在信息不透明中行动的处境。核心方法论是"利艰贞"——不是强行照亮环境，而是在黑暗中保持判断力和持续行动。

**履卦**的"视履考祥"给出判断闭环：回顾走过的每一步才能验证判断是否正确。

这个 skill 帮用户做四件事：
1. 判断当前观察到什么层级（童观→窥观→观我生→观国之光→观其生）
2. 识别装饰与实质的差距（贲/白贲）
3. 在信息不透明的环境中行动（明夷）
4. 用回顾验证前面的判断（视履考祥）

## A1 - 源文件应用案例

### 案例 1：童观到观其生 — 层级跃迁的触发条件

- 场景：某创业者看了竞品报告就决定放弃项目（童观）。
- 文本动作：从"观我生"（自省：我有什么他们没看到的？）到"观其生"（审视生态：市场缺口真的消失了吗？）。
- 关键判断：多数日常决策到"窥观"够了。**以下 3 个条件满足任意一条，必须升级到观我生/观其生**：①决策不可逆 ②涉及长周期承诺（> 6个月）③两个以上信息源互相矛盾。
- 反例：买个日用品不需要观其生，不要在大事上偷懒、在小事上过度分析。

### 案例 2：白贲测试 — 实操三步法

- 场景：投资人看到一份 PPT 精美的 BP。
- 白贲测试三步：①写出对方承诺的核心（去掉所有形容词）②列出支撑核心的可验证证据 ③如果核心和证据之间差了两层以上包装 → 这是贲过度。
- 反例：不要对所有形式做白贲测试。合理的结构化表达、必要的品牌包装不算贲。贲 = 包装与实质不匹配。

### 案例 3：明夷 — "利艰贞"的最小有效动作清单

- 场景：公司重组期信息完全封闭，员工不知该留该走。
- 最小有效动作：①列出 3 件确定的事（哪怕很少）②列出 3 个可获取但尚未获取的信息源（那个"左腹"——谁能给我核心信息？）③做 1 个可逆的、消耗小于日资源 10% 的试探动作 ④不在这个阶段做不可逆决定。
- 反例：明夷不是放弃观察。"垂其翼"是低飞省力，不是落地不动。

### 案例 4：视履考祥 — 判断力校正 SOP

- 场景：做了季度策略决策后想复盘。
- SOP：①回顾当时判断依据（不是结果）②标出当时不确定但假设成立的点 ③检查哪些假设被证实/证伪 ④记录：如果重来一次，在哪个信息节点应该暂停等更多数据？
- 输出：不是"对/错"的二元评判，是"哪个信息节点判断力需要校准"。

## A2 - 触发场景

### 用户会在什么情境下需要这个 skill?

1. 用户面对表面和实质不一致的情况（项目说得好但质量差、包装精美但内容空洞）。
2. 用户在信息不透明、被有意遮蔽的环境中需要做决策（组织变动、市场不明、关系暧昧）。
3. 用户想判断自己需要观察多深才能做出足够好的决策。
4. 用户想建立判断力反馈和校准机制。
5. 用户读到观、贲、明夷等卦，想知道怎么转成现代语境。

### 语言信号

- "这件事看起来很好，但我感觉不对"
- "信息太少了，不知道怎么决策"
- "他们是不是在包装，实质怎么样"
- "怎么在黑暗时期保持判断力"
- "观卦/贲卦/明夷卦怎么用"
- "怎么训练自己的判断力"
- "我之前的判断到底对不对"

### 与相邻 skill 的区别

- 与 `auspicious-risk-language` 的区别：本 skill 处理感知质量，后者翻译吉凶术语。
- 与 `hexagram-situation-diagnosis` 的区别：本 skill 聚焦信息质量和观察深度，后者做处境分类。
- 与 `advance-retreat-boundary` 的区别：本 skill 先解决"看不看得清"，后者解决"能不能动"。

## E - 可执行步骤

### 模板：观察深度判断表

| 维度 | 你的回答 | → 对应动作 |
|------|---------|-----------|
| 🔄 决策可逆吗？ | 是 / 否 | 是→窥观够用，否→必须升级 |
| ⏳ 时间跨度？ | < 1月 / 1-6月 / > 6月 | > 6月→必须升级到观我生 |
| 📊 信息来源互相矛盾吗？ | 无矛盾 / 局部矛盾 / 严重矛盾 | 有矛盾→升级，严重矛盾→观其生 |
| 🎭 核心与包装差几层？ | 0-1层 / 2层 / > 2层 | ≥ 2层→判贲过度 |
| 🌑 有信息源但被遮蔽？ | 是（明夷）/ 否（真空） | 明夷→利艰贞；真空→先建源 |

### 步骤

1. **填表定位**：逐行填空，得出当前观察层级（童观/窥观/观我生/观国之光/观其生）和贲/明夷状态。
2. **白贲测试**：写出核心承诺（去形容词）+ 可验证证据。核心与证据之间差 ≥ 2 层 → 输出「去掉装饰后，这事还剩____。」
   🔴 **CHECKPOINT**：展示填表结果 + 白贲结论，等待确认。
3. **明夷动作**：若填表判定明夷，做三件事：①列出 ≥ 3 件确定的事（不到 3 件标注「信息严重不足」）②列出可获取但未获取的信息源 ③给 1 个可逆的试探动作（消耗 < 日资源 10%）。
   🛑 **STOP**：确认上一步。
4. **校准闭环**：设定回顾点，输出校准模板：`[日期] 判断：[X] | 依据：[Y] | 假设：[Z] | 回顾结果：[待填]`

## B - 边界与 Fallback

### 不要在以下情况使用

- 用户有充足可量化数据，不需要判断信息质量。
- 用户要求预测结果或给出确定答案。
- 用户需要纯粹逻辑推理或数学计算。
- 用户问的是行动决策而非观察方法（转用 advance-retreat-boundary 或 response-action）。

### 失败模式与预警

- ❌ 把所有含糊都说成明夷，掩盖真正可获取信息的方法。
- ❌ 过度强调剥除装饰（白贲），忽视合理包装和仪式在组织沟通中的必要性。
- ❌ 要求每件事都到"观其生"层级，浪费精力在低风险判断上。

### Fallback（if-then 三段式）

| 触发条件 | 一线修复 | 仍失败 → 兜底 |
|---------|---------|-------------|
| 用户把所有不确定都说成明夷，停止尝试获取信息 | 问：有没有内部信息源还没用到？有没有间接指标可以替代直接观察？ | 如果确认已穷尽所有信息源 → 接受明夷状态，用 Step 3 的试探动作推进 |
| 白贲测试做过头，否定了一切修饰（包括必要的形式和品牌） | 区分：白贲针对的是"遮蔽本质的过度装饰"，不是"所有形式"。列出哪些修饰是必要的功能性形式 | 如果用户仍坚持剥除一切形式 → 提醒：贲卦本身"小利有攸往"——适度的贲是有利的 |
| 要求用户对所有问题都深入"观我生/观其生"层级 | 用 Step 1 强制升级规则反向过滤：是否不可逆？是否 > 6个月？是否信息矛盾？三条都不满足 → 降回窥观 | 如果用户焦虑要求所有事都深究 → 这本身是童观和窥观的混淆，解释"什么层级的问题用什么深度的观察" |
| 白贲测试的核心无法被提取（面对高度复杂的技术方案/专业领域） | 改为"外行测试"：找一个该领域的聪明外行，让他用自己的话复述一遍核心。如果他复述不出来，就是贲过度 | 如果找不到外行测试者 → 用"5岁小孩测试"：如果连给 5 岁小孩解释都做不到，包装太厚 |
| 用户处在信息真空（非明夷）却被判为明夷 | 重新诊断：信息真空 = 完全无信息源（如进入全新领域），不是明夷。明夷 = 有信息源但被遮蔽。信息真空应先去建立信息源 | 如果无法建立任何信息源 → 这不是周易范畴，属于需要向用户说明的极端不确定场景 |

### 来源边界

本 skill 依据经文中的观、贲、明夷、履卦原文，不延伸到后世心学或佛道观察论。

## 反例黑名单（dim9）

| # | 不要做的事 | 为什么 | 正确做法 |
|---|-----------|--------|---------|
| 1 | 把所有信息不足判为"明夷" | 混淆了信息真空（无源）和信息遮蔽（有源被挡） | 先区分：有信息源但被遮蔽？还是根本无信息源？ |
| 2 | 对日常小事做到"观其生"深度 | 浪费认知资源，制造不必要的焦虑 | 用 Step 1 强制升级三条件过滤 |
| 3 | 把白贲测试变成"反形式主义"，否定一切包装 | 合理的结构与形式本身就是信息和信任的载体 | 贲卦"小利有攸往"——适度贲有利 |
| 4 | 用卦象分析替代真实的信息获取行动 | 观察框架是辅助工具，获取新信息才是核心 | 每次分析结束后至少给出 1 个可执行的信息获取动作 |
| 5 | 把"视履考祥"变成结果论——好结果=判断对，坏结果=判断错 | 判断质量和结果质量是两个维度 | 分开评估：判断质量（当时信息下是否合理）vs 结果质量（发生了什么事） |
