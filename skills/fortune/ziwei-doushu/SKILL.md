# Ziwei Doushu — 紫微斗数

## R — 来源（已对照原文，2026-10-02）
- 核对版本：《紫微斗数全书》四卷整理本（托名陈希夷，成书不早于明代）。星性与四化见卷一《诸星问答论》；安星、宫位、大限小限见卷二各诀；大限祸福见卷三
- evidence：十二宫名、十四主星、甲戊庚壬四化、大限小限规则已逐条核对
- 立场：原书是吉凶断语体系（如化忌「守身命一生不顺」、疾厄宫断病）；这里只取**结构**（宫位、星曜、四化、大限），心理转译**非原书立场**

## I — 方法论骨架

### 1. 十二宫 = 人生十二个领域（紫微最擅长的"领域地图"）
原书顺序（卷二《安十二宫例》）：命宫、兄弟、妻妾、子女、财帛、疾厄、迁移、奴仆、官禄、田宅、福德、父母

| 宫 | 领域 | 宫 | 领域 |
|---|------|---|------|
| 命宫 | 自我、核心性格 | 迁移宫 | 外出、外部世界中的自己 |
| 兄弟宫 | 手足、平辈同伴 | 奴仆宫（原书名；今通行作交友/仆役） | 朋友、下属、人脉 |
| 夫妻宫（原书作「妻妾」） | 亲密关系模式 | 官禄宫 | 事业、做事方式 |
| 子女宫 | 子女、创造、下属 | 田宅宫 | 居所、家庭根基 |
| 财帛宫 | 赚钱与理财方式 | 福德宫 | 内心享受、精神状态 |
| 疾厄宫 | 身体倾向（**仅作养生提示**） | 父母宫 | 父母、上级、文书 |

### 2. 十四主星 → 性格原型（简表）
原书安星诀（卷二）：紫微系「紫微天机逆行旁」6 星，天府系「天府太阴与贪狼」8 星。

| 主星 | 原型 | 主星 | 原型 |
|-----|------|-----|------|
| 紫微 | 帝王：领导、自尊（原书「帝座」） | 天府 | 库房：稳重、保守 |
| 天机 | 谋士：思虑、变动 | 太阴 | 月亮：细腻、内敛 |
| 太阳 | 光热：付出、外放 | 贪狼 | 欲望：多才、交际 |
| 武曲 | 财星：果断、务实 | 巨门 | 口舌：探究、质疑（原书「主是非」） |
| 天同 | 福星：享受、童心 | 天相 | 印星：协调、辅佐 |
| 廉贞 | 囚星：原则、复杂 | 天梁 | 荫星：照顾、老成 |
| 七杀 | 将星：冲锋、独立（原书「上将」） | 破军 | 原书"耗星"→ 读作破旧立新 |

**化忌落在不同星上的功课**（未知是哪颗星时，给最常见的 2-3 种供用户对照）：太阳忌 = 付出得不到回应；太阴忌 = 情绪内耗、安全感；巨门忌 = 沟通误会、口舌；武曲忌 = 钱与决断的压力；天机忌 = 想太多、反复变动；文曲/文昌忌 = 文书、表达上的疏漏；贪狼忌 = 欲望难满足；廉贞忌 = 原则与人情的冲突

### 3. 四化 = 能量流向
| 四化 | 原书（卷一） | 这里的读法 |
|-----|------------|----------|
| 化禄 | 福德之神 | 资源、缘分自然流入的地方 |
| 化权 | 掌判生杀之神 | 你想抓住主导权的领域 |
| 化科 | 主掌文墨之星 | 容易被看见、被帮助的领域 |
| 化忌 | 多管之神，「守身命一生不顺」 | **最在意、最放不下的地方**——也是成长功课所在 |

> 化忌讲成"功课"是心理转译，**非原书立场**；对用户只在开头说一次"这里的读法是…"，不重复声明。

### 4. 大限（10 年）、小限与流年 → "今年的焦点宫位"
当前大限/流年落入哪一宫，该领域就是这段时间的"主战场"。

原书规则（卷二《安大限诀》《安小限诀》）：
- 大限：原书称「阳男阴女从命前一宫起顺行」（阴男阳女逆行），与今通行"从命宫起大限"不同；`iztro` 等排盘库多采通行规则——**以用户排盘结果为准并注明**
- 小限：按生年地支起（如「寅午戌人起辰宫」），男顺女逆
- 流年：原书以太岁论吉凶（卷三），本 skill 只取"焦点宫位"之义

## A1 — 应用案例
- 命宫七杀、夫妻宫化忌 → "独立冲锋型性格；在亲密关系上投入很深也最容易卡住——关系是你这一生的重要功课，而非'婚姻不顺'"
- 今年流年走到官禄宫 → "今年事业领域是焦点，变化与机会都集中在这"→ 用 `maodun-fenxi` 核对用户自述的主要矛盾是否确实在事业；不在则以用户事实为准

## A2 — 触发场景
- ✅ "我的紫微命盘是……（粘贴），帮我看今年"
- ❌ "我能活多久""疾厄宫有化忌是不是会得癌"（→ 拒绝，转医疗）

## E — 执行步骤
1. **取盘**：本仓库不含紫微排盘工具。请用户从紫微排盘软件（如文墨天机）或 `iztro` 开源库排盘，按模板粘贴；**禁止心算安星**
   ```
   命宫: [地支] 主星__ 四化__ | 身宫在: __宫
   其余十一宫: 宫名 [地支] 主星__ 四化__（每宫一行）
   当前大限: __宫（__-__岁） | 今年流年: __宫
   所用四化表/流派: __
   ```
2. **展示核对** + 声明流派
   🔴 **CHECKPOINT 🛑**：用户确认盘面无误后再进入第 3 步；**用户只给了部分宫位时跳过本关卡**，直接读已给部分
3. **命宫/身宫速写**：主星原型 → 核心性格倾向（七杀/破军/贪狼坐命可加 1 句"杀破狼"格局 = 变动中开创的倾向，不说吉凶）
4. **四化流向**：化禄（顺）与化忌（卡）各在哪宫 → 天赋领域与功课领域；化忌写明是哪颗星、来自生年/大限/流年（未知则注明）
5. **焦点宫位**：当前大限与流年所在宫，并同读其**三方四正**（对宫 + 两个三合宫，例：官禄 → 对宫夫妻、三合命宫与财帛），各 1 句；用户没给这些宫 → 只用宫位的领域含义各说 1 句（如"对宫夫妻 = 合作与伴侣会牵动事业"），注明"未见主星"
6. **缺信息时**：**先读已给出的部分，不停下**；没给的项不单独成段，并入末尾补问（最多 2-3 个最关键的问题）。化忌来源未知时，用 1 句说明差别："生年化忌是一辈子的功课，大限/流年化忌是这一阶段的功课"
7. **语言转换** → 执行 `fortune` 转换表
8. **落地**：针对用户所问领域给 1 个本周能做的行动。用自然段落按序写：命宫性格 → 化禄（顺）→ 化忌（功课）→ 焦点宫位 → 行动 → 待补清单；**不用代码块**

## B — 边界与 Fallback

| 触发条件 | 一线处理 | 仍失败 → 兜底 |
|---------|---------|-------------|
| 只给了部分命盘（如"命宫七杀、夫妻宫化忌"） | 按第 6 步：先解读给出的宫位，末尾列补问清单 | 用户想看全局 → 发第 1 步模板 |
| 用户贴截图或软件原排版 | 提取宫名、主星、四化、大限，按模板回显请用户确认 | 缺项 → 列出请补 |
| 没有命盘，只有生日 | 发第 1 步模板 | 用户无法排盘 → 改走 `bazi-liunian`（`tools/divine.py` 可排八字）或 `zhouyi-divination` |
| 用户要求"按生日帮我安星" | 拒绝心算，说明安星规则复杂、易错，发模板 | — |
| 用户的四化与原书十干表不同 | 以用户排盘软件为准，注明流派差异 | — |
| 用户问疾厄宫是否会得病、问寿元 | 先 1 句接住担心（"看到化忌落在疾厄宫会紧张，很正常"），再原样回答："紫微不能判断疾病或寿命。" 只给作息关注提示，并建议就医检查 | 用户坚持 → 不再解读疾厄宫 |
| 用户问"化忌在 X 宫是不是一辈子 Y"（如财帛 → 缺钱） | 原样回答："化忌不代表一辈子缺什么，它标出的是你最在意、最需要用心经营的领域。" 再给该宫的功课式解读 + 1 个行动 | — |
| 用户引用原书断语（"化忌一生不顺"） | 告诉用户"这里只借用命盘结构，不用吉凶断语"，再给功课式解读 | — |
| 解读引发焦虑 | 停止，转 `psyche` | 危机信号 → `cross-system-hub` C5 |

- 科学性：同 `fortune` 边界第 1 条

## 不要做什么

| # | 反模式 | 为什么 | 替代做法 |
|---|-------|-------|---------|
| 1 | 心算安星 | 安星规则复杂、流派多，极易错 | 请用户按模板粘贴 |
| 2 | 疾厄宫断病、推算寿元 | 原书有疾病断语（如「天机…头面破相」），本 skill 刻意不采用 | 只给作息提示 + 建议就医 |
| 3 | 把化忌讲成"灾"、把七杀讲成"凶" | 原书立场如此，但本体系不采用吉凶断语 | 化忌 = 功课所在；说明取舍 |
| 4 | 混用不同流派的四化表而不说明 | 结论互相矛盾 | 写明所用四化表，以用户软件为准 |
| 5 | 用杂曜、神煞下断语 | 流派分歧大 | 不展开 |
| 6 | 用流年焦点宫位推翻用户自述的现实 | 象征不得推翻事实 | 以用户事实为准 |
| 7 | 夫妻宫说"晚婚""感情来得晚"、疾厄宫说"不会得重病" | 婚期与健康的正反断语都是预测 | 只谈关系模式；健康只给体检与作息提示 |
