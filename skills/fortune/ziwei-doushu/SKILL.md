# Ziwei Doushu — 紫微斗数

## R — 来源（位置引用 + 转述）
- 十四主星、十二宫、四化的基本体系：《紫微斗数全书》卷一至卷二相关篇章（转述）
- 托名陈希夷（陈抟），成书实际不早于明代——学界通说，作者归属存疑
- evidence label：reliable-secondary（据通行整理本转述）

## I — 方法论骨架

### 1. 十二宫 = 人生十二个领域（紫微最擅长的"领域地图"）
| 宫 | 领域 | 宫 | 领域 |
|---|------|---|------|
| 命宫 | 自我、核心性格 | 迁移宫 | 外出、外部世界中的自己 |
| 兄弟宫 | 手足、平辈同伴 | 交友宫（仆役） | 朋友、下属、人脉 |
| 夫妻宫 | 亲密关系模式 | 官禄宫 | 事业、做事方式 |
| 子女宫 | 子女、创造、下属 | 田宅宫 | 居所、家庭根基 |
| 财帛宫 | 赚钱与理财方式 | 福德宫 | 内心享受、精神状态 |
| 疾厄宫 | 身体倾向（**仅作养生提示**） | 父母宫 | 父母、上级、文书 |

### 2. 十四主星 → 性格原型（简表）
| 主星 | 原型 | 主星 | 原型 |
|-----|------|-----|------|
| 紫微 | 帝王：领导、自尊 | 天府 | 库房：稳重、保守 |
| 天机 | 谋士：思虑、变动 | 太阴 | 月亮：细腻、内敛 |
| 太阳 | 光热：付出、外放 | 贪狼 | 欲望：多才、交际 |
| 武曲 | 财星：果断、务实 | 巨门 | 口舌：探究、质疑 |
| 天同 | 福星：享受、童心 | 天相 | 印星：协调、辅佐 |
| 廉贞 | 囚星：原则、复杂 | 天梁 | 荫星：照顾、老成 |
| 七杀 | 将星：冲锋、独立 | 破军 | 先锋：破旧立新 |

### 3. 四化 = 能量流向
| 四化 | 含义 | 本体系翻译 |
|-----|------|----------|
| 化禄 | 顺利、资源、缘分 | 能量自然流入的地方 |
| 化权 | 掌控、主导 | 你想抓住主导权的领域 |
| 化科 | 名声、条理、贵人 | 容易被看见/被帮助的领域 |
| 化忌 | 执着、亏欠、卡点 | **最在意、最放不下的地方**——也是成长功课所在（不是灾祸） |

### 4. 大限（10 年）与流年 → "今年的焦点宫位"
当前大限/流年落入哪一宫，该领域就是这段时间的"主战场"。

## A1 — 应用案例
- 命宫七杀、夫妻宫化忌 → "独立冲锋型性格；在亲密关系上投入很深也最容易卡住——关系是你这一生的重要功课，而非'婚姻不顺'"
- 今年流年走到官禄宫 → "今年事业领域是焦点，变化与机会都集中在这"→ 联动 Hub 的毛选引擎确认主要矛盾是否确实在事业

## A2 — 触发场景
- ✅ "我的紫微命盘是……（粘贴），帮我看今年"
- ❌ "我能活多久""疾厄宫有化忌是不是会得癌"（→ 拒绝，转医疗）

## E — 执行步骤
1. **取盘**：用户粘贴命盘（各宫主星+四化+当前大限），或用 `iztro` 等开源库排盘；**禁止心算安星**
2. **展示核对** + 声明流派 → 🔴 **CHECKPOINT**
3. **命宫/身宫速写**：主星原型 → 核心性格倾向
4. **四化流向**：化禄（顺）与化忌（卡）各在哪宫 → 天赋领域与功课领域
5. **焦点宫位**：当前大限与流年所在宫
6. **语言转换** → 执行 `fortune` 转换表
7. **落地**：针对焦点宫位的 1 个最小行动

## B — 边界
- 疾厄宫仅可作"作息/养生关注点"提示，**禁止任何疾病判断**
- 化忌必须讲成"功课"，禁止讲成"灾"
- 杂曜、神煞不展开；流派冲突时说明并给出两种读法
- 科学性：同 `fortune` 边界第 1 条
