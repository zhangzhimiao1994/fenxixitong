# Bazi & Liunian — 八字与流年

## R — 来源（位置引用 + 转述）
- 以日干为"我"、十神由生克定义：《渊海子平》；月令为提纲：《子平真诠》"论用神"；"中和"为贵：《滴天髓》
- evidence label：reliable-secondary（据通行整理本转述，未核对原刻本）

## I — 方法论骨架

### 1. 读盘四步（只读结构，不下断语）
| 步 | 看什么 | 翻译成 |
|---|-------|-------|
| ① 日主 | 日干五行（甲乙木/丙丁火/戊己土/庚辛金/壬癸水） | 你的"底色"气质 |
| ② 旺衰 | 取 `divine.py` 的"旺衰计分"行（月令 + 干支生扶的简化计分） | 能量是"满"还是"需要补给"；中和时只谈倾向 |
| ③ 十神分布 | 哪类十神最多/缺失 | 生活重心与盲区（见下表） |
| ④ 喜忌 | 取 `divine.py` 的"喜用（扶抑法）"行；中和时不定喜用 | 适合的环境、节奏、补给方式 |

### 2. 十神 → 心理/生活主题（本体系翻译，非传统断语）
| 十神 | 与日主关系 | 心理主题 | 过旺时 | 缺失时 |
|-----|-----------|---------|-------|-------|
| 比肩/劫财 | 同我 | 自我、同伴、竞争 | 固执、与人争 | 缺少支持感 |
| 食神/伤官 | 我生 | 表达、创造、才华 | 叛逆、口舌 | 表达受阻 |
| 正财/偏财 | 我克 | 掌控资源、务实 | 过度逐利、操心 | 对物质无感 |
| 正官/七杀 | 克我 | 规则、压力、责任 | 压力过大、被管束 | 缺少约束与方向 |
| 正印/偏印 | 生我 | 学习、庇护、依赖 | 依赖、想太多不行动 | 缺少滋养与后盾 |

### 3. 大运流年 → "季节"类比
- **大运**（10 年）= 这十年的"气候"；**流年**（1 年）= 今年的"天气"
- 流年/大运带来**喜用五行** → 顺风期："播种/扩张"
- 带来**忌神五行** → 逆风期："蓄力/守成"
- 流年地支**冲**日支/月支 → 变动年：环境、关系、居所更易变化（**不说吉凶，只说变动**）
- **交运**前后 1-2 年 → 转换期

## A1 — 应用案例
- 工具输出：丁火日主，旺衰 -3 偏弱，喜用木、火；2026 丙午 → "底色温和细腻、能量需要补给；今年流年火来扶身，是补给与被支持的一年"
- 行动：本周约一位能给你建议的前辈聊 30 分钟

## A2 — 触发场景
- ✅ "1994-05-01 早上 8 点出生，女，看今年"；"四柱是甲戌 戊辰 丁亥 甲辰，看大运"（→ 补问性别 + 生日）
- ❌ "什么时候结婚"（→ 改写为感情领域的节奏）；"会不会出大病"（→ 拒绝，转就医）

## E — 执行步骤
1. **取盘**：用户粘贴四柱+大运，或运行 `python tools/divine.py bazi YYYY-MM-DD HH:MM --gender m|f`（有出生城市加 `--lon 经度`）；**禁止心算**。排大运需要性别和出生年份，只有四柱时须补问
2. **展示核对**：原样列出四柱、日主、起运岁数；提醒真太阳时/早晚子时问题
   🔴 **CHECKPOINT（核对，不空停）**：展示四柱后**同一轮完成第 3-6 步**，末尾 1 行请用户核对："时辰或出生城市有出入告诉我，我修正后重看。"出生时间离时辰交界 <30 分钟且无城市 → 改用 `--no-hour` 三柱解读，说明两个候选时柱各是什么、换了会影响哪部分
3. **读盘四步** → 输出"底色 / 能量状态 / 重心与盲区 / 适合的补给"
4. **定位周期**：当前大运 + 今年流年（取 `divine.py` 的"流年"行；问本命年/犯太岁时另跑 `divine.py taisui 出生年`），用"季节"类比，标注"顺风/逆风/变动"；大运流年方向相反 → 以流年定本年节奏
5. **语言转换**：执行 `fortune` 的运势语言转换表
6. **落地**：1 个顺应周期的最小行动，并说明"如果你不信命理，这个行动本身是否仍有道理"
   输出用自然段落（不用代码块），按序：底色 → 能量 → 重心与盲区 → 补给 → 大运 → 流年 → 行动 → "这套系统描述的是倾向，选择权在你"
7. **与身心维度接口**：五行偏枯可提示 `five-elements-network`/`seasonal-regimen` 做生活调养参照（非医疗）

## B — 边界与 Fallback
| 触发条件 | 一线处理 | 仍失败 → 兜底 |
|---------|---------|-------------|
| 用户没给任何出生信息（"我五行缺什么"） | 一次问齐：公历生日、出生时间、性别；拿到后运行工具 | 不给 → 说明"没有出生信息无法判断五行"，可改走 `zhouyi-divination` 或 `tarot` |
| `divine.py` 输出 `[DEPENDENCY_MISSING]` | agent 执行 `pip install -r requirements.txt`，成功后重跑 | 环境禁止安装 → 请用户从排盘软件粘贴四柱+大运；仍无 → 只按出生年做年柱简读，**不补全其他柱** |
| 无时辰 | 运行 `divine.py bazi YYYY-MM-DD --no-hour --gender m|f`（只排三柱，旺衰与喜用不含时柱）；标注"缺时柱，子女/晚年层面不解读" | 出生日期也不确定 → 只做年柱简读 |
| 只有四柱、没有性别或生日 | 补问性别 + 公历生日 1 次（同一四柱 60 年一循环，排大运必须有生日），拿到后用 `divine.py` 重排 | 不给生日 → 只读原局，不排大运 |
| 无时辰且无性别 | 用 `--no-hour --gender m` 运行，**丢弃大运段**（不向用户解释占位参数），照常读原局与今年流年；末尾 1 行一起问性别，并提示找回时辰的办法（出生证明、问长辈） | — |
| 时辰模糊（"3 点多""下午"） | 用两个候选时辰各跑一次，只解读两盘共同的部分 | 两盘差异过大 → 只读三柱 |
| 用户说盘排错了 | 核对公历/农历、时区、真太阳时、早晚子时后重排 | 仍有分歧 → 以用户软件的盘为准 |
| 用户要"旺衰"的确定答案 | 说明扶抑/格局/调候各派分歧，只给工具计分的倾向 | — |
| 结果令用户焦虑 | 暂停，转 `psyche`；重申"倾向不是命定" | 危机信号 → `cross-system-hub` C5 |
| 用户问化解/改运 | 用 `fortune` 边界第 4 条固定回答 | — |
- 不纳入神煞、六亲吉凶断语、寿元（见下表）；科学性见 `fortune` 边界第 1 条

## 不要做什么

| # | 反模式 | 为什么 | 替代做法 |
|---|-------|-------|---------|
| 1 | 心算四柱或大运 | 节气换月、立春换年极易算错 | 运行 `divine.py` 或请用户粘贴 |
| 2 | 补全工具没有输出的柱 | 等于编造命盘 | 标注"缺 X 柱"，只读已有部分 |
| 3 | 预测生病之年、结婚日期、寿命 | 无证据且伤害大 | 拒绝，转为"这一阶段的关注领域" |
| 4 | 给流年下"吉/凶"判词 | 宿命化 | 用"顺风/逆风/变动"+ 季节类比 |
| 5 | 投资择时（"哪年买房/炒股"） | 高风险决策 | 拒绝作为依据，建议咨询持证财务顾问 |
| 6 | 推荐付费化解、改名、开光 | 利益冲突 | 只给作息、环境、学习层面的建议 |
| 7 | 用神煞下断语（"命带孤辰"） | 流派分歧极大 | 不提，或标注"趣味说法，无定论" |
