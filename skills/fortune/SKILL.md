# 运势维度 (Fortune) —— 命理三系路由

## 核心立场：命盘是"天气预报"，不是"判决书"

- **倾向不是命定，周期不是吉凶**：输出用"这套系统认为…"，不用"你会…"
- **内因决定**：运势是外因，用户的行动是内因（`neiyin-juedinglun`）

## 〇、执行流程

| 步 | 动作 | 输出 / 关卡 |
|---|------|-----------|
| 0 | 安全与高风险筛查：危机信号 → `cross-system-hub` C5；寿命/疾病/投资择时 → 拒绝该部分并说明原因，其余照常 | 🛑 危机时终止 |
| 1 | 盘点用户已给的出生信息（日期/时间/地点/性别/已有命盘） | `数据: __ | 缺: __` |
| 2 | 按第一节路由表选方法；缺信息时只追问 1 次。缺出生地：八字先排并注明"未做真太阳时校正"；星盘按城市中心坐标排并在 🛑 展示坐标 | 方法名 |
| 3 | 取盘（第二节铁律） | 原样排盘结果 |
| | 🔴 **CHECKPOINT 🛑**：展示排盘结果，等用户确认无误 | — |
| 4 | 交给子 skill 解读，结论经第三节转换表 | 第四节格式 |

## 一、方法路由

| 用户已有/愿提供 | 首选方法 | 子 skill | 擅长回答 |
|---------------|---------|---------|---------|
| 出生年月日 + 时辰 | 八字 | `bazi-liunian` | 五行性格倾向、10 年大运节奏、今年流年主题 |
| 出生年月日 + 时间 + 地点 | 西方星盘 | `astrology-transit` | 心理动力、关系模式、当前行运（土星/木星周期） |
| 出生年月日 + 时辰（农历亦可） | 紫微斗数 | `ziwei-doushu` | 人生十二领域格局、哪个领域是今年焦点 |
| 只有出生日期（无时辰） | 星座/日柱简读 | `astrology-transit` 简版 / `bazi-liunian` 三柱 | 仅性格倾向，**明确标注精度不足** |
| 无出生信息 / 只想问一件事 | 周易起卦 | `zhouyi-divination` | 一件具体事情的当下态势 |
| 无出生信息 / 想看整体状态 | 塔罗 | `tarot` | 当下的内在态度与关注点 |

**无出生信息时的分流**：先问"最近最在意的是某一件具体的事，还是整体状态？"→ 具体事走周易起卦，整体状态走塔罗。
**本命年 / 犯太岁** → 年支简读（只需出生年；只说"今年本命年"时，生年地支 = 今年流年地支，如 2026 丙午 → 午年生人）：
```
今年: [流年干支] | 你的生年地支: [X] | 关系: 本命/冲/无
转译: [第三节转换表] | 行动: [1 个复盘或调整节奏的小行动]
```

**多方法并用**：用户提供完整出生信息且要求"全面看运势"时，八字为主、星盘或紫微为辅（最多两套），避免信息过载。三套结论冲突时，标注张力，不择优挑选好听的。

## 二、排盘数据铁律 🛑

1. **禁止心算排盘**。四柱、星盘行星位置、紫微安星都必须来自：
   - 用户从专业排盘软件/网站获得并粘贴给你（首选）
   - 八字：`python tools/divine.py bazi YYYY-MM-DD HH:MM --gender m|f`
   - 星盘：`python tools/divine.py astro YYYY-MM-DD HH:MM --tz 8 --lat 纬度 --lon 经度`
   - 紫微：用户从排盘软件或 `iztro` 粘贴（模板见 `ziwei-doushu`）
2. 排盘结果必须**原样展示**给用户核对，再进入解读；时辰不确定 → 按 `cross-system-hub` C11 处理

### 取盘失败的处理
| 触发条件 | 一线处理 | 仍失败 → 兜底 |
|---------|---------|-------------|
| `divine.py` 输出 `[DEPENDENCY_MISSING]` | agent 执行 `pip install -r requirements.txt` 后重跑 | 环境禁止安装 → 只做年柱简读（按出生年，立春为界），并请用户粘贴完整命盘；**不补全缺失的柱** |
| 用户说排盘结果不对 | 核对输入（公历/农历、时区、真太阳时、早晚子时），修正后重排 | 仍有分歧 → 以用户软件的盘为准 |
| 用户拒绝提供任何出生信息 | 按第一节分流到周易起卦或塔罗 | — |

## 三、运势语言转换表（必须执行）

| 命理原话 | 输出时改为 |
|---------|-----------|
| 大凶 / 灾年 | 压力较大的年份，适合守成、打基础 |
| 犯太岁 / 冲太岁 | 变动较多的年份，环境变化可能加速 |
| 本命年 / 值太岁 | 回到起点的一年，适合复盘与调整节奏（不是"倒霉年"） |
| 破财 | 财务上需要更谨慎，避免冲动大额支出 |
| 克夫/克妻 | **禁止使用**；改述为"关系中容易出现的张力模式" |
| 血光之灾 | **禁止使用**；最多提示"注意安全与休息" |
| 寿元 / 何时去世 | **拒绝回答** |
| 大吉 / 走大运 | 窗口期，资源与机会相对充足，仍需行动兑现 |

## 四、输出格式（单独使用与被 Hub 调用通用；不写权重）

```
【运势】方法: 八字/星盘/紫微 | 数据来源: 用户提供/工具排盘 | 精度: 完整/缺时辰
  盘面要点: [2-3 个关键结构，原样列出]
  周期定位: [当前大运/流年/行运处于什么阶段，用"季节"类比]
  倾向提示: [这套系统认为你此期更容易…]
  行动: [顺应周期的 1 个最小行动]
  ⚠️ 命理提示: 描述的是倾向与节奏，选择权在你
```

## 五、边界（必须对用户透明）

1. **科学证据**：Carlson (1985, *Nature*) 双盲实验未发现占星师能将星盘与性格档案匹配到超过随机水平；"巴纳姆效应"（Forer, 1949）说明泛化描述容易被个人认同。命理输出应视为**自我反思的框架**
2. **高风险领域**：健康、法律、投资、婚育决定 → 运势**不得作为依据**，明确说明并转专业渠道
3. **宿命焦虑**：用户因运势结果明显焦虑/恐惧 → 暂停运势分析，转 `psyche`（`freud-anxiety-defense`）
4. **不收费改运**：用户问化解 → 固定回答："不需要花钱化解。这一年更适合做的是：规律作息、重要决定多留一周缓冲、给自己安排一次复盘。"
5. **流派差异**：`divine.py` 八字排盘采用——立春换年、节气换月、晚子时（23:00 后）日柱仍算当天、**未做真太阳时校正**；星盘为回归黄道 + 整宫制；紫微以用户软件的四化表为准
6. **问寿命的固定回答**："寿命不在命理可以回答的范围。如果你在担心健康，我们可以看看今年适合怎样的作息节奏，同时建议做一次体检。"
