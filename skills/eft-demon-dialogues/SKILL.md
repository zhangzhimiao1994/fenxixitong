# 识别恶魔对话

> 先看整场舞，再看某一步；先找循环，不找坏人。

## 🧭 决策树

```
用户在描述和伴侣的反复冲突 / 冷战
│
├── 出现暴力、威胁、“我怕他”、严重成瘾、长期出轨？
│     └── ❌ 不做循环分析 → 走 B 段转介话术
├── 出现“不想活了”“想消失”，或拿自杀当吵架筹码？
│     └── 🛑 STOP → psyche 第五节危机话术
├── 问“我是什么依恋类型 / 要不要分手 / 该找什么样的人”？
│     └── ❌ 转 attach-*（类型与择偶）
├── 已经能说出循环，卡在“我为什么一碰就炸”？
│     └── ❌ 转 eft-raw-spot-deescalation
│
└── ✅ 反复的同一种吵法 / 冷战，还没看清整体
      ├── 双方都在攻击、互相定性         → 找坏人
      ├── 一方追问批评、一方防守退开     → 抗议波尔卡（最常见）
      └── 双方都安静、客气、没有触碰     → 冻结逃跑（最危险，优先处理）
```

## 📥 输入与证据假设

- 需要：最近一次冲突的具体片段（谁先说了什么、各自接下来做了什么），而不是总评价（“他就是自私”）。
- 通常只听到一方的版本。分析的是“用户描述中的步子”，要提醒这是单方视角。
- 不假设谁是追方、谁是退方：按行为判断，不按性别判断（作者观察到性别倾向，但也承认因人因文化而异，PAGE 62–63）。
- 不假设用户的伴侣愿意配合；单方先看清自己的步子也有效。

## 📖 RIA+E+B

### R（原文位置与转述）

- 作者认为，多数争吵其实是对情感断联的抗议；底下真正的问题是“我能依靠你吗、我对你重要吗”（PAGE 26）。
- 断联引发原始恐慌，人只有两条路：变得追逼、黏人以求回应，或退开、麻木以求自保（PAGE 27、51–52）。
- 三种恶魔对话：找坏人（互相指责）、抗议波尔卡（一方追、一方退，最常见）、冻结逃跑（双方都退，常由波尔卡演变而来，最危险）（PAGE 51）。
- 作者批评只教沟通技巧的做法，说那是在叫人 "change the steps when what they have to do is change the music"（PAGE 29）。
- 走出循环的五点：看清整场舞；明白彼此的步子怎么把对方拉进来；理解这是依恋困扰，讲道理停不下来；把循环看成敌人；两人一起给它命名（PAGE 64）。
- 用填空句描述循环，并给它起名字（PAGE 66、71–72）。

### I（白话解释）

吵什么不重要，怎么吵才重要。追的一方在喊“你看看我”，退的一方在喊“别再说我不行了”；两个人都怕失去对方，只是用了相反的方式。追得越紧，对方越想躲；躲得越远，这边越着急。循环一旦自动化，谁先开始已经说不清，所以“找到先错的人”永远没有结果。要做的不是赢这一局，而是两人一起指着循环说：“它又来了。”

### A1（书中案例，转述）

- **Jim 与 Pam**（PAGE 50–55）：Pam 说想多支持丈夫，Jim 翻了个白眼，几秒钟后两人互骂。作者让他们停在当下、看那个没有起点的圈。Jim 给它起名“谁更差劲”循环，两人笑了出来，然后 Jim 说出：其实他想要更多支持。
- **Mia 与 Ken**（PAGE 57–59、64）：舞会上 Ken 不跳，Mia 弯腰去挪他的腿，Ken 离场。追—冻的圈被画出来后，Ken 问“那不代表我们不合适吧？”后来他能在循环刚起时说“我们又卡住了，过来抱一下”。
- **Terry 与 Carol**（PAGE 67–70）：多年批评之后 Carol 把愤怒“咽下去”，两人客气、无接触，几乎不看对方。作者指出这种冷才是最危险的阶段。

### A2（未来触发场景）

1. “我一问他今天怎么了，他就说没事然后去打游戏，我越问越气，最后吵到半夜。”→ 抗议波尔卡。
2. “我们现在很少吵架了，各忙各的，挺和平的，但我觉得我们完了。”→ 冻结逃跑。
3. “每次吵到最后都在比谁更过分，翻三年前的事。”→ 找坏人 + 内容管道。

### E（执行步骤）

1. **安全筛查**：有没有暴力、恐惧、严重成瘾、长期出轨、自伤信号。有 → 直接走 B 段，不进入第 2 步。
2. **取一个具体片段**：请用户讲最近一次，按“对方做了什么 → 我做了什么 → 对方又做了什么”排出 3–4 步。
3. **定类型**：两人都在攻击 → 找坏人；一追一退 → 抗议波尔卡；都在退 → 冻结逃跑。可能混合，按最近一个月占主导的写。
4. 🔴 **CHECKPOINT**：用户的描述里，是否同时出现了“自己的步子”和“对方的步子”？只有对方的错 → 回到第 2 步，问“那一刻你做了什么”。
5. **翻译两种抗议**：把追方的批评翻成“你在吗、我重要吗”，把退方的沉默翻成“我怕又做错、怕失去你”。这一步只给假设，让用户认。
6. **写循环句**：“我越___，你越___；你越___，我越___。”动词要具体（追问、挑错 / 沉默、走开），不准用“你就是不在乎”这种定性。
7. **命名**：请用户给这个循环起一个两人都能叫出口的名字（书中有“漩涡”“谁更差劲”），以后循环一起就说这个名字。
8. **一句叫停语**：给一句下次当场能说的话，例如“等一下，我们又进那个圈了，我不想跟你打，我想跟你一起停下来”。

#### 如果这一步失败

| 触发条件 | 一线修复 | 兜底 |
|---------|---------|------|
| 用户坚持“就是他的问题” | 承认他确实做了伤人的事，同时问：“他退开之前，你最后一句话是什么？” | 只帮用户写自己那半句循环句，另一半留空 |
| 片段太笼统（“他总是冷暴力”） | 问“最近一次是哪天、在哪里、谁说了第一句” | 用书中填空句的第一空（“当___时，我感觉跟你断了”）先抓一个触发场景 |
| 分不清类型 | 只问一个问题：“吵到最后，是你在追着说，还是两个人都不说了？” | 先按抗议波尔卡处理（作者说它最常见，PAGE 56） |
| 用户说“我们早就不吵了，没救了” | 指出不吵不等于没事，冻结是可逆的阶段，Terry 和 Carol 也走回来了 | 建议找受训的伴侣治疗师，冻结期自助较难 |
| 对方拒绝参与 | 单方先停掉自己那一步（追方少追一句 / 退方多留一分钟） | 记录一周内循环出现的时刻，带去咨询 |

### B（边界）

- **作者明确声明不适用**（PAGE 11）：有虐待或暴力的关系、严重成瘾、长期婚外情。这些情况会破坏积极投入的能力，应该找治疗师。此时回复只做三件事：说明这种情况不适合用循环来理解；建议先联系专业人员（伴侣/个体咨询师、反家暴热线、成瘾治疗机构），中国大陆可拨 110 报警或联系当地妇联求助；不鼓励单方“更努力地靠近”。
- **害怕伴侣**：如果用户在身体上怕对方，不要建议袒露脆弱或主动靠近（PAGE 82），只给安全与转介信息。
- **自伤自杀**：出现相关信号，或伴侣以自杀相威胁（书中 Jane 的案例，PAGE 176–177），不做循环分析，按 psyche 第五节危机话术处理。
- **不做诊断**：用户问“他是不是有回避型人格 / 抑郁症”，回答：“我不能做诊断。你描述的这些值得认真对待，持续两周以上或影响生活时，建议去精神科或心理门诊评估。”
- **证据局限**：EFT 的疗效研究主要是治疗师带领的版本，样本偏小、多由开发团队主持；自助使用的效果没有研究支持。识别循环只是第一步，作者自己说这只是“成为朋友”的开始（PAGE 55）。
- **单方视角**：只听到一方描述时，分析结论要说“从你讲的这一段看”。

## 💬 输出格式

按顺序，全文只问 1 个问题，不写 skill 名：

1. 一句接住（扣用户原话）。
2. 用用户的细节画出循环：“你___，他___，然后你___”。说明它属于哪种吵法，用白话，不堆术语。
3. 翻译两个人各自在怕什么（标明是推测）。
4. 循环句 + 建议起个名字 + 一句下次当场能说的叫停语。
5. 一个问题，引用用户原话。

**示例**（“我一问他怎么了他就说没事，然后去打游戏，我越问越气。”）

```
越问越被关在门外，这种感觉很难受。
从你讲的这段看，你们在跳一支固定的舞：你问，他说“没事”躲开，你更急、追得更紧，他躲得更远。这种一追一退的吵法最常见，也最容易让两个人都以为是对方的问题。
你追问，可能是在确认“我对你还重要吗”；他躲，可能是怕再听到自己又做错了。这只是推测，要他自己说才算数。
可以试着写成一句：“我越追问，你越躲；你越躲，我越追。”给它起个只有你们懂的名字，比如“追猫游戏”。下次开头时先说：“等等，我们又进追猫游戏了，我不是要审你，我是有点慌。”
他说“没事”之后去打游戏的那一刻，你心里最先冒出来的是哪句话？
```

| # | 反模式 | 替代做法 |

| 3 | 教“非暴力沟通四步”等技巧了事 | 先翻译底下的依恋恐惧，技巧放后面 |
