# 识别恶魔对话

> 先看整场舞，再看某一步；先找循环，不找坏人。

## 🧭 决策树

```
用户在描述和伴侣的反复冲突 / 冷战
│
├── 任何安全信号？ → 🛑 E1 STOP
├── 问“我是什么依恋类型 / 要不要分手 / 该找什么样的人”？
│     └── ❌ 转 attach-style-reading / attach-anxious-avoidant-trap
├── 已经能说出循环，卡在“我为什么一碰就炸”？
│     └── ❌ 转 eft-raw-spot-deescalation
│
└── ✅ 反复的同一种吵法 / 冷战，还没看清整体 → E2–E9
      ├── 双方都在攻击、互相定性         → 找坏人
      ├── 一方追问批评、一方防守退开     → 抗议波尔卡（最常见）
      └── 双方都安静、客气、没有触碰     → 冻结逃跑（最危险，优先处理）
```


## 📥 输入与证据假设

- 需要：最近一次冲突的具体片段（谁先说了什么、各自接下来做了什么），而不是总评价（“他就是自私”）。
- 通常只听到一方的版本。分析的是“用户描述中的步子”，结论一律以“从你讲的这一段看”开头。
- 不假设谁是追方、谁是退方：按行为判断，不按性别判断（作者观察到性别倾向，但也承认因人因文化而异，PAGE 62–63）。

## 📖 RIA+E+B

### R（原文位置与转述）

- 作者认为，多数争吵其实是对情感断联的抗议；底下真正的问题是“我能依靠你吗、我对你重要吗”（PAGE 26）。
- 断联引发原始恐慌，人只有两条路：变得追逼、黏人以求回应，或退开、麻木以求自保（PAGE 27、51–52）。
- 三种恶魔对话：找坏人（互相指责）、抗议波尔卡（一方追、一方退，最常见）、冻结逃跑（双方都退，常由波尔卡演变而来，最危险）（PAGE 51）。
- 作者批评只教沟通技巧的做法，说那是在叫人 "change the steps when what they have to do is change the music"（PAGE 29）。
- 走出循环的五点：看清整场舞；明白彼此的步子怎么把对方拉进来；理解这是依恋困扰，讲道理停不下来；把循环看成敌人；两人一起给它命名（PAGE 64）。
- 用填空句描述循环，并给它起名字（PAGE 66、71–72）。

### I（白话解释）

吵什么不重要，怎么吵才重要。追的一方在喊“你看看我”，退的一方在喊“别再说我不行了”；两个人都怕失去对方，只是用了相反的方式。循环一旦自动化，谁先开始已经说不清。要做的不是赢这一局，而是两人一起指着循环说：“它又来了。”

### A1（书中案例，转述）

- **Jim 与 Pam**（PAGE 50–55）：Pam 说想多支持丈夫，Jim 翻了个白眼，几秒钟后两人互骂。作者让他们停在当下、看那个没有起点的圈。Jim 给它起名“谁更差劲”循环，两人笑了出来，然后 Jim 说出：其实他想要更多支持。
- **Mia 与 Ken**（PAGE 57–59、64）：舞会上 Ken 不跳，Mia 弯腰去挪他的腿，Ken 离场。追—冻的圈被画出来后，Ken 问“那不代表我们不合适吧？”后来他能在循环刚起时说“我们又卡住了，过来抱一下”。
- **Terry 与 Carol**（PAGE 67–70）：多年批评之后 Carol 把愤怒“咽下去”，两人客气、无接触，几乎不看对方。作者指出这种冷才是最危险的阶段。

### E（执行步骤）

1. 🛑 **STOP·安全筛查**（唯一能让整轮停下的步骤）— 输入：用户原话。核对：暴力或威胁、“我怕他”、严重成瘾、长期出轨、自伤自杀。输出：
   - 暴力、成瘾、长期出轨（作者声明不适用：它们会破坏积极投入的能力，应找治疗师，PAGE 11）→ 只做三件事，结束：①说明这种情况不适合用循环来理解；②给出去处：伴侣或个体咨询师、反家暴热线、成瘾治疗机构，中国大陆危险时拨 110 报警或联系当地妇联；③不鼓励单方“更努力地靠近”。
   - 身体上怕对方 → 不要求袒露脆弱或主动靠近（PAGE 82），只给安全与转介信息。
   - 自伤自杀，或伴侣以自杀相威胁（书中 Jane 的案例，PAGE 176–177）→ 只输出 `cross-system-hub` C5 危机话术，结束。
   - 信号模糊（“他生气时挺吓人的”）→ 本轮只问“跟他吵的时候，你会担心自己的安全吗？”，等用户回答再继续；出现过推、打、摔东西威胁，一律按本步处理，不以用户自评为准。
   - 都没有 → 第 2 步。
2. **取一个片段** — 输入：用户讲的冲突或冷淡日常。输出二选一：吵起来的 → 动作链“对方做了什么 → 我做了什么 → 对方又做了什么”；没有冲突、只有“客气/各忙各的/不碰触” → 把用户原话里的日常动作当片段（如“各自刷手机”“说话客气”）。
3. 🔴 **CHECKPOINT·定性之前** — 核对：①吵起来的是否至少 3 步动作链（有动作链、没日期 → 视为满足）；冷淡型有 2 个以上日常动作即满足；②是否同时有用户的步子和对方的步子。规则：先按已知信息继续做 E4–E9，缺的那一项用结尾唯一的问题去补——吵起来的缺① → 问“最近一次是谁先说了第一句？”；冷淡型缺① → 问“最近一次你想跟他说点什么却咽回去，是什么时候？”；缺② → 循环句里用户那半句留空，问“那一刻你做了什么？”。
4. **定类型** — 输入：动作链。输出：找坏人 / 抗议波尔卡 / 冻结逃跑之一；混合时按描述里最后一个动作定：最后有人追着说 → 抗议波尔卡；最后两人都不说 → 冻结逃跑；最后互相定性 → 找坏人。
5. **翻译两种抗议** — 输入：类型 + 动作链。输出：追方一句“可能在确认我对你还重要吗”、退方一句“可能怕又做错、怕失去你”，每句标“推测”。
6. **写循环句** — 输入：动作链里的动词。输出二选一，空格只填用户原话里的动作：吵起来的 → “我越___，你越___；你越___，我越___。”（追问、挑错 / 沉默、走开）；冷淡型 → “我越___（不说 / 客气），你越___（忙 / 不靠近）；你越___，我越___。”例：“我越客气，你越忙；你越忙，我越客气。”不出现“你就是不在乎”这类定性。
7. 🔴 **CHECKPOINT·给叫停语之前** — 核对循环句两条判据：①前半句主语是“我”（用户本人）；②不含“就是”“总是不在乎”这类定性词。不符合 → 重写第 6 步；用户坚持“就是他的问题” → 只写用户自己那半句，另一半留空。
8. **命名** — 输入：用户细节。输出：1 个 ≤ 5 字的候选名，注明“可以换成你们自己的叫法”。
9. **叫停语** — 输入：候选名。输出：1 句 ≤ 30 字、以“等一下，我们又进___了”开头的话，例如“等一下，我们又进那个圈了，我不想跟你打，我想跟你一起停下来”。冻结逃跑时改为 1 个 ≤ 30 字的主动靠近动作，例如“今晚睡前走过去说一句‘我有点想你’，不等回应”。

#### 如果这一步失败

| 触发条件 | 一线修复 | 仍失败兜底 |
|---------|---------|-----------|
| E2 信息不足：片段太笼统（“他总是冷暴力”） | 按已知的那一两步先画半个圈，结尾问“最近一次是谁说了第一句” | 用书中填空句第一空（“当___时，我感觉跟你断了”）先抓一个触发场景 |
| E3 有动作链但没有日期或第一句话 | 视为满足，直接定类型、写循环句 | 结尾问题改为“最近一次是哪天开始的”，下一轮再补细节 |
| E2/E3 冷淡型：没有冲突片段，只有“客气 / 各忙各的” | 用原话里的日常动作当片段，按冷淡型模板写循环句 | 结尾问“最近一次你想跟他说点什么却咽回去，是什么时候？” |
| E3/E7 用户否认自己有步子，坚持“就是他的问题” | 承认他确实做了伤人的事，再问：“他退开之前，你最后一句话是什么？” | 只帮用户写自己那半句循环句，另一半留空 |
| E4 用户不认同类型或分不清 | 只问：“吵到最后，是你在追着说，还是两个人都不说了？” | 按抗议波尔卡处理（作者说它最常见，PAGE 56） |
| E1 用户否认危险：“他推过我但不算暴力” | 只问安全问题，不做循环分析 | 按 E1 处理，不以用户自评为准 |
| 用户坚持越界要求：诊断对方、替他判定分不分手、写一段“骂醒他”的话 | 说明这里不做诊断和去留判断，回到“你们那一圈是怎么转的” | 诊断 → B 段“不做诊断”原话；去留 → attach-anxious-avoidant-trap |
| “我们早就不吵了，没救了” | 指出不吵不等于没事，冻结是可逆的阶段，Terry 和 Carol 也走回来了 | 冻结期自助较难，去受训的伴侣治疗师（EFT 治疗师） |
| 对方拒绝参与 | 单方先停掉自己那一步（追方少追一句 / 退方多留一分钟） | 记录一周内循环出现的时刻，带去伴侣咨询 |
| `cross-system-hub` C5 不可用 | 直接说：“你的安全最重要，现在有危险就拨 110 或 120。” | 给当地心理援助热线，并请用户把一句话发给一个信任的人：“我现在状态不好，能陪我一下吗？” |

### B（边界）

- **不做诊断**：用户问“他是不是有回避型人格 / 抑郁症”，回答：“我不能做诊断。你描述的这些值得认真对待，持续两周以上或影响生活时，去精神科或心理门诊评估。”
- **证据局限**：EFT 的疗效研究主要是治疗师带领的版本，样本偏小、多由开发团队主持；自助使用的效果没有研究支持。识别循环只是第一步，作者自己说这只是“成为朋友”的开始（PAGE 55）。

## 💬 输出格式

单轮回复执行 E1–E9（E3、E7 是内部核对，不单独输出）。除 E1 外不整轮停下：缺信息时照常给出第 1–4 条，只把第 5 条换成 E3 的补缺问题；信息齐全时，第 5 条按类型二选一：吵起来的 → 问片段里用户自己最先冒出的念头；都退开的 → 问最近一次想靠近却没开口的时刻。

严格按顺序，全文 ≤ 320 字，只在最后问 1 个问题，不写 skill 名，不说“恶魔对话/抗议波尔卡/冻结逃跑”等术语：

1. 接住（≤ 30 字），扣用户原话。用户问了字面问题（“算正常吗”“到底怎么回事”）→ 这一句先直接回答。
2. 画循环（≤ 70 字）：“你___，他___，然后你___”，再用白话说是哪种吵法（互相指责 / 一追一退 / 都退开）；都退开的 → 末尾加“这种安静比吵架更难察觉，但能走回来”。
3. 翻译双方在怕什么（≤ 60 字），每处都标“推测”。
4. 循环句 + 候选名 + 一个动作 + 一句常识（≤ 110 字），按类型二选一：
   - 吵起来的（互相指责 / 一追一退）→ 叫停语（以“等一下，我们又进___了”开头，≤ 30 字）+ “别在他刚进门或正累时开口，约好吵过二十分钟先停、第二天再聊”。
   - 都退开的 → 一个 ≤ 30 字的主动靠近动作 + “长期走不出来就去伴侣咨询”。
5. 一个问题，引用用户原话。

**示例·吵起来的**（退方视角：“她一挑我毛病我就不说话，去阳台待着，她就更火，追到阳台继续说。”）

```
你一不说话，她反而更火，夹在中间挺憋的。
从你讲的这段看：她挑毛病，你闭嘴去阳台，她追过来说得更多，你就更想躲。这是一追一退的吵法，最常见。
你躲开，可能是怕再听下去会觉得自己怎么做都不对；她追过来，可能是在确认“我说话你还在乎吗”（都是推测）。
可以写成一句：“她越说，我越躲；我越躲，她越追。”先叫它“阳台拉锯”，也可以换成你们自己的叫法。下次开头时说：“等一下，我们又进阳台拉锯了，我不是不理你，我是有点扛不住。”另外别在她正火时接话，约好吵过二十分钟先停、第二天再聊。
她开始挑毛病的那一刻，你心里最先冒出来的是哪句话？
```

**示例·都退开的**（“在一起五年，现在下班各自刷手机，周末也各过各的，很久没牵过手了，我们是不是没感情了？”）

```
不一定是没感情，更像是两个人都退开了，这很常见。
从你讲的看：下班各自刷手机，周末各过各的，谁都不先伸手。这是两个人都退开的状态，这种安静比吵架更难察觉，但能走回来。
你不伸手，可能是怕伸了没人接；他也许同样在等你先动（都是推测）。
可以写成：“我越刷手机，你越刷手机；你越各过各的，我越各过各的。”先叫它“各刷各的”，也可以换成你们自己的叫法。今晚放下手机，走过去牵一下他的手，不等回应。长期走不出来就去伴侣咨询。
你说“很久没牵过手”，最近一次你想牵却没伸手，是什么时候？
```

| 1 | 判定谁先错、谁更过分 | 循环没有起点，判对错只会让一方更防御 | 画没有起点的圈，承认双方都被困住 |
| 2 | 跟着用户逐条翻旧账（内容管道，PAGE 54） | 争的是内容，转的是同一个圈 | 只取一个片段，看步子不看是非 |

| 5 | 有暴力或恐惧时仍劝“多理解他的退缩” | 作者声明暴力关系不适用（PAGE 11），劝靠近会增加危险 | 按 E1 转介，不做循环分析 |
