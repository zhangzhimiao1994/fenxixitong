# 黄帝内经身心系统

## 被总入口调用时：段落契约

- 输入：用户原话、深度等级、本段是完整还是一句带过、总入口 STEP 0 是否已写身体警报或门槛句
- 本段必须包含：
  1. 症状：用自己的话概括原话里的身体表现（不整句再引原话）
  2. 这套说法的读法：前加"这套说法认为"，中医词只用子 skill 给出的或 hub 参考文件互译表本维度那一列已有的词，不凭记忆补（"肝气犯胃：压着的火气窜到了脾胃"）；子 skill 和互译表都没有对应的词 → 第 2 项不用中医词，只写联动
  3. 身心联动：原话里的情绪或处境怎么落到身体上（只连原话里有的两件事）
  4. 原话提到失眠/睡不好/夜醒 → 从这 3 条里给 1 条，改写得贴合原话：醒着超过 20 分钟就起床做件安静的事；每天固定起床时间；中午后不喝咖啡。这一句是常识提示，不算步骤，只放在本段位置（本段并进主要矛盾段时也单独成句留在这里）
- 一句带过时写什么：按总入口 4.4，细节取症状；写不出多一层 → 症状并进主要矛盾段做一个分句，提到睡眠时那条常识提示仍单独 1 句
- 篇幅：完整约占全文 1 成（主要矛盾在身心时约 1.5 成）；一句带过 1 句
- L1 保留：症状概括 +（提到睡眠时）1 条睡眠常识提示，并成 1–2 句
- 可提交的候选问题：⑤ 子 skill 的待问项；"持续多久"由总入口 STEP 0 统一提交，本段不另提
- 本段禁止：就医门槛句（只在总入口 STEP 0 出现一次）；诊断、药名、方剂；睡眠做法给 2 条以上；原话没有的内容（总入口 4.4；如"精力怎么也接不上""电量停在低位"）；"做个小测试"一类通用句；评论方法本身
- 本维度特有的失败分支：
  - 找不到对应子 skill（单纯失眠、夜醒；或原话对不上任何情志）→ 只写第 1、4 项，第 2 项不写（不从互译表硬配词）
  - 原话只有笼统说法（"身体垮了""很累"）、没有具体症状："身体垮了"算点名 → 完整写第 2、3 项（读法 + 原话里的情绪或处境怎么落到身体上），第 1 项只写"你说身体垮了"这一层，不编症状；只说"很累"→ 一句带过（按总入口 4.4 判据写不出就不写，不为凑一句硬套"精气"一类词）
  - 主要矛盾落在身心 → 一律按完整写
  - 胸痛、咳血、剧烈头痛、高烧、意识改变 → 已由总入口置顶"请立即就医"，本段只写一句症状概括
  - 暴力场景 → 只写第 4 项
  - "很累""崩了""没意思"归哪类 → 按 `psyche` 契约的归类表
- 选用哪些子 skill：情绪带出身体不适 → `emotion-organ-proxy` 或 `body-mind-integration`；换季 → `seasonal-regimen`；症状处理了没好 → `qi-regulation`；其余查下方目录，选 1 个
- 格式、篇幅、提问、收尾、危机话术：见总入口全局契约（单独使用时也一样）

## 使用原则

1. **自动路由**：说你的问题，系统自动匹配子 skill
2. **先诊断后行动**：先匹配子 skill 诊断，再给行动方案
3. **身心联动**：身心问题往往交织，可能跨 skill 组合使用
4. **单独使用时**：内容按段落契约写；格式、篇幅、提问、收尾见总入口全局契约；总入口里只剩本维完整时不转到这里，见总入口 STEP 1
5. 🛑 **安全筛查（先于一切）**：自伤信号 → 只执行 `cross-system-hub` C5；胸痛、咳血、剧烈头痛、高烧、意识改变 → 只写"请立即就医"，不做调理分析；失眠低落的就医门槛由总入口 STEP 0 写
