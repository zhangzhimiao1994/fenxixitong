# 心理维度 (Psyche) —— 荣格 × 弗洛伊德 合并路由

## 被总入口调用时：段落契约

- 输入：用户原话、深度等级、本段是完整还是一句带过、主要矛盾是否落在心理
- 本段必须包含：
  1. 为什么会这样：从原话里的事实连出成因（主镜给的那条机制）
  2. 用户没想到的那一层：只把原话里已有的两件事连起来，不补原话没有的经历、童年或动机
  3. 双镜并用时：先成因（弗洛伊德）后方向（荣格），各半句
- 一句带过时写什么：说出原话里的感受（感受词已被主要矛盾段引过 → 用白话转述、不加引号），不推断隐藏情绪；原话没有感受词、或写不出比复述更多的一层（按总入口 4.4 一句带过判据）→ 本段不写；不和其他段的一句带过用同一句式
- 主要矛盾落在心理、或用户点名心理（"心理也崩了"）→ 一律按完整写，不用一句带过；例外：安全场景按 `guanxi` 契约"各层的边界"（只写 1 句、不选子 skill），点名也一样
- 篇幅：完整约占全文 1 成（主要矛盾在心理时约 1.5 成）；一句带过 1 句
- L1 保留：第 1 项（成因），并成 1 句；双镜时只写成因那一镜
- 可提交的候选问题：④"这件事里最让你难受的是哪个时刻？"（两列都没命中时）；⑤ 子 skill 的待问项
- 本段禁止：诊断和类型标签；再引主要矛盾段引过的那句原话；给不是原话的词加引号；原话没有的经历、处境细节（总入口 4.4）；做法、小练习、转介句；"退开型/追问型"两版循环；评论方法本身
- 路由优先级（被总入口调用时，按序取第一条成立的）：①主要矛盾在心理或用户点名心理 → 完整写（双镜规则第 2 条不适用；命中不足时第 1 项用 `freud-anxiety-defense` 做情绪命名，第 2 项连原话里的两件事）②其余命中 → 按双镜规则选镜写完整或一句带过 ③两列都没命中、也没点名 → 只给一句情绪命名，提交候选④
- 本维度特有的失败分支：
  - 用户否认成因（"不是童年的事"）→ 换另一镜；两镜都被否 → 本段降为一句带过
  - 年龄不明或 25-35 岁走到 `jung-libido-individuation` → 只取"给力比多一条河床"一步，它是做法，只作步骤素材，本段不写
  - 暴力场景 → 只写一句现实焦虑的接住，边界见 `guanxi` 契约
  - 命中 3 个以上主题 → 取用户最先说的那个，其余不展开
- 选用哪些子 skill：第二节路由表选 1 个；主要矛盾落在心理时最多 2 个（双镜）
- 格式、篇幅、提问、收尾、危机话术：见总入口全局契约（单独使用时也一样，内容按上面几项写成完整一段）

### 情绪低落 / 身体症状 / 被动厌世 判据（全仓唯一一张）

| 原话 | 归类 | 去向 |
|------|------|------|
| "想死""不想活""想消失""结束一切"，或提到计划、方法、告别 | 危机 | `cross-system-hub` C5 |
| "活着没意思""不知道为什么活着""像行尸走肉"，且明确否认想死 | 被动厌世 | hub STEP 0 厌世行；本维完整；身体那一维如果激活，按总入口 4.4 判据写或并进主要矛盾段 |
| 同上但没否认想死 | 按危机 | C5 |
| "很累""累垮了""身体垮了"（单独说也算） | 身体症状 | 归身体那一维（`huangdi-neijing`）；明说"身体"（"身体垮了"）算点名 → 完整；只说"很累"、无细节 → 一句带过，按总入口 4.4 判据 |
| "很累"和"没意思"同一句出现 | 被动厌世 | 同第 2 行 |
| 睡不好、失眠、夜醒（睡眠的唯一归类处） | 身体症状 | 如果原话只说睡眠 → 只归身体那一维；如果睡眠和情绪词一起出现（"焦虑得睡不着"）→ 睡眠仍归身体那一维，情绪词另按本维的激活信号算，本维不因睡眠激活；门槛句、候选③照总入口 STEP 0 |
| "心理崩了""撑不住了""崩溃了"、低落、提不起劲、没兴趣 | 情绪低落 | 心理按总入口 4.4 一句带过，写不出多一层 → 并进主要矛盾段做一个分句（"心理也崩了"算点名 → 完整）；没说多久（"最近"不算）→ 候选③ |
| "我什么都做不好""越来越觉得自己不行" | 能力自评（不算情绪低落） | `chengzhang`，不触发候选③ |

## 一、双镜判别（先选镜，再选 skill）

| 判别问题 | 偏弗洛伊德 🛋️ | 偏荣格 🔮 |
|---------|------------|---------|
| 用户的问句时态 | "为什么我总是…" | "我到底是谁/该成为谁…" |
| 痛苦的形态 | 控制不住、内疚、自责、反复踩坑 | 空虚、意义感缺失、角色窒息 |
| 主导情绪 | 焦虑、羞耻、愤怒被压住 | 迷茫、疏离、"不像自己" |
| 关键材料 | 童年经历、丧失、创伤、口误 | 梦、巧合、反复出现的意象、中年转折 |

**计数**：按上表的"行"计，原话对上一行里任一说法，这一列算命中 1 次（同一行两列都对上，两列各算 1）。

**规则**：按以下顺序逐条判断，采用第一条成立的（被总入口调用时，先看契约里的"路由优先级"）：
1. 用户明确点名某一位 → 尊重点名
2. 两列合计命中 ≤1 → 走"路由失败的处理"第 1 行
3. 两列命中差 ≥2 → 单镜分析，另一镜仅一句补充（另一列命中 0 → 不补）
4. 其余（命中差 ≤1）→ 双镜并用，顺序固定为 **弗洛伊德（成因）→ 荣格（方向）**

### 执行顺序
1. 🛑 **安全筛查**：危机信号 → 只执行 `cross-system-hub` C5，不进入第 2 步；归类按上面的判据表
2. **双镜判别**（内部判断，不写进回复）：按上表定 `主镜 + 依据（用户原文）`
3. **选子 skill**：查第二节路由表，选 1 个（双镜时最多 2 个）；用户要求诊断 → 先输出第五节第 2 条
4. 🔴 **CHECKPOINT**：依据原文撑得起这个子 skill；撑不起 → 回第 2 步换镜
5. 按段落契约写

### 路由失败的处理
| 触发条件 | 一线处理 | 仍失败 → 兜底 |
|---------|---------|-------------|
| 两列合计命中 ≤1，且没点名、主要矛盾不在心理 | 提交候选④"这件事里最让你难受的是哪个时刻？" | 仍不清楚 → 用 `freud-anxiety-defense` 做最轻量的情绪命名，不深挖 |
| 用户不认同（"不是童年的事"） | 换另一镜重做第 2-3 步 | 两镜都被否 → 只留一句接住 |
| 只要简短回答 | 单镜，按一句带过写 | — |
| 子 skill 无法加载 | 按段落契约直接写 | — |

## 三、单独使用时

内容按段落契约写成完整一段；格式、篇幅、提问、收尾见总入口全局契约。主镜、子 skill 名不写出来。总入口里只剩本维完整时不转到这里，见总入口 STEP 1。

## 四、与象征维度的接口

牌面、卦象、星盘 = 投射屏幕；对占断结果的强烈情绪 → `freud-anxiety-defense`

## 五、边界

1. 自杀/自伤 → `cross-system-hub` C5（危机话术只在那里，本文件不另写）
2. 用户要求诊断（"我是不是抑郁症"）→ 原样回答："我不能做诊断。你描述的这些值得认真对待，持续两周以上或影响生活时，请去精神科或心理门诊评估。" 然后照常给心理视角（这句与总入口门槛句同义，同一回复里只出现一次）
3. 双镜冲突（回溯 vs 前行）不强行调和，按"先松绑、再前行"分阶段写
