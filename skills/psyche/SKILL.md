# 心理维度 (Psyche) —— 荣格 × 弗洛伊德 合并路由

> 弗洛伊德看"为什么会这样"（向后看），荣格看"正在成为谁"（向前看）。本文件只做路由，不新增理论主张。

## 一、双镜判别（先选镜，再选 skill）

| 判别问题 | 偏弗洛伊德 🛋️ | 偏荣格 🔮 |
|---------|------------|---------|
| 用户的问句时态 | "为什么我总是…" | "我到底是谁/该成为谁…" |
| 痛苦的形态 | 控制不住、内疚、自责、反复踩坑 | 空虚、意义感缺失、角色窒息 |
| 主导情绪 | 焦虑、羞耻、愤怒被压住 | 迷茫、疏离、"不像自己" |
| 关键材料 | 童年经历、丧失、创伤、口误 | 梦、巧合、反复出现的意象、中年转折 |

**规则**：
- 按顺序判断，命中即停：两列合计命中 ≤1 → 走"路由失败的处理"第 1 行
- 两列命中差 ≥2 → 单镜分析，另一镜仅一句补充
- 命中差 ≤1 → 双镜并用，输出顺序固定为 **弗洛伊德（成因）→ 荣格（方向）**，先松绑再前行
- 用户明确点名某一位 → 尊重点名

### 执行顺序
1. **安全筛查**：出现"不想活/想消失/结束一切/伤害自己"等信号 → 🛑 **STOP**，执行第五节危机话术，不进入第 2 步
2. **双镜判别**：按上表计两列命中数，输出 `主镜: 弗洛伊德/荣格/双镜 | 依据: [用户原文]`
3. **选子 skill**：查第二节路由表，选 1 个（双镜时最多 2 个）；用户要求诊断 → 先输出第五节第 2 条
4. 🔴 **CHECKPOINT**：命中 3 个以上主题时，先问用户"最想先谈哪一个？"，等回答再继续
5. 按第三节格式输出

### 路由失败的处理
| 触发条件 | 一线处理 | 仍失败 → 兜底 |
|---------|---------|-------------|
| 两列都没有命中 | 问 1 个澄清问题："这件事里最让你难受的是什么时刻？" | 仍不清楚 → 用 `freud-anxiety-defense` 做最轻量的情绪命名，不深挖 |
| 用户不认同所选镜头（"不是童年的事"） | 换另一镜重做第 2-3 步 | 两镜都被否 → 承认"可能不适合用心理框架"，只给 1 个情绪落地行动 |
| 用户只要简短回答 | 单镜，只输出视角 + 行动各 1 句 | — |
| 子 skill 文件不存在或无法加载 | 用本文件第三节格式直接输出，标注"未调用子 skill" | — |

## 三、输出格式

给用户看的回复：先 1 句接住感受 → 用大白话给 2-3 种可能的解释（"可能是…也可能是…"）→ 1 个用户没想到的角度 → 1 个今天能做的行动 → 1 个引用用户原话的问题。主镜、子 skill 名称只在内部用，不写出来。

**示例**（"为什么我每段感情都会在同一个地方崩掉？"）
```
每次都在同一处崩掉，会让人很挫败，也会开始怀疑自己。这通常不是运气，而是一个在重复的模式。
可能的原因有几种：关系变近时旧的不安被触发；你习惯的相处方式在某个阶段不再管用；或者你会被同一类人吸引。
容易忽略的一点：崩掉的那一刻，往往正是关系开始变得重要的时候。
今天可以做：写下最近三段关系"开始崩"的那一刻，你当时在想什么。
你说的"同一个地方"，通常是关系里的哪个时刻？
```

## 四、与象征维度（塔罗 / 运势 / 周易）的接口

牌面、卦象、星盘 = 投射屏幕（问"你第一反应是什么"）；对占断结果的强烈情绪 → `freud-anxiety-defense`

## 五、边界

1. 🛑 **自杀/自伤意念 → 立即停止分析**，按 `cross-system-hub` 的 C5 四要素回应：温暖接住 → 问"你现在安全吗？有没有想过具体怎么做、身边有没有可能伤害自己的东西？"（有就请对方先放远、别独处）→ 热线 12356 / 400-161-9995 / 010-82951332，紧急拨 120/110 → "愿意的话继续跟我说，我在。" 之后不做心理分析；答"不安全"或拒绝联系 → 重复 120/110，请对方马上联系身边的人
2. 用户要求诊断（"我是不是抑郁症"）→ 原样回答："我不能做诊断。你描述的这些值得认真对待，持续两周以上或影响生活时，建议去精神科或心理门诊评估。" 然后照常给心理视角
3. 双镜冲突（回溯 vs 前行）不强行调和，交由 Hub 的张力检测做阶段化处理
