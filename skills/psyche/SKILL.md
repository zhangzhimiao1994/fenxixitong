# 心理维度 (Psyche) —— 荣格 × 弗洛伊德 合并路由

> 弗洛伊德看"为什么会这样"（向后看），荣格看"正在成为谁"（向前看）。本文件只做路由，不新增理论主张。

## 一、双镜判别（先选镜，再选 skill）

| 判别问题 | 偏弗洛伊德 🛋️ | 偏荣格 🔮 |
|---------|------------|---------|
| 用户的问句时态 | "为什么我总是…" | "我到底是谁/该成为谁…" |
| 痛苦的形态 | 控制不住、内疚、自责、反复踩坑 | 空虚、意义感缺失、角色窒息 |
| 主导情绪 | 焦虑、羞耻、愤怒被压住 | 迷茫、疏离、"不像自己" |
| 关键材料 | 童年经历、丧失、创伤、口误 | 梦、巧合、反复出现的意象、中年转折 |

**规则**：
- 两列合计命中 ≤1 → 走"路由失败的处理"第 1 行
- 两列命中差 ≥2 → 单镜分析，另一镜仅一句补充
- 命中接近 → 双镜并用，输出顺序固定为 **弗洛伊德（成因）→ 荣格（方向）**，先松绑再前行
- 用户明确点名某一位 → 尊重点名

### 执行顺序
1. **安全筛查**：出现"不想活/想消失/结束一切/伤害自己"等信号 → 🛑 **STOP**，执行第五节危机话术，不进入第 2 步
2. **双镜判别**：按上表计两列命中数，输出 `主镜: 弗洛伊德/荣格/双镜 | 依据: [用户原文]`
3. **选子 skill**：查第二节路由表，选 1 个（双镜时最多 2 个）
4. 🔴 **CHECKPOINT**：命中 3 个以上主题时，先问用户"最想先谈哪一个？"，等回答再继续
5. 按第三节格式输出

### 路由失败的处理
| 触发条件 | 一线处理 | 仍失败 → 兜底 |
|---------|---------|-------------|
| 两列都没有命中 | 问 1 个澄清问题："这件事里最让你难受的是什么时刻？" | 仍不清楚 → 用 `freud-anxiety-defense` 做最轻量的情绪命名，不深挖 |
| 用户不认同所选镜头（"不是童年的事"） | 换另一镜重做第 2-3 步 | 两镜都被否 → 承认"可能不适合用心理框架"，只给 1 个情绪落地行动 |
| 子 skill 文件不存在或无法加载 | 用本文件第三节格式直接输出，标注"未调用子 skill" | — |

## 三、输出格式

```
【心理】主镜: 弗洛伊德/荣格/双镜 | 子 skill: [名称]
  视角: [成因或方向，1-2 句]
  洞察: [用户没意识到的那一层]
  行动: [1 个 5 分钟内可开始的最小行动]
  提问: [1 个把洞察交还给用户的问题，引用用户原话]
```
不写权重（被 Hub 调用时由 Hub 内部记录）。

**示例**（"为什么我每段感情都会在同一个地方崩掉？"）
```
【心理】主镜: 弗洛伊德 | 子 skill: freud-death-drive-repetition
  视角: 每次在同一个位置崩掉，说明这不是运气，而是一个在重复的模式。
  洞察: 重复往往发生在"关系开始变得重要"的那个节点——越靠近，越触发旧的不安。
  行动: 写下最近三段关系各自"开始崩"的那一刻，你当时在想什么。
  提问: 你说"同一个地方"——那个地方通常是关系里的哪个时刻？
```

## 四、与象征维度（塔罗 / 运势 / 周易）的接口

- 牌面、卦象、星盘意象 = **投射屏幕**：问"你第一反应是什么"，不问"它决定了什么"；禁止用荣格为占卜背书
- 用户对占断结果的强烈情绪（恐惧、反复求证）是心理材料 → `freud-anxiety-defense` / `jung-complex-archetype`

## 五、边界

1. 🛑 **自杀/自伤意念 → 立即停止分析**，原样输出：
   > 我听到你正在经历非常痛苦的时刻，我想先确认你的安全。你现在安全吗？
   > 可以马上联系：全国心理援助热线 12356；希望24热线 400-161-9995；北京心理危机研究与干预中心 010-82951332。紧急情况请拨 120 / 110，或去最近医院急诊。（中国大陆以外请使用当地热线）
   > 也请尽快联系一位你信任的人陪着你。

   之后不做任何心理分析。用户答"安全" → 只问一个陪伴性问题（"现在身边有人吗？"），本次对话不再回到分析；答"不安全"或拒绝联系 → 重复 120/110，请对方马上联系身边的人
2. 不做精神疾病诊断，不贴"人格障碍""抑郁症"标签；持续两周以上的显著功能受损 → 建议专业心理/精神科评估
3. 双镜冲突（回溯 vs 前行）不强行调和，交由 Hub 的张力检测做阶段化处理
