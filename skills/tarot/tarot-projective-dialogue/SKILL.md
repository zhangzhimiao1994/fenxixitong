# Tarot Projective Dialogue — 投射式对话

## R — 来源
- RWS 牌面是细节丰富的叙事图像（人物、动作、背景），天然适合作为投射刺激物
- 荣格"积极想象"：与意象对话以接触无意识内容（见本仓库 `jung-complex-archetype`）
- 注：荣格本人对塔罗有零星论述，但**不存在"荣格证明塔罗有效"的结论**，禁止如此表述

## I — 方法论骨架

**核心转换**：从"这张牌是什么意思" → "你在这张牌里看到了什么"

### 五个投射问题（按顺序，最多问 3 个）
1. **第一眼**："看到这张牌，你第一眼注意到画面上的什么？"
2. **身份**："如果你是画里的某个人/物，你是谁？此刻在想什么？"
3. **情绪**："这张牌让你身体哪里有感觉？是什么情绪？"
4. **故事**："画面的下一秒会发生什么？"
5. **对话**："如果这个人物能对你说一句话，他会说什么？"

### 反应类型与路由
| 用户反应 | 心理信号 | 处理 |
|---------|---------|------|
| 恐惧/抗拒某张牌 | 触及回避的议题 | 问"这张牌最可怕的部分像你生活里的什么？"→ 可联动 `freud-anxiety-defense` |
| "太准了" | 牌面命中了已有判断 | 问"你其实早就知道的是什么？"——把功劳还给用户 |
| 想重抽 | 想要的答案与牌面冲突 | 问"你希望抽到哪张？"——愿望即答案 |
| 强烈画面感/联想 | 情结被激活 | 联动 `jung-complex-archetype` |
| 无感 | 问题不对或防御 | 回到 `tarot-draw-protocol` 重新校准问题 |

## A1 — 应用案例
- **用户**："抽到高塔，心里咯噔一下，好怕。"
- **对话**："画面里塔顶被闪电击中，有人在往下坠。你第一眼看到的是闪电、坠落的人，还是那座塔？" → 用户："塔。它看起来很坚固但其实是空的。" → "你生活里有什么看起来很坚固、但你知道里面是空的？" → 用户："我的婚姻。" → 这才是真正的议题，交给 Hub 的心理维度
- **关键**：模型没有说"高塔代表婚姻破裂"，是用户自己说出的

## E — 执行步骤
0. **先承接情绪**：用 1 句话接住用户的感受（例："看到这张牌心里一紧，这个反应很真实。"），再提问
1. 识别反应类型（见上表）
2. 选 1 个投射问题提出
   🔴 **CHECKPOINT 🛑**：问完即停，等用户回答；**一轮只问一个问题**，最多进行 3 轮
3. 复述用户的话（用用户的词，不换成术语）
4. 指出"这是你自己看见的"，把洞察归属给用户
5. 若触及深层议题 → 标记给 Hub 的心理维度（`psyche`），提升其权重 +1
6. 若出现危机信号 → 立即停止，执行 `cross-system-hub` 的 C5 危机话术

## B — 边界与 Fallback

| 触发条件 | 一线处理 | 仍失败 → 兜底 |
|---------|---------|-------------|
| 用户说"不想继续/不想说了" | 立即停止，原样输出收尾句："好，我们就停在这里。你愿意的时候随时可以再聊。" 不再提问 | — |
| 用户对投射问题没有联想（"不知道""没感觉"） | 换用问题 4（"画面的下一秒会发生什么？"），只换一次 | 仍无联想 → 停止投射，回到 `tarot-card-meaning` 给标准释义 |
| 用户只想要标准牌义 | 转 `tarot-card-meaning` | — |
| 用户的联想指向创伤或强烈痛苦 | 放慢，只复述不追问，询问"要继续吗？" | 痛苦持续 → 建议专业心理咨询；有危机信号 → C5 |
| 用户问"荣格是不是证明了塔罗是准的" | 纠正：共时性描述的是体验，不是预测机制 | — |

- 不做心理治疗，只做觉察引导；持续痛苦 → 输出专业咨询提示
- 不诱导：问题必须开放，禁止"这是不是让你想到你父亲？"式的暗示
- 失败模式：模型替用户"投射"（"我觉得这张牌是在说你…"）
