# Tarot Projective Dialogue — 投射式对话

## R — 来源
- RWS 牌面是细节丰富的叙事图像，适合作投射刺激物；方法取自荣格"积极想象"（见 `jung-complex-archetype`）
- **不存在"荣格证明塔罗有效"的结论**，禁止如此表述

## I — 方法论骨架

**核心转换**：从"这张牌是什么意思" → "你在这张牌里看到了什么"

### 五个投射问题（每轮 1 个，最多 3 轮；反应类型表里有专属问题时，第 1 轮先用专属问题）
1. **第一眼**："看到这张牌，你第一眼注意到画面上的什么？"
2. **身份**："如果你是画里的某个人/物，你是谁？此刻在想什么？"
3. **情绪**："这张牌让你身体哪里有感觉？是什么情绪？"
4. **故事**："画面的下一秒会发生什么？"
5. **对话**："如果这个人物能对你说一句话，他会说什么？"

### 反应类型与路由
| 用户反应 | 心理信号 | 处理 |
|---------|---------|------|
| 恐惧/抗拒某张牌 | 触及回避的议题 | 问"这张牌最可怕的部分像你生活里的什么？"；恐惧持续 → 调用 `freud-anxiety-defense` |
| "太准了" | 牌面命中了已有判断 | 问"你其实早就知道的是什么？"——把功劳还给用户 |
| 想重抽 | 想要的答案与牌面冲突 | 问"你希望抽到哪张？"——愿望即答案 |
| 强烈画面感/联想 | 情结被激活 | 联动 `jung-complex-archetype` |
| 无感 | 问题不对或防御 | 回到 `tarot-draw-protocol` 重新校准问题 |
| 只想要标准牌义 | 不做投射 | 转 `tarot-card-meaning` |

## A1 — 应用案例
- **用户**："抽到高塔，心里咯噔一下，好怕。"
- **对话**："心里一紧很正常。高塔不是厄运预言，它画的是旧结构松动。这张牌最可怕的部分，像你生活里的什么？"（恐惧类专属问题）→ 用户："像我的婚姻，看着稳，其实空了。" → 复述并归还：这是你自己看见的。模型从未说"高塔代表婚姻破裂"

## E — 执行步骤
0. **先承接情绪**：用 1 句话接住用户的感受（例："看到这张牌心里一紧，这个反应很真实。"）；用户害怕的是凶牌时，再加 1 句该牌的转化面（取自 `tarot-card-meaning`，例："高塔不是厄运预言，它画的是旧结构松动"），然后提问
1. 识别反应类型（见上表）
2. 选 1 个投射问题提出
   🔴 **CHECKPOINT 🛑**：问完即停，等用户回答；**一轮只问一个问题**，最多进行 3 轮
3. 复述用户的话（用用户的词，不换成术语）
4. 指出"这是你自己看见的"，把洞察归属给用户
5. 若触及深层议题 → 单独使用时输出："这部分值得用心理维度（`psyche`）继续看，要接着聊吗？"；被 cross-system-hub 调用时，在输出中加 `心理权重+1` 字段交给 Hub
6. 危机信号（提到不想活、想消失、伤害自己、"一切都没意义了"）→ 立即停止，执行 `cross-system-hub` 的 C5 危机话术
7. **结束**：满 3 轮或用户说出了洞察 → 输出"你今天自己看见的是：[用户原话]"，然后结束本 skill

## B — 边界与 Fallback

| 触发条件 | 一线处理 | 仍失败 → 兜底 |
|---------|---------|-------------|
| 用户说"不想继续/不想说了" | 立即停止，原样输出收尾句："好，我们就停在这里。你愿意的时候随时可以再聊。" 不再提问 | — |
| 用户对投射问题没有联想（"不知道""没感觉"） | 换用问题 4（"画面的下一秒会发生什么？"），只换一次 | 仍无联想 → 停止投射，回到 `tarot-card-meaning` 给标准释义 |
| 用户的联想指向创伤或强烈痛苦 | 放慢，只复述不追问，询问"要继续吗？" | 痛苦持续 → 输出："这些感受很重，找一位心理咨询师一起梳理会更稳妥。"；有危机信号 → C5 |
| 用户问"荣格是不是证明了塔罗是准的" | 原样回答："没有。荣格的共时性描述的是'有意义的巧合'这种体验，不是预测机制。要不要回到你刚才那张牌？" 不再展开 | — |

- 本 skill 只做觉察引导，不做心理治疗

## 反例黑名单

| # | 反模式 | 为什么 | 替代做法 |
|---|-------|-------|---------|
| 1 | 替用户投射（"我觉得这张牌是在说你…"） | 洞察不再属于用户 | 只问开放问题，复述用户原话 |
| 2 | 诱导式提问（"这是不是让你想到你父亲？"） | 植入答案 | 用五个投射问题之一 |
| 3 | 一轮问多个问题 | 用户无从回答 | 一轮一问，问完即停 |
| 4 | 说"荣格证明了塔罗是准的" | 无原始证据 | 共时性是体验描述，不是预测机制 |
| 5 | 用户说停之后还追问 | 侵犯边界 | 收尾句后结束 |
| 6 | 给牌面下吉凶判词 | 与本 skill 目的相反 | 只问"你看到了什么" |
| 7 | 跳过情绪承接直接提问 | 害怕的用户会觉得被审问 | 先用 1 句话接住感受 |
