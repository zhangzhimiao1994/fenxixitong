# 让人害怕的牌：可挑的"带出口"画面细节（tarot-projective-dialogue 参考）

依据 RWS（Pamela Colman Smith 绘）的画面。第 0 步承接恐惧时，从"带出口的细节"里挑 1 个与用户处境相关的，**只描述画面，不替用户解释**；"会加重恐惧的细节"不主动提。

| 牌 | 带出口的细节（可挑） | 会加重恐惧的细节（不主动提） |
|----|------------------|-----------------------|
| 高塔 | 塔是被闪电打开的，打开后能看见外面的天空 | 坠落的人、火焰 |
| 死神 | 远处两座塔之间升起的太阳；旗上是一朵白玫瑰 | 倒下的国王、骷髅 |
| 恶魔 | 两个人脖子上的锁链很松，抬手就能摘下 | 恶魔本身、角与尾巴 |
| 月亮 | 一条小路从水边一直通向远山 | 嚎叫的狗与狼、从水里爬出的龙虾 |
| 宝剑十 | 远处的地平线正在破晓，水面是平静的 | 背上的十把剑 |
| 宝剑三 | 背景是雨云——雨会停 | 刺穿心脏的剑 |
| 宝剑九 | 被子上绣着玫瑰和星座，人是从梦里坐起来的 | 墙上的九把剑 |
| 圣杯五 | 身后还有两只立着的杯子；远处有桥通向房子 | 倒下的三只杯子 |
| 倒吊人 | 头顶有光环，表情平静 | 倒挂的姿势 |

用法示例：用户怕抽到恶魔 → "画面里两个人脖子上的锁链其实很松。" 然后问投射问题，不接着解释"这说明你可以摆脱"。

画面以用户手上的牌为准：用户用的不是 RWS 系牌套时，请用户描述画面，不套用本表。
