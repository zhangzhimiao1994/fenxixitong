# Tarot Spread Synthesis — 牌阵综合

## R — 来源
- Waite 凯尔特法按位置逐张读、以第 10 张为汇总点（Part III §7）；先浏览整体再细读（§8）✅
- 元素分布、大牌比例等统计法为后世通行实践（inference）

## I — 方法论骨架：四层扫描

| 层 | 看什么 | 意味着 |
|---|-------|-------|
| 1. 大牌比例 | 大阿卡纳占比 | >50%：人生层面的议题；1-50%：日常事务中夹着一个深层主题（找出那张大牌）；0 张：日常可控层面 |
| 2. 元素分布 | 四花色数量（圣杯 = 情感关系，宝剑 = 思维冲突，权杖 = 行动热情，星币 = 物质身体） | 某元素缺席 = 该领域被忽视；某元素过半 = 主战场 |
| 3. 重复信号 | 同数字/同宫廷出现 ≥2 | 该阶段（如多个 5 = 冲突期）被强调 |
| 4. 正逆比例 | 逆位占比 | >50%：能量普遍受阻/内化，先处理内在再谈行动；≤50%：照常读 |

牌数 ≤3 时只做第 2、4 层；第 2 层只看"问题领域对应的元素是否缺席"（如问感情却 0 张圣杯），其他元素缺席是样本太少，不提。

然后做**叙事线**：按位置顺序讲一个"起-承-转-落"的故事，并找出**关键张**（最能改变走向的那张）：

| 牌阵 | 候选位置 |
|------|---------|
| 三张 | 第 2"现在"、第 3"趋势"（过去已发生，不作关键张） |
| 关系五张 | 第 4"阻碍"、第 5"建议" |
| 凯尔特十字 | 第 2"交叉"、第 7"自我态度"、第 10"将来" |

在候选中按顺序挑：① 逆位优先 ② 元素与问题领域一致（问"整体状态"时跳过）③ 仍并列 → 用户现在最能着手改变的那张。给用户只讲这张牌为什么关键，不讲挑选规则。

## A1 — 应用案例

**三张牌：问"要不要换城市"**
- 过去：圣杯六正位｜现在：宝剑二逆位｜趋势：VII 战车正位
- 扫描：1/3 大牌（日常决定里夹着一个"往前走"的深层主题）；水→风→大牌（从怀旧情感 → 犹豫不决 → 意志驱动）；1/3 逆位
- 叙事线："对熟悉环境的眷恋（圣杯六）→ 现在的僵持开始松动、不得不选（宝剑二逆）→ 一旦选定，会有统合力量往前冲的势头（战车）"
- 关键张：宝剑二逆 —— 拖延已经撑不住了，选择本身比选哪个更重要
- 镜子问题："如果明天必须给出答案，你嘴里先说出的是哪个？"
- 最小行动：把留下和离开各写 3 条理由，圈出你最不愿承认的那一条

## E — 执行步骤

1. 列出所有牌面（位置 · 牌名 · 正逆），确认来自 `tarot-draw-protocol`
   🔴 **CHECKPOINT**：牌面缺位置或正逆 → 先追问一次再做统计；仍缺 → 按 B 表默认并标注
2. 四层扫描，输出统计结论（每层 1 句）
3. 逐位置简读（每张 ≤1 句，引用 `tarot-card-meaning` 结论）
4. 叙事线：起-承-转-落，≤4 句
5. 确定关键张，理由落到用户的问题上（"它关系到你问的 X"）
6. 输出用自然段落（不用代码块；前提假设最多 1 行，逐张简读并入叙事线），按序：象征主线（1-2 句）→ 关键张及原因 → 元素提示（缺席时镜子问题优先问这个领域）→ 1 个镜子问题 → 5 分钟可开始的最小行动 → "这是象征叙事，不是预测"
7. 🔴 **CHECKPOINT**：问用户"哪张牌让你最有感觉？"→ 进入 `tarot-projective-dialogue`

## B — 边界与 Fallback

| 触发条件 | 一线处理 | 仍失败 → 兜底 |
|---------|---------|-------------|
| 用户说"抽好了"但没列出牌面 | 先回应用户话里已有的信息（如"全是好牌"→ 按下方全吉行给出镜子问题和小行动），再请用户按 `位置 · 牌名 · 正逆` 列出 | 用户还没抽 → 转 `tarot-draw-protocol`（可用 `python tools/divine.py tarot --spread cross`） |
| 牌面不全（缺位置或正逆） | 追问一次 | 仍缺 → 正逆按正位读、位置按牌阵默认顺序，并标注 |
| 用户抽牌前没有明确问题 | 在扫描**之前**用 1 句问"这次你想看的是哪件事？"，同轮先按"当下整体状态"读完，关键张和镜子问题落到用户处境上 | 用户说"随便看看" → 维持整体状态读法 |
| 牌面信号互相矛盾 | 不强行统一，说"牌阵呈现了两种力量的拉扯" | 镜子问题问"这两股力量，你现在更站在哪一边？" |
| 全是凶牌 | 先问一句"看到这组牌你现在心里怎么样？"，再找转化面最强的一张（`tarot-card-meaning` 转化面列最贴近用户问题的）作为出口 | 用户明显恐慌 → 转 `tarot-projective-dialogue`；危机信号 → `cross-system-hub` C5 |
| 全是吉牌，用户要求"确认会成功" | 提醒"牌面顺利≠结果保证，它说的是你的状态有利"；牌面已列 → 关键张选最需要付出努力的那张；未列 → 结尾只问 1 句"这次想成的是什么事？顺便把牌按'位置 · 牌名 · 正逆'发我"；都给镜子问题"成功需要你做到哪一件事？"+ 最小行动 | — |
| 用户认为"不准" | 不辩护。问"哪里不像？"——不像的部分同样有信息 | 用户说明后：以用户描述的现实为准，只重写叙事线和镜子问题，不重抽、不改牌义 |

## 反例黑名单

| # | 反模式 | 为什么 | 替代做法 |
|---|-------|-------|---------|
| 1 | 逐张背词条，没有叙事线 | 没有整体判断 | 起-承-转-落 ≤4 句 |
| 2 | "趋势"位说成"结果注定" | 宿命化 | "按当前态势，可能走向…" |
| 3 | 忽略元素缺席（问感情 0 张圣杯） | 漏掉信息 | 写出缺席项 |
| 4 | 牌面不全照样统计 | 结论失真 | 补齐或标注 |
| 5 | 逆位一律读成"坏" | 逆位有三种读法 | 按 `tarot-card-meaning` 规则 |
| 6 | 一轮问多个镜子问题 | 无从回答 | 只问 1 个 |
| 7 | 省略"这是象征叙事，不是预测" | 被当成预言 | 每次保留 |
