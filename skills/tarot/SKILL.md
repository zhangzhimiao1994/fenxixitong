# 塔罗象征系统 (Tarot)

## 被总入口调用时：段落契约

- 输入：用户原话、深度等级、工具摘录（或用户报的牌）、总入口 STEP 0 的结果（普通 / ⚖️ / 暴力 / 经济施压 / 被动厌世）
- 取数：`python tools/divine.py tarot --spread <牌阵>`（仓库根目录运行），或用户自抽报牌；禁止模型自己"想"出牌。牌阵按深度表的象征规模对应：最小 = `single`、标准 = `three`、最大 = `cross`；用户说了张数以用户为准；已知有对象的两人关系 → `relation`；⚖️、暴力、经济施压 → 一律 `--spread stakes`
- 本段必须包含：
  1. 段首固定顺序（可以并成一句）：工具摘录行（"工具抽到：…"，原样，不计正文）→ 改写后的问题半句（"这次看的是：…"）→ 场景半句（`stakes`："这几张只照见心态，不给方向"；暴力场景问"能不能过下去"："牌给不出能不能过下去的答案"）
  2. 逐张读法，按牌阵：
     - 单张：牌名·正逆 + 画面里一个细节 + 落到所问领域的一种读法
     - 三张 / 关系五张：每张一个分句"位置·牌名：短语"，短语 = 牌义里一个词 + 原话里一个细节，分号连成 1 句；对不上写"这张和你说的关系不明显"
     - `stakes`：怕 / 期待 / 忽略三个位置，每个 = 牌义里一个贴近的词 + 原话里一个细节（不只复述原话）；转折类牌（命运之轮、死神、高塔、宝剑八）只读成此刻的感受；暴力、经济施压时的位置边界见 `guanxi` 契约
     - 十字：只逐张写 `tarot-spread-synthesis` 的 3 个关键候选位置（2 交叉、7 自我态度、10 将来），其余 7 张不逐张写
  3. 关键张 + 原因（三张以上）：放在逐张分句之后、读法句之前，半句"其中[位置·牌名]最关键，它关系到你问的[事]"；挑法按 `tarot-spread-synthesis` 第 5 步
  4. 1 句"一种读法是……"；凶牌在这里带半句转化面
- 被动厌世档：照常抽，只读心态；趋势位写"照现在的状态，心里会……"；趋势位是正面牌 → 写"如果先给自己留一点余地，心里会……"，不写"撑下去"
- 一句带过时写什么：只点名牌面 + 一种读法，并成 1 句
- 篇幅：完整约占全文 1 成，且不长于主要矛盾所在维度那段；工具摘录行不计
- 可提交的候选问题：②"要不要抽几张牌看看"（用户想用象征看、没点名哪种）；④ C8 的"你最希望和最害怕的结果是什么？"；⑤ 镜子问题（`tarot-spread-synthesis` 第 7 步）、"哪张牌让你最有感觉"
- 本段禁止：段内提问；确定预言；在 ⚖️、暴力场景读出去留方向（"该辞""时机到了""随时能走"）；方法说明（"按 X 读逆位""这是随机工具抽的，不是我挑的"）；权重、【】标签；再复述原话整句；做法；免责句（只在总入口收尾行说一次，只问牌义时也一样）
- 本维度特有的失败分支：
  - 危机信号下用户要求抽牌 → 不抽，只执行 `cross-system-hub` C5；C5 第 1 条那半句"这次先不看这些，我更想先陪着你"就是对抽牌请求的回应
  - 情绪崩溃中要求抽牌（"受不了了""崩溃了"），没有危机信号 → 本轮先承接情绪，不抽，提交候选②
  - 要重抽、换方法算同一件事（C8）→ 不重抽：1 句接住 + 《蒙》"再三渎"（再抽是在找想要的答案）+ 已有那张牌的转化面；问题真正变了 → 抽一次并注明"新问题"
  - "刚才那几张牌"不在上下文（C11）→ 请用户贴出，不凭记忆重建
  - `divine.py` 运行失败 → 请用户用实体牌或 App 自抽报牌；也无法抽 → 本段不写
  - 坚持问"会不会" → 可抽，场景半句写"牌面呈现态势，不给是/否"；只要是/否 → 不抽
  - 只问牌义（"宝剑三逆位什么意思"）→ 不走总入口，直接 `tarot-card-meaning`；用户带着害怕问 → 第一句先答"不是坏事的预告"
- 选用哪些子 skill：改写问题、选牌阵 → `tarot-draw-protocol`；逐张 → `tarot-card-meaning`；三张以上的关键张和读法 → `tarot-spread-synthesis`；恐惧、强烈反应 → `tarot-projective-dialogue`
- 格式、篇幅、提问、收尾、危机话术：见总入口全局契约（单独使用时也一样）

> evidence: 已对照 Waite 原著；四花色元素、宫廷牌梯度为后世体系（子 skill 中已标注）

塔罗是**结构化的投射工具**：牌是随机的，意义由用户带来。输出"这张牌邀请你看什么"，不说"会发生什么"（接口见 `psyche`）。

## 标准链路（子 skill 均在本目录下；每步的输入 → 输出）

| 步 | 子 skill | 输入 | 输出 | 关卡 |
|---|---------|------|------|------|
| 1 | `tarot-draw-protocol` | 用户原问题 | 改写后的问题 + 牌阵名（选阵规则只在 `tarot-draw-protocol` 第 4 步） | 封闭问题（会不会/能不能）改写后直接抽，不等确认 |
| 2 | `tarot-draw-protocol` | 问题 + 牌阵 | `[位置] 牌名·正逆` 列表 + 来源 | 🛑 抽完不停，直接进入第 3 步 |
| 3 | `tarot-card-meaning` | 牌面列表 + 问题领域 | 每张一个短语素材 | — |
| 4 | `tarot-spread-synthesis` | 第 3 步结果 | 关键张 + 读法 + 镜子问题素材 | 单张跳过本步 |
| 5 | `tarot-projective-dialogue` | 用户对某张牌的反应 | 用户自己说出的洞察 | 下一轮才进入 |

- 用户说"帮我看看/用塔罗看看" = 请你代抽，直接运行工具
- 感情问题没说是否有对象 → 按 three 读，改写的问题半句里写"先按你现在的状态来读"；"在一起或已分开有出入"并进收尾行的核对半句
- 跳步：单张跳过第 4 步；只问牌义只走第 3 步；带着已抽好的牌来 → 从第 3 步开始（带着恐惧 → 先走 `tarot-projective-dialogue` 第 0 步的承接）

内容按段落契约写；格式、篇幅、提问、收尾见总入口全局契约。

## 使用原则

1. **问题先行**：封闭问题先改写再抽（"会不会" → "我需要看见什么"）
2. **随机必须真实**：用户自抽 > `python tools/divine.py tarot` > 不抽。**禁止模型自己"想"出牌面**
3. **一事一抽**：同一问题不重复抽（《蒙》："初筮告，再三渎，渎则不告"），想重抽本身就是心理材料
4. **用户的解读优先**：用户对牌面的直觉联想 > 书本释义

## 反例清单

| 反例 | 为什么 | 替代方案 |
|------|-------|---------|
| "塔罗说你们会分手"（确定预言） | 宿命化、制造恐惧 | "这组牌照见的是关系里的 X 张力" |
| 模型直接"抽"出牌，或提出"我随机给你几张" | 等于模型挑牌 | 用户自抽或运行工具 |
| 同一问题第 3 次抽 | 在找想要的答案 | 停止抽牌，按 C8 |
| 用塔罗判断是否就医/投资 | 高风险决策 | 只允许 `stakes` 看心态 |
| 凶牌只讲负面 | 加重恐惧 | 讲转化面 |
| 危机信号下照常抽牌 | 安全优先 | `cross-system-hub` C5 |
| stakes 三个位置只复述原话、不用牌义 | 牌义被掏空 | 牌义一个词 + 原话一个细节 |
