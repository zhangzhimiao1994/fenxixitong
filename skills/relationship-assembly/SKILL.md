# Relationship Assembly

## R - 原文

## I - 方法论骨架

《周易》下经以咸恒开篇，专门讨论情感联结和持久关系的结构。这条线迄今未被已有 skill 充分覆盖。

**咸卦**：感应的逐步深入。咸其拇（脚趾—最初接触）→咸其腓（小腿—开始移动但危险）→咸其股（大腿—跟随但被动）→咸其脢（背脊—最深的感知，无悔）→咸其辅颊舌（口舌—表达）。这是一条从浅到深的感应链。"憧憧往来，朋从尔思"：真正让人跟随的不是指令，是你的所思所想。

**恒卦**：持久的反直觉。恒不是死守——"浚恒"（过度深求恒久）反而凶，"振恒"（震荡摇摆）也凶。"不恒其德，或承之羞"：不守恒会有羞耻后果。核心智慧：恒久的反面不是不变，而是不偏——既不能"浚"（用力过度），也不能"振"（忽左忽右）。

**家人卦**：家庭的秩序。关键区分是"家人嗃嗃"（严厉但有秩序，悔厉吉）vs"妇子嘻嘻"（松散欢乐，终吝）。前者短期不愉快但长期有利，后者短期开心但终将有吝。九五"王假有家"——王者回到家中，不用忧虑——这是家作为后盾的最高状态。

**睽卦**：分裂与误解。睽不是完全断裂，是小分歧。核心智慧："小事吉"——分裂时只做小事，不推大事。"丧马勿逐，自复"——丢失的东西不追，自己会回来。"见恶人，无咎"——必要时见不喜欢的人也可以。上九极度分裂的戏剧性描写（见猪滚泥、鬼车、先弓后放），但结论是"匪寇婚媾，往遇雨则吉"——你以为的敌人可能是来联姻的。

**萃卦**：聚集的规则。聚集有风险：初六"有孚不终，乃乱乃萃"——信任不持久，聚集就会变乱。聚集有方法：六二"引吉"——引导而非强制。九五"萃有位，匪孚"——有位置但缺信任，要用"元永贞"来补救。

**兑卦**：愉悦与互动。六种兑：和兑（和谐互动，吉）、孚兑（有信任的互动，吉）、来兑（讨好逢迎，凶）、商兑（有摩擦的协商）、孚于剥（信任被侵蚀，有厉）、引兑（引导互动）。核心区别：主动真诚的互动是吉的，被动逢迎或信任被侵蚀是危险的。

这个 skill 帮用户处理六类关系问题：
1. 情感联结的深度（咸）
2. 持久关系的维护（恒）
3. 家庭/团队秩序（家人）
4. 分裂后的修复（睽）
5. 群体的聚合（萃）
6. 日常互动的质量（兑）

## A1 - 书中的应用

### 案例 1：咸卦的感应深浅

- 问题：一段关系（感情/合作）不知道到了什么深度。
- 文本动作：六个爻从拇到舌，逐级深入。最浅只是接触，最深处（脢/背脊）是无声的感知。到了舌（口舌表达）反而是末端的。
- 方法论：真正深度的关系不在说多少话，而在不在你走路的时候感到对方的重量（咸其腓），不在你心里的人走来走去（憧憧往来），在看朋是否"从尔思"。
- 结果：现实中评估合作/感情深度，不问"他说了什么"，问"他有没有无声地知道你需要什么"。

### 案例 2：恒卦的持久悖论

- 问题：想维持一段关系但越用力越糟。
- 文本动作："浚恒，贞凶"——想去深挖恒久，反而凶。恒不是挖出来的，是自然流出来的。
- 方法论：维持长久关系不是靠加大投入、频繁确认、过度在意。恒之德是"不太用力地持续"。九三警告"不恒其德，或承之羞"——如果不维持基本的稳定，会有羞耻。但初六警告"浚恒"——用力过度第一个就凶。
- 结果：现实中关系的长期维护是在"不管就散"和"管太多就炸"之间找平衡。

### 案例 3：家人的秩序 vs 欢乐

- 问题：组织/家庭里该严还是该松。
- 文本动作："家人嗃嗃，悔厉吉"——家人之间有严厉、有摩擦、有不舒服，但有秩序，吉。"妇子嘻嘻，终吝"——全家嘻嘻哈哈没规矩，最后会有损失。
- 方法论：好的家庭/团队不是不吵架，是有秩序地吵。"闲有家"——家有屏障和规则，悔恨就不会发生。富家的路径是：先立规则（初九）→再分工（六二）→不怕严厉（九三）→自然富足（六四）→王者回归（九五）→有威有孚（上九）。
- 结果：现实中管理团队或家庭，先把规则讲清楚（嗃嗃），欢乐（嘻嘻）自然会有。反过来先追求嘻嘻，终吝。

### 案例 4：睽卦的分裂修复

- 问题：已经分裂了怎么办。
- 文本动作："丧马勿逐，自复"——不要追着丢失的马跑。"见恶人，无咎"——该见的人还是要见。"匪寇婚媾"——你以为对方是敌人，可能是过来联合的。
- 方法论：分裂后的修复三部曲：不追（停止扩大裂痕）、接触（该见面的见面）、反转解读（重新定义对方不是敌人）。
- 结果：现实中团队分裂、朋友翻脸、合作关系破裂时，先停下来不追责，再小范围接触，最后看看是不是误解了对方的意图。

### 案例 5：萃卦的聚集风险

- 问题：想把一群人聚合起来做事。
- 文本动作："有孚不终，乃乱乃萃"——信任不能维持，聚集就会乱。"引吉"——引导而非强制。"萃有位，匪孚"——光有位置没有信任不行。
- 方法论：聚集的第一步不是喊人，是建孚。没有信任的聚集叫"乱乃萃"。有了信任，小仪式（"孚乃利用禴"——简单祭祀）就够了。
- 结果：现实中组团队、建社群、拉合作，先问信任基础，再谈规模。

## A2 - 触发场景

### 用户会在什么情境下需要这个 skill?

1. 感情关系中的深度判断和持久性评估。
2. 长期合作关系是否该继续、怎么维护。
3. 家庭或团队内部的秩序与规则建立。
4. 关系/团队已经分裂，需要修复。
5. 想要把人聚起来做事但不知道怎么聚。
6. 日常人际互动中判断什么是有效互动。

### 语言信号

- "这段感情能不能长久"
- "我们之间到底到什么程度了"
- "越用力维护关系越糟糕"
- "家里/团队该严管还是该宽松"
- "已经闹翻了还能修复吗"
- "怎么把人聚起来"
- "咸卦/恒卦/家人/睽/萃/兑怎么用"

### 与相邻 skill 的区别

- 与 `conflict-coalition-diagnosis` 的区别：前者处理争端、动员、联盟（讼/师/比/同人），本 skill 处理情感联结、持久合作、家庭秩序、分裂修复、聚合（咸/恒/家人/睽/萃/兑）。
- 与 `repair-renewal-cycle` 的区别：前者处理制度和系统的修复，本 skill 处理关系的修复。
- 与 `advance-retreat-boundary` 的区别：本 skill 先诊断关系状态，后者给行动边界。

## E - 可执行步骤

1. **识别关系结构**
   - 完成标准：标注当前问题是感应深度（咸）、持久性（恒）、秩序（家人）、分裂（睽）、聚合（萃）、互动质量（兑）中的哪种。
2. **提取核心张力**
   - 完成标准：写出关系的核心矛盾——例如"太近会窒息，太远会散""太严压抑，太松失控""想聚但缺信任"。
   🔴 **CHECKPOINT**：在进入下一步之前，将分析结果展示给用户，等待确认后再继续。

3. **匹配方法**
   🛑 **STOP**：请确认上一步的分析结果后再继续。

   - 完成标准：
     - 咸：标注当前感应深度（拇/腓/股/脢/舌），如果不到九四（朋从尔思）说明还需深入
     - 恒：检查是否"浚恒"（用力过度）或"振恒"（摇摆不定）
     - 家人：建议先"闲有家"（立规则）还是先调整嗃嗃/嘻嘻比重
     - 睽：走不追→接触→反转解读三步
     - 萃：检查"孚"是否到位再谈聚集
     - 兑：识别当前互动是哪种兑（和/孚/来/商/孚于剥/引）
4. **给出最小一步**
   - 完成标准：接下来 24 小时内可以做的、能改变关系质量的最小动作。

## B - 边界

### 不要在以下情况使用

- 用户问题涉及纯组织架构、制度设计、业务流程（应使用 repair-renewal-cycle）。
- 用户需要法律上的婚姻/家庭/合同纠纷建议。
- 用户只是情绪倾诉，不需要框架分析。
- 涉及第三方隐私严重不足，无法形成有效判断。

### 失败模式

- 用卦象替代真实对话——关系问题最终要回到真实互动，不是分析完就完。
- 把所有困难关系都判睽（分裂），忽略咸的渐进和恒的维护。
- 家人卦的"嗃嗃"被理解成鼓励高压管理，忽略了它最终会通向"富家"和"王假有家"。
- 萃卦过度强调"孚"导致永远不敢聚人。

### 来源边界

本 skill 依据咸、恒、家人、睽、萃、兑六卦经文，不延伸到后世婚恋家庭理论或心理学。

### Fallback（if-then 三段式）

| 触发条件 | 一线修复 | 仍失败 → 兜底 |
|---------|---------|-------------|
| 把所有关系问题都判为睽（分裂），吓得用户觉得必须彻底决裂 | 回撤：睽只是"小事吉"——有分歧但不是什么都不能做。先确认：这真的是睽（分裂），还是恒的不稳定期，还是咸的感应还没到？ | 如果用户仍坚持判睽 → 做"最小接触测试"：24小时内发一条不涉及争议的普通消息。对方正常回应 → 不是睽，是恒波动 |
| 家人卦的"嗃嗃"被用户当成鼓励持续高压管理 | 纠正：嗃嗃的终点不是一直嗃嗃。家人卦路径：立规则（嗃嗃）→ 富家 → 王假有家 → 有孚威如。嗃嗃是起点不是终点 | 如果用户认为"不嗃嗃就乱" → 检查是否已进入"富家"阶段（资源到位后嗃嗃应自然减少）。仍坚持 → 建议设定"嗃嗃退出条件"：团队/家庭连续 3 次自主遵守规则后，减少主动管控 |
| 萃卦围绕"孚"做了太多分析，用户觉得永远聚不起来 | 简化：孚不是全有全无。小范围、明确共同目标、短期的聚集不需要完美的孚。从"二簋可用享"级别开始 | 如果用户连最小范围都推不动 → 不是孚的问题，是共同目标不明确。回到：这群人到底要一起做什么？目标都没共识，孚无从谈起 |
| 恒卦的判断让用户认为"不变"是唯一答案 | 纠正：恒是"不偏"不是"不变"。浚恒（过度求恒）本身就是凶。可以微调方向、调整力度，但不要大转弯也不要不转弯 | 如果用户陷入"到底变不变"的死循环 → 用恒卦六五："恒其德，贞，妇人吉，夫子凶"——不同角色对恒的要求不同。问：在你的角色里，什么算"恒"？ |
| 咸卦分析只停留在"深度"判断，不给具体互动建议 | 咸卦不是让你评级，是让你行动。从当前感应层级（拇/腓/股/脢/舌）出发，给一个升级动作 | 如果用户说"已经到舌了还要怎样" → 咸到舌（口舌表达）是最表层。真正深度在脢（背脊）——无声的感知。问：有没有他不说你也能感知到的事？ |
| 关系分析做完用户不行动 | 关系问题的本质不是"理解"而是"互动"。每次分析结束必须给一个 24 小时内可执行的互动动作 | 如果用户说"我不敢" → 这不是周易范畴。用 response-action 的履卦做行动风险评估 |
