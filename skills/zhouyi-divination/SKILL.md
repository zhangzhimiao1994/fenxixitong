# Zhouyi Divination — 周易起卦

## R — 来源（《周易本义》部分已对照原文，2026-10-02）
- 《蒙》卦辞："初筮告，再三渎，渎则不告。" → 一事一占 ✅
- 《系辞上》第九章（朱熹本）："大衍之数五十，其用四十有九" → 蓍草法原型；具体揲法见朱熹《筮仪》（附《周易本义》后）。本 skill 以三钱法代之——《本义》《筮仪》均只载蓍草法，不涉钱法 ✅
- 《系辞上》第二章："君子居则观其象而玩其辞，动则观其变而玩其占" → 占是为了"观变"，不是为了"知命" ✅
- 命名同《本义》乾初九注："阳数九为老，七为少，老变而少不变"；《筮仪》以过揲 36/32/28/24 定老阳/少阴/少阳/老阴 ✅
- 变爻取辞：《筮仪》末云"卦变别有图说见启蒙"，完整规则在《易学启蒙·考变占》（**未取得原文，转述**）。其中"一爻变读该爻"（乾初九注）与"乾坤六爻皆变读用九/用六"（用九、用六注）两条，《本义》有明文 ✅

## I — 方法论骨架

### 1. 三钱法
- 三枚硬币掷 6 次，**自下而上**成卦；背（阳）=3、字（阴）=2
- 和为 6 老阴（变）、7 少阳、8 少阴、9 老阳（变）
- 老阴变阳、老阳变阴 → 得之卦
- 工具：`python tools/divine.py iching`（OS 级随机，含本卦/变爻/之卦）

### 2. 变爻取辞规则（朱熹《易学启蒙·考变占》；1 变、6 变（乾坤）两行另见《周易本义》，其余各行待对照《启蒙》原文）
| 变爻数 | 读什么 |
|:-----:|-------|
| 0 | 本卦卦辞 |
| 1 | 本卦该变爻爻辞 |
| 2 | 本卦两变爻爻辞，以**上面**一爻为主 |
| 3 | 本卦卦辞与之卦卦辞，本卦为主（贞）、之卦为辅（悔） |
| 4 | 之卦两**不变**爻爻辞，以**下面**一爻为主 |
| 5 | 之卦唯一不变爻爻辞 |
| 6 | 乾坤读"用九/用六"，其余读之卦卦辞 |

### 3. 读卦三层
1. **本卦 = 现在的局面**（交给 `hexagram-situation-diagnosis` 做处境归类）
2. **变爻 = 局面中正在变化的那个点**（交给 `line-position-timing` 定位阶段）
3. **之卦 = 如果按当前趋势发展，局面会转向哪里**（不是必然结果）

吉凶词汇统一经 `auspicious-risk-language` 翻译（"凶"= 高风险，"无咎"= 可以做但需要谨慎，"悔"= 会后悔需修正）

## A1 — 应用案例
- 问："要不要接下这个跨城市的新工作？"
- 起卦：本卦"需"（坎上乾下），九三变，之卦"节"
- 取辞：1 个变爻 → 读需卦九三："需于泥，致寇至。"
- 解读：需 = 等待时机的局面；九三 = 已经走到泥泞处，再等下去会招来麻烦；之卦节 = 局面会转向"需要设边界、量力而行"
- 输出："这一卦呈现的不是'去或不去'，而是'等待已经到了临界点'。如果决定，宜设清楚边界（试用期、退路）。"→ 交给 `advance-retreat-boundary`

## A2 — 触发场景
- ✅ "帮我就要不要换工作起一卦""我刚摇到地雷复，九二变"
- ✅ 运势维度：用户不愿提供出生信息但想"看看最近运势" → 改问"最近最在意的一件事是什么"，就那件事起卦
- ❌ "起卦看我一辈子的命"（→ 周易占的是事，不是命）
- ❌ "刚才那卦不好，再起一次"（→ 再三渎）

## E — 执行步骤
1. **定问题**：一件具体的事 + 用户的选项（问题改写规则同 `tarot-draw-protocol`）
2. **高风险过滤**：医疗、法律、投资、人身安全 → 不起卦
3. **起卦**：用户自己掷硬币报 6 个数，或运行工具；**禁止模型编造卦象**
4. **列卦**：本卦、变爻、之卦（原样展示）
5. **取辞**：按变爻规则确定要读的辞，引用原文（短引）
6. **读卦三层** → 调用诊断类 skill
7. **语言转换**：经 `auspicious-risk-language`
8. **落地**：1 个最小行动 + "这一卦不替你做决定"

## B — 边界与 Fallback
| 情况 | 处理 |
|------|------|
| 同一问题要求重起 | 拒绝，引"再三渎"；问"你希望得到什么卦？" |
| 得到"凶"辞，用户恐慌 | 讲清"凶"是对**某种做法**的风险提示，指出该卦的出路（每卦都有"利"面） |
| 用户追问"到底成不成" | "卦呈现的是态势与条件，不是是/否。条件是 X，你能做的是 Y" |
| 用户熟悉纳甲六爻、要求六亲断法 | 说明本 skill 不含京房纳甲体系，仅做义理解读 |
- 三钱法为后世简法，概率分布与蓍草法不同（蓍草法老阴概率更低），需要时可说明
