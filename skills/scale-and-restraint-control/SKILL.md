# Scale And Restraint Control

## R — 原文引用

### 大小尺度判断
> 小过：亨，利贞。可小事，不可大事。飞鸟遗之音，不宜上宜下，大吉。（第六十二卦）
> 小过·九三：弗过防之，从或戕之，凶。 — 不设防会受伤
> 小过·上六：弗遇过之，飞鸟离之，凶，是谓灾眚。 — 飞太高了回不来
> 大过：栋桡，利有攸往，亨。（第二十八卦）
> 大过·九三：栋桡，凶。 — 栋梁弯了，有危险
> 大过·九四：栋隆，吉。有它吝。 — 栋梁隆起来了，好，但有其他麻烦
> 大过·上六：过涉灭顶，凶，无咎。 — 涉水过头了，但无咎（尽力了）

### 蓄积与释放
> 小畜：亨。密云不雨，自我西郊。（第九卦）
> 小畜·九三：舆说辐，夫妻反目。 — 积蓄期的内部摩擦
> 小畜·六四：有孚，血去惕出，无咎。 — 有信任，危险就过去了
> 小畜·上九：既雨既处，尚德载，妇贞厉。月几望，君子征凶。 — 快到满月时行动危险
> 大畜：利贞，不家食吉，利涉大川。（第二十六卦）
> 大畜·初九：有厉利已。 — 有危险就该停下
> 大畜·六四：童牛之牿，元吉。 — 从小牛就给角上装防护
> 大畜·六五：豶豕之牙，吉。 — 阉猪的獠牙不会伤人
> 大畜·上九：何天之衢，亨。 — 积蓄足够后走上通天大道

### 资源配置与调整
> 损：有孚，元吉，无咎，可贞，利有攸往。曷之用，二簋可用享。（第四十一卦）
> 损·初九：已事遄往，无咎，酌损之。 — 做完事快走，适当减损
> 损·九二：利贞，征凶，弗损益之。 — 守正有利，攻击凶，不损不益
> 损·六三：三人行，则损一人。一人行，则得其友。 — 三人太多减一个，一人太少会有朋友来
> 损·上九：弗损益之，无咎，贞吉，利有攸往，得臣无家。 — 不损反增
> 益：利有攸往，利涉大川。（第四十二卦）
> 益·初九：利用为大作，元吉，无咎。 — 增益期可以做大事
> 益·上九：莫益之，或击之，立心勿恒，凶。 — 没人给予反而被攻击，心不坚定则凶

### 节制
> 节：亨。苦节不可贞。（第六十卦）
> 节·初九：不出户庭，无咎。 — 不出门就没有问题
> 节·九二：不出门庭，凶。 — 该出门时不出门反而危险
> 节·九五：甘节，吉，往有尚。 — 舒服的节制，推进有成效
> 节·上六：苦节，贞凶，悔亡。 — 痛苦的节制，最后悔会消失

### 其他尺度相关
> 颐：贞吉。观颐，自求口实。（第二十七卦） — 看别人怎么吃/养，自己找食
> 颐·初九：舍尔灵龟，观我朵颐，凶。 — 放弃自己的灵龟看别人动嘴
> 坎·九二：坎有险，求小得。（第二十九卦） — 危险中只求小收获
> 坤·六三：含章可贞，或从王事，无成有终。（第二卦） — 有才华但含而不露
> 屯·九五：屯其膏，小贞吉，大贞凶。（第三卦） — 小施舍吉，大施舍凶

## I — 方法论骨架

《周易》不断区分大小、蓄积、过度、损益和节制。核心张力是：**目标规模和承载能力是否匹配**。

**尺度判断框架**：

| 维度 | 过小的问题 | 合适 | 过大的问题 |
|------|-----------|------|-----------|
| 行动规模 | 该做的大事缩成小事 | 小过：可小事不可大事 | 大过：栋桡（结构承压） |
| 资源蓄积 | 还没蓄够就释放 | 大畜：利涉大川 | 小畜：密云不雨（蓄而未发） |
| 资源调配 | 该给不给 | 损/益适度配置 | 该减不减 / 该增不增 |
| 节制程度 | 该出不出（不出门庭凶） | 甘节 | 苦节（过度节制） |

**关键洞察**：
1. **小过不是不能做**，是只能做小事。定义清楚大小分界线。
2. **大过不是继续努力就行**，是结构问题。不加固结构再努力也没用。
3. **损不是纯减**，"三人行损一人"是因为冗余；"一人行得其友"是吸引聚合。损的智慧是去冗余而增效。
4. **节制有两面**：甘节（舒服的节制）是好事，苦节（痛苦的节制）不可持续。

## A1 — 源文件应用案例

### 案例 1：小过 — 不是完全不做
- **文本**："可小事，不可大事。飞鸟遗之音，不宜上宜下。"
- **解读**：飞鸟留下叫声，告诉后面的人不要往上飞（危险）、应该往下（安全）。
- **应用**：条件不足时，把大承诺降为小试点。MVP、局部修复、试运行——这些都是"小事"。

### 案例 2：大过 — 栋桡不是努力不够
- **文本**："栋桡。"
- **解读**：栋梁弯曲了。这不是"再加一把劲"能解决的，是结构本身出了问题。
- **应用**：组织/资金/系统容量过载时，不是加人/加钱/加时的问题。是减负或者改结构的问题。

### 案例 3：小畜 — 蓄而未发
- **文本**："密云不雨，自我西郊。"
- **解读**：乌云密布但还没下雨。积蓄已经完成但释放时机未到。
- **应用**：准备够了但还没到行动窗口时，继续蓄力等待西风（正确的时机和方向）。

### 案例 4：损 — 减的智慧
- **文本**："三人行，则损一人。一人行，则得其友。""曷之用，二簋可用享。"
- **解读**：三个人一起走，减一个效率更高；一个人走，反而会有朋友来加入。祭祀用两个簋就够了——精简不等于不足。
- **应用**：团队/流程/产品线太冗余时，减掉多余的反而更好。但精简不是为了少而少（二簋刚好，不是零簋）。

### 案例 5：节 — 节制有度
- **文本**："苦节不可贞。""不出户庭，无咎。""不出门庭，凶。"
- **解读**：苦节（痛苦的节制）不可持续；刚开始节制不出门是好的；但永远不出门就变成了退缩和自我封闭。
- **应用**：任何节制都要问——这是甘节（舒适可持续的），还是苦节（痛苦不可持续的）？同时注意节制的阶段：初九该收就收，九二该放就放。

## A2 — 触发场景

### 适合触发
1. 用户想判断做小试点还是大投入。
2. 用户担心目标太大、资源太少、承诺太满。
3. 用户处理预算、团队、产品范围、学习计划、改革规模。
4. 用户读到小过、大过、小畜、大畜、损、益、节、颐。

### 不适合触发
1. 用户只问是否该行动，不涉及规模。
2. 用户要精确财务预算但没有数据。
3. 用户要求用周易替代项目管理。

## E — 执行步骤

### 模板：尺度匹配诊断表

| 检查项 | 你的回答（选项） | → 自动判定 |
|--------|---------------|-----------|
| 你要做的事规模多大？ | 小事/试点 / 中等/标准 / 大事/大投入 / 涉大川/巨变 | → 目标等级 |
| 你手里有多少资源？ | 时间：[充裕/刚好/不够] | 资金：[充裕/刚好/不够] | 团队：[充裕/刚好/不够] |
| 信任储备够吗？（相关方信任你吗？） | 有信任积累 / 信任不足 / 完全没有 | → 决定是「大畜」（够）还是「小畜」（蓄而未发） |
| 制度/流程/结构能承载吗？ | 能承载 / 勉强 / 结构已变形 | 结构变形→大过（栋桡），不是加力能解决 |
| 存在冗余可减吗？（人/流程/产品线） | 明显冗余 / 刚刚好 / 已有不足 | 冗余→损（去冗余增效）；不足→益（增补） |
| 当前的压力/推进速度感觉如何？ | 轻松愉快 / 正常适中 / 痛苦难熬 | 痛苦难熬→苦节，不可持续，需放松 |

**推导规则**：第 1 项 vs 第 2-4 项 → 判断尺度错配类型（小过/大过/小畜/大畜）；第 5 项 → 判断损益方向；第 6 项 → 判断甘节/苦节。

### 步骤

1. **填表诊断**：输出 `尺度判定：[小过/大过/匹配] | 蓄积：[小畜/大畜/正常] | 损益：[损/益/不需要] | 节制：[甘节/苦节/正常]`
2. **标出分界线**：如果不匹配，明确写出「小事分界线」——在此线以下可做，以上不可做。
   🔴 **CHECKPOINT**：展示诊断+分界线，等待确认。
3. **输出调整方案**：给出具体动作——
   - 目标过大 → 缩小到 `[具体范围]`
   - 结构承压 → 减负或改结构（不是加人加钱）
   - 需蓄积 → 等 `[具体条件]` 发生
   - 有冗余 → 砍 `[具体项目/人/流程]`
4. **设定复查信号**：输出 `复查：[N天后] | 信号：[Y发生→可升级规模] | 警戒：[Z发生→必须缩小]`
   🛑 **STOP**：输出完整方案前确认上一步。

## B — 边界与 Fallback

### 反例黑名单（不做什么，什么情况下这个 skill 不灵）

| # | 反例模式 | 为什么危险 | 正确姿势 |
|---|---------|-----------|---------|
| 1 | **小过被理解为完全不做** | 「可小事不可大事」≠ 完全停止 → 错过小范围行动窗口 | 小事/大事分界线要明确。在小事范围内自由行动。问：在现有条件下，最小的可执行动作是什么？ |
| 2 | **大过被理解为再努力一点** | 栋桡（结构弯曲）≠ 努力不够 → 加码加速崩溃 | 大过 = 结构本身承载不了。策略是减负或改结构，不是加力。问：去掉什么比加上什么更重要？ |
| 3 | **只看资源数量忽略信任和制度** | 只看钱/人/时间 → 忽略信任储备和制度韧性 | 加入两个额外维度：信任储备（大家信这个系统吗？）+ 制度韧性（碰到冲击不散架吗？）。三位一体评估 |
| 4 | **苦节当甘节** | 痛苦的节制不可以持续 → 但用户以为是常态 | 区分甘节（舒适可持续）和苦节（痛苦不可持续）。苦节必须设退出时间表。问：「这个节制 3 个月后你还能接受吗？」 |
| 5 | **阶段错位：初九和九二搞反** | 该收的时候放（不出户庭→凶），该放的时候收（不出门庭→凶） | 节制的阶段判断：初九（初期限缩）= 该收就收。九二（过了初期）= 该放就放。阶段判定错误 = 方向错误 |

### 失败模式
- 把"小过"说成完全不做。
- 把"大过"说成继续努力即可。
- 只看资源多少，不看信任和制度承载。

### Fallback（if-then 三段式）

| 触发条件 | 一线修复 | 仍失败 → 兜底 |
|---------|---------|-------------|
| "小过"被理解为"完全不做" | 纠正：小过是"小事可以，大事不可"。和用户一起定义小事/大事的分界线，小事范围内自由行动 | 用户分不清小事大事 → 给默认分界线：影响范围≤你自己=小事；影响到他人或系统=大事 |
| "大过"被理解为"再努力一点" | 纠正：大过不是努力不够，是"结构本身承载不了当下负荷"。要减负或者改结构，不是加力 | 用户坚持"我再努力试试" → 不阻止，但设硬性安全阀："如果 X 指标恶化到 Y，你必须立刻停止加力" |
| 只看资源数量忽略信任和制度 | 加入两个额外维度：信任储备（大家信这个系统吗？）和制度韧性（碰到冲击能不散架吗？） | 用户说"我没时间算这些" → 只给最简版："按直觉，1-10 分，信任几分？韧性几分？"低于 3 分的维度就是最大风险 |
| "苦节"当"甘节"——痛苦的节制被当常态 | 区分甘节（舒适可持续）和苦节（痛苦不可持续）。苦节必须设退出时间表 | 用户说"我习惯了痛苦" → 问"3 个月后你还能接受吗？不能的话，现在就需要开始找替代方案" |
| 初九（该收）和九二（该放）阶段搞反 | 节制的阶段判断：初九=该收就收；九二=过了初期该放就放。方向搞错全盘皆错 | 分不清初九还是九二 → 默认按初九处理（保守），设回顾日"X 天后确认是否进入九二阶段" |
| 蓄积（小畜/大畜）被当成"囤更多就对了" | 小畜=积累到一定量要释放；大畜=囤到能支撑系统大动作。不是无限囤积 | 用户说"我还想再攒攒" → 问："你攒够什么标准就够？"如果标准的答案是一个模糊数字 → 没想清楚，需要先定义 |

### 来源边界
依据经文中的大小、蓄积、损益和节制结构，不延伸到完整预算模型。
